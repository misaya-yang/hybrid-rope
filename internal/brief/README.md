# EVQ-Cosh Briefs

This directory contains standalone PDF briefs that summarize the current EVQ-Cosh story in a readable, non-submission format.

## Files

- `evq_cosh_core_brief.tex`: English source
- `evq_cosh_core_brief.pdf`: compiled English PDF
- `evq_cosh_core_brief_zh.tex`: Chinese source built around the historical
  `paper_draft/CORE_THEORY.md` and an external author-held rigorous-theory source
- `evq_cosh_core_brief_zh.pdf`: compiled Chinese PDF

## Scope

Both briefs focus on:

1. the core thesis,
2. the variational theory and its closed-form solution,
3. the strongest experimental evidence,
4. the current interpretation and next open questions.
