# 从 MrPro 的构造解释 BM 的收益与代价

2026-09-08，独立分析任务。已读论文、现有结果及失败复盘，并做 CPU 精确分数和实际 FP32 数组复算；没有启动 GPU、改动执行任务代码或重跑基线。本文不是新方法已胜出的报告。

用户规则：从有依据的构造出发做零训练验证，复用已有可比 MrPro baseline；胜出后换模型、换任务，没有基线的模型/任务补跑一次并存档。允许有依据的快速实验与理论分析并行。研究目标不是永久限定于 BM。

## 1. MrPro 的可解释动机与未证明部分

[MrRoPE 原文](https://arxiv.org/html/2601.22181v1) 的构造重点是保持较快通道的原有位置关系，并在较慢通道完成扩展。中段 radix 增量采用等差递增，是设计假设，不是从任务损失推得的唯一最优解。对于中段宽度 N、边界后第 q 槽，

\[
\epsilon_i^{M}=\frac{2i}{N(N+1)},\qquad
m_q^{M}=\sum_{i=1}^{q}\epsilon_i^{M}
=\frac{q(q+1)}{N(N+1)},\qquad
\nu_q=\omega_q S^{-m_q}.
\]

相对于同边界 MrUni 的 m_q=q/N，MrPro 每个内部槽的累计压缩更小，且越靠前越保守；终点仍 m_N=1。因此“渐进”真正做的是延后累计压缩，而非仅使曲线外观平滑。

这提供了直接的零训练设计动机：改变已经学过的位置关系有代价，扩展所需的改变应尽量避免过早累积。其有效性仍需真实生成验证；单槽已转过一圈不证明整组相位与内容的联合分布被训练覆盖。

## 2. BM 做了超出修边界的改变

现有 BM 的精确累计指数为

\[
m_q^{B}=\frac{q(q+1)(3N+2-2q)}{N(N+1)(N+2)},
\quad
m_q^{B}-m_q^{M}
=\frac{2q(q+1)(N-q)}{N(N+1)(N+2)}>0
\quad(0<q<N).
\]

这不是浮点或示意曲线效应：BM 每个内部中频槽都比 MrPro 更慢。精确分数复算在 N=2..100 成立；当前 N=17/18 的实际数组方向也一致。

进一步，排除两个固定端点后，

\[
\sum_{q=1}^{N-1}m_q^{M}=\frac{N-1}{3},\qquad
\sum_{q=1}^{N-1}m_q^{B}=\frac{N-1}{2}.
\]

即总累计压缩指数增加 50%。其含义是各槽相对 Native 频率比的负对数之和增加；它不是能力预算或损失的充分统计量。BM 的该总量恰与同边界 MrUni 相同，但两者分配不同。

Qwen N=17：第一项增量由 1/153 增至 1/57，是原来的 2.684 倍；末项由 1/9 减至 1/57。原来的末端负担被向前搬移。

| --- | ---: | ---: | ---: |
| 24 | 0.9910 | 0.9760 | 1.51% |
| 28 | 0.8729 | 0.7352 | 15.77% |
| 32 | 0.6652 | 0.4719 | 29.06% |
| 34 | 0.5499 | 0.3769 | 31.46% |

## 3. 边界不平滑为何没有自动构成模型缺陷

BM 最小化相邻 radix 增量的一阶差分平方。该数学问题的唯一解没有争议，但它引入了“相邻频率槽的间距变化应平滑”这一额外偏好。实际 RoPE 各槽与不同的内容投影相乘；注意力计算不直接对槽索引求导，没有由间距跳变本身产生的算子奇点。

终点恒等式 m_(N−1)=1−epsilon_N 说明：减小最后增量，必然增加最后一个内部槽的累计压缩。但让**全部**内部槽更压缩，是 BM 的全段对称优化选择，并非修末端边界必须支付的代价。

因此最初“找到 MrPro 边界缺口”的强说法应收紧为：发现一个几何不平滑处，构造了一种有代价的重分配。尚未证明原边界是性能瓶颈，也没有证明平滑收益超过提前压缩的损失。

已有 OLMo BM16K51.32%、MrPro2.78%、MrUni32.12% 的同输入复核必须保留。它同时说明更多压缩并非普遍有害、总压缩量也不能独自解释胜负。见 [OLMo 结果](ROPE_OLMO_BM_RESULT_20260908.md)。

## 4. 3B128K 当前能解释到哪一层

[3B 配对结果](ROPE_BM_TRANSFER_RESULT_20260908.md) 的长端差值是−7.29个百分点：多键−25、QA−25、多查询+6.25，其余任务均值相同，六任务等权。VT/FWE内部各有正负行相抵。不是所有任务都在128K同时崩溃。

两条已知反例给出的更强信息是：

- 精简背景、保留原128K位置后，BM可恢复。
- 保留原长背景形成的KV，晚期只筛可见集合不能完全恢复。
- MrPro来源前缀用BM读取仍保持这两例的正确/召回；BM来源前缀换MrPro读取仍失败。

来源：[背景/可见性诊断](ROPE_BM_128K_DIAGNOSIS_20260908.md)、[交叉缓存诊断](ROPE_BM_CROSS_CACHE_20260908.md)。VT召回100%且达到30-token预算但无EOS，不能称完整字符串加EOS正确。

理论上，后层 pre-RoPE K/V 依赖前层 attention 写入的 hidden state；换频不仅改变最后查询与key之间的相位，也改变整个预填充过程中的状态形成。当前最有根据的工作解释是：BM额外的全中段压缩改变了这些内容—位置关系，在这批密集背景下产生的状态代价超过了部分任务收益。此解释符合上述干预，但还没有识别具体槽、K或V、某个层组以及可量化的任务效用方向。

“128K相位本身不可用”“仅靠末端换读表即可恢复”不符合这两例；“BM必定破坏局部绑定”“softmax分母是唯一原因”也尚未被识别。

## 5. 当前一个有明确构造依据的快速候选，以及身份核查

执行任务提出如下候选供独立审查：继承 MrPro 最大增量
c=2/(N+1)，保留非负增量、总和1及原外频/gain，在每步不超过 c 的条件下尽量延后压缩。

对任意可行表，剩余 N−q 步最多提供 (N−q)c，因此

\[
m_q\ge\max\{0,1-(N-q)c\}.
\]

各个下界可以同时达到：

\[
m_q^*=\max\{0,1-(N-q)c\}
=\operatorname{clip}\!\left(
\frac{q-(N-1)/2}{(N+1)/2},0,1\right).
\]

这是该约束族唯一逐坐标最小的累计压缩表。无需猜幂次、层界或搜索系数；每个频率与Native的标量差不大于MrPro。该可行域的cap来自MrPro，并不是已测得的模型安全阈值。

**精确身份：** 它就是缩窄过渡区的 MrUni。Qwen N17时，从q8（零基槽31）开始，到槽40结束，九个增量均1/9；OLMo N18时，等效起点为零基槽22.5、终点32，第一非零增量为1/19，其余为2/19。不能把这称为全新的RoPE算子或未曾存在的函数族；潜在贡献只能落在有依据的分区选择规则及真实收益上。当前检索的本地owner未发现这一精确配置的已完成负结果，未完成全历史/外部新颖性检索。

**最强竞争解释：** MrPro 的渐进压缩可能本来就在保护中频的长距联合关系。将较快中频完全恢复Native可能恢复部分绑定，也可能失去MrPro原本提供的长距收益。OLMo上更强压缩BM已获益，本身就反驳“越接近Native越强”的普遍说法。此候选应作当前Qwen问题的一次有目的验证，而不是跨模型保证。

**两项非空泛的限制：**

1. Qwen中其间距粗糙度是MrPro的1.8889倍：最大单项gap没有增大，但大增量进入点变突然，不能说所有谱结构扰动都更小。
2. 单槽连续距离最坏旋转差的界虽不更坏，在128K上槽32–39的新旧界均已饱和于2，不能用它预测这些槽的任务方向。具体整数lag18765、槽32，MrPro相对Native的旋转误差约0.0001622，候选约1.946698；这是周期性导致的反例，不是模型损失或候选已失败。

该候选现在有清楚的构造与可证伪问题，值得考虑一次快速零训练验证；不将“数学下界取到”写成“生成最优”。已有MrPro基线直接复用，若取得真实收益，再按用户规则换模型、换任务。若未取得收益，不通过扫描cap继续救同一解释。

## 6. 关于 MrPro 强度与 YaRN 的边界

MrRoPE原文Qwen3B完整RULER从32K78.5降至128K53.2；同128K YaRN50.1。因此MrPro有可见退化，不是已解决128K，更不能把本地六任务78.12%与论文全13任务53.2%直接比较。

[Qwen3技术报告](https://arxiv.org/html/2505.09388v1) 记载长上下文训练及YaRN/DCA等配方。[官方模型说明](https://huggingface.co/Qwen/Qwen3-32B)验证了YaRN扩展配置。产品采用某配方不构成所有零训练换表方法的受控排名。超过MrPro值得研究，但应凭相同条件下的结果建立，而非由厂商采用YaRN推出必然性。
