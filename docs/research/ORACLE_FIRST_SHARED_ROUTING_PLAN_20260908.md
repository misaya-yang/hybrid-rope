## 1. 论文最核心的一句话问题

**在共享 KV 选块的原生稀疏注意力中，最大化各 query head 的总 attention mass，是否会系统性地漏掉区分“哪个事件、哪一次状态”的少数必要读取路径；能否在同样读取预算下恢复完整关系答案？**

核心不是证明 RoPE 有缺陷，而是检验：位置关系已经存在于原生模型的可用计算中，却在多头合成一个稀疏读取集合时被丢掉。是否发生、是否由此造成答案错误、是否能低成本修复，均需实验回答。

它与“某个 head 的 mass 低”不同。必要路径必须通过 mask 干预恢复答案、再撤去同一路径重现错误来定义，不能按 attention 大小或 frequency 标签预先命名。

## 4. 从实际计算得到的理论与因果链

### 4.1 固定接口

在一个 KV group 的一个 query 上，h 表示 query head，b 是互不重叠的物理 KV 块。以真实 reader 的全部合法 key 计算：

\[
p_{hb}=\frac{\sum_{j\in b}\exp(q_h^\top R(p_j-p_q)k_j/\sqrt d)}{\sum_{j\in \mathrm{legal}}\exp(q_h^\top R(p_j-p_q)k_j/\sqrt d)}.
\]

partial RoPE 的未旋转通道照原生实现保留；NoPE reader 则使用其真实分数。此处不能对已有 pre-RoPE Q/K 宣称它们没有上游位置信息。

L 是固定必读的 sink、local 和当前合法尾部块，S 是额外选择的远端块，二者不重叠。定义

\[
r_h(S)=\sum_{b\in L\cup S}p_{hb},\qquad |S|=K.
\]

COBS 的精确加性 mass 选择优化 \(\sum_h r_h(S)\)，其论文明确说明 GQA 下是对读取误差目标的放松。不是完整生成的最优 oracle。InfLLM 的窗口均值、跨头求和、max-pool 又是另一种估计和聚合，不能当作完全相同公式。

### 4.2 严格结论：平均保留率不能控制最差 head

若 H−1 个 head 的 r 接近 1，一个 head 接近 0，平均值仍接近 1−1/H。准确的有限H界是 \(\min_h r_h\ge\max(0,H\bar r-H+1)\)，该界可达；因此平均保留率只有高到超过1−1/H时才排除完全漏掉一个head，不能笼统说平均值永远不给界。这个接口结论不证明真实模型依赖那个head，也不给最终答案保证。

对每个 head 的 token 分布 p_h，把其限制并重新归一化到 L∪S 得到 p_h^S，则严格有

\[
\operatorname{TV}(p_h^S,p_h)=1-r_h(S),\qquad
D_{KL}(p_h^S\Vert p_h)=-\log r_h(S).
\]

正向 KL 一般为无穷，不能写反方向。设

\[
J(S)=-\sum_h\log r_h(S),
\]

则 \(\max_h\operatorname{TV}(p_h^S,p_h)\le 1-e^{-J(S)}\)。这给出一个同时约束所有 head 的分布失真量；它可能保守，并且仍不是语言能力指标。

若某 head 的 value 集合直径是 D_h，则固定 Q/K/V 下

\[
o_h=r_h o_{h,S}+(1-r_h)o_{h,\bar S},\qquad
\|o_h-o_{h,S}\|\le (1-r_h)D_h.
\]

高 TV 也可能对应相同 values 或被输出投影消掉，故不能从上式推出实际 logit 或答案损失。整个生成链还经过 W_O、残差、后续层、后续 KV 状态与 greedy 决策；这些路径都必须保持合法并实际重放。只在额外有有效的全计算图扰动界和逐 token margin 时，才能给完整生成不变性证明，当前不声称已有这种可用证书。

### 4.3 已检查的有限反例，绝非神经实验

16 个 head、4 个候选远端块、预算 K=2。前15个 head 各有 local=.01、公共内容块=.80、冗余块约=.19；第16个 head 有 local=.01、关系块=.90、尾部块约=.09，其余使用 1e−8 正概率并相应调整，所有行归一。

枚举所有两块集合：加性目标选择公共块＋冗余块，平均保留 **.938125**，最差 head **.01000002**；最大化 log 覆盖选择公共块＋关系块，平均保留降至 **.816250**，最差 head升至 **.81000001**。greedy 在此例取得同样集合。

CPU FP64 检查 reverse-KL 恒等式最大误差 4.44e−16，并枚举所有子集确认 diminishing returns。这只验证有限分布中的严格反例与实现计算；它没有训练模型、没有真实 Q/K，也没有回答或 EOS 结果。

**独立反证本方案的过度解释（22:35 UTC追加）：** 固定上面的全部Q/K概率、两个候选集合和同一个“各head输出相加”的W_O，仅改变共享V。若只有关系块的V=1、其它V=0，则dense输出=.90000015，加性选择=0，log覆盖=.98901116；若只有冗余块的V=1，则dense=2.84999971，加性=2.85000076，log覆盖=0。两种情形用同一个0.5阈值读出，哪个选择正确完全反转。CPU已直接计算验证。这是抽象共享KV读取反例，不是实际checkpoint或语言任务结果。

因此，**改善最差head覆盖本身也可能只是proxy，log覆盖不能仅靠更好的覆盖界取得方法资格。** 必须在相同真实V/W_O/后续网络下，经完整答案干预证明需要保留的路径确实重要；不能把原来“平均mass→能力”的跳跃换成“最差headmass→能力”。

### 4.4 唯一待检验的机制假设

真实的位置关系任务中，少数 head／层需要读取与其他 head 不同的事件实例；共享加性选择会在预算竞争中漏掉这些块。其后果应为：来源事实单独查询可答，但关系查询失败；补回这些合法块并替换等量其他块后，完整关系答案恢复。

如果只是总体质量差、格式不服从、证据已在 hidden state 中冗余保存、完整读取本来就不会作答，或者其它层补偿了缺失路径，该预测不会成立。不能通过增加 attention 统计把失败说成成功。

## 5. 方法前的 oracle causal test

### 起点和有效预算

只使用已经下载并校验的 **MiniCPM4.1-8B**。本地回执显示 dense_natural_02 已完成24题、175.604秒，峰值约21.4GB；这是旧模板、约9K–17.5K的运行回执，不是32K新任务吞吐保证。

原生配置为32层、32 query heads、2 KV heads，即每group16头；B=64，local=2048，sink保留，官方配置 topk64 还内部加入32个local块。实际总集合大小按原生mask逐行核验，**不能错误地再给干预臂加64个远端块**。

问题到来前的文档缓存使用原生稀疏路径，且不包含问题。各干预从第一个问题 token 起应用，继续到终止；所有臂复制同一前缀状态，不注入 dense hidden states、不输入参考答案、不增大可读块数。prefix QA 是明确部署场景，不把这项实验称为完整 sparse-prefill 加速。

### 冻结数据与顺序

用64个独立文档／日志家庭，每个含两种改变正确答案的合法事件顺序，共128个输入；16K或32K长度按实际输入前瞻冻结。实体、事件值、查询实体、marker位置随机化，查询在完整事件流之后确定，排除“总取marker邻居／首次值／全局最后值”等捷径。每个家庭另有内容查询控制。

先用独立的8–12个短开发例一次性验证 prompt 和完整字符串＋EOS 可执行，修正若必要只改明确的模板问题并留记录。不能在同一holdout上反复修提示词直到分数漂亮。旧24题多数答案有解释段，不能拿其F1主导的小幅差异继续筛方法。

按下面依赖顺序运行，后面的臂不在前一判断失败时自动展开：

1. **原生 sparse 与 dense 可解性参照。** dense只提供能力上限参照，其内部状态不移植给任何稀疏臂。报告全部预先冻结例子的表现，另分析 dense正确／sparse错误子集，不把该条件子集当总体benchmark。
2. **证据位置 oracle。** 使用生成器或独立标注的全部必要证据块E，仅将E强制纳入，并按原生分数移出同数非必读块；其余保持原生规则。E中的竞争记录和顺序标记一起保留，避免只暴露正确答案所在块。E若放不进固定预算，标记该例不适用，不能偷偷放宽。这个oracle使用特权证据位置，是可实现修复量的见证，不是最优支持集上界。
3. **特异性反事实，只对需要识别的开发失败配对运行。** 用同数量、近似同距离的错误记录块替代E；对已恢复轨迹从开始重新运行并撤去关键E块。若错证据同样恢复，或移除关键块不影响答案，不能把结果归因于该证据路径。
4. **仅在2–3通过后区分目标与估计。** 在同一原生缓存和物理预算上比较精确原始Q/K的加性mass选择与精确分布下的log联合覆盖选择；这两个都读取全部key作oracle计算，仍只把选中的原生K/V交给reader。不能声称此阶段节省了key读取或已经可部署。

第2步必须先建立最终答案恢复。第4步中，若精确加性mass已经恢复几乎所有可恢复错误，本方案关于“加性共享目标是瓶颈”的主张被否定；不能继续做新的coverage方法，只能保留已有方法能解决该批失败的事实。

如果证据oracle在原生稀疏prefix上无效，仅在换成dense-prefix后才有效，那么decode侧selector修复不足，本方案停止。至多使用必要的小量交叉回放区分状态形成问题，不开启另一条prefix修复队列。

## 6. 只有上述因果证据通过，才实现的最小方法

保持原生频率、Q/K/V、reader、local/sink、KV物理布局和训练权重，**只替换共享集合的选择目标**：

\[
\max_{|S|=K} F(S)=\sum_h\log\left(\widehat\lambda_h+\sum_{b\in S}\widehat p_{hb}\right),\qquad \widehat\lambda_h=\sum_{b\in L}\widehat p_{hb}.
\]

这里必读质量 \(\widehat\lambda_h\) 也由同一个归一化估计器计算，不能重复计入L。使用开发阶段冻结的最强可缓存估计器，所有目标对照共享完全相同的估计分数。不是给本方法精确key、给对手粗均值。

greedy每步加入具有最大增益的块：

\[
\Delta_b=\sum_h\log\left(1+\frac{\widehat p_{hb}}{\widehat\lambda_h+\sum_{c\in S}\widehat p_{hc}}\right).
\]

真实softmax与非空必读集保证数学上正概率；数值实现用log域处理下溢，不把任意epsilon当可扫超参数。固定非负分数下，F−F(空集)是单调次模函数，标准greedy给该**估计目标的增量**1−1/e保证。不是最差head最优解，也不是生成准确率保证，更不是新的次模定理。

注意这不是对每个块先求各head概率乘积再top-k；后者偏好所有头共同关注的单块，与覆盖互补证据不同。

额外计算为选块阶段的O(KHB)标量增益评估，可能有严重串行和kernel-launch开销。若融合实现不能在同延迟／总读取成本下胜出，就失败；不以零新增参数掩盖成本。第一版不增加gate、head权重、学习模块或频率扫描。估计分数无法实现oracle收益时，记录近似失效并停止，不再换摘要无限追。

## 7. Hero result：一个主实验及预算

**要交付的图：在原生窗口内，完整关系答案＋EOS和自然任务正确率对实测端到端成本的曲线；本方法用相同预算恢复被共享路由丢失的关系答案，并在相同质量下需要更少总成本。**

- 主模型MiniCPM4.1-8B。只有主效应出现后，使用已有Qwen3.5-0.8B做异构迁移：仅其full-attention层接同样共享selector，GDN保持原生。明确标为稀疏转换，不冒充Qwen3.8/QSA原生实验；若该模型任务资格不够，不下载新模型凑覆盖，跨架构主张仍未完成。
- 确认集：256个独立双世界关系家庭，另512个自然长文问题。开发与确认按原始文档隔离；自然数据优先HotpotQA/Qasper的可核对证据，再加入需要事件更新／先后关系的自然任务材料。不得仅凭样本总数把半合成实验升级为自然能力证据。
- 主对照：原生selector、开发阶段选定并冻结的最强适用外部方法、共享相同分数估计器的加性目标、本方法，dense作能力参照。开发先比较Quest、完整Prism/COBS估计器移植和适用的FASA/coverage方法；不阉割关键校准／协方差。标清estimator port与作者整套系统不同。只有最强对照进入主确认以节省成本，其余必要消融随后补。
- 主指标：双世界都完整答对且EOS的pair accuracy；自然题整段答案的盲审正确性与终止，保留raw输出，整段exact/F1单独报告。不要取首数字、首行或substring。若采用标准benchmark scorer，报告其定义且不能把它称为严格exact。推理题允许解释时，判完整答案是否正确且自洽，而不按长短加分。

## 9. 成功后的统一论文故事：四项核心结果

1. **真实且可修复的失效。** 原生模型能够解题，共享稀疏支持丢掉决定事件实例的路径；同预算的证据介入恢复完整答案，错证据／回退不能保留收益。
2. **机制与可反驳的理论。** 精确加性mass仍可能保住平均量却漏掉必要head；给出严格分布分离、读出误差条件及与真实反例一致的预测。标准KL／次模工具归为推导工具，不能作为新颖性本身。
3. **最小修复的真实收益。** 同估计器只改共享支持选择，恢复oracle中明确可恢复的那批答案，并超过强已有selector的质量—成本位置。
4. **有边界的迁移。** 在已有混合模型上检验同一失效和修复，说明适用的是共享支持与关系计算的接口；不把V4压缩value、Kimi无显式PE或Qwen终止差异都收入未经验证的解释。

严格reviewer值得在意的结果应是：**已经会做关系推理的模型，不必改权重或增加KV读取，就能避免一种可复现的稀疏化能力损失；证据同时指出现有优化目标为什么在此失效、为何简单替换奏效以及系统上节省了什么。** 若拿不到这组三者一致的结果，这套方案没有达到要求。
