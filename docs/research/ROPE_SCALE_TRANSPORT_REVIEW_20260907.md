## 1. 判断：可用的候选构造，不是新的总纲

Pro 比此前泛泛的“通用最优”讨论前进了一步：先测各频率在不同距离上的局部输出响应，再把响应距离增长转换成频率缩放。它给出了可计算输入、构造、失败情形，值得纳入研究。

但研究主线仍是 **MrRoPE 强基线 + CoPE 的深尾稳定机制 + 本方分配改进**。这份文档没有真正覆盖 CoPE 方向，且又增加了对手微调。不能因文档来自 Pro 就恢复已经撤销的安排，也不应把尚未集成的校准器当成已准备好的方法。

本轮推荐：用其统计驱动候选替代原计划中手设的尾部 `/2` 候选，保持 CoPE 组合为另一方向。主表先最多五张：Native、YaRN、MrPro、MrPro+CoPE-style tail、一个尺度驱动候选。中段/尾部来源消融和过渡只在候选有实际增益后追加。该候选若不能形成可靠输入，就维持前三个参考和 CoPE 比较，不为了维持五张表而强行产出结果。

这减少待比较的候选表，不意味着降低总成本：模型 hook、校准前向与缓存重放都有额外开销，必须先测实际开销再决定是否值得投入。

## 2. 值得吸收的三个部分

### 2.1 用增长率代替机械的尾段倍率

在可比的关系距离随长度增长 s^β 的条件下，保持对应相位得到 ν=ωs^(−β)。若 β=1/2，s=4 时是 `/2`；若 β=1，才是 `/4`。这解释原计划尾部放松对照的物理含义，但没有事先假定真实尾频一定属于 β<1。

Pro 用两档响应距离的分位函数 Q_a、Q_b，求

\[
r=\operatorname{clip}_{[1/a,1]}
\frac{\int Q_aQ_b}{\int Q_b^2},\qquad
\beta=-\log r/\log a.
\]

在分母正且分布确有相应尺度意义时，它是所写二次目标的解。比再挑一条曲线具体，也可以产生非均匀的中段增量。尺度匹配原则已有先行工作，真正待验证的增量是**这组模型统计能否给出更有用的逐槽决策**。[Wu 等 §4](https://arxiv.org/html/2607.07678v1)

### 2.2 响应量包含 V 和输出投影

\[
\partial y/\partial\phi_{ij}
=p_i a_{ij}W_{O,h}(v_i-o).
\]

这是固定该层输入和其他相位后的局部导数。它比单看 attention mass 更接近注意力模块的输出变化；但“变化大”不等于“对正确答案有益”。不同 key 的真实换频相位变化是共同耦合的，独立噪声平方和也不等于完整频率干预的效果。Pro 已承认这些限制，不能把它们误写成作者遗漏的代数错误。

独立检查采用显式旋转 q 后计算 softmax/值聚合，与该导数做中心有限差分，最大绝对差 `6.62e-12`。这里只核对一个非退化单头算例，未核验真实模型 hook、QK norm、GQA、全层传播或附带程序。

### 2.3 保留对“干扰解除”的检查

某频率可能通过负 logit 压低无关 key。它在源窗口 attention mass 很小，恰好可能因为抑制有效；不能据此说它不重要。Pro 的完整 sin/cos 重放和跨文档 key 检查瞄准了这个问题。[LeRoPE §7](https://arxiv.org/html/2607.10134v1)

保留这类诊断，但区分：跨文档 key 是人为声明的干扰分布；经验 log-mean-exp 不是实际长文本错误率或认证上界；固定 Native hidden states 的重放不包含深层状态改变。其五点 λ 规则只能生成一个待测候选，不能取代最终生成/Native 验证。λ=0 就返回 MrPro，不为相同表重跑。

## 3. 新发现：增长率可能来自观察窗口，而非关系被拉伸

Pro 的 H_{j,L}(d) 随可见窗口截断，再归一化为 P_{j,L}。因此窗口变大、更多远距离进入统计，本身就能产生近似尺度增长。

**解析反例（针对识别能力，不否定实际模型）：** 设一个始终不变的距离响应核 H(d)=1，仅观察 0<d<L。则 P_L=Uniform(0,L)，分位函数 Q_L(u)=Lu。于是 Q_{2L}=2Q_L，Pro 的估计精确返回 β=1，形状残差为零。1K→2K 的估计还能完美预测 2K→4K。

这里没有任何内容关系从距离 d 搬到 2d；只是同一个平坦响应核露出了更大范围。如果真实任务确需新增可见关系，更宽的有效响应可以有用，但**这个统计本身不能区分“关系拉伸”“新增覆盖”和“背景响应”**。因此不能由预测成功单独认定逐槽缩放获得了因果依据。该例也不是证明统一 PI 必然不对。

离散 token 距离 d=1,…,L 的精确分位数积分给出：

| 固定平坦核，只有可见窗口改变 | β | 相对形状平方残差 |
| --- | --- | --- |
| 1024→2048 | 0.99947215 | 2.23e−7 |
| 2048→4096 | 0.99973596 | 5.59e−8 |

用第一行 β 预测第二个长度步，相对 W2² 误差仍仅 `3.57e−7`。这是标准库独立计算，无模型、无拟合曲线。离散积分可直接复算：令长窗槽位 k=1,…,2N，则同一分位区间内 Q_a=ceil(k/2)、Q_b=k，以质量 1/(2N) 求交叉乘积及二阶矩，再代入 §2.1。

**最小补充控制：** 保留 Pro 的独立文档/长度预测；同时在缓存中固定同一长窗源 Q/K/V，逐级截断 visible keys，重新计算完整 softmax、o 和响应，测出仅可见集合/归一化改变能解释多少增长。再与真实嵌套上下文前向比较，并单列共有距离范围内的响应变化。这个控制用于分解测量来源，不用含目标输出的统计回拟合 β，也不是用未来信息增强的预测基线。

若候选的主要依据在这个控制下都能由裁切解释，就把 β 视作覆盖统计；不能让其“预测通过”启动大训练。仍可直接测已定义好的 Mr/CoPE 有限比较，无需等待新的大一统理论。

## 4. 与当前路线的明确冲突及处理

| Pro 内容 | 当前处理 | 理由 |
| --- | --- | --- |
| 频率限制 ω/s≤ν≤ω，β∈[0,1] | 保留为“相位放松”候选的定义，同时单独保留 Mr+CoPE | CoPE 有 ν<ω/s 甚至 ν=0，这个可行域无法产生它；不把扩大区间自动称为统一方法 |
| OLMo 主体、E1 16K 主终点 | 首个效果基线继续用 Qwen2.5-3B-Instruct；OLMo 可作实现检查资产 | 不继续让接近全零的旧终点决定新方法价值；Qwen 是 Mr 原论文模型 |
| 新方法 vs MrPro/YaRN 同预算 LoRA | 不采纳当前执行安排 | 作者已明确对手保持冻结，适配只属于本方；因此也不声称获得了相同适配预算下的纯频率优势 |
| 建议不再投入旧 Z full | 记录为外部建议，不改变已有任务 | 本轮是研究评议，当前执行授权由作者和 HANDOFF 管理；不凭外部建议停作业 |
| warmup 后一次自举分配用于 scratch | 保留为后续可检验实现思路 | 可以解决无成熟 teacher 的输入问题，但 warmup 响应稳定性、物理训练窗口与部署倍率尚未验证 |
| 允许等频、消融允许槽位频率交叉 | 数学上可以，当前运行代码不支持 | `check_table` 要求严格正且严格降序；不能静默排序、加 epsilon 或修改正在使用的冻结代码 |

MrRoPE Appendix B.1 已实测两条边界变化，也给出 Qwen 的 (23,40) 默认选择。因此“首次考虑三个频段的边界”不是可用的创新点；我们的目标应是更有效的分配依据和最终性能。[MrRoPE Appendix B.1](https://arxiv.org/html/2601.22181v1)

## 5. 在现有计划里怎样落地

1. **强基线先成立。** Qwen Native/YaRN/MrPro，固定 s=4；实现、模板、评分和有效控制清楚后再比较候选。保持 CoPE 的代码定义，零尾项属于显式操作。
2. **尺度统计只做一版。** 校准使用 Native 内相对长度、独立构造/检查文档，加入上一节的裁切控制；不扫响应定义、领域权重和许多阈值。高频保持 Mr 的频率，将新统计先用于中低频，冻结这个范围。这是基于 Pro 的受限候选，不冒称其全槽原版。
3. **生成一张候选，而非另一套大搜索。** 有效统计给出 β，经保槽位顺序的约束处理；若沿用 Pro 五点重放，保留每点记录和 REFERENCE_ONLY 状态。分区接口、零响应槽位的回退和相同频率必须有明确实现约定。未完成这些步骤前只叫 proposal，不能用计划文字代替数组。
4. **只增加一个统计驱动效果臂。** 它替代手设 `/2` 的 T↑，不再同时先做 Z 中段和 Hermite 桥接。与 Mr+CoPE 比较稳定/放松方向，最终仍由成对 Native 与长任务输出决定。
5. **有效之后才拆解和适配。** 若联合候选获益，追加仅中段/仅尾段以解释来源。仅在连接处有明确问题时再做一次过渡比较。自己的同表轻适配及 scratch 跟在有效候选后；保留三阶段目标，不给对手自动排训练。

**成本修正：** Pro 的 229376 输入 tokens 对应 OLMo 的 1K/2K/4K 和 32 文档。Qwen 若采用对应的 8K/16K/32K，名义量是 `32×(8192+16384+32768)=1835008`，还不含再次重放前向、实际模板与控制。不能把 OLMo 的 token 量当 Qwen 校准成本，更不能换算成未经测量的小时数。先流式处理选定查询，不物化全 L×L attention。

**决策边界：** 若校准成本或 hook 开发明显压过一次有限基线比较的价值，可先完成 Mr+CoPE 的直接比较，统计臂保持未运行；不能为了等待校准器而阻塞所有实际方法比较。若尺度统计无法形成新表，报告具体失败点，不扩大搜索救它。
