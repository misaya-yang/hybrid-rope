## 作者想法与需要你判断的问题

MrRoPE 参考 YaRN 的三段划分：高频保持，中段改变，低频统一除以扩展倍率 s。我们怀疑尾段可能减慢过多，而两个区域边界与中段没有共同优化，可能错过更好的频率使用方式。

精确地说：

\[
\omega'_j=\omega_j/\prod_{d<j}\lambda_d=\omega_js^{-m_j}.
\]

高频 m=0，低频 m=1，中频从 0 到 1。低频不是统一改 base；gain 也可能影响频率未变的高频贡献。MrPro 的离散中段累计位移为 t(t+1)/[n(n+1)]，MrUni 为 t/n，其中 t 是从高频边界开始的截断边数。

“低频多一些旋转”至少有三种含义：尾段不全部除以 s；在固定 K 内给目标尺度安排更多有效槽位；重新设计中频到两端的过渡。请判断哪个有机制依据，必要时否定我们的直觉。若 ω'_j=ω_j s^(-ρ)，目标窗口上的旋转圈数相对训练窗口放大 s^(1-ρ)，必须同时解释分辨率收益和相位暴露/权重兼容性代价。

我们希望解决的是频率分配，而不是简单把 ramp 换成 smoothstep。离散频率的曲线更光滑并不自动改善能力，更多旋转也不自动意味着更多有效信息。不要把既有 YaRN/MrRoPE 已包含的机制重新命名。

## 已知项目现状

1. 当前论文以 x=-log ω=a+Rz、固定 support、完整 sin/cos 几何、Cosh 变分构造和跨阶段实验为主。MrRoPE 的累计 radix 与 log 位移可互相转换；分解和固定端点本身已不足以承担主要 novelty。
2. 旧 151.9M 主实验 K=32、训练长度 256、每臂约 500M tokens，三 seeds；Cosh 改内部频率后，固定 support 的 OOD NLL 改善，但 ID 有代价，目标匹配 support 又反转。作者明确不回到 Cosh 水床式调参。这些是特定协议现象，不是“所有频率方法必然水床”的定理。
3. 现有成熟候选 Z 并非 Cosh。它使用 legacy uniqueness 得到 m=(1-normalized_U)^2，部署为 ω'=ω·4^(-m)，OLMo gain=1+0.074 ln 4。p2、log action 和 gain 经历史选择，不能宣称无搜索或理论预先推出；legacy least-squares cutoff 也不能当成天然常数。
4. 可用成熟主模型是 OLMo-2-0425-1B-Instruct（实际约 1.485B，原窗口 4K，K=64），另有 Qwen2.5-1.5B-Instruct。已有 151.9M Geo/Cosh 的 seeds 137/256 checkpoint。历史 seed42 结果保留，不寻找权重、不重训。
5. 已有静态表评测、完整答案/EOS、Native 分项评测、teacher cache、full/LoRA 训练及成本探针代码。当前训练准备版交替使用 8K/16K CPT，若沿用它，16K 是本轮适配已见长度。纯 all-linear r16 与旧额外训练 norm/embedding 的配方不同。

## 最新结果：只作为开发诊断，不是 SOTA 比较

五个 frozen arms 使用相同 OLMo、模板、512 rows、固定 s4 部署表和各自声明的 gain。每个 single-evidence 组包含两个答案世界，必须都完整答对且 EOS：

| Arm | 2K compact，/32 组 | 16K near，/32 组 | 16K far，/32 组 |
| --- | ---: | ---: | ---: |
| Native | 27 | 0 | 0 |
| YaRN | 27 | 0 | 0 |
| MrUni | 26 | 3 | 1 |
| MrPro | 27 | 0 | 0 |
| Z | 26 | 6 | 1 |

所有方法在 16K double-evidence / binding 的 near/far 组成功都是 0/16；Native compact 相应为 2/16 和 8/16，deleted 原答案成功为 0。故部分任务 resolving power 很弱，不能据此宣布 MrRoPE 方法无效或 Z 已胜出。

Native 的 64-row instruction 完整答案+EOS：Native/YaRN/MrUni/MrPro/Z 为 20/13/15/13/17；reasoning 为 2/0/1/1/0，position-format 都是 13。64-row text 的 token-weighted NLL 为 2.7108/2.7958/2.7890/2.8021/2.7708；text 未生成答案。小 text NLL 变化不代表生成保持，reasoning 低基线也不足以衡量通用能力。

新 scratch overlays 已完成。2K 下 Cosh−Geo tail NLL，seeds 137/256：固定 s4 MrPro 为 −0.2175/−0.1810，按目标 s8 MrPro 则为 +0.2217/+0.2252。两种策略回答不同问题，不能任选一种宣称全面互补；这些是 32 个历史 anchors 的 NLL，无生成能力结论。
