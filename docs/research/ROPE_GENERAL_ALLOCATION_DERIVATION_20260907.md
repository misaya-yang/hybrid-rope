# 通用 RoPE 分配：本轮独立推导、CPU 检查与未闭合部分

> **研究路线已替换（2026-09-07）：** 作者要求从 MrRoPE、CoPE 与本方已有结果推进具体改进。本文件的通用定义、MGDA/语料校准不是当前方法方向，也不构成实验前置条件；数学与 CPU 检查仅作历史记录。当前计划见 [MrRoPE 基线上的频率研究](ROPE_FREQUENCY_UNIFIED_PLAN_20260907.md)。

- **日期 / 状态：** 2026-09-07；数学推导与 CPU 原型完成，真实模型算法集成、方法新颖性及 SOTA 收益未确立。
- **作者问题：** 不再围绕某种 retrieval 任务猜曲线；研究能覆盖一般语言建模用途、从零训练 / 适配 / 冻结部署的频率分配方法。
- **范围：** 本轮由当前助手直接推导和检查，未调用 Pro、未修改 Pro 提示词、未启动 GPU 或改变 Luna 训练计划。
- **证据：** [标准库 CPU 程序](../../scripts/analysis/verify_general_rope_allocation.py)、[结果 JSON](ROPE_GENERAL_ALLOCATION_CPU_20260907.json)；程序 SHA-256 `052daffee4cd5396cd228334d3f9056c868984ac5743dad42a4438bc5ed0d613`。
- **标签：** 下列命题是在显式假设下的 Derived results；数值是数学程序检查，不是语言模型效果。通用语料驱动的谱更新是可执行优化核心，不是已验证的全新 SOTA 方法。

## 1. 这轮采用的“通用”定义

同一规则适用于不同模型、内容域和长度，不使用某个 benchmark 的答案、不按题型另造曲线。允许使用模型自身的结构和通用文本统计，但校准成本必须明示。

这区别于“只输入 K、base、长度，就保证所有内容、模型和任务最优”。已有 [可识别性研究](../../paper-2027/research/foundations/ROPE_OPTIMALITY_IDENTIFIABILITY_AND_CONDITIONAL_EQUATIONS_20260903.md) 已限定后者，不能拿那个结论拒绝前者。本轮不重复证明这个分布无关的不可能结果。

## 2. 一个不能继续使用的简化模型

**命题：** 固定一个 query q，若每个 key 独立于 q、彼此独立，并且其分布对所用二维分块旋转不变，那么任意确定的 RoPE 频率表都产生相同的该行 logits 联合分布，因此 softmax 行分布也相同。

**证明：** 对每个 key 的确定性分块正交矩阵 R_j，有 R_j k_j 与 k_j 同分布。独立性保留其联合分布；固定 q 的内积映射和随后的 softmax 不改变这个分布等价关系。结束。

这不是说真实模型中频率无用。它说明这个独立、旋转对称的噪声模型把决定频率作用的内容相关性移除了：在该模型内不可能区分“更好的表”。真实 Q/K 相关、非各向同性或跨 token 结构不满足该前提；不能把此命题用于否定真实模型结果。

CPU 用独立圆周网格的相位置换验证，完整双 key 概率分布的最大差为 2.78e-16。去掉独立性，使用与 query 对齐的 key，改变相位即可使一个二元 softmax 概率从 0.7311 变为 0.2689。该检查只核对前提的重要性。

**实际含义：** 能解释一般模型的理论必须保留已学内容与频率的耦合；仅用均匀旋转、频率个数或覆盖程度建模，可能从起点就失去分配依据。

## 3. 真正从要求推出一个几何规则，然后在 CPU 阶段审查它

先不选曲线。对单个频率，提出两个一般性要求：原窗口的相同物理距离尽量保真；目标窗口的拉伸距离尽量对应原窗口位置。明确假设两类旋转误差等权、距离分别在各自窗口均匀分布、内容系数固定、gain 不变。这些是建模选择，不是自然语言定律。

二维旋转的平方 Frobenius 距离为 4(1−cos(δω·Δ))。因此两项平均误差除以 4 后，精确得到

\[
J_q(y)=2-\operatorname{sinc}(y-q)-\operatorname{sinc}(sy-q),
\quad q=\omega L_0,\ y=\omega'L_0,
\quad\operatorname{sinc}(u)=\sin(u)/u.
\]

第一项比较 ω' 与 ω；第二项比较 ω' 与 ω/s，目标窗口为 sL0。对 q→0、y=O(q)，

\[
J_q(y)=\frac{(y-q)^2+(sy-q)^2}{6}+O(q^4),
\qquad
\frac{\omega'}{\omega}\longrightarrow\frac{s+1}{s^2+1}.
\]

这是求导得到的结果，没有预先选择 Cosh、二次或 sigmoid。s=4 时比例是 5/17≈0.29412，比 PI 的 0.25 少压缩一些尾频。但它只是这个明确几何模型的慢相位极限。

**有限相位检查没有支持把它直接变成通用方案。** q 增大后 sinc 目标有振荡和多个极小区。对 OLMo 的 K=64、base=500000、L0=4096 几何参数，逐频率的 2001 点区间网格最小值产生 11 处输出频率次序交叉。网格搜索不是连续全局最优证书，排序约束也可能改变解；这里不声称整个问题无解。

关键不足是：这个目标仍只比较旋转函数，没有内容符号、softmax 竞争与整网输出。它接近项目以前已经发现局限的 coverage / displacement 路线。不能因为推出了漂亮的 5/17，就把它作为新候选交给 GPU；本轮不采用它作为模型分配规则，也不以平滑、排序修补后宣称问题已解决。

## 4. 不按任务造曲线：用通用语言模型目标给出实际分配更新

这里给出一个比“未知 utility + argmin”更具体的优化核心，同时承认它属于需校准的方法。

### 4.1 可获得的输入

- 原始模型 W 与实际频率 Ω；初始可行表，例如 Native。
- 提前固定的通用文本校准集合，包含多个领域及长度区间；与最终 benchmark 文档隔离。
- 每个集合都采用同一种自监督目标：真实下一个 token 的平均负对数似然。无人工 retrieval 答案、无每题频率表。
- 原生窗口各集合的允许损失增量；这个容差是工程要求，不伪装成数学常数。

对域/长度单元 i 定义

\[
\ell_i(x,W)=-\frac1{N_i}\sum_t\log p_{W,\exp(-x)}(a_t\mid a_{<t}),
\quad x_j=-\log\omega_j.
\]

这直接定义了要计算的量。所有集合的 loss 都以每 token 的 nats 计，不靠任意 1/1/1 混合权重隐藏冲突。通用语料的覆盖与域权重仍影响外部适用性；有限校准集合不等于所有任务。

### 4.2 完整有符号频率梯度

对于固定局部内容系数的一个 rotary logit，

\[
s_j=c_j\cos(\omega_j\Delta)+d_j\sin(\omega_j\Delta),
\qquad
\partial_{x_j}s_j=\omega_j\Delta[c_j\sin(\omega_j\Delta)-d_j\cos(\omega_j\Delta)].
\]

将它与整网损失对每层 attention logit 的 adjoint 相乘并求和，得到 g_i=∇x ℓ_i。必须通过真实整网求导；不得拿 detached-Q/K 的局部差、Q/K 范数或 Gram rank 替代。这个梯度原理已有 [项目推导](../../paper-2027/research/foundations/ROPE_OPTIMALITY_IDENTIFIABILITY_AND_CONDITIONAL_EQUATIONS_20260903.md) 和 [LeRoPE](https://arxiv.org/html/2607.10134v1) 支持，不是本轮新发现。

### 4.3 分配更新由共同下降问题决定

对希望同时改善的若干通用域/长度 loss，求

\[
v^*=\arg\min_v\left\{\frac12\|v\|^2+\max_i g_i^\top v\right\}.
\]

其无约束解可由小问题得到：

\[
\lambda^*=\arg\min_{\lambda_i\ge0,\,\sum\lambda_i=1}
\frac12\left\|\sum_i\lambda_i g_i\right\|^2,
\qquad v^*=-\sum_i\lambda_i^*g_i.
\]

**分配规则就是**

\[
\boxed{x^{new}=x+\alpha v^*,\qquad
\omega_j^{new}=\omega_j\exp(-\alpha v_j^*).}
\]

没有预定三段、没有假定指数等差，也不事后拟合一个漂亮曲线。各频率可以有不同位移，选择取决于完整模型在通用文本上的响应。此处固定 gain；若扩展到 gain，需增加明确变量与相同校准制度，不能静默改变温度。

**共同下降保证：** 令 u*=Σλ*g 为凸包中最小范数点，最优性给出 (g_i−u*)ᵀu*≥0。因此 g_iᵀv*≤−||u*||²。当 u*≠0 时，对有限个可微 loss，足够小的步长会同时降低它们。u*=0 表示这些梯度没有严格共同的一阶下降方向，不是全局最优、全部方法不可行或整个频率空间无法改进。

这是经典 [MGDA](https://comptes-rendus.academie-sciences.fr/mathematique/articles/10.1016/j.crma.2012.03.014/) 的应用，求解器和上述结论不申报新颖性。CPU 原型报告 dual gap 与实际方向导数；未收敛不能被误报成不存在改进。

### 4.4 Native 保护与有限步接受条件

Native 作为真实的容差约束，而非要求所有短窗 loss 都严格下降：

\[
\ell_{N,d}(x^{new})\le\ell_{N,d}(x^0)+\varepsilon_d.
\]

通用长文本单元组成下降目标，Native 集合独立进行实际前向检查和回溯。Native 若严格有余量，连续性保证存在足够小的可行步；恰好在边界时没有这个自动保证，须使用可行方向约束或返回未找到可行步。不能只靠一阶 Native 条件宣称有限步保护。

有序频率也在回溯时直接检查。沿同一已算出的方向缩小 α，而不是试多个手造表。接受条件不成立就不接受更新；不给出“一定能走出每个局部冲突”的保证。

这个保证只保护声明的校准 NLL。它不是 EOS、格式或任务正确性的证书；独立生成评测仍决定能力主张。若坚持完全零数据、零梯度、零校准，则这一规则不满足该定义，不能冒充 MrRoPE 式无数据公式。

## 5. 三阶段怎样联系，以及尚未交付的部分

| 阶段 | 同一频率更新的用法 | 必须明确的限制 |
| --- | --- | --- |
| 冻结骨干部署 | 固定 W，只校准 K 个频率，最终部署一张静态表 | 无模型权重微调，但有频率学习/校准成本；不是完全零训练/零搜索 |
| 本方轻量适配 | 现有 adapter 更新与频率校准交替，频率步固定当时 W | 此局部下降不保证后续权重更新仍保留全部收益；MrRoPE/YaRN 保持冻结参考 |
| 从零训练 | 在当前 W 上校准频率，并继续标准权重训练 | 不是已证明的双层训练终点最优；若校准用了长文本，该长度已被训练过程看到 |

当前生产 evaluator 将频率作为冻结数组装入；CPU 原型并没有接好真实 LM 的可微 RoPE、通用多域数据或回溯执行。不能声称只运行这个脚本就会得到一个 OLMo SOTA 表。

严格无数据公式、学习机制对最终权重的影响、频率校准相对已有方法的增量，仍未闭合。给一个共享更新接口不等于三个阶段都已成功。

## 6. 本轮结果与文献边界

CPU 检查全部通过：旋转对称分布不变性；有限 sin/cos 二元 likelihood 的解析梯度与中心差分最大误差 3.61e-10；共同下降方向证书及有限步下降；反向梯度的零方向；两时钟目标的慢相位极限。结果中的 toy loss 和频率倍率只用于数学检查，不是任何真实模型的结果或待部署数组。

本轮还确认了两个直接的先行方向：

- [CoPE](https://arxiv.org/html/2602.05258v1) 已研究低频 soft clipping / 平滑过渡，不能把这几个关键词当成新的 novelty。
- [AdaRoPE](https://arxiv.org/html/2607.19363v1) 已研究 head-wise 频率与 attention scaling 的异质需求；泛泛引入 head 条件同样不足。

因此，这轮交付是：**排除一个没有分辨力的简化模型；推出并在 CPU 阶段限制一个几何目标；写出不预选曲线的通用语料频率更新核心及其明确保证。**没有得到可宣称优于 MrRoPE 的无数据闭式新方法，也没有证明新增优化组合具有足够论文创新。不能把这些数学检查包装成 SOTA；本轮不据此发起新的 GPU 候选试验。
