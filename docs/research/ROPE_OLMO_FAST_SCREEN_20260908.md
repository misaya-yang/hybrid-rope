# OLMo 混合 RULER 短评测

2026-09-08：替换旧自造任务。作者开机并授权自主运行后，本轮完整比较、独立复核、已有方法对照及后续实验均已完成；见[完整结果](ROPE_OLMO_BM_RESULT_20260908.md)。

## 问题与设计

在冻结 OLMo-2-0425-1B-Instruct 权重、相同输入与解码下，MrPro-BM 是否比 MrRoPE-Pro 改善长上下文任务？使用既有模型和完整候选数组，静态 s=4；不训练、不调整候选参数。

| 官方任务 | 覆盖能力 | 每条输出预算 |
| --- | --- | ---: |
| niah_single_2 | 文章背景中的精确检索 | 128 |
| niah_multikey_2 | 密集相似记录中的检索 | 128 |
| niah_multiquery | 一次回答多个检索目标 | 128 |
| vt | 四跳变量追踪 | 30 |
| fwe | 高频词聚合 | 50 |
| qa_1 | SQuAD 自然问答与干扰文档 | 32 |

每项 4K 两条、16K 四条，共 36 条。沿用 NVIDIA RULER 上游生成器、任务参数、模板及评分规则，套用模型聊天模板和官方回答前缀；seed=20260909。题目在模型运行前确定，不根据某个方法的输出挑题。所选任务覆盖四类能力，但不是完整 RULER，也不能代表全部长上下文能力。

保留官方输出预算并计入长度上限，不截断输入、不缩短回答来凑运行时间。使用 greedy、repetition_penalty=1、BF16、Flash SDPA，其他解码及模型身份保存在准备 manifest。

## 比较与解释

先跑一次 MrPro，再跑一次 BM，共 72 条生成；共享一次模型加载。同条件完整基线可复用。运行耗时由实际基线测量，没有自行设定的硬时限。

主指标是 16K 六任务等权平均分，4K 同口径另报。检索、追踪及聚合按官方多答案命中比例评分，QA 按任一有效参考答案命中评分。EOS、逐题得失、分项和运行成本另报，不改变主分。

前瞻假设：BM 的中段改动有可能提高 16K 任务表现，但增加压缩也可能损伤 4K。16K 提升且 4K 不降，记为开发收益；16K 提升而 4K 下降，记为取舍；16K 不提升，则本轮不支持该候选的长端收益。任一结果均不能证明平滑性的因果机制。

基线全零或满分的任务单独标记，仍保留原分数与比较；不因结果不利删题。若面板没有足够区分度，先记录本轮局限，再明确修订面板；修订后重新建立对应基线，不把旧分数混入新比较。

## GPU比较与后续判别

36条开发集完成：MrPro 4K/16K=37.2222%/14.9306%；BM=79.4444%/49.0278%，24胜1负11平。两臂生成耗时46.46/48.17秒，整个监督阶段104.08秒，未截断。

独立seed20260910复核每任务4K四条、16K八条；QA使用官方pre_samples=64避开原题号，共72条。MrPro 4K/16K=37.8472%/2.7778%；BM=81.8056%/51.3194%，44胜0负28平。QA跨长度仍共享问题，不视为双倍独立样本；多任务同模板和小样本限制仍在。该结果支持同OLMo冻结权重、静态4倍扩展下的真实局部收益，不能泛化为所有模型、完整RULER或SOTA。

新增[选择性gain实验](ROPE_BM_SELECTIVE_GAIN_20260908.md)两项均未超过BM，已保留负结果。下一步固定BM原公式与MrPro公式、相同gain，检验静态S8的4K/32K；不因尺度变化重调公式。新seed20260911，每任务4K四条/32K八条，QA从128起。主终点32K均分，4K另报；若长端双方地板或BM退化，只声明适用边界，不改变本轮评分或挑题。

同一复核集24条4K Native参照为75.625%，BM为81.8056%；BM的VT更高，但QA从Native100%降到75%，多查询从93.75%降到87.5%。因此当前结果不支持逐任务原生能力保持。已有方法对照MrUni及官方线性ramp YaRN已排在S8运行后，使用同一72条复核输入；MrUni与BM在中段累计exponent总和一致（浮点误差除外），用于区分简单压缩总量与分配形状。此对照不是新提出的方法，不用旧E1面板分数代替。

后续S8及尺度上限方案现已完成，32K未恢复有效检索/追踪；不再沿用此前排队/进行中的时间状态。最终完成状态和适用边界见完整结果报告与HANDOFF。
