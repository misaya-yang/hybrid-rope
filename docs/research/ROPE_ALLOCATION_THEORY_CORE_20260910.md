# RoPE 频率分配：理论核心与下一轮推导起点

日期：2026-09-10。性质：研究准备与材料整理，不是已完成的最优性证明或新方法胜利报告。

## 1. 本轮确认的研究问题

**把 RoPE 作为有限通道上的非均匀离散傅里叶表示来研究：是否存在最优频率分配，使 native／近距离计算的损失尽可能小，同时获得尽可能强的远距离表示、区分和使用能力？最优条件是什么，能否从中解释或推出已有分配规律，并得到更好的具体频率表？**

覆盖对象是频率分配本身，包括几何 RoPE、PI、NTK、YaRN、MrRoPE-Uni／Pro、EVQ，以及已有其他分配构造。EVQ 与 MrRoPE 是重要例子，不是框架的全部边界。

需要回答：

1. 高频的冗余在哪里，哪些冗余可用于重新分配而不损害必要的近距计算？
2. 中频为什么关键，其过渡结构由什么最优条件决定？
3. 低频需要多少资源，怎样同时获得长距离范围与有效区分能力？
4. 各尺度应分配多少通道、频谱位置或间隔？若使用搬运解释，资源从哪里到哪里、移动多少？
5. 能否给出可求解的最优性／KKT 条件、实际有限频率表和模型效果？

主流分段结构“高频保持、中频过渡、低频除以 S”是强经验参照和需要解释的现象。**搬运是可能采用的理论，水床不等式是可能揭示资源权衡的工具；二者都不预先等于问题本身。**

当前目标不预设必须测完整 Q/K 统计、取得监督标签、学习梯度或训练适配器。那些是本轮代理提出的可选机制与求解工具，已经归档，不作为下一轮开始推导的先决条件。

交付链条是：**分配规律 → 有限频率表 → 实际效果**。先保持问题准确，再判断采用何种数学工具。

## 2. 统一的有限频率对象

设 K 为 rotary pairs 数，正频率表为 ν=(ν₀,…,νₖ₋₁)。位置差 d 下的表示和旋转为

    Xν(d) = [cos(dν₀), sin(dν₀), …, cos(dνₖ₋₁), sin(dνₖ₋₁)]
    Rν(d) = diag(R(dν₀), …, R(dνₖ₋₁)).

这是连接非均匀傅里叶表示、近距分辨率和长距行为的共同对象。固定 Q/K 时，注意力分数具有带系数的有限傅里叶和形式；因此既可以先研究表示本身，也可以在验证阶段分析其如何被已训练权重使用。

为比较不同构造，使用对数频率坐标：

    xⱼ = −log νⱼ,
    aᵢ = xᵢ − xᵢ₋₁,
    A = xₖ₋₁ − x₀ = Σ aᵢ.

需要分别记账：K（通道数）、x₀（高频端）、A（频谱跨度）、内部间隔／位置、幅度 gain。固定端点意味着固定 A，不自动意味着固定累计压缩量。

对 native 表 ω，写 νⱼ=ωⱼ S^(−mⱼ)，则

    xⱼ = xⱼ(native) + mⱼ log S,
    aᵢ = aᵢ(native) + (mᵢ−mᵢ₋₁) log S.

在 m_l=0、m_h=1 时，新增间隔总量为 log S。Σm 是另一项控制量；可以为特定因果比较固定，但不能未经推导就当作所有分配问题的物理守恒量。

冻结部署需记住频率与原 rotary pair 的对应关系；从头训练允许权重适应分配。两种情形应放在同一频谱问题中比较，同时注明权重是否可变。

## 3. 已有方法究竟规定了什么

以下统一令 t=q/N，q=0,…,N，两个频率锚点相隔 N 个间隔。公式需与实际离散采样、边界取整和 gain 一起使用。

| 方法 | 频率／压缩规则 | 提供的内容 |
| --- | --- | --- |
| 几何 RoPE | xⱼ 等间隔 | 基础均匀对数频谱 |
| PI | νⱼ=ωⱼ/S | 所有时钟统一重标定；对数频谱整体平移 |
| NTK-aware | native 几何格上 mⱼ=j/(K−1) | 高频端保持、低频端达到 /S 的全谱过渡 |
| 标准代码 YaRN | νⱼ=ωⱼ(1−t+t/S) | 中段在频率比例上作索引线性混合 |
| MrRoPE-Uni | m_q=q/N | 中段对数缩放均匀累积 |
| MrRoPE-Pro | m_q=q(q+1)/[N(N+1)] | 等差对数 radix 增量产生二次累计压缩 |
| EVQ-Cosh | νⱼ=b^(−Qτ(uⱼ)) | 从密度的变分目标到分位数离散频率 |

MrPro 的二次形式来自等差增量假设；该事实不取消它的实际效果，也不等于已经证明该形式最优。已有强方法可以为下一轮提供结构线索，不必先有完整任务最优性理论。

### 新附件提供的重要比较事实

[用户提供的完整分析](rope_allocation_20260910/source_inputs/mrrope_yarn_user_analysis.md)已归档。已核查的原始 YaRN 和公开 MrRoPE 代码使用上述索引线性频率混合；公开 MrRoPE 构造函数调用 yarn()，圈数插值另在 yarn2()。公开分支与论文最终实验提交的对应仍未核定。

标准 YaRN 的 m_Y(t)=−log(1−t+t/S)/log S 也是凸的。不能把标准代码的对比概括成“YaRN 递减、MrPro 递增”；论文附录的圈数表达与索引表达需要区分。

固定 native 频率和中段边界时，令 ηⱼ=−∂logνⱼ/∂logS：

    η_Y(t,S) = t/[S(1−t)+t],
    η_M(q,S) = q(q+1)/[N(N+1)].

YaRN 严格中段的 η 随 S 增大趋零，MrPro 保持固定幂律响应。第一个过渡槽的频率扰动分别为 O(1/N) 和 O(1/N²)，这里固定 S。它们是可复用的结构事实，不单独推出任务胜负。

Qwen（N=17，S=4）中，MrPro 在槽24–37比 YaRN 更快，在38–39更慢；Llama3（N=17，S=16）对应19–24和25–34。比较包含两个方向，不能简化成中频全部更接近 native。

## 4. EVQ 已有的变分与水床工具

### 4.1 已明确目标下的 Cosh 解

现有纯 tether 泛函为

    J[ρ] = (α/2)∫ρ(φ)²dφ
         + (β/2)∬ρ(φ)ρ(ψ)min(φ,ψ)dφdψ,
    ρ≥0, ∫ρ=1, α>0, β≥0.

其驻点条件及正解为

    αρ(φ) + β∫min(φ,ψ)ρ(ψ)dψ + λ = 0,
    ρ'' − τ²ρ = 0,  ρ'(1)=0,  τ²=β/α,
    ρτ(φ) = τ cosh[τ(1−φ)]/sinhτ.

该泛函严格凸，归一化 Cosh 是此问题的唯一最优解。其分位数为

    Qτ(u) = 1 − asinh[(1−u)sinhτ]/τ.

τ→0 回到几何分配。u=j/K、u=(j+1/2)/K、端点归一化采样是不同有限表，不能混用。

等价的分位数导数 h(u)=Q'(u) 满足

    J[h] = (1/2)∫[α/h(u) + β(1−u)²h(u)]du,
    h>0, ∫h=1.

这条等价关系能直接连接密度、频率间隔和 KKT，是下一轮应优先复用的材料。[Sol02](rope_allocation_20260910/agents/sol02.md)、[6Pro 原文](rope_allocation_20260910/source_inputs/pro6_allocation_analysis.md)

### 4.2 水床不等式的现有精确含义

原有推导假设 I(φ)=cρ(φ)b^(−2φ)，且局部误差代理 E(φ)≥1/I(φ)，由归一化与 Jensen 得到

    ∫₀¹ log E(φ)dφ ≥ log b − log c.

它刻画该分辨率模型中的积分权衡。下一轮需要说明它如何约束目标中的近距／远距能力；它本身没有宣称“任何长任务收益必然伴随短任务分数损失”。

### 4.3 精确有限窗与连续近似

精确 cosine kernel 是距离先验下 cos(ωd)cos(νd) 的积分。它与 αI+βmin 的近似要分开。

[Astra02](rope_allocation_20260910/agents/astra02.md)给出了连续距离先验、紧致正频率区间、自由概率测度下的唯一有限原子最优解证明和小型 CPU 解例。该结论不直接覆盖固定 K 等权频率表，也不直接覆盖有限整数距离的 Gram 问题。它提供“采用哪种变量与极限会得到哪种最优解”的重要线索。

同一报告指出连续 I 不是 Hilbert–Schmidt 算子；若采用投影解释，需要声明有限维分辨率和归一化。这是后续核对 α、β、τ 与 K／L 关系时的数学准备，不在本轮宣布新的参数定律。

## 5. 下一轮最优性／KKT 问题的准备形式

目标是建立能够说明近距代价与远距收益的频谱准则。暂记

    D_near(x;ω)：native／近距表示损失，
    G_far(x;L)：目标远距表示与区分能力。

一种准备形式为最大化 G_far，约束 D_near≤ε 及所声明的可行域。另一种是完整记录 Pareto 权衡。**这只是待具体化的问题接口，不是已经选定的最终目标函数；不能为了得到某条曲线倒造 D、G 或权重。**

若写成 min −G_far(x)，约束 D_near(x)−ε≤0、g(x)≤0、h(x)=0，则满足适当约束资格条件的最优点应满足

    −∇G_far + λ∇D_near + J_gᵀμ + J_hᵀη = 0,
    λ≥0, μ≥0,
    λ(D_near−ε)=0, μᵢgᵢ=0,
    原始可行性。

下一轮须明确：变量是有限频率、间隔、密度还是整数通道数；哪些端点／跨度固定；是否允许重复频率；使用整数距离还是连续近似。紧致可行域和连续目标可用于存在性，凸性可用于充分性／唯一性；不能从“KKT 可写”直接跳到全局最优。

主流三段式可以作为参考可行族。更强的推导应研究高频保持和低频 /S 是否由最优条件自然激活，中频解如何连接二者，而不先把所有边界和曲线都写死。
