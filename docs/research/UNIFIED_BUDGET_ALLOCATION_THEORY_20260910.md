## 1. 问题形式化：守恒预算 + 两个端点不变量 + 一个自由度

固定 W=32768、S=4、L=131072、64 槽、表 ν_j = ω_j·S^{−m_j}（m 单调非降）。所有零训练扩展方法都是在这个空间里选一条 m 路径。

**端点设计刻面（6Pro 裁决：最强基线的设计约束，非零容忍定理；违例方向均有直接实测代价〔措辞更正〕）：**

- **I1（bank 恒等，m=0, j ≤ 23）**：面板上 I1 侧唯一被测端点违例是 HighGapToLong（从高频段抽预算 → 32K −17.1 / 128K −10.8，36 行 0 升 7 降）。〔更正：MrUni **不违端点**——m23=0/m40=1 逐位守恒，其 64.6 是桥形失败；E8 置零槽 51 属尾带，是 **I2 侧**证据〕
- **I2（尾部精确 ÷S，m=1, j ≥ 40）**：E2 把平台推到 m40=1.1557（有效尾比 4^1.155715＝**÷4.9638**，原文 ÷4.93 为误〔更正〕）→ 128K 54.7（12 行面板，基线 64.4444）；E8 置零单个尾槽 → 50.6（12 行，−13.89pp）。E2/E8 断同两行（mq_128_0、fwe_128_0）⇒ 尾部一条慢钟都不能少 [D1/D3]。

端点固定后，过渡段 17 个 log-gap 的**总跨度**被锁定为 17·(ln b)/64 + ln S = **5.0560 nats**，其中**超原生预算**部分 Σ_g(gap_g − ln b/64) = ln S = 1.386 守恒（水床恒等式的路径形式；**禁写"17 个 gap 之和＝ln S"**——字面版违反 D4 红线 #4，G1 24 张端点固定表零违例已复核〔措辞更正〕）。于是整个"低/中/高频分配"问题归结为一个自由度：

> **额外 ln S 放在哪里。**

三个由此定义的结构量：

1. **识别地平线** D_j = W·S^{m_j}：时钟 j 的部署相位在距离 d ≤ D_j 内，其未取模坐标回到 ≤W（训练窗内）。〔更正：d 超过 D_j 后"**进入训练从未覆盖的相位弧段**"已被否证——槽 36–39 原生即在 W 内转 1.15–2.20 整圈，圆周早已全覆盖（0452/U9）。幸存形式：r<1 的欠采样（准线性坡）＋**联合谱覆盖**风险；其可检验版＝Core-C 的距离-准确率衰减（§7-C），且地平线是**风险因子非门控**（6Pro #2，§4 反例已记）〕
2. **周期梯子的洞比率** ρ_g = T_{g+1}/T_g（原生 ≈ 1.241）：额外 gap 在尺度 T_g 制造覆盖洞；短端任务需要 ≤32K 尺度的时钟，长端任务需要 ≤128K。
3. **预算质心** B = Σ m_j：只反映放置位置加权（6Pro 的恒等式），本身不是目标函数。

## 2. 核心理论：学习计算的二分法（filter bank vs arc clocks）

按**原生周期数** r_j = W/T_j^nat 把时钟分成两个学习态：

| | **Filter bank**（r_j ≳ 8–10，槽 ≤ ~29） | **Arc clocks**（r_j ≲ 8，槽 ~29–63） |
|---|---|---|
| 训练内行为 | 相邻 token 相位步**从 1 rad（槽 0）几何衰减到 6.98e-3 rad（槽 23）**——跨三个数量级，原文"~O(0.1–1 rad)"在槽 15–23 错两个数量级〔更正〕；缠绕 ≥10 圈，模型学到**整数对齐的锐利局部判别** | 每窗 ≤ 数圈到不足一圈（r<1 是准线性坡）；模型学到**弧上平滑的慢函数** |
| 窗内扰动容忍度 | **零容忍**：任何 m>0 平移整数相位，破坏已学局部计算（I1 全部证据；pair 的 2.9–4.2K 洞 1.46× 即破长端） | **高容忍**：压缩只轻微改变窗内弧（E2/MrPro 窗内损失小且 gain 可补） |
| 超 D_j 后（弧不安全） | **良性**：其在长距离的相位本就准随机/混叠，模型依赖它做局部而非远程 | **恶性**：进入未训练弧段，学到的慢函数失控外推（r<1 时尤甚） |
| 正确部署 | 恒等（m=0），接受其远程不安全 | 完成到 m=1（整块 ÷S = 精确重参数化），保证到 128K 安全 |

**分配规则（由二分法直接推出）**：

> **bank 恒等；从第一个使用范围延伸到 L 的 arc clock 起（危险区，本模型为槽 36–39，原生 r ∈ [1.15, 2.2]）全部完成到 m=1；两者之间放一座宽度仅由洞预算决定的桥。桥宽是唯一的设计参数。**

危险区的定量刻画：MrPro 的 m_36–39 = 0.5948–0.8889（原文 "0.51" 系槽位错位：0.5098 实为 m_35〔更正〕）→ D = 74.7/84.8/97.2/112.4K，**全部 < 128K**——MrPro 自己在目标长度内留下了地平线未完成的时钟。这是它的 H 残项（§4 两失败行落在该带内，但**风险因子非门控**）；两个赢臂作用点**不同**：LBS 修危险区完成，s28_less 的 D_36–39 与 MrPro 逐位相同、修的是 bank 保真〔6Pro #5——勿称"所有赢家的共同作用点"〕。

## 5. 回答：MrRoPE 为什么窗内极好、外推也极好、且不需要训练

**窗内（32K）**：(i) 24 个最快时钟（T ≤ 900）精确原生——全部锐利局部判别（token 绑定、相邻结构）零扰动，这是它窗内强的主因；(ii) 桥时钟属 arc 态，窗内弧只被轻度压缩，学习函数平滑可容忍；(iii) logit 幅度损失由 attention gain 补偿（gain 四格实验证明幅度与相位弧正交）。

**窗外（128K）**：(i) m=1 块是**精确重参数化**——块内任意两位置的成对旋转 = 原生在 ¼ 位置处的成对旋转，块内联合几何在 128K 上下文里逐点重演训练见过的 32K 流形。模型在这 24 个慢时钟上"看到的"就是熟悉的 32K 几何，粗尺度位置感无损迁移；(ii) 桥提供单调地平线梯度；(iii) 不安全的 bank 时钟退化是良性的（§2）。

**不需要训练**：因为两个精确态都不产生新计算——恒等即原计算，整块 ÷S 是原计算的位置重参数化；没有任何部件需要重学，只有"锚点重放"。

**它的定量缺陷**（论文的进攻点）：危险区欠完成（D_36–39 = 75–112K < 128K）+ bank 边缘（槽 24–28）过度压缩。我们的全部收益来自修这两点，而非发明新机制。

## 6. EVQ 的和解：诊断正确，处方需反转

EVQ 原始视角："压缩高频侧 log-间隔，让给低频侧，使慢时钟更分散"。

- **对的部分（sink）**：慢时钟确实需要分散/完成——P2 的 gap-29 尖峰 + 31 槽完成、LBS 的危险区完成，都是"把间隔给慢端"的正确实现，也都赢了 128K。
- **错的部分（source）**：对**冻结**模型，bank 不是"冗余可压"的密度——它是整数对齐的锐利滤波器组。HighGapToLong 把 EVQ 的字面操作做出来（从高频抽 0.216 log 单位给长程间隔），两端全输、36 行 0 提升。P2 实际只从高频段取了 0.0008（少 280 倍），它的预算来自桥的渐进性本身。
- **统一表述**：EVQ 优化的是"可重学网格"的表征条件数；冻结部署优化的是"已学计算的保持"。两者共享 sink（慢端分散），但 source 必须从"高频密度"反转为"桥的渐进性"。**预算守恒使这一选择成为零和：你不能既保 bank 又保桥又完成危险区——必须砍桥。**

## 8. 外部分析（"姐夫"稿）的整合评估（2026-09-10 补）

该稿与本模型的对照结论：**形式化升级采纳三件，实验设计采纳两件，方法主张修正三处**。 novelty 引用已核实（见下）。

### 8.1 采纳：形式化升级

1. **三操作分解**：频率表 = 高端位置 x₀ + 总跨度 A + 间隔分配 {aᵢ/A}。整体平移 / 扩跨度 / 重分配是三种不同操作。它把我们的模型放到更大的设计空间里，而我们的 I1/I2 证据恰好把其中大片区域判死（平移=MrUni 失败、超界扩跨度=E2 失败）——分解 + 可行域证据 = "设计空间大、可行域小"的干净叙事。数值可用：4× 窗口只需 +10.19% 对数跨度（13.60→14.99），贵的是放置不是跨度。
2. **EVQ 的变分改写**：密度 → 间隔 h(u) 的变量替换精确等价于 J[h] = ∫[α/h + β(1−u)²h]/2 du，∫h=1，cosh 解为一阶条件。〔**有效域限定（验证更正）**："精确等价"仅在局部 δ-核 ＋ μ_F=0 模型下成立；精确核 K_L 带非局部脊 h_c，δ 近似对**每个非零波数**的窄扰动系统性**过罚**（ridge 乘子 0.9916@k=π→0.3556@k=64，见 `EVQ_NONLOCAL_KERNEL_CORRECTION_20260910.md`；`THEORY_MATH_VALIDATION.md` §3 已相应降级）。故不得反向用 J[h] 充当"锐过渡内在坏"的证据。〕这把"EVQ 本来就是间隔预算问题"变成严格数学（条件式），并且暴露了它的间隔代价函数 β(1−u)² 是**表征先验**（重学情形合理）；冻结部署的间隔代价是**兼容成本**，其符号与位置由我们的二分法给出（bank 无穷贵 / arc 便宜）。两者合并后，本文档 §6 的 EVQ 和解升级为严格版。
3. **J_r 配方分解**：J_r(c₀,ν) = 频谱表示质量 + (c₀−c*)ᵀ(G_r+ζI)(c₀−c*) 兼容成本。这是"使用层"的数学语言；我们的 filter bank / arc clocks 二分法正是兼容成本项的机制化实例（bank 上 G 的锐利整数对齐使该项爆炸，arc 上平滑弧使其有界）。分工：该分解组织假设，二分法给可测的方向预测。需保持其"线性读出近似，非整网定理"的定位（E7 的 160× 教训，即便大部分是 BF16 舍入）。

### 8.2 采纳：实验协议

4. **±v 镜像控制**：任何被推荐的分配方向 v，必测 x± = x^Mr ± v（同端点、同扰动范数）。我们已有的事实是它的特例——但如实记账〔证据验证更正〕：**真 36 行镜像对只有 LBS/Faster 一对**（+1.94 / −4.17）；s28 的 reverse_matched 是 12 行面板、对正 gain 不敏感、且构造脚本未复原，只能记 [部分证据]。升级为标准协议后，"规则有方向预测力"才有正面证据。
5. **三条件位置/干扰因子实验**：原生短 / 同 token 块间位置拉伸（p=bM+r → p'=SbM+r）/ 真实稠密长输入。它拆开我们证据里的一处真实张力：09-08 诊断显示两条负例"去背景保位置→满分、紧凑位置→也对"（竞争/状态主导），而 LBS 完成危险区修好 106K VT（位置跨度主导）——两个结论并不矛盾，因为它们测的是不同机制通路，该因子设计正是分离两者的正确工具。GPU 回来后优先级排在 N′ 族之后。

### 8.3 修正：不采纳为主轨的三处

1. **校准-KL 规则生成器（其 §6）**：仍是固定态代理。我们的直接反例：E8 的固定态代理预测增益大于 E1、实际 128K −13.9pp；E1 的两个开发胜例由同一代理在同一面板选出（循环）；margin 分解证明需要前缀+读取双通路。定位降为假设生成工具；主线仍是"结构化族 + 任务裁决 + 镜像控制"。
