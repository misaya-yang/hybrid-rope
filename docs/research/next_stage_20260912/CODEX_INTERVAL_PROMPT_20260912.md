## 0. 目标（一句话）

为一**张固定表**（固定频率逐值 + 固定 gain，全会话不换表）在运行长度 r∈[1,s] 的
整个区间（含原生短段）上选型：OLMo-2-1B 主区间 4K→16K（s=4），Llama-3-8B g8
面板 8K→64K（s=8）作跨模型判决。不允许逐长度换表；逐长度重设计的表只能进
"包络"参照并单列。

## 2. 已关闭路线（不要再开；每条都有实测判决）

2. **m≤1 的表用于 8×**——s8 四臂全 0/48；振幅必须=log₄s。

## 3. 本批判别实验（按序；每项先在结果 owner 顶部写死预注册预测再看数）

### 第 0 步（零 GPU）：归档曲线逐长度抽取
从已归档输出读出全部臂的逐长度×逐任务值，定出每臂最弱长度与逐长度包络
（包络=归档固定表∪Native 在该长度的最大值）。报告 BM 与 γ3 的最弱点各在哪个长度：
短端（2K–8K，指向 bank 边缘机制）还是长端（12–16K，指向尾缘机制）——这决定 E1 的读法。

### E1 OLMo γ 上探（核心判别）
- 表：`m_incr_beta(shape_a=b=γ−1, n=18, low=14)`，γ∈{6,8} 必跑，γ4 可选；
  频带/平台/gain 与部署 BM 完全一致；**γ=2 必须与部署 BM FP32 数组对上
  （≤1e-7）才算构造正确**。
- 面板：与归档完全同合同（第 1 节 OLMo 行），同输入 row IDs。
- 预注册预测〔CPU 复算依据〕：γ 族覆盖严格不变（n_int=12.04、min n(u)=7@u≈1、
  带内最大谱洞 γ8≈1.55×，远小于致死洞 2.97×）；带缘压缩 γ3/γ6/γ8 = 0.0039/≈0/≈0。
  - 若"半完成时钟更少/带缘保真"机制对：γ6 在均值与最弱点上 ≥ γ3，且增益集中在
    第 0 步定位出的瓶颈段；
  - 若 γ6/γ8 在某长度出现坑（配对 95% CI 下界 < −5pp）：方差有二阶代价，
    γ≈3 近优，γ 扫描停止并记录坑位置与所属任务。
  - 两个方向都是判决；不因 γ6 输回退为无边界调参。

### E2 Llama g8 γ 臂（跨模型 + 交叉判决）
- 表：从归档 g8 构造读出 band/plateau/amplitude(1.5)/gain；同一 band 上用对称
  Beta γ=3（n=带宽）重构 ramp，γ=2 对上归档 BM_g8 后才跑；gain 不变。
- 只跑候选臂 × 全部长度格（含已补的 48K），复用归档 48+12 条输入。
- 预注册预测：1×/2× 处 γ3_g8 ≥ BM_g8 − 2pp（带缘更温和）；
  - 若 γ3_g8 在 8–64K 全格 ≥ max(BM_g8, MrPro_g8) − 噪声：**单张固定表消除交叉**
    （headline 结果）；
  - 若仍交叉：交叉位置随形状移动，如实记录位置；交叉的机制预测属研究侧，不在本合同。

### E3 gain 候选（第二拨盘，沿执行会话已在做的）
- BM_g8 频率逐值不动，gain 由 1+0.1·ln8 改为区间常数均值 1+0.05·ln8≈1.104
  〔执行报告〕；OLMo 镜像可选：部署 BM + 1+0.05·ln4≈1.0693。
- 预注册预测：短端相对同表@gain1.208 改善、远端回吐；最终由逐长度数据定。

### E4 端点地板 + 自然任务（对 E1–E3 的当前区间最优表）
- OLMo E3（980 行，16K+4K）对照归档 C42V24/BM/C42/MrPro；
- 自然任务区间曲线：OLMo 631 条长输入池 + 短指令按实际长度；Llama 13 格与
  64K 自然小面板复用；
- 报告原生段损失清单（长度、任务、幅度）。

### E5（选表完成后，按作者既定顺序）微调对照

## 4. 选择与报告规则（描述用，非门槛）

- **主统计量**：逐长度 worst measured regret，参照=候选集逐长度包络
  （第 0 步定义；逐 r 重设计表如 YaRN(s=r) 只能进包络并单列，不入可部署排名）。
- **副**：log-length AUC（仅声明取样范围）、最弱点、逐任务表、截断率；
  NLL/official/exact+EOS 分开报告，不合成单一总分；AUC 不得掩盖中段坑。
- **坑判定**：配对 bootstrap 95% 下界 < −5pp 才算坑；点估计 2–3pp 的 dip 是噪声。
- 当前最优固定表 = 满足端点地板参照（与归档 E3 强臂同面板比较后如实报告差距）
  且区间 regret 最小的候选；结论写明"截至本批"。

## 5. 执行纪律与停机

- 同长度完全同输入；新长度格（48K）一次补全后永久归档复用。
- 主分数 official `string_match_all` contains；exact/EOS/hit-cap 诊断单列。
- 64K 用已验证的 8K 分块 prefill 累计 KV 路径。
- 可信克隆，不做 SHA 门禁；Sol 唯一 GPU 调度，不重启健康进程。
- 每项完成即写结果 owner（status、输入身份、复用 vs 新跑、解码、统计、预注册文本），
  负结果完整保留；〔执行报告〕与〔已核验〕分开记账，更新最近一级 index。
- **本批 E1–E4 汇报完成（或 E5 启动）后停下等作者**；不开新路线，不做无边界
  γ/带/gain 联合扫描。

## 6. 为什么这批实验长这样（研究侧依据，执行可略读）

- CPU 复算：γ 族在 OLMo s=4 上覆盖严格不变 → γ3 对 BM 的区间优势不是覆盖效应，
  只能来自增量方差（带缘更温和、半完成时钟更少）→ γ 上探是单变量判别实验。
- 几何密度 ρ* 与冻结实测反向、Bridge 非凸 → 部署选型只能整表预注册 + 面板裁决。
- gain 是唯一 RATIO≈1 的方向性杠杆；其区间均值形式是第二拨盘的最小干净测试。
