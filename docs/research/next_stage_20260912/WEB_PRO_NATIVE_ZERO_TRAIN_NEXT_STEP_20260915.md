## 1. 研究目标与已有基础

当前论文是 **Beyond the Base: Frequency Allocation in RoPE**。研究对象是内部频率分布 z；Cosh、TailSpline 是构造实例，原生增强、外推及窗口内外联合改善是不同作用形式。

令

\[
x_k=-\log\omega_k=a+Rz_k,\qquad 0=z_0<\cdots<z_{K-1}=1.
\]

固定 a、R、K 就固定了实际最快、最慢频率及旋转通道数，内点 z 仍可改变。原生增强的核心比较希望保持这些量、频率槽位和 gain=1，只改变 z。若你认为某个控制条件必须放宽，应说明必要性及改变后的科学问题，不将其他干预混称为纯 z 效应。

已有固定支持训练/冻结干预说明 z 有独立作用；完整 sin/cos 几何与权重×频率表交叉实验说明，位置方向的多样性与模型学会怎样使用它们需要分别研究。TailSpline 已在冻结部署中提高 Llama clean 16K/32K RULER，比 MrPro 分别高 3.39/11.72pp；但它是 S=4 扩展表，S=1 时退回 Native。这些扩窗结果不能代替原生增强。

**当前目标是原生窗口本身变强。** 不将它替换为更大的外推倍率、扩窗后的原生保持，或有限适配后的收益。零训练主方案不通过梯度优化频率，不更新模型权重；优先争取只依赖公开配置、无需逐 checkpoint 校准的规则。V1 和 LeRoPE 学得表可作为发现线索，但直接迁移、插值、拟合这些校准表，不构成本次所求的方法设计交付。若你认为必须读取冻结权重或做少量前向统计才能构造方向，请给出明确算法及信息来源，说明成本与校准依赖，和纯公开参数构造分开评价。

## 2. 最相关的文献问题

[LeRoPE: Learnable RoPE Frequencies Improve Language Modeling](https://arxiv.org/html/2607.10134v1) 通过联合学习频率与模型权重，提高窗口内语言建模和多键检索。其 Fixed LeRoPE 用独立运行学得的表重新训练模型权重，不是直接换入成熟冻结模型。它观察到中慢频减速，以及波长约为训练长度 2.2 倍的强位置通道；因此慢频不能自动标记为纯语义通道。

[Round and Round We Go!](https://arxiv.org/html/2410.06205v3) 也是相关机制背景。请核对原始论文，并按需要检索直接相关工作，区分学习频率、固定表从头训练、成熟模型零训练替换和原生任务效果。**我们真正尚未解决的是：能否从可说明的设计原则得到新的 z 构造，在成熟冻结模型的原生窗口实现收益？**

## 3. 历史正面参照：Native-Z5 是校准方法

## 4. 新实验：解析半周收缩几乎不增益，冻结 V1 出现任务收益

### 被测试的解析规则

设 D=L−1，\(\phi_k=D\omega_k\)，\(\ell=\phi_{K-1}\)，\(c=\min(\pi,\phi_0)\)，固定 \(\eta=1/4\)。若 \(\ell\ge c\) 返回 Native，否则定义

\[
h(\phi)=
\begin{cases}
\eta\min(\phi-\ell,c-\phi),&\ell\le\phi\le c,\\
0,&\text{其他}.
\end{cases}
\]

主候选 H 为 \(\omega_k^H=\omega_k-h(\phi_k)/D\)，反向控制 B 为 \(\omega_k^B=\omega_k+h(\phi_k)/D\)。两张表保持端点、严格顺序、外侧频段与 gain=1；逐通道正反相位位移绝对值相同。这里 H/B 是为了避免与扩窗实验的等位移控制 C 混淆。

原假说是：适度减慢半周内的频率，可能减少内容匹配的旋转干扰。相关条件推导依赖正确证据与 query 的正对齐关系及旋转对称噪声等假设；实际 logits 仍有带符号的 sin/cos 系数，真实多层模型是否满足这些条件未知。CPU 证明的是结构性质，不是任务排序。

OLMo 上 H 实际修改零起始索引 35–62，共 28 对；全原生窗口内最大相位改动约 0.36231 rad，最大相对减速约 24.82%。这些设置在评测前固定，没有根据结果调参。

**推荐一个最有依据的具体方法，并把数学与实现做实。** 可以否定半周收缩假说、当前参数化或我们对结果的解释，也可以提出新的数学对象；不需要为现有公式辩护。方法形式和推导路径开放，不预设低频收缩、V1 迁移或任何曲线族。

最终回答需要交付：

- **设计依据与推导。** 明确试图改善的模型计算或行为，解释频率改动怎样作用于它，以及何种条件下有理由期待好于 Native。将数学可证部分、对真实模型的假设和仍未知的环节分开。仅证明有序性、扰动小或自定平滑目标最优，不足以完成这一项。
- **完整构造。** 给出从声明输入到最终静态频率表的公式或算法。幅度、边界、尺度及其他常数都需要明确数值或不依赖目标任务分数的确定规则，不能把最关键的选择留给下游搜索。利用已有数据形成的经验选择须如实标记。
- **可复算实现。** 提供最小代码或无歧义伪代码，并在给定 OLMo 公开参数上实际算出候选表及关键结构量；若可执行代码，输出复算结果。说明同一算法如何用于不同 Native 长度和频率配置，不用新的模型分数重新定参。CPU 输出只验证构造，不冒充任务效果。
