# 给Web Pro：重新研究RoPE的原生窗口增强

请结合以下研究背景、已完成实验和必要的原始论文检索，分析：**如何通过设计RoPE内部频率分布z，可靠改善模型在原生上下文窗口内的能力？** 请给出有理论依据、可执行且值得优先验证的研究方案。

## 研究对象与目标

我们的研究对象是RoPE内部频率分布z。Cosh、TailSpline等是不同构造，原生窗口增强、外推、窗口内外联合改善是不同作用形式；训练期设计与冻结模型部署是不同验证协议。请从这个上位问题出发，不把研究绑定到TailSpline，也不把最大外推倍率当成目标。

将严格有序的正频率表写为：

\[
x_k=-\log\omega_k=a+Rz_k,\qquad 0=z_0<\cdots<z_{K-1}=1.
\]

固定a、R和K时，改变z只改变实际最快/最慢频率之间的内部配置。我们已有固定支持干预、完整sin/cos位置基几何、权重与频率表交叉实验，以及Cosh/TailSpline的解析构造和模型结果。已有认识是：有限窗几何与模型学得的使用方式需要区分；几何指标不能直接保证任务排序，训练时有效的表也未必适合事后直接换入冻结模型。

本次重点是native增强：在原生长度L以内改善能力。优先希望得到依赖公开RoPE参数即可构造、无需逐checkpoint校准的可迁移规则。请以冻结成熟模型的z-only干预为起点，也判断配对训练或有限适配是否具有必要性；不同路线的成本和科学主张应分别说明。

## 已经尝试的Native-Z5

模型为OLMo-2-0425-1B-Instruct，原生L=4096。全部模型权重冻结，最快/最慢实际频率、support、base和gain=1不变。

参数化为七个固定pair-index knots，六个正gap经softmax归一化，累计形成五个有效内部z自由度。从Native初始化，只优化gap logits。

校准数据是PG19 validation的50本书，每本一个4097-token窗口，分成design/selection/internal-confirm的16/16/18本。AdamW，lr=0.003，40步，单初始化与seed；selection选中step35。目标是完整4K dense NLL，四段等长位置NLL平均与它代数等价。任务分数不参与选表。

独立评价为ProofPile test 32文档与PG19 test 14文档，共46文档，测1K/2K/4K；任务为原生4K classic协议的RULER Full-13×10共130条，以及未截断、prompt加生成预算不超过4K的Natural-QA99：2WikiMQA24、HotpotQA5、Qasper70。

### 结果：差值均为候选减Native

| 尝试 | 4K NLL差及95%区间 | 任务结果与结论 |
|---|---|---|
| V1 | −0.0021088，区间[−0.0042071,−0.0001483] | RULER +1.68pp [−3.15,+6.44]；自然QA +1.98pp [−2.75,+6.73]。NLL有小幅独立改善，任务收益未确认 |
| Split-consensus | −0.000631，区间[−0.003530,+0.002141] | RULER −1.28pp [−5.63,+2.87]；自然QA +2.73pp [−2.71,+8.19]。未得到稳健增强 |
| All-50 refit | −0.001543，区间[−0.003855,+0.000623] | 未通过4K NLL改善及优于V1点估计的推进条件，未进入fresh-task确认 |

补充事实：

- V1在独立1K/2K的NLL差分别为−0.0066496/−0.0027749，区间也均小于0；4K Native/V1绝对NLL为2.2978120/2.2957033。
- V1在design、selection、internal-confirm上的NLL差约−0.00798、−0.00843、−0.00895。它不是只在selection上改善。
- Consensus从三个design block得到共同一阶下降方向，selection选alpha=0.25；正方向优于反方向，但独立4K未稳定优于Native，且显著差于V1。
- All-50沿用同一参数化、lr和35步；校准50本的NLL差为−0.007168。它在PPL46上相对V1的差为+0.000566，区间跨0。
- PPL46在后续尝试中已被反复查看，之后只能视为开发证据。新的确认需要新数据；Natural-QA99也有样本少且任务不平衡的问题。

因此，这次“失败”指没有得到稳健的原生任务增强及可迁移方法；V1的小幅NLL存在性结果仍然成立。不能据此判断z没有原生增强潜力，也不能把小幅NLL改善直接当作能力增强。
