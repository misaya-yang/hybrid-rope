# 下一阶段：倍率与模型迁移，而非继续扩大同一面板

2026-09-13，依据作者最新要求。当前优先级改为引入8×及其他checkpoint，检验冻结构造的结构规律；不以继续加大Llama S4样本量或修复单个FWE CAL作为默认主线。本文是实验指导，不表示新增远端运行已获本任务执行或已完成；Sol按其当前授权接续健康作业。

## 1. 出发点与要回答的问题

当前[结果owner](LLAMA_S4_RANGE_CONFIRM_AND_INTERFACE_RESULT_20260913.md)已给Llama S4组合方案在匹配面板上相对BM/MrPro/C42的明显收益，同时保留Native FWE损伤。这值得进入倍率与模型测试，不需要先把Native所有任务修好。

“靠极端外推换Native损失”是待区分的解释，不是定论：Native退化集中FWE，gain-only能显著改变它；已有结果还不足以证明所有Native功能都退化，或这种取舍不可避免。组合方法收益不能全部算频率单变量收益。

下一阶段的三个问题：

1. 同一分配规则从S4到S8，强长端收益是否保留，Native代价是否扩大？
2. 变化来自频率缩放、gain规则，还是输入长度/竞争者数增加？
3. 同一规则迁移到其他checkpoint时，使用何种边界坐标，不重新搜赢家？

## 2. 倍率变化的严格分解

固定m_k，ν_k(S)=ω_k S^(−m_k)。从S4到S8：

    ν_k(8)/ν_k(4)=2^(−m_k).

高频m=0不变，低频m=1再减半，中频居中。这是确定的频率变化，不保证任务效果方向。

在相同绝对距离Δ处，相位同样乘2^(−m_k)；因此在相同32K输入上换S4/S8，只改部署频率/gain，不混入文本增长。

在各自目标端Δ=SL处：

    θ_k(SL)=Lω_k S^(1−m_k),
    θ_k(8L)/θ_k(4L)=2^(1−m_k).

尾部m=1保持目标端相位，高频m=0翻倍，中频介于两者。故“用了/S，所有频率在更长端点都安全”不成立；也不能把相同长度上的S变化与4L→8L输入变化混为一项。

固定Q/K的一层attention上，cos/sin幅度g使logit乘g²；模型全程换g还会改变后续Q/K，不能当作仅末层温度变化。当前候选gain规则：

    g_mid(S)=sqrt(1+0.1 log S),
    g_mid(4)=1.0670658068,
    g_mid(8)=1.0990651274.

这是预先冻结的部署规则，不是已证明的最优gain。8×时同时改变g会混入另一个因素，故保留一个固定g的桥接臂。

## 3. Llama S8：主实验

冻结mix075的系数0.25BM+0.75frontloaded、band[16,34]、完整/S尾部。S8先不改band、不重拟合混合权重，不把旧C42在S8偏好[14,32]直接当作新方案最佳边界。

| 配置 | 作用 |
|---|---|
| C4：现有S4 mix075、g_mid(4) | 共同输入上的基点；原始行匹配则复用 |
| C8-fixed-g：S8同m、g_mid(4) | 隔离更强频率缩放 |
| C8-rule：S8同m、g_mid(8) | 检验整个冻结构造规则 |
| canonical MrPro S8 | 与主要目标方法匹配比较 |
| canonical static YaRN S8 | 补齐当前核心缺失强对照；实现身份用代码版 |
| BM S8 | 若同合同旧行可用则复用；否则在核心比较之后补必要格 |

主要长度8K、32K、64K。8K测真实Native保留，32K是两种S的共同输入桥，64K检验8×目标端。Native@8K同prompt复用；不要求Native在64K当强基线。

比较必须拆成：

- 同32K、C8-fixed-g减C4：倍率配置造成的频率效应。
- 同32K或64K、C8-rule减C8-fixed-g：当前S8表上的gain条件效应。
- 同64K、C8-rule减MrPro/YaRN：实际8×方法价值。
- 同8K、候选减Native：Native成本；FWE与其余任务分列。

仅有这些格不声称识别完整S×gain交互；若之后确需该归因，才补C4配g_mid(8)的共同32K格。不要一开始铺完整析因网格。

使用当前Core-6任务身份与已有小块规模，优先同一批8K/32K旧prompts，64K生成对应独立合法样本，不直接截断或拼接旧输入。先保持每格6行的开发块，检验变量变化而非全benchmark确认；噪声影响下一决定时才针对分歧补行，不要求每张表自动扩到12/60。64K实测可能较慢，先用已有吞吐估计安排队列，不预言分钟数、不为省时间移除强基线或换成PPL。逐任务结果、EOS/cap和完整输出照常保留。

## 4. 其他模型：先区分倍率交互，再验证第三种结构

### OLMo S8：优先且与Llama互补

OLMo已经在S4出现不稳定/混合收益，是检验规则是否依赖checkpoint的有价值反例。冻结现有[14,31]及mix075，不追用Llama[16,34]。长度4K、16K、32K，与Llama分别对应1×/4×/8×。

复用S4父表与匹配基线；新增S8候选及S8 MrPro/YaRN，必要时固定g桥接。先检验同一模型内S4→S8，再比较模型之间差异；不能因OLMo1B更快就把Llama8B的现象判作相同。

OLMo S8与Llama S4都在32K结束，还可帮助分开“相同绝对输入长度”和“相同扩展倍率”的解释，但两checkpoint内容计算不同，不能作为纯模型因果效应估计。

### Qwen2.5-1.5B：第三种checkpoint上的冻结迁移

优先复用已有checkpoint与32K/64K面板，先S2验证同一分配规则的第三模型迁移；它不等于Qwen S8已验证。若核心问题明确是跨模型S8，则Qwen Native32K对应256K，需按实际资源另行安排，不偷偷把Native改成4K。先不要为此下载新模型或制作巨量长样本。

从Llama[16,34]按相同Native winding迁移边界，解析公式为：

    k_B=K_B/log B_B × [log(L_B/L_A)+(k_A/K_A)log B_A].

Llama L8192、B500000、K64映射Qwen L32768、B1e6、K64，连续位置[21.6192,38.7161]，预定最近整数为[22,39]。该坐标在历史Qwen实验中已出现并已开封，不能叫全新的前瞻理论预测；新内容是冻结mix075及gain规则的迁移测试。

不重拟合0.75。比较Qwen候选与canonical MrPro/YaRN，Native@32K保留。Qwen1.5不是MrRoPE论文Qwen3B，明确模型身份。若以后扩大至S4/128K，按本节的共同长度桥接办法，而非同时换倍率、边界和gain后只报一个总分。

## 5. 预先写下结果如何改变判断

| 观察 | 可推进的判断与下一步 |
|---|---|
| 同32K换S8已明显变差 | 损伤不能全归新64K输入；继续看固定g和规则g区别，不先扫band |
| 32K保持、64K下降 | 新距离/竞争范围仍有缺口；尾部相位保持不是全模型安全证书 |
| S8候选对强基线优势扩大且Native成本增大 | 支持明确的倍率相关权衡，不宣称成本是理论必然 |
| Llama S8与OLMo S8都保留优势 | 支持相同规则的跨checkpoint价值；各自条件仍单列 |
| 模型之间反转 | 规则不是统一赢家；定位实际频段与任务差别，不按新结果再重拟合每个模型 |
| gain桥接解释大部分变化 | 方法为频率+gain组合，避免将总收益归z |
| FWE仍是唯一明显短端损失 | 功能特异缺口；不把修复FWE设为所有迁移实验的前置条件 |

本阶段不继续答案margin/QP修复循环，不用“接口尚未补齐”新增depth插值。保留其已有失败记录。理论主线用倍率的精确相位关系和预定边界映射产生判别实验，实验决定适用范围，不倒过来重写公式。
