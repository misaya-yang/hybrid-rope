## 最多两条值得投入的实验增强方向

### A（优先）：固定端点下，学习损失与解析设计各自选择怎样的 allocation？

资源充足时，建议把 **151.9M 同架构、2K 与 4K 两个训练窗口、Geo / anchored Cosh / constrained learnable-z 三臂、三个配对 training seeds** 作为主实验，合计 18 个完整训练运行。选这一规模是为了直接衔接已建立的因果识别，同时把结果推进到更常规的上下文；不是继续扩充 tiny-model pilot。额外机器优先并行这些完整对照，而不是增加曲线家族或 benchmark 数量。若需要更大规模确认，在主结果完成后用一个 400M 级架构复验最关键对照；它回答规模迁移，不能替代主矩阵中的配对和重复。

两种训练窗口共用一个预先确定的 sampled support 和 pair count，取自选定可靠训练配方，避免随窗口重新设 base 后把范围变化混进 allocation×训练窗口比较。每个窗口/seed 内，三个臂共享初始化、底层 token 流与打包规则、优化器、训练预算和评估。跨窗口的打包边界必然不同，长度交互估计应比较各窗口内部的配对效果，不把两个窗口的绝对损失差直接归于位置分配。Cosh 的强度与 finite-grid 规则提前固定；若按窗口使用不同强度，则该交互只能称为“构造规则×窗口”，不能称同一 allocation 的纯窗口交互。

训练应达到能判断效果随学习进程是否保持的预算。建议按 **1B–3B tokens/运行** 做资源预案，再由实际收敛轨迹和可信训练配方确定一个三臂共同预算；这是建议规模，不是已测吞吐或充分训练保证。保留中间 checkpoint，在共同 token 节点比较窗内与外推曲线。不能以某一臂暂时领先的 checkpoint 作为结果，也不因学习型臂更慢就单独延长它。已完成的 151.9M/256 实验用于历史锚点，不再将“只补旧协议的一条臂”作为时间紧时的默认主方案。

正 gaps 归一化累积保持端点和次序，K−1 logits 有一个平移冗余，实际自由度 K−2。先用短的独立开发运行确认梯度进入安装频率、z 确实变化及位置参数 LR 合理；历史 learnable-τ 近零初始化梯度饥饿应避免，但它不能作为学习型方法无效的预判。主实验开始前固定 LR、最终预算和评估；使用独立自然文本集测 1×/2×/4×/8×，同时保留两窗口重叠的绝对长度点。训练目标先保持自然文本 next-token loss，使“窗内优化会选择怎样的长度泛化”成为清楚的问题。

**在同一批模型上建立几何—学习—读出的连接：**

1. 在共享 checkpoint 节点保存实际频率表和完整 sin/cos Gram，按同一组评价距离分布计算重叠、有效方向与尺度覆盖。记录 learned-z 的轨迹，提出并检验“训练目标在什么尺度上重新分配位置方向”的具体预测。既定计算可同时看 uniform 与 causal separation measure 的敏感性；不事后选最相关的统计量作主机制。
2. 对最终 Geo/Cosh/learnable-z 权重做同支持的 **3×3 交叉换表**，在同一 held-out 输入上测量。模型权重不变时的表效应、各自训练后的效果、权重×表交互由同一个矩阵联系起来；静态 rank 增加但换表变差时，应解释为几何供给与学得使用的分离。crossing 测到的是兼容性，不自动等于某个 rank 量的因果中介效应。
3. 若要强化“上下文利用”，用这些已完成的配对模型接上**一套相同预算的读出训练/适配协议**，固定其 supervision 与位置暴露，随后测新提示的完整答案加立即 EOS。优先一个可判定的远距检索任务，再用一个预先确定的自然 QA 任务检查任务意义。自然文本 loss 是泛化结果，完整生成是读出结果，两者均需成功测量。这里比再引用另一个模型的正结果更有价值，因为它能把同一 allocation 干预、学习状态与读出行为连接起来；不过经过读出训练后的总效果仍属于这一完整协议，不能全归因于原始预训练阶段。

以上三步沿同一批 checkpoint 展开，不是新增三条搜索战线。最高价值交付是同端点三臂的两窗口长度曲线、学得表的变化及对应 crossing；读出实验提升它的行为意义。先确定机制预测和目标任务，再安排机器，不能因机器多就铺开任务全集。

**论文主张如何自然增强：** 若解析和学习型分配在两个窗口都改善外推，可从“可识别的设计自由度”推进为“可通过解析先验或直接学习利用、在不同训练窗口中产生可重复长度收益的设计对象”。若 learned-z 窗内更好但长端更差，则结果具体揭示短程训练目标与跨尺度部署目标的差异；只有轨迹/交叉干预提供对应证据时才进一步谈原因。若同一批模型的匹配读出也提升，可直接展示内部分配如何进入学习并改善上下文使用，不再依靠跨模型结果拼接这段关系。

learnable-z 更好说明存在进一步优化空间；Cosh 相近说明解析先验有实用竞争力；Cosh 更好只支持该训练目标和预算下的比较。若 Cosh 或两种非均匀臂在新设置没有收益，如实报告与原三 seed 的差异，结合训练轨迹和窗口交互判断现象，不把失败重新解释为预期成功。若实验尚未完成，原稿的已证主张仍可保留，尚未验证的增强句不写进摘要。

### B（次优先）：同一位移预算内的结构差异，能否预测新的任务表现？

选择已冻结的 C42/C42V24 两个构造，保留 OLMo 检查点、support、band、总位移 42、gain 和 decoder，在**独立于原 350-row 选型面板**的生成题上检验原方向。优先用同任务分布的新提示得到干净的确认，再加入一个已有自然 QA 任务层检查是否具有任务意义；合计规模依据原配对差的离散度决定，不把 prompt 数当 training seed 数。完整报告任务均值、逐提示配对差及 EOS；不以 NLL 的方向代替生成结果。

这里检验的是一个具体的形状预测，而非重新搜索赢家。原 350 行 +10.73pp 足以支持事前方向，尚不足以支撑独立泛化；新比较能将“总位移之外还有结构”从开发发现提升为可复验设计认识。先完成这一个对照，不同时跑几十条曲线、改阈值、调 gain 或追加第三套理论。

有稳定确认，则在 §6.1 提升这一同预算结构结论；区间宽则只报告未定，不继续挑任务缩窄区间；显著负向或零效应则把原结果保留为开发发现并给出新结果，不再将该具体形状作为泛化实例。BM 五任务 QA、C2 的紧凑表示及纯内点主命题仍各有既有证据。跨模型迁移仅在这一对照完成后、且映射规则能在看结果前完全确定时考虑，不作为本轮第二条线的默认扩张。
