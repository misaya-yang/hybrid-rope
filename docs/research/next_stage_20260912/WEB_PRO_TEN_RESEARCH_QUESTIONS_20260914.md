## 必要背景

### 研究对象和目标

对 K 个有序正频率，定义

\[
x_k=-\log\omega_k=a+Rz_k,\quad z_0=0,\ z_{K-1}=1.
\]

(a,R) 固定实际采样的频率端点，内部 z 决定有限旋转对在范围内的分配。所有 geometric 表的归一化 z 都等距，改变 base 不改变这一性质。我们的贡献意图是建立分配的独立作用、几何与学习联系、有效构造及受控实验；坐标重写本身不是贡献。

论文已有学习期 EVQ-Cosh、多形状、full-z 相关探索，以及成熟模型的冻结频率干预。当前实用目标是在冻结 checkpoint 上安装一张跨层、跨输入长度的静态表，改善实际上下文质量。训练期重新学习一种分配与冻结模型安装新表是两种不同问题。

设 Native 窗口 L，扩展倍率 S，H=SL；成熟模型写成

\[
\nu_k=\omega_kS^{-m_k}.
\]

现行三段式通常为高频 m=0、低频 m=1、中频从 0 过渡到 1，band 为 [l,h]。这些是方法选择，尚不能当作最优性的前提。attention gain 单独控制；同一频率表在各输入长度保持不变。

对给定内容 Q/K，单槽 logit 贡献可写为

\[
\operatorname{Re}(C_k e^{id\nu_k})=A_k\cos(d\nu_k)-B_k\sin(d\nu_k).
\]

C 随内容、层、头变化；深层激活还可能随频率表变化。最终输出涉及 key 竞争、softmax、value、后续网络及解码。纯频率几何不能保证任意内容上的任务排序，但具体 checkpoint 仍可能存在可检验规律。

### 中频构造为何仍令我们困惑

令 n=h-l，q=0,...,n，m_q 为累计指数，epsilon_q=m_q-m_(q-1)。仓库中的同端点构造为

\[
m_q^{Pro}=\frac{q(q+1)}{n(n+1)},\qquad
m_q^{BM}=\frac{q(q+1)(3n+2-2q)}{n(n+1)(n+2)},
\]

\[
m_q^{TailSpline}=\frac{q(3n^2+3n+1-q^2)}{n(n+1)(2n+1)}.
\]

在 sum(epsilon)=1 下，TailSpline 唯一最小化

\[
J_0=\sum_{q=1}^{n-1}(\epsilon_{q+1}-\epsilon_q)^2+\epsilon_n^2;
\]

增加首端惩罚 epsilon_1^2 得到 J_1，其唯一解是 BM。两种条件最优性已有 CPU 核验，但为什么模型应偏好单边或双边边界，仍未解决。连续调整首端惩罚又会得到一族曲线；我们不希望把它变成新一轮超参数搜索。历史 mix075 是经验混合，不等于有限网格上的精确 TailSpline。当前精确 TailSpline 尚无统一 benchmark 性能结论。

## 十个问题

### 1. 三段式本身是可推导结构，还是我们过早限制了设计空间？

我们一直假设存在连续的高频保持区、中频过渡区和低频完整插值区。什么明确的模型计算、优化条件或近似机制，会导出这种结构？在什么假设下会出现两个边界，而不是多个活动区、非单调表或全频微调？请给出最有希望的推导起点及可反驳条件，并指出哪些假设是在重复写入三段式答案。

### 2. 高频为什么应该保持不动，band 的起点和终点应怎样确定？

用 Native 窗口内的转圈数 L·omega/(2pi) 定义32圈/1圈边界，能表达什么，又缺少什么？频率高是否足以推出“承担局部功能，改动代价高”？如果边界必须依赖 checkpoint，应测哪种信息，才能在不查看目标benchmark分数的情况下决定 [l,h]？请给出可计算的边界规则或说明无法唯一决定的原因，以及最小的边界干预验证；同时区分移动band和改变band宽度。

### 3. 低频尾部为何要恰好除以 S，怎样才能理论上选择终点？

H·(omega/S)=L·omega 只给出相位范围对应。为什么这可能适合冻结模型，又为何可能损伤Native？我们已有一个条件模型：对 r∈[1,S] 的log均匀权重，最小化偶对称、随误差幅度严格增加的失真 F(ar-1)，得到 a=2/(S+1)，而非1/S；它没有变成稳定任务赢家。请审查该目标与模型用途之间缺失的环节，并提出真正区分tail-only终点、整表depth和中频联动的比较，避免重复“整表软化失败，所以低频不能改”的归因错误。

### 4. 两端确定后，中频究竟应该平滑什么，为什么？

应该约束频率nu、log频率、累计位移m、radix增量epsilon，还是模型的某种响应？BM和TailSpline都有漂亮的唯一最优解，但更换边界惩罚就换了赢家。请判断单边与双边平滑各自隐含的计算先验，能否从attention计算导出偏好或可测条件，以及连续解离散到有限K后是否改变判断。如果能提出更合适的目标，请说明它为何能预测任务取舍，而不只是重新定义一个由候选最小化的能量。

### 5. 从频率分配到任务收益，最小的理论桥梁是什么？

我们不需要完整解释Transformer，但需要至少一个“事前预测干预方向、事后允许被否证”的机制。针对已有Native损伤、VT/FWE能力交换和EOS反转，哪些竞争解释值得区分：相位失配、key排序、softmax放大、value混合还是输出终止？请选最有信息的一处计算给出推导或反例，并明确最少要采集什么。已有平均Q/K不能当逐key信息；不要假设仓库已有完整signed-C或Q/K capture数据。

### 6. 跨长度、倍率和模型迁移，到底应保持哪个对象？

固定m、固定全谱z、固定band内部归一化坐标、保持相位分布、保持学得响应分别在控制什么？fixed-u的解析迁移已经在一个OLMo比较中输给fixed-m，因此坐标恒等式不足以决定性能。能否给出适用条件和可检验的迁移准则，解释什么情况下应保持或重新计算边界？请区分倍率S变化、实际输入长度变化、Native base/K变化以及gain变化，不以跨模型宏平均差异直接证明机制。

### 7. 怎样用最少但足够的实验结束“猜表”，并作出最终方法判决？

当前准备冻结Llama-3-8B上的精确TailSpline，与YaRN、MrPro和BM统一评测PPL、完整NIAH/passkey及Full-13 RULER；同gain/band/support的归因比较复用这些数据。已启动的Core-6块因长度筛选实际只有8K/32K每臂72行，只能作诊断。请给出一份优先级明确的实验设计：哪项最终benchmark必须做，哪项机制比较值得补，哪些已有对照能复用，如何处理开发选择暴露与不确定性，以及何种结果支持继续、收束或缩小claim。不要默认再扩大band/gain/曲线网格，也不要要求每个任务逐格获胜。

### 8. 我们最强且可辩护的论文核心claim是什么，理论应承担多大责任？

基于上述证据，怎样把z的独立作用、EVQ构造、full-z探索、学得兼容性和成熟模型部署连成贡献链？哪些只是在重参数化，哪些是受控发现，哪些是条件定理，哪些是有价值的方法？请分别考虑TailSpline最终明显胜出、收益与代价并存、没有胜出三种情况：论文的核心贡献和理论表述应如何变化？评估时不要把新候选失败扩大成旧实证无效，也不要把“分配重要”当作无需进一步论证的新颖性。

### 9. 超大实验资产应怎样筛选、分组并呈现，才能形成证据而不是堆结果？

请依据上面的证据族，具体划分“主文必需、附录必要、仅保留复现/探索记录”三类，并说明每组排除哪个替代解释、支撑哪个claim。多模型、多seed、训练/续训/LoRA、冻结干预、完整配置、自然QA和几何反例如何组合才有说服力？请给出一个可直接使用的claim—实验—指标—证据限制映射表；对负例和开发暴露也安排明确位置，避免只保留漂亮结果或把异质指标平均成总提升。

### 10. 如果由你重写这篇9页主文，章节、图表和叙事会怎么安排？

请给出具体页数预算、章节顺序和核心图表草案：第一幅图如何让读者立即理解“同范围、不同分配”的发现；哪幅图连接几何与学得兼容；哪张表呈现训练期证据；成熟模型的全窗口收益与Native/任务代价怎么画？比较“先学习期构造再成熟部署”与现稿顺序，推荐最能支撑核心claim的一种。附录如何按科学问题索引并保留大量有效资产？指出哪些旧条件推导、失败探索或重复表格应离开主文，并用简短摘要提纲展示整篇论文的论证走向。
