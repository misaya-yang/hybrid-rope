# 从计算约束到构造：功能区间、最小改动与跨倍率 z 迁移

2026-09-14。数学推导与CPU验证；没有新增模型运行。此文回应作者要求：不能用
“承认缺口”和“再测一批”代替实际推导。它给出两个可计算结论，并明确不能推出的
任务结论。不是已经超过MrRoPE的新方法报告。

## 1. 当前候选到底改了什么：严格逐槽排序

固定band `[l,h]`，`n=h-l`，`q=k-l`，`t=q/n`。仓库实际公式为：

    P(q) = q(q+1) / [n(n+1)]                         (MrPro)
    R(q) = 2t-P(q)                                 (反向增量)
    B(q) = q(q+1)(3n+2-2q) / [n(n+1)(n+2)]         (BM)
    M(q) = B(q)/4 + 3R(q)/4                        (mix075)
    nu(q) = omega(q) S^(-m(q)).

对每个内部槽 `0<q<n`：

    B-P = 2q(q+1)(n-q) / [n(n+1)(n+2)] > 0,
    R-B = 2q(n-q)(n+1-q) / [n(n+1)(n+2)] > 0,
    M-t = q(n-q)/[n(n+1)] * [3/4+(2q-n)/(4(n+2))] > 0.

所以 `M>B>P` 且 `M>t`。给定同band与倍率，mix075每个中频都比BM慢，BM每个
中频都比MrPro慢。这不是只交换几个gap的“微调”，而是整个中频的更强压缩。
canonical默认band不同时，不得直接套这个逐槽排序。

Llama `[16,34]` 的中点 `k=25`：

| 指数 | MrPro | BM | mix075 |
|---|---:|---:|---:|
| m | 0.263158 | 0.5 | 0.677632 |

mix075/MrPro的频率比在4×为0.56294、8×为0.42237。它因此更强地改变已学位置
响应。若某个固定内容分量是 `A cos(nu*d-omega*d0)`，对应峰的一个分支从`d0`
移至`S^m d0`；这是具体分量的严格峰位关系。不能据此把全部FWE损失归因于峰位。

**已解决的判断**：当前候选不是“比MrPro更保护中频Native结构”的方案。其
频率几何采取了更强压缩，任务收益必须来自这种改动的有用作用或gain等其他变量，
不能再用“更接近Native”来解释。

## 2. 三个问题缺的共同对象：功能区间，而不是整圈计数

固定一对pre-RoPE内容向量，一个槽的真实响应写成：

    f(d;nu) = A cos(nu*d) - B sin(nu*d)
            = r cos(phi+nu*d),   A+iB = r exp(i phi).

它没有在`nu*d=2pi`处的奇点。对已确定需要保持正或负响应的分量，边界来自对应
相位区间，而不一定是Native长度或一整圈。

例1：`f=-r sin(nu*d)`，要求所有`d in [0,H]`非正。对`nu>=0`：

    f(d)<=0 for every d in [0,H]  iff  nu*H<=pi.

例2：`f=r cos(nu*d)`，要求同一区间非负：

    f(d)>=0 for every d in [0,H]  iff  nu*H<=pi/2.

证明：分别取从0出发的首个连续符号区间；若超过右端，必有一段相反符号。
这里是连续lag结论；实际整数lag使用连续约束是充分、可能保守的保护。

这两种功能给出的安全上界已经不同。更一般地，若选定一个连续允许相位区间
`[a,b]`，要求`phi+nu*d in [a,b]`对`d in [dmin,H]`成立，则因为`nu>=0`：

    phi + nu*dmin >= a,   phi + nu*H <= b.

`dmin>0`时得到一个精确频率区间；`dmin=0`时必须先满足`phi>=a`。多个已经
识别的分量给出的区间取交集。相位分支必须预先指定，不能为候选成功而更换分支。

### 对问题②的一个真正最优性结论

在负正弦例中，限定只能减速，且目标是**保持其整个目标区间的抑制符号，同时
使频率最接近Native**，唯一解为：

    nu* = min(omega, pi/H).

令`H=SL`，`x=omega L`。若`x<=pi/S`，根本不必减速；若`pi/S<x<=pi`，则
`nu*/omega=pi/(Sx)`。仅在`x=pi`时恰为`1/S`。例如`x=3pi/4,S=8`时，最小
必要减速为`omega/6`，不是`omega/8`。

这是明确约束下可证明的端点结论，不是说OLMo应该用`/6`。旧`/3.6,/3.9`只改
一段tail，并未测量该段的内容相位与必要功能，既没有检验这个条件命题，也不能
当作它在OLMo成立的证据。

### 为什么不能直接用这条公式生产所有槽

正/负贡献不自动等于好/坏贡献；某个key需要抑制，另一个key可能需要保留。
同一个槽可在不同头、不同内容上产生不同phi。换表还会改变深层Q/K。若把全部
分量都要求保号，交集可能为空，也可能只是把无用计算保护住。因此必须已有证据
说明约束对应哪项计算，不能把短文本平均C或范数当作功能标签。

这条限制是构造输入的一部分，不能用“理论绝对正确”掩盖输入未识别。

### 同一个槽承担两类计算时，冲突可以直接判定

设一类内容在该槽形成局部峰`cos(nu*d-omega*d0)`，要求对应峰的连续分支仍在
`[d0,d0+delta]`；另一类内容需要`-sin(nu*d)`在`[0,H]`保持抑制。前者给出
`nu>=omega*d0/(d0+delta)`，后者给出`nu<=pi/H`。因此两项功能同时可行当且仅当

    omega*d0/(d0+delta) <= min(omega,pi/H),

其中`d0>0,delta>=0`。固定`H`时，必要的最小峰位容忍度为

    delta >= max(0,d0*(omega*H/pi-1)).

这是某槽已识别功能之间的精确冲突，不是“所有模型Native和长上下文必然冲突”。
它也指出缺失输入具体是什么：该槽是否真的承载这些计算、d0与允许偏移是什么。
任意把所有槽当语义槽或位置槽，都会给出错误可行集。

## 3. 一旦功能区间已识别，三个接口可一起解析求解

设每个槽由上节得到允许频率区间`[vmin_k,vmax_k]`，与`(0,omega_k]`相交。
使用`nu_k=omega_k S^(-m_k)`，这等价于：

    a_k <= m_k <= b_k,
    a_k = max(0, log(omega_k/vmax_k)/log S),
    b_k = log(omega_k/vmin_k)/log S.

`vmin=0`对应`b=+infinity`。这里**不先锁m<=1**；否则已把/S写进可行集。
若另要求常用的单调压缩`m_0<=...<=m_(K-1)`，则定义：

    m*_k = max_{j<=k} a_j.

**定理**：可行解存在，当且仅当每个`m*_k<=b_k`。存在时，`m*`是所有可行解中
逐坐标最小者，因而是任意逐坐标严格递增Native改动代价的唯一最小解。

证明：任意可行m在k处必须不小于全部j<=k的a_j，故m_k>=m*_k。m*单调并满足
下界；满足全部上界就可行，否则任何更大的m都不能救回。逐坐标最小性给出结论。

**三个问题的条件解**：

- 高频保持区：`m*=0`的初始平台，来自实际约束何时激活；不预设32圈。
- 最低频终点：`omega_last S^(-m*_last)`；不预设m_last=1。
- 中间过渡：前缀最大值决定，不需要另猜抛物线或混合系数。

若要求固定两端，作为额外上下界加入即可。若上界交集为空，输出的是该已声明
功能合同与单调族不相容，不能推成整个RoPE空间无解。所得轮廓不一定平滑；平滑
若被加入就是额外偏好，不能冒充计算结构强制要求。

可证明的Native保护量包括单槽连续lag算子差的最坏值：

    E_k(nu;L) = sup_(0<=d<=L) ||R(nu*d)-R(omega*d)||_2
              = 2 sin(min(L*|omega-nu|,pi)/2).

在`0<=nu<=omega`上，频率越接近Native，这个最坏值不会增大；超过pi后上界饱和，
不再提供严格排序。这不是实际任务损失，也不是固定某个lag的单调性。

**本节状态**：解析问题已经解出；当前没有识别出的checkpoint功能约束输入，
所以没有装作得到一张OLMo/Llama最优表。历史Fisher、KL、NLL和margin失败不应被
重新包装为这些输入。没有因此安排全层capture平台或新GPU搜表。

## 4. 可以现在直接执行的理论结论：固定m不是固定z

这是针对当前8×实验的确定构造，不依赖上一节尚缺的功能识别。

设Native band的log跨度为`A=log(omega_l/omega_h)>0`。几何Native网格上
`log(omega_l/omega_(l+q))=A t`。保持快端`omega_l`、慢端`omega_h/S`，定义band
内部归一化log坐标，特意记为u以区别整谱z：

    u_S(q) = log(nu_l/nu_(l+q)) / log(nu_l/nu_h)
           = (A t + log(S) m_S(q)) / (A+log(S)),
    u_S-t = log(S)/(A+log(S)) * (m_S-t).

只要`m!=t`，冻结m并增加S就改变u。mix075满足每个内部槽`m>t`，因此增加S
会进一步把其u推离Native均匀坐标。当前S4→S8实验正确检验的是**固定指数生成
规则迁移**，不是“保持相同band内z形状只改长度”。它不因此失效。

**唯一保持u的跨倍率解**：从`S0`迁到`S1>S0`，

    alpha = log(S0)*(A+log(S1)) / [log(S1)*(A+log(S0))],
    m_(S1) = alpha*m_(S0) + (1-alpha)*t.

直接令两边u相等、解一次方程即得唯一解。因`0<alpha<1`，原来单调的m仍然
单调，原来0/1端点仍为0/1。连续迁移满足复合一致性：`alpha_02=alpha_01 alpha_12`。
这里的uni成分系数由Native跨度和倍率唯一决定，不是再搜一个mix。

对于非几何Native频率，令`t`改为`r_q=log(omega_l/omega_(l+q))/A`，同一解仍成立。
更基本的写法是：给定两端和内部u，`nu_q=nu_l^(1-u_q)*nu_h^u_q`唯一确定表。
这是坐标迁移结论，不主张这个已知log插值关系本身是新颖贡献。

Llama `[16,34]` 从4×到8×：

    A=3.690664700, alpha=0.757685348,
    m8_u = 0.757685348*m4 + 0.242314652*t.

中点指数从直接迁移的0.677631579变成0.634588845，所有内部频率更快，最大加速
约9.56%；两侧平台按同一个8×合同完全相同，gain不变。

**严格事前预测**：

1. u与4×父表相同，误差仅来自数值实现；直接冻结m的u最大偏移约0.015831。
2. 每个内部槽更接近Native，连续lag单槽算子最坏偏差不增加；不能承诺FWE上升。
3. 每个内部槽目标端相位更大，因此不是“同时免费提高覆盖与保留”。
4. 改善若存在，只能归给这个确定的中频变更；band、tail与gain被控制。

整谱归一化z不等于u。要求整谱z完全固定，会迫使快频平台也变化；不能同时宣称
保持高频平台与整谱z不变。对当前问题③，u是两端给定后的正确局部坐标。

### 实际参数的反检：上界在所有中频槽上饱和

不能只证明上界不增加，还要代入实际参数。Llama Native L=8192时，迁移后全部
17个内部槽的`L|omega-nu|`仍大于pi，最小也为8.2083；所以每个槽的上述最坏
算子差都为2，与直接m迁移相同。OLMo也全部饱和（最小7.5890）。Qwen几何的
合成S4→S8检查同样如此，但Qwen实际本批是S2，不能冒充其8×结果。

因此**这个上界不能为当前Native任务提供任何严格改善证书**。固定u公式是
有意义的变量控制，却不是已完成的性能设计理论；不得仅凭“更接近Native”启动
新改进实验。原来的0.75父表也是经验选择，迁移公式没有倒推它最优。

## 5. 怎样让现有数据裁决，而不是继续猜

先查已有表是否与上述u迁移解逐槽相同；可复用就不重跑。旧“full-z scale flow”
或“固定m组合律”名称不能替代数组比较。CPU验证只证公式，不算模型预测通过。

只有当作者需要区分固定m与固定u迁移时，这项理论识别对照才有明确用途；不能把
它默认排成“预计恢复Native”的改进队列。若决定执行，唯一新增臂就是上述8×表；对照为现有同gain的直接m
迁移表，复用相同prompt与scorer，先同时覆盖Native和目标端，不只挑FWE。已有
BM/MrPro等正式基线继续复用。这里没有授权新增预算，也没有自行启动远端运行。

结果应回答具体命题：

- 若Native改善、长端保持：支持固定u迁移比固定m迁移更合适，构造规则冻结。
- 若Native改善、长端下降：量化了该中频迁移取舍，不能称全面改进。
- 若Native不改善：几何Native偏差上界不足以预测该任务，不能增加uni权重追赢家。
- 若两端无明确差异：该比较未识别行为优势，不以CPU恒等式宣称获胜。

这些不是事前保证任务正负，而是事前确定的构造、数学性质和可否定的行为推论。
任务有效性仍需实际模型决定；绝对保证不能通过省略内容和下游计算获得。

## 6. 与旧路线和论文的关系

本轮最新Sol CPU回执（Qwen S2，尚未由本任务复算raw）已给出明确比较：累计18/格
候选AUC79.722，BM75.839，差+3.883pp，配对95%区间[+0.810,+6.932]；对MrPro差
+2.141pp，区间[-1.319,+5.594]；对C42差+2.288pp，区间[-0.296,+4.967]。独立追加
12/格的三项AUC差区间全部跨0。准确结论是累计开发+确认面板对BM有正证据，尚未
独立确认对MrPro/C42的优势，不是全面胜出。累计区间不能消除首批选择暴露。

| 路线 | 已有状态 | 本文处理 |
|---|---|---|
| 一圈/32圈、OOD/SEP | 有数学定义，任务排序出现反例 | 不用作唯一性能目标 |
| uniqueness + quadratic、Fisher、replay KL | 已有条件最优解或代理失败 | 不再换名字启动 |
| 完整答案margin | 路径判据正确，CAL迁移未成功 | 不作为本次新构造入口 |
| 固定m跨S | 本批实际已测 | 正确登记为固定生成规则迁移 |
| band内固定u跨S | 本文解析构造、CPU通过 | 查已有等价表后再决定一臂验证 |
| 功能相位区间 | 条件定理与解析解 | 缺checkpoint功能识别，不伪装已完成 |

论文仍以固定支持的z发现、EVQ、full-z及成熟模型结果为主线。已有几何定理说明
位置函数空间如何改变；现有成熟结果说明冻结权重下存在收益和代价；本文补上
“固定分配”与“固定缩放生成规则”的区别，并把band/tail的功能条件写成可求解
约束。不能把这几部分加起来冒称已经证明mix075全模型最优。

MrRoPE的算术递增是明确构造假设，随后验证推理期效果；其比较本身就是无微调，
所以本项目static YaRN频率控制不是因无训练而自动不值得比较，但仍要匹配gain、
runner、模型和benchmark。[MrRoPE §3.2–4.1](https://arxiv.org/html/2601.22181v1)

LeRoPE在其训练模型中观测到抑制性频段窗外变号，并用只插值该频段减轻外推PPL
问题；这支持研究功能区间，不证明本项目的每个checkpoint具有同样频段。
