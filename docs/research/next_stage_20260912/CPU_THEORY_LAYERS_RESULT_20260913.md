## 1. 权重级 per-slot engagement（无数据、无前向）

对每个 rotary pair (i, i+hd/2) 取 Q/K 投影范数积（GQA 感知、逐层平均）：

| 槽组 | OLMo-2-1B | Llama-3-8B |
|---|---:|---:|
| fast bank（0–13，全部表钉死） | 0.59x | 0.56x |
| transition band（14–32） | 0.85x | 0.91x |
| slow plateau（33–63） | 1.28x | 1.26x |

- `corr(log U, log turns)`：OLMo −0.958、Llama −0.907——engagement 单调偏向慢端；
  最快的槽（0–4）承载最低。
- **跨模型 log-usage 相关 r = 0.970**。同 (B=5e5, K=64) 网格的两个模型，逐槽
  承载结构几乎相同——这是 OLMo 拟合剖面能跨模型迁移的 usage 层解释。
- 旧 output-Fisher 尖峰槽 24/35 在 engagement 上无异常（秩 43/64、30/64 与
  11/64）：Fisher 测的确实不是 pair 承载，为它的死因补了机理注脚。

## 2. 激活级相位核（hook q/k pre-RoPE，c_i = q_i·conj(k_i)）

单篇短文本探针（OLMo 512 token、Llama 384 token；非任务条件化普查）：

- 激活 |c| 同样集中慢端（plateau 1.34x / 1.5x+），与权重 U 相关 0.738（OLMo）
  ——权重代理被验证有信息。
- **Δ-结构（核对比度）集中在带缘/平台头部**：OLMo 峰区槽 21–42（窗内转数
  8.8–0.12），Llama 峰区槽 33–46（转数 1.5–0.4，槽 40 为疑似 attention-sink
  伪影，|c|=508，待排除 sink 后复核）。
- **两模型的核对比度剖面相关 ≈ 0（−0.025）**：哪些槽真正携带位置信息是
  模型特异的。这给出"单一普适曲线不存在"的定量版本：三层中几何与
  engagement 跨模型守恒，位置结构层模型特异。
- 承载 ≠ 位置信息：深平台（40+）高承载、低对比度（0.17–0.24）——它们窗内
  核近 Δ 平坦。这正是 SLACK（带内重分配窗内代价噪声级）的微观解释；而同一批
  槽在 Δ→sL 时相位首次扫过训练未历区间，其暴露状态决定远端成败。

## 4. 落点

- 论文理论章的三层分解现在每层有仪器与数字：几何（解析）、engagement
  （权重扫描、跨模型 0.970）、位置结构（激活核、模型特异 ≈0）。
- 对 P6/P7 的预注册建议：剂量臂上加两条预测——(i) 深槽暴露 (E-1) 与 64K
  分数方向；(ii) 对比臂的分岔日程（最小 X* 于深载体）预测差异出现长度。
- 边界：engagement 为幅度代理（无相位结构）；激活核为单短文本探针、含
  疑似 sink 槽，任务条件化 usage 需更长自然文本并排除 sink；全部零 GPU 可复算。

## 5. Winding-Matched 相位新颖性审计（WM0 之上的增量）

在 codex WM0 回执（边界/有序/整数绕圈/FP32 残差成立，sum(m)=19.92 复现一致）
之上，本仪器补测 WM 相对已有全部构造的新维度——**相位新颖性**：

- 斜率结构：槽 0–34 斜率 ≈ 0.999–0.94（几乎不减速，任意长度相位 ≈ Native，
  零新颖性）；槽 46–63 满额 PI（部署相位域收缩回训练弧内，零新颖性）；
  **唯一呈现训练未见相位值的是绕圈区槽 36–44**（n*∈{1..5}、r_i<1），未见弧
  占圆周 0.19–0.84（修正初版指标：n*=0 的满 PI 槽不产生新颖性）。
- 与激活核峰区（33–46，本模型的位置信息载体）重叠：WM1 的赌注恰好押在
  最有信息量的槽上。预注册预测：若 WM1 在中间长度出现弱点，优先检查依赖
  36–44 槽核的任务；若全区间强，则说明核以相位值而非相位-距离斜率为主，
  斜率式覆盖（BM/PI 语义）不是必要条件。
- 与 BM 的对照：BM 使 42 个槽斜率偏离 >20%；WM 只有 22 个。WM 是
  "Native 保持优先"的极端：以端点同余（绕圈）而非斜率压缩提供远端点，
  把斜率式覆盖与同余式覆盖变成可判决的二分。
- 未做：WM-vs-BM 分岔日程（`wm_audit.json` 已含全部 α 场，可直接算）；
  该日程预测 WM 与 BM 的分数分歧出现长度，建议与 WM1 同批预注册。
