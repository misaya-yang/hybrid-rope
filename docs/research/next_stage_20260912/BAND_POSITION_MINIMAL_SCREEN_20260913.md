# Band 位置最小筛选：Llama、OLMo 与 Qwen 统一假设

更新：2026-09-13。本页是固定 C42 内部累计形状、只改变 transition band 的
分钟级零训练实验 owner。结论只限锁定开发面板；“当前最佳”不等于模型级或文献
SOTA。

## 问题与协议

这轮不再接受 YaRN 的 low/middle/high 边界为前提。每张候选仍写成

\[
\omega'_k=\omega^N_k S^{-m_k},
\]

但 `low/high` 是实验变量。每个 arm 在所有层和所有运行长度使用同一张表；模型
权重冻结，内部 C42 shape 与目标倍率对应的标准 gain 保持不变。主判据分列为：

- passkey/NIAH 的 RULER official contains 分数；
- 自然文本 PPL/NLL；
- QA 只作额外能力族诊断，不混入两项 NIAH 主宏平均。

PPL 不替代检索；小面板单任务交叉不作为删除 Pareto 点的门禁。

## Llama-3-8B-Instruct

模型 Native 长度 8192，RoPE base 500000，head dimension 128、64 个频率槽。
生成面板为 `niah_single_1`、`niah_multikey_1`、`niah_multivalue`，每个长度和
任务 4 行；PPL 使用两篇固定 PG19 文本。

## 冻结迁移到 OLMo-2-1B

OLMo Native 长度 4096，但同样使用 base 500000、head dimension 128 和 64 槽。
Llama S=4 胜者 `[16,34]` 的 FP32 表和 gain 原样安装到 OLMo；没有重映射、重构或
OLMo 调参。生成复用既有 `internal_confirm` 的相同 36 行，PPL 使用历史 16 篇
自然文本、tail-512 口径。

| 固定表 | NIAH 4K / 8K / 16K | QA2 4K / 8K / 16K | tail-512 NLL 4K / 8K / 16K |
|---|---:|---:|---:|
| BM | 100 / 75 / 75 | 75 / 75 / 25 | 2.9551 / 2.9549 / 2.8621 |
| MrPro | 25 / 0 / 0 | 50 / 25 / 0 | 3.2106 / 3.2565 / 3.6880 |
| OLMo C42 `[14,32]` | **100 / 87.5 / 75** | 50 / **100** / **50** | **2.9219 / 2.9312 / 2.8301** |
| Llama赢家 `[16,34]` | 100 / 62.5 / 50 | **75** / **100** / 25 | 2.9484 / 2.9682 / 3.2420 |

直接迁移没有泛化成 OLMo 赢家：相对 BM，8K/16K NIAH 为 -12.5/-25pp，16K NLL
为 +0.3800 nat；相对 OLMo `[14,32]`，16K NLL 为 +0.4119 nat。16 篇文档配对
bootstrap 中，`[16,34] - BM` 的 16K NLL 95% 重采样区间为
`[+0.3055,+0.4626]` nat，16/16 篇均更差。它在 8K QA 上仍有收益，因此结论是
能力族交叉和跨模型失败，而不是“表完全无效”。

> OLMo 当前最佳 basin 为 `low=14, high=31--32`；点估计 `[14,31]`，但现有
> 证据不能区分 high=31 与 32。

high 在 31/32 间不改变这批生成。`[14,30]` 和 `[14,33]` 都使 16K NIAH下降，
因此局部停止，不扩大网格。

## 为什么固定槽位/单一winding还不是通用公式

单层 attention 可局部写成

\[
a(d)=\sum_k \operatorname{Re}(C_k e^{id\nu_k}),\qquad
\nu_k=\omega_k S^{-m_k},
\]

从而

\[
\frac{\partial a}{\partial m_k}
=\log S\,d\nu_k\operatorname{Im}(C_k e^{id\nu_k}).
\]

导数符号随距离、任务、层、头和 checkpoint 的内容系数 `C_k` 改变。它解释为何
band 移动会产生非单调、任务交叉和模型差异；这是机制假设，不是最优性定理，
也不等于已经证明不存在跨模型、跨倍率的条件化坐标。

若用 Native winding 数

\[
r_k=\frac{L\omega_k}{2\pi}
\]

跨模型等值映射，则

\[
k_T=K\frac{\log(L_T/L_S)+(k_S/K)\log b_S}{\log b_T}.
\]

OLMo `[14,32]` 映射到 Llama 约 `[17.38,35.38]`，接近 YaRN 几何边界，却不是
实测小面板最佳 `[16,34]`。绝对槽位也预测失败；波长相对窗口只是 winding 的
倒数，并非独立信息。几何适合提出少量候选，但统一规律还必须显式包含目标倍率S
与checkpoint谱敏感度。另外，同宽 band 整体右移会同时减少总 `sum(m)`，所以
当前结果判的是完整部署 profile，尚未把 placement 与压缩剂量完全分离。后续的
Native窗相位预算与两边界假说见
[两边界理论草案](TWO_BOUNDARY_BAND_THEORY_20260913.md)。

## Qwen 最小统一判决（历史预注册）

服务器已有 Qwen2.5-1.5B：配置 Native 32768、base 1000000、head dimension
128、64 槽，无配置级 rope scaling。tokenizer 的 `model_max_length=131072` 不能
替代训练曝光证据。

下一轮固定 S=2、统一标准 gain，只跑四张 C42 profile：

| band | 来源 | 能区分什么 |
|---|---|---|
| `[14,32]` | OLMo 绝对槽直搬 | 槽位身份是否压倒窗口/base几何 |
| `[16,34]` | Llama S=4 最佳槽直搬 | Llama局部偏好是否能迁移 |
| `[22,39]` | Llama最佳按等 winding 映射 | Llama到Qwen的相对Native相位假设 |
| `[23,40]` | OLMo等 winding 映射，亦接近Qwen自身YaRN几何 | 本地波长边界假设 |

第一轮只使用 32/64K、固定前 4 行的 passkey/multikey NIAH，以及两篇固定自然
文本；64K生成是主判据，32K负责 Native 保留，PPL只辅助诊断。最佳两臂才补剩余
行。无论结果如何，都不能从一个 Qwen checkpoint 推出普适 band 定理。

这四臂已经完成；点估计与64K扩充结果由
[跨模型、跨倍率机制研究](BAND_NEXT_STAGE_RESULT_20260913.md)维护。它们没有覆盖
后来由OLMo+Llama留一推出的Native窗相位预算预测`[20,38]`，所以不能把原四臂
解释为所有统一坐标的最终判决。候选冻结后的统计确认不继续使用4行点估计；统一
升级到[RULER四级评价合同](RULER_TIERED_PANEL_CONTRACT_20260913.md)。
