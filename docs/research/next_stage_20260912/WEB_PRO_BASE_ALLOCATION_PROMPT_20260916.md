# 给 Web Pro：RoPE base 如何改变内部配置的作用

请研究一个具体问题：**较大的RoPE base是否会削弱改变内部频率配置z的收益？如果会，在哪些条件下；如果不成立，正确的理论表述是什么？** 我们需要能解释现有现象、指导少量判别实验并有潜力进入论文的分析。

## 研究对象与构造

对K个旋转对，原生频率为ω_k=b^(-k/K)。将x_k=-logω_k写为x_k=a+Rz_k，其中R是实际采样频率的log跨度，z_0=0、z_(K-1)=1。几何原生表有R=(K-1)log(b)/K、z_k=k/(K-1)。因此base与内部配置是不同设计变量。

冻结模型扩展采用ν_k=ω_k s^(-m_k)，两种方法保留相同高频段、相同低频/s尾部和gain。过渡band由原生长度L下的32/1-turn边界确定：l是最后一个ω_kL/(2π)>32的槽，h是第一个小于1的槽；n=h-l，q=clip(k-l,0,n)。

MrRoPE-Pro：m_P(q)=q(q+1)/[n(n+1)]。

TailSpline：m_T(q)=q(3n²+3n+1-q²)/[n(n+1)(2n+1)]。

其差为q(n-q)(3n+q+1)/[n(n+1)(2n+1)]。两法波长之比为s^(m_T-m_P)。TailSpline是离散目标sum(ε_(q+1)-ε_q)²+ε_n²在sum ε=1下的唯一解，ε_q=m_q-m_(q-1)。构造不读取权重、Q/K/V、激活、梯度或校准分数。

## 已有结果：T/P分别指TailSpline/MrPro

- Llama S4：clean16K Full-13，650对，86.09/82.71%，+3.39pp；clean32K，2600对，68.27/56.54%，+11.72pp。
- OLMo S4：clean16K Full-13，2600对，50.65/9.23%，+41.42pp；Natural-QA631，24.92/21.62 F1，+3.30pp，文档簇区间为正。
- Llama S16、128K：Full-13×10，22.05/1.28%，+20.77pp；10篇ProofPile PPL2.5870/2.6714。
- Qwen3B S2、64K：NIAH-8×5，86.25/80.63%；S4、128K：72.50/73.13%。Qwen1.5B S4、128K：81.25/76.88%。这些小面板任务区间均跨零，不能先给模型收益定性。
- Qwen3B S4的三项single任务均5/5，MK3均0/5；MQ/MV的正差被MK1一条失分抵消。两法40条中32条同分，但只有5条输出文本完全相同。
- 同为S4时，Llama和Qwen的n都是17，max s^(m_T-m_P)=1.7656，sum(m_T-m_P)=4.6095。目标4L处max d|ν_T-ν_P|为Llama108.20rad、Qwen117.16rad。因此不能直接说Qwen的几何干预更弱。

这些结果跨模型、倍率和面板，不能当作base单因素实验，也不能将RULER Full-13与NIAH-8直接合并比较。
