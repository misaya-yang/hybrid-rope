## 2. 通用预算与执行合同

### 2.1 吞吐：哪些实测，哪些不是

P2 §2.2 记录：4080S、151.9M、实际 2K、Flash-only BF16，丢弃编译步后的资格检查吞吐为 **69,055 tokens/s**；正式 Geo 稳态约 **74K tokens/s**；峰值显存 **11,791,566,336 bytes**，约 11.79 GB 或 10.98 GiB。5090 的约 **183K tokens/s** 来自旧 **L=256** trainer，不能直接作为 2K full-z 的工期。Pro 6000 没有该仓库实测吞吐。（均为[材料]。）

用于下面算术的训练假设：

| 机器与路径 | tokens/s | 身份 |
|---|---:|---|
| 4080S，2K fixed Geo | 74,000 | 附件实测近似 |
| 4080S，2K fixed Cosh | 74,000 | 假设与 Geo 相近 |
| 4080S，2K learned full-z | 60,000 | 假设 |
| 5090，2K fixed Geo/Cosh | 120,000 | 假设 |
| 5090，2K learned full-z | 90,000 | 假设 |
| Pro 6000，4K fixed / learned | 60,000 / 45,000 | 假设，仅 E9 |

以下推理吞吐**全部是假设**，必须在匹配 precision、batch、attention backend、缓存及实际长度的条件下重测：

| 模型 / 阶段 | 长度与吞吐 |
|---|---|
| 151.9M teacher-forced 评价 | 2/4/8/16/32K：50K/40K/25K/15K/8K input tokens/s |
| 432M MLA teacher-forced 评价 | 8/16/32K：20K/12K/6K input tokens/s |
| OLMo 冻结生成 prefill | 4/8/16K：6K/4K/2.5K input tokens/s |
| OLMo 冻结生成 decode | 60 output tokens/s |
| Llama-3-8B prefill | 8/16/32K：2K/1.2K/0.6K input tokens/s |
| Llama-3-8B decode | 40 output tokens/s |

这里的 decode 吞吐是实际配置的总输出吞吐；不能把单请求速度乘以 batch size 当成批量实测。推理计时应覆盖原生全词表输出头；仅需答案位置 logits 的因果诊断另记路径。不得通过缩掉全注意力窗口来满足预算。

### 2.2 预算公式

每条正式训练轨迹：

\[
T=999,948,288\quad\text{processed input tokens}.
\]

\[
H_{\rm train}=1.15\sum_i \frac{T_i}{3600q_i}.
\]

其中 15% 是[假设]的编译、保存与轻量执行开销。生成评价：

\[
H_{\rm eval}=1.20\sum_L\left(\frac{I_L}{3600q_{{\rm prefill},L}}+
\frac{O_L}{3600q_{{\rm decode},L}}\right)+H_{\rm load}.
\]

20% 是[假设]的执行余量，固定加载费用另列。**即使只评分末 128 tokens，输入仍必须经过完整长上下文，不能用 128 作 prefill 工作量。** E7 的插桩额外乘 1.5，单独明示。

可下载计算器 `rope_budget_20260912.py` 与同名 JSON 保存每个实验的分子、吞吐和按机型小时。只修改吞吐/价格假设即可重算；它不会启动任何训练。

### 2.3 机器资格门和已有合同保护

4080S 当前链继续：B=500000、seed42 三臂→既定评价→seed137 三臂→既定评价。5090 承接 B=2048 的三 seeds 共九臂，再承接 B=500000、seed256 三臂。（P2 §2.1、§5。）

新机先用丢弃式资格检查测 fixed 与 learned 两条路径，不只测 Geo。检查初始化权重、真实端点、排序、uniform 初始化前向、位置参数的有限梯度、实际更新以及跨 optimizer step 的缓存计算图。允许个别梯度为零；不要求 softmax 的每个坐标每步都非零。判定的是整条学习路径没有被 detach 或缓存切断。

**缺失但必须继承的配置：**P2 没有给出当前 2K 正式训练的全部 resolved args，包括 full-z 参数组 LR、其 weight decay/clip、精确 global token batch、全部 scheduler 细节。必须从当前正式作业配置读取并冻结；不得直接把 P1 旧 256-window 的优化器设置当成新作业配置，也不得依据本计划临时改正在跑的合同。

每个 support×seed 的全部比较臂必须在同型号 GPU、同软件栈完成。E6 新增的 Cosh-init 臂也跟随原配对块，不能把所有新增臂扔到 Pro 6000 后与旧 4080/5090 臂直接比较。不同支持块存在硬件构成差异，因此跨 support 的训练差异作为分层结果呈现；真正无硬件混杂的运行范围干预由 E5 在同一 checkpoint 上实现。

32GB 的 5090 并不自动排除 8B BF16 推理；约 16GB 的权重字节量只是内存的一部分，是否容纳目标 KV 与中间激活要实测。类似地，不能由 2K 峰值显存直接断言所有 4K 配置都必定超过 16GB。Pro 6000 优先承接长上下文和复杂插桩，是为了稳定容量，不是已经证明的必需条件。

### 2.4 统计与停止通则

训练实验以**配对训练 seed**为重复单位，评价文档/pack 是 seed 内观测。所有 1B 正式臂完成，不按 500M 或某个 seed 的 OOD 输赢取消后续。训练输出保存 500M 和 1B，但 500M 是同一 1B schedule 的中点，不能冒充旧 500M 终止 schedule 的复现。（P2 §7。）

生成实验优先配对、按任务分层；同一文档的多个 QA、同一基础案例的距离/反事实版本作为一个重采样 cluster。任务平均先按任务算，再等权宏平均；不将更大的任务样本数变成更大的任务权重。

默认报告点估计和 95% 区间；多项“优于对手”的正式宣称使用预指定 contrast family 的 Holm 校正。三 seeds 要展示逐 seed 值；三次同向不自动等于显著。以配对 t 区间为参考时，n=3 的 95% 临界值约为 4.303，而不是 1.96；基于文档的窄区间只描述固定训练对上的评价变异。

本计划采用以下**设计性**尺度，均不是业界标准：NLL 的实用差异参考值 0.02；任务收益参考值 3 pp；明确的正向结构确认参考值 5 pp；短窗 PPL 成本参考上限 3%，对应 \(\Delta\mathrm{NLL}=\log(1.03)\approx0.02956\)。它们用于解释效果大小，不作为看到阴性后停止完整合同的借口。若声称等价，必须检验区间落入事先指定的等价带，不能用 p>0.05 代替。

技术停止限于数据泄漏、身份错误、梯度/表更新异常、非有限损失、显存或稳定性问题；停止的是有问题的工程运行，不记为方法阴性。硬截止时未完成的比较标记 pending，不用 smoke、中间点或部分 seeds 替代。

## 3. E0：版本、数据与实现审计

**科学作用。**这不是一项要拿来宣称贡献的实验，而是使后续对照有可解释性的前置条件。P1 最后一页记录，同名 BM 后续运行出现 24/350 行评分、210/350 段生成文本不同；因此仅核对方法名称不够。（P1 §G.11，第49页。）

**设计。**建立实际 PDF—源码 commit—checkpoint—runtime frequency tensor—gain—数据 manifests—scorer 的关联记录。校验 P1/P2 SHA 差异；记录变更但不假定其原因。分别追回旧 151M 绝对评价四格、六个 MLA checkpoints 和新实验将用的原始生成配置。旧 151M 数字只存在配对差时不反解绝对 NLL；checkpoint 可用则原 32 anchors 重评，作为“同协议重评”标记，不能声称追回原文件。（P1 §B.1；P2 §3.3。）

频率表记录构造函数、参数、网格类型、实际 FP32 tensor SHA，而不是只写 base/方法名。每个请求 prefill 前安装表并保持整个 KV 生命周期不变。YaRN 记录具体实现版本与实际计算路径；固定-index ramp、wavelength blend、官方 channel-index ramp 不能混称。（P1 §D.3、E.1、G.8；P2 §7。）

**机器和预算。**CPU 人工排查[假设]4–8小时；新 5090 与一台 Pro 各预留1 GPU·h。已有 4080S 不插入新 qualification。若同一机型存在不同驱动/软件版本，按新配置处理。

**主终点。**所有正式比较能追溯到精确输入、输出、模型和表的身份；已知缺失项目有明确状态，不要求不可能追回的历史文件才能推进所有新实验。

**停止与分叉。**定向追档给每类资产约2人工小时的第一轮上限[设计]，避免无边界搜目录。发现实现不一致则先修工程，再启动受影响新实验；资产不可达则使用对应 B 计划，不编造已完成状态。成功只说明证据可审核，不为任何方法增加一分性能。

## 4. E1：MLA 独立语料复评

### 科学问题

三 seed MLA 长度收益能否在真正独立的评价语料上重现？现有 16K 的 138.8→95.6 来自旧共享缓存，准备过程不能认证训练文档隔离；这是摘要级数字的首要补证点。（P1 §E.1、Table 16，第34–35页。）

### 设计与合同

使用现有 Geo/Cosh × seeds42/43/88 的**六个最终 checkpoints**，不重训。每个 checkpoint 同时评两种已存在运行策略：保留其原训练表；对其原表施加同一个论文 wavelength-blend，s=4。该 blend 不命名为官方 YaRN。

固定 8/16/32K 三长度、64 个文档级独立长 pack[设计]。长 pack 的文档不能同时出现于其他 pack；文档有多问题时以文档为 cluster。每个32K pack产生嵌套长度评价；全序列 NLL 是复评主口径，另保留同目标尾部评价作为辅助而不替换主口径。tokenizer、EOS/拼接规则与原评价明示，避免更换 tokenizer 后直接比较绝对 PPL。

独立性必须相对于**全部训练与选型文档的并集**检查，不只是“新文件名”或“另一个 shard”。若训练清单不足以做此证明，可使用有可核查时间/来源证据的新外部语料，但名称应是跨分布复评，不包装为同分布独立 holdout。当前模型训练已经结束，因此与原先不同的、未参与选型的新评价集可以冻结后一次性开封。

### 主终点、样本量和统计

主终点：每 seed 的原表条件下 **16K 全序列 Cosh−Geo NLL**。先按每 seed 聚合 NLL，PPL 为该值的指数；三个 seed 的平均 NLL及逐 seed PPL同时呈现。若继续显示旧 Table16 的 arithmetic mean PPL，单列该统计定义，不混为 exp(mean NLL)。8K成本、32K及共享 blend 是次终点。

64 packs 的理由不是已有数据证明功效足够，而是以下透明的精度设计：若配对 pack 差的标准差约0.10 NLL[假设]，希望固定训练对内区间半宽约0.025[设计]，则 \(n\ge(1.96\times0.10/0.025)^2\approx62\)。所以预先固定64；它不解决训练 seeds 只有3个的问题。取消“看完32的区间再决定64/128”的临时扩样。若要128，必须在正式结果开封前根据资源与预先锁定精度目标改为128，并完整执行。

### 机器与吞吐换算

Pro 6000 一台。总输入量为

\[
6\times2\times64\times(8192+16384+32768)=44,040,192.
\]

用8/16/32K的20K/12K/6K input tokens/s[假设]，计算约1.54小时；加20%执行开销及1小时总加载，约 **2.85 GPU·h**。全部为规划值；数据下载、追档人工另计。checkpoint 之间顺序加载，不要求六个同时驻留显存。

### 停止条件与结果解释

达到固定64 packs × 全六 checkpoints × 两运行策略才闭合比较，不因先看到一个 seed 阴性而停。技术或数据独立性检查失败则暂停对应新评价。

**正结果：**把 MLA 从共享缓存压力测试升级为独立评价支持的较大模型构造结果；仍不将 midpoint 协议改写为固定端点因果识别。

**负结果：**若三 seed 的原表16K收益在独立集上消失/反转，不能继续用旧138.8→95.6作为独立泛化的主数字；保留旧实验身份，新结果成为主表，研究外部有效性的边界。它不否定另一个精确固定支持训练实验。

**区间宽：**报告未定，不宣称等价或稳定复现。

**B计划：**六个 checkpoints 不可达时，不临时重跑整个432M三 seed训练去赶摘要。将旧结果按原稿“shared-corpus stress test”留在支持证据；摘要优先使用已确认的固定支持与自然任务结果。部分 checkpoints 可评，但明确“可用子集”，不当成完整三 seed复评。

**入稿位置：**Table1、§5.3、§E.1；若新证据完整，再更新摘要数字。

## 6. E3：固定总位移 C42 结构对的独立确认

### 科学问题

在 sampled support、外段规则、transition band、总位移和increment质心都固定时，内部形状的差异是否仍能转化为完整生成差异？原来的+10.7286pp来自开发面板，确认这件事比再设计十个profile更有信息价值。（P1 §G.7，第47页。）

\[
p_r=\frac{6r(19-r)}{18\cdot19\cdot20},\qquad v_r=r-\frac{19}{2},

\[
\epsilon^A_r=p_r\left(1-\frac{10}{119}v_r\right),

\[
\epsilon^B_r=p_r\left(1-\frac{10}{119}v_r+
\frac{35}{1496}(v_r^2-\frac{357}{20})\right).

## 7. E4：完成已启动的实际 2K 固定支持三臂主实验

### 科学问题与不可更改的主合同

对同一采样范围，解析固定分配与直接学习内部z分别带来什么样的训练窗内—外推行为？这不是要求learned一定输或Cosh一定赢。

完整继承P2 §3.1：151,898,880参数、K=32、实际连续L=2048；B=2048和500000；seeds42/137/256；每个support×seed三臂，共18条轨迹：

| 臂 | 表 | 学习 |
|---|---|---|
| G | 固定Geo | 只学习模型权重 |
| C | 固定anchored Cosh，τ=√2 | 只学习模型权重 |
| L_G | Geo-init full-z | 学习模型权重与完整内部z |

full-z使用31个正gap的softmax参数化：

\[
g_j=\mathrm{softmax}(v)_j,\quad z_0=0,\quad
z_k=\sum_{j=1}^{k}g_j\ (k=1,\ldots,31).
\]

softmax共同平移是gauge自由度，因此有效自由度30。实际表按基准的**真实采样端点**构造 \(\omega_k=\exp[-a-Rz_k]\)，不是把未采到的 \(b^{-1}\) 当成最低频率。端点、K、gain均固定；参数跨层/头共享。记录每个保存点的gap、表及其实际变化，确认学习路径工作，但不以表移动幅度替代语言模型收益。

每臂999,948,288 processed tokens；它是冻结499,974,144-token前缀的两轮遍历，**不是约1B unique tokens**。所有臂同token顺序、初始化、预算与终止schedule；500M保存点只是共同中点。（P2 §3.1、§7。）

### 新统一评价

锁定128个互不重用文档的16K packs[设计]，不与train、calibration及其他选型集重叠。各长度2/4/8/16K使用共同结束位置：同一pack取不同长度的后缀，末128目标不变。全序列NLL评分有效普通文本targets，EOS/文档首token处理必须事前统一；再另列final128 NLL。使用32个独立calibration packs做技术检查，不拿正式128 packs调学习率或τ。

主终点在1B处，每个support分别定义：

\[
\Delta_{b,s}^{A-G}=\frac{1}{3}\sum_{r\in\{2,4,8\}}
[\mathrm{NLL}_{A,b,s}(rL_0)-\mathrm{NLL}_{G,b,s}(rL_0)].
\]

主NLL口径为全序列，A=C或L_G；同目标final128为关键一致性检查。分别报告三个seed，不能只报两个support混合后的胜率。C−G与L_G−G在两个support形成四个预指定主要对照；若做“显著改善”的综合宣称，对该family校正。C−L_G、500M→1B差异与几何诊断为预指定次分析。

窗内NLL、3%PPL成本参考线与逐长度结果必须同图显示。2B式覆盖、外推不同倍率不混成唯一总分掩盖窗内损失。

\]

## 8. E5：原始训练表 crossing、范围交互与系数诊断

### 科学问题

模型学到的是抽象“更高rank”，还是与具体表和运行范围共同适配的使用方式？P1的151M crossing使用了从训练表另外派生的factor-four表；新实验直接使用训练结束的原始表，避免把派生算法也放进crossing。（P1 §B.2，第26页。）

### E5a：直接3×3 crossing

使用E4全部1B checkpoints。对每个support×seed，把三个冻结权重 \(W_G,W_C,W_{L_G}\) 与该seed的三张原始训练表 \(T_G,T_C,T_{L_G}\) 完整交叉。gain=1、端点不动、使用同一128 packs及2/4/8/16K长度。三条对角线复用E4同身份结果，只新增六个off-diagonal。

主比较为Geo/Cosh crossing，逐seed定义：

\[
S_G=L(W_G,T_C)-L(W_G,T_G),
\]
\[
S_C=L(W_C,T_G)-L(W_C,T_C),\qquad I=S_G+S_C.
\]

同时报告两个swap penalty与interaction。**I>0本身不证明两个模型都偏好自己的表**，因为其中一个很大的惩罚可能覆盖另一个负值。learned对应的crossing作为次比较；不选最灾难的错配格做唯一图。

### E5b：同权重运行范围干预

预先固定第二种range规则，不调参：

\[
B_{\rm run}(L)=B\frac{L}{L_0},\quad
R_{\rm run}(L)=R+\frac{K-1}{K}\log\frac{L}{L_0}.
\]

最快频率保持，z保持，每个1B checkpoint在4/8/16K比较保留原range与上述retarget。B=L0时它恢复旧识别实验的target-base形式；B500000块则是同一个乘法base规则。它不是YaRN，也不被预设为最优扩展。

主分析是同一权重、同一输入下的allocation×runtime-range interaction。有没有反转都完整报告；没有反转也不能据此否定旧256模型上已经观测的反转。

### E5c：供给几何与实际系数分开记录

CPU计算每张表在uniform距离、causal-triangular距离、预先固定的任务证据距离分布上的raw Gram、block-whitened overlap、去除span{1,t}后的剩余谱。小相位时使用数值稳定的sinc/重标度基和固定精度策略，避免求逆病态误差成为“rank变化”。

用固定内容q/k做phase-only诊断。写 \(x_k=\omega_kL\)、\(t=\Delta/L\)，某固定内容对贡献

\[
f(t)=\sum_k[C_k\cos(x_kt)+D_k\sin(x_kt)].
\]

直接由Taylor余项得到：

\[
\left|f(t)-\sum_kC_k-t\sum_kD_kx_k\right|
\le\frac{t^2}{2}\sum_k|C_k|x_k^2+
\frac{t^3}{6}\sum_k|D_k||x_k|^3.
\]

这是带实际系数的诊断界，不是PPL界；内容系数在真实移动证据时会改变，不能把固定q/k的phase-only曲线冒充完整任务机制。主用途是区分“方向重合”与“该方向实际可产生多大信号”。P1已经明确raw λ−与whitened几何不同。（P1 §A.1，第16页。）

增加一次“频率与Q/K块同步置换”的功能阳性对照：在Q/K归一化之后、RoPE之前施加补偿，处理GQA共享映射；允许与no-op同量级的浮点误差。只换频率与同步换块是两个不同干预。此恒等式核验是实现检查，不另算经验发现。

### 机器、预算与停止

Pro 6000。新增off-diagonal输入141,557,760 tokens，约3.90 GPU·h；range复评新增66,060,288 input tokens，约1.17 GPU·h；系数/激活采样预留1 GPU·h[假设]。总约 **6.07 GPU·h**，几何计算CPU另预留2–4小时[假设]。

checkpoint缺失则等对应完整块，不能只展示已完成且错配最强的seed。若补偿置换不恢复no-op水平，先修实现，不能解释为模型机制。几何方向预测被输出否定时保留反例，不再为结果临时改距离权重。

**正结果：**原始表crossing支持学习兼容性；同权重range interaction支持运行尺度与分配的耦合，且比跨硬件训练比较更直接。

**弱/负结果：**若wrong table同样好，说明该强度和训练预算下兼容性不强；若更高rank没有更低NLL，说明纯几何不足以选表，而非几何恒等式错误。不能用可证明的算子不等价替代经验风险差。

**入稿位置：**§4和主图crossing/range两面板；数值诊断放附录，只有形成并通过模型层检验的预测才升为机制贡献。

## 9. E6：Cosh-init full-z，补齐2×2设计

**科学问题。**解析Cosh的作用是一个固定表先验，还是也能改善直接学习的初始工作点？三臂设计没有Cosh-init learned，因此不能区分初始化和允许学习的交互。

**设计。**在每个E4 support×seed补一条Cosh-init full-z，共6条。初始模型权重仍与原三臂完全相同；gap logits用锚定Cosh相邻gap的log初始化，并去掉无效共同平移。其余学习路径、参数组、1B processed-token合同与评价完全继承。

形成Geo/Cosh初始化×固定/学习四格。主终点为每support三seed上的初始化×学习交互、以及 Cosh-init learned−Geo-init learned 的窗内/OOD对比。最终表接近程度是次终点。该四格能识别初始化和学习处理的效应，但**不能单凭最终表相似就分离全部优化路径效应**；严格区分最终表本身与训练路径需要新初始化下固定最终表重训，本轮不默认增加该重训。

**机器与预算。**新增的B500000 seed42/137留4080S，60K tok/s假设，含15%约10.65 GPU·h；其余四条放对应5090，90K tok/s假设，约14.20 GPU·h；新增两个checkpoint评价约1.30 Pro GPU·h。合计 **26.14 GPU·h**。

**停止。**在E4新结果开封前决定完整六条是否纳入；纳入后不能只补Cosh不利的support或seed。若2K主实验发生共同实现错误，先解决该错误；不另外定义更有利的新增臂优化器。

**正结果。**Cosh-init learned优于Geo-init learned，支持解析构造作为初始化先验的价值；Cosh-init学到另一有效表也说明固定解析表不是唯一可用点。

**负结果。**两初始化在可判别精度下收敛到同样性能，说明该预算下初始形状收益有限；Cosh-init更差则是明确的优化路径代价。它不影响固定Cosh在另一合同上的观察事实。

**入稿位置。**§5.2用四格总结，不另起一条方法主线。投入优先于9条4K训练，因为它直接补齐当前主实验的解释缺口。

## 10. E7：真实远距来源利用与完整答案因果实验

### 科学问题

频率调整带来的attention/source概率变化，是否确实转成了依赖远处正确证据的完整输出？P1中8B LoRA已有远源移除ΔNLL改善但16K生成仍为零的例子，不能再只展示attention热图。（P1 §F.3，第42页。）

### 不把实验绑在S1小模型的未知读出能力上

使用现有成熟冻结OLMo checkpoint和已锁定的BM/MrPro(s=4,g4)，不向S1训练数据临时加入检索监督。选择有明确来源块的三类检索任务：single-needle、multikey、multiquery；任务模板与完整答案规范在开发资格集上锁定。

先用Native、真实4K做**24个独立基础案例×两个等token长度的来源值**的资格检查[设计]。要求完整答案基础准确率达到70%[设计，非已有事实]，确认这个冻结模型会完成该读出任务。此门不比较BM/MR长端输赢。未通过时停止昂贵因果插桩，报告任务/读出未具备可识别性，不把该失败归给几何理论，也不在正式测试上训练修答案格式。

### 正式设计

每任务32个基础案例，共96个[设计]；每案例设置3个预定来源—查询距离：约2K/8K/14K，均位于真实16K连续输入中。通过等token长度的源块与distractor块交换来改变距离，固定query、总长度、候选数、答案长度及其余块的多重集；块顺序的变化属于明确的任务干预。每个距离再做两种来源值，要求答案随来源改变，因此共有96×3×2=576个正式长上下文。

不使用全局position-ID平移替代相对距离，不用虚拟长gap代替这项真实16K读出评价。同一基础案例所有版本作为一个统计cluster。

进行两类干预：

**层组2×2表替换。**前半层、后半层分别选择MR或BM，得到MR/MR、BM/MR、MR/BM、BM/BM四种配置。每个层内使用原合法表，端点/gain不变，避免拼半条频率表导致无意破坏排序。全MR、全BM是方法端点，混合配置只是机制干预，不作为新部署方法。某个混合格既可被理解为从MR恢复一组，也可理解为从BM移除另一组；不能把同一格重复计算为两次独立因果证据。

**来源遮挡与sham。**在全MR和全BM上分别增加answer-side attention屏蔽gold块，以及屏蔽相同长度、匹配位置范围distractor块的sham。保留所有token及原位置，不重排KV。这个遮挡只识别直接answer-side来源通路，早先prefill中的间接信息传递仍可能存在，不能宣称已切断所有来源因果路径。

正式四格2304次生成；全MR/全BM各自两种额外mask又2304次；另加192个Native4K正式能力控制和48个资格输入，最大共4848次生成[换算]。资格未通过时不会花掉后续全部预算。

### 主终点与分析

主要行为终点为完整答案的来源反事实一致性：同一案例两个来源值都答对的比例，按距离分别展示并预先等权汇总；完整字符串与EOS终止情况分开记录，不以first-number命中替代。

机制终点为gold-mask相对sham造成的行为损失和答案NLL变化，以及两层组表替换的效应。方向性假说为：若BM改善真实来源利用，其正确完整输出应追随来源值；gold-mask影响应强于sham；将关键层组改回MR应降低这种能力。它是待检验预测，不要求数据必然满足。

多距离、双来源和八个干预版本不会把96个独立案例变成数千个独立样本。各版本产生的token loss仅是固定模型的配对观察。小样本不适合宣称普遍层定位规律。

### 机器、预算与停止

Pro 6000，完整分支输入76,480,512 tokens；平均输出128 tokens[假设]，输出预算620,544。按4/16K prefill6K/2.5K及decode60 tokens/s[假设]，额外1.5倍插桩/附加评分开销[假设]，再加20%执行余量及1小时加载，约 **21.35 GPU·h**。工程实现与验收另估1.5–3人日[假设]，这是本项ROI低于简单重评的主要原因。

模型近距能力不足或mask/no-op不守恒时停止机制解释。通过资格门后按完整固定案例集执行，不依据BM早期长端成绩挑层、换band或挑distance。

**正结果。**获得“调整→远源依赖→完整输出”的行为证据；解释限定于被干预模型、层组和任务，不自动证明BM平滑先验是唯一机制。

**attention/NLL改善而完整输出不改善。**证据链停在访问/概率层，不能写完整任务收益；这一结果恰好区分论文目前容易混淆的两个层次。

**BM提升但gold-mask与sham无差。**不能把性能改善解释为已识别的直接来源通路，可能有间接信息或其他因素；不能编造已被证明的机制。

**入稿位置。**§4的“怎样使用分配”与§6构造结果之间；完整干预矩阵放附录。

## 11. E8：Llama-3-8B 冻结跨家族确认

**科学问题。**BM的实际价值是否主要局限于OLMo？P1现有Qwen3B/7B的128K小面板均偏向MrPro，已经不支持“BM普遍优于MrRoPE”。本实验不是为了抹去这些负例，而是增加一个固定规则、不同家族的测试。（P1 Table18、Table31，第35、45页。）

**设计。**冻结 Llama-3-8B-Instruct，使用实际native8K频率表。四种扩展为BM/Pro/Uni/确切官方YaRN，固定s=4、同g4；分别在真实8/16/32K评价。同样的静态长表也用于8K，不能在8K偷偷切回Native。另加Native@g1的8K能力控制。

采用P1六任务面板的任务类型：single-2、multikey-2、multiquery、variable tracking、frequent words、QA-1；每任务40个独立新基础案例/长度[设计]。每方法每长度240条，四扩展×三长度，再加240 Native，总3120次生成。相同基础问题跨长度时按基础问题cluster，不把三个长度当独立样本。

主终点为32K六任务宏平均上BM对Pro/Uni/YaRN三个预指定对照，做family校正；8K成本、16K曲线和逐任务值为次终点。样本规模用于避免每任务2–4条的筛选级不稳定，但没有现成配对方差，不能声称40/任务已保证检出3pp；报告区间，必要时接受不确定结论。

**机器与预算。**优先Pro 6000，BF16；必要时chunk MLP/输出头而不截断attention。总输入57,016,320 tokens，按8/16/32K prefill2K/1.2K/0.6K tokens/s，平均输出128、decode40 tokens/s[均假设]，加20%与0.75小时加载，约 **27.56 GPU·h**。5090是否可承接某长度由容量资格检查决定；一个比较面板的所有方法使用同一路径。

**停止。**规则与样本量固定，不因Llama看起来不利而重新调BM边界或gain。技术失败不记分；如果所有扩展在目标长度任务地板，完整报告地板及Native短窗对照，不将其解释为精确方法排序。

**正结果。**扩大静态规则的外部有效性，但与已有Qwen负结果一起报告，最多支持有条件跨家族可用。

**负结果。**BM的适用范围进一步收窄；“内部配置影响行为”仍可成立，而“该BM规则具有普遍竞争力”不成立。全文用已确认的条件结论，不再追加无目的模型直到找到赢的一家。

**入稿位置。**§6.3与完整跨模型附录；不自动升级为主图Hero Result。

## 12. E9：实际4K训练窗口——保留设计，但本轮不默认执行

**科学问题。**2K固定支持结论能否扩到实际4K训练？使用151.9M、B500000、三臂三seed，共9条；τ保持√2、每臂同999,948,288 processed tokens。若改τ=1，则是“随窗口调整工作规则”的联合变化，不是此处的窗口扩展。

三臂全部在同一Pro型号/软件栈跑，4/8/16/32K统一评价128packs，主终点为1B处8/16/32K等权OOD全NLL，4K成本单列。保存500M/1B，遵守与E4相同的完整预算及统计单位规则。

**停止。**一旦正式承诺9条即完整执行，不因2K某seed阴性取消。允许在独立机器上、不读取2K结果、按预先固定合同并行开跑；“并行”本身不产生选择偏差。本计划延后的理由是它比E6和E8更贵、当前中心缺口的边际价值更低，不是因为必须先看到2K胜利。
