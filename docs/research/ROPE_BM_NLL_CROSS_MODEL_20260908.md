# 固定BM：自然文本NLL的跨模型差异

同一组16篇冻结FineWeb-Edu自然前缀，在各模型tokenizer重新分词，逐文档配对。
每个长度评估最后512个真实next-token；不将NLL当完整字符串生成或长检索证明。
原parquet已不在服务器，使用既有Qwen32K token前缀，核验源文件SHA后解码重分词。
前缀源记录与重分词结果全部保存，不能称重新核验了原始parquet。

只比较每行同模型的部署差值，不直接横比不同tokenizer的NLL数值。
OLMo4K及16K均16/16篇BM低于MrPro；16K平均差−0.82592，文档配对重采样95%
区间[−1.08299,−0.62445]。但4K BM仍比Native高0.12001，不能声称无短端代价。
Qwen3B的32K差−0.00111、区间[−0.00767,+0.00480]，基本接近；16K小幅退步
+0.00425。该结果不支持把128K的任务退化解释成原生范围内普遍语言建模损坏。
没有Qwen3B128K自然NLL，不外推到那个长度。

BM所有内部中频位移更大，但OLMo比MrPro明显更好，Qwen原生范围基本接近。
频率接近Native的几何量不能单独判别这种差异。另一方面，这些结果也没有证明
边界平滑性或某个头/槽就是因果机制；需要结合长背景表示形成的既有干预。
