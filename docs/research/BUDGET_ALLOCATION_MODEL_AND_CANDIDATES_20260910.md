## 1. 模型

Qwen3B，64 槽，W=32768，S=4，目标长度 131072。表 ν_j = ω_j·S^{−m_j}，m 单调非降，频率有序。

**两个端点设计刻面（6Pro 裁决：最强基线的设计选择，非零容忍定理；违例方向均有直接实测代价）：**

- **j ≤ 23 恒等（m=0）**。HighGapToLong 从高频间隔借预算 → 32K −17.1 / 128K −10.8、36 行 0 升 7 降——面板上 **I1 侧唯一被测端点违例**。高频时钟在 W 内缠绕 ≥36 圈（wrapped-dense）、训练弧覆盖率已饱和（r_j≥1 对全部 j≤39 成立），m>0 买不到任何弧安全；且任何压缩直接付短端（已学局部计算依赖原旋转）。〔更正：MrUni **不是**端点违例证据——它是过渡段内线性斜坡、段外逐位同 MrPro（m23=0/m40=1 双守恒），其 32K 64.6 是桥形失败（m28=.294 压进 bank），见 §2 表〕
- **j ≥ 40 精确 ÷S（m=1）**。违例代价：E2 把平台推到 m40=1.1557（有效尾比 4^1.155715 = **÷4.9638**，非 ÷4.93）→ 128K 54.72（**12 行面板，基线 64.4444——不得与 36 行的 78.125 锚直比**）；E8 置零单个尾槽（ν51=0，j=51∈尾带→**I2 侧证据，非 I1**）→ 50.56（12 行，−13.89pp）。E2/E8 断的是同两行（mq_128_0、fwe_128_0）⇒ 95K 尺度附近有共享必要通道，一条都不能少 [D1 §3]。平台块内部 ν_j/ν_k = ω_j/ω_k 保持原生比值，是"位置重参数化 p→p/S"下的精确重标定；块内成对几何在 128K 上下文内等于原生在 32K 内见过的流形。改平台水平 = 破坏这个精确性质（全部赢家族都保持它）。

**守恒预算**：两端点固定后，过渡段（槽 24–39）17 个 log-gap 之和恒等于 17·(ln b)/64 + ln S。唯一自由度是**额外 ln S = 1.386 的分布位置**。这就是水床恒等式 B = N − Σ i·ε_i 的路径形式。

**分配的收益与代价**：

- **收益（arc-safety）**：槽 j 的相位弧安全距离 D_j = W·S^{m_j}。额外 gap 放在位置 g 会抬高所有 j > g 槽的 m，即同时购买下游所有时钟的弧安全。
- **代价（覆盖洞）**：额外 gap 在周期 T_g 尺度上制造洞（相邻部署周期比 > 原生 1.24×）。短端任务需要 ≤32K 尺度的时钟；长端任务需要 ≤128K。
- **危险区**：原生 r_j = W/T_j ∈ [1.15, 2.2]（槽 36–39，r=2.199/1.772/1.428/1.151，周期 15K–28K）的时钟缠绕少（窗内 1.15–2.2 整圈，局部判别弱；"学到准线性坡"只对 r<1 的槽 40+ 成立〔更正：0452/U9 否证了把准线性坡/未覆盖弧安到 36–39 的说法〕）又欠弧安全。我们的设计规则把它们推到 m→1；其长端效应是**风险因子而非门控**（75–112K 危险带 n 太小，6Pro #2 已降级，统计版待 0450/0451）。MrPro 的 m39 = 0.889 → D_39 = 112K < 128K，即 MrPro 自己的过渡在 128K 内留下地平线未完成的时钟。
