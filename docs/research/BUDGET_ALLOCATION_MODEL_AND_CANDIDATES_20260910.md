# 频段预算分配模型：理论、全部证据映射与三个新候选

2026-09-10。本文档把"低/中/高频分配"形式化为一个预算分配问题，用本轮全部 27 个已测面板统一解释，并给出据此构造的三张新候选表（已入队）。目标：零训练、冻结 Qwen2.5-3B，找到整体优于 MrRoPE-Pro 且可跨模型表述的分配规则。

## 1. 模型

Qwen3B，64 槽，W=32768，S=4，目标长度 131072。表 ν_j = ω_j·S^{−m_j}，m 单调非降，频率有序。

**两个被端点固定的约束（均已有直接实验证据）：**

- **j ≤ 23 恒等（m=0）**。HighGapToLong 从高频间隔借预算 → 32K −17.1 / 128K −10.8、36 行 0 提升；MrUni 全表 ÷4 → 32K 64.6。高频时钟在 W 内缠绕 ≥36 圈（wrapped-dense），其已学局部计算依赖原旋转，任何压缩都直接付短端且无长端回报。
- **j ≥ 40 精确 ÷S（m=1）**。E2 把平台推到 ÷4.93 → 128K 崩至 54.7%。平台块内部 ν_j/ν_k = ω_j/ω_k 保持原生比值，是"位置重参数化 p→p/S"下的精确重标定；块内成对几何在 128K 上下文内等于原生在 32K 内见过的流形。改平台水平 = 破坏这个精确性质。

**守恒预算**：两端点固定后，过渡段（槽 24–39）17 个 log-gap 之和恒等于 17·(ln b)/64 + ln S。唯一自由度是**额外 ln S = 1.386 的分布位置**。这就是水床恒等式 B = N − Σ i·ε_i 的路径形式。

**分配的收益与代价**：

- **收益（arc-safety）**：槽 j 的相位弧安全距离 D_j = W·S^{m_j}。额外 gap 放在位置 g 会抬高所有 j > g 槽的 m，即同时购买下游所有时钟的弧安全。
- **代价（覆盖洞）**：额外 gap 在周期 T_g 尺度上制造洞（相邻部署周期比 > 原生 1.24×）。短端任务需要 ≤32K 尺度的时钟；长端任务需要 ≤128K。
- **危险区**：原生 r_j = W/T_j ∈ [1, 2.2]（槽 36–39，周期 15K–28K）的时钟既非缠绕致密（只见过 1–2 圈，学到的是准线性坡）也无弧安全。它们必须被推到 m→1 才在 128K 内安全。MrPro 的 m39 = 0.889 → D_39 = 112K < 128K，即 MrPro 自己的过渡在 128K 内留下不安全的时钟。

## 5. 与理论的对接（论文口径）

规则表述：**"缠绕致密时钟恒等、准线性时钟整块 ÷S、过渡带宽最小化且后端必须完成——额外 ln S 的位置决定一切，总量不可变。"** MrPro 是本族中 N=17 的均布成员；E1/LBS 是其一阶扰动；N′ 族是其单参数收缩。跨模型表述只需 (l, h, S)（OLMo 上按周期定义的 ScaleTaper 构造检查已通过，见 scale_taper_cross_model_geometry.json）。EVQ-Cosh 与本模型的关系：EVQ 的"高频冗余→低频"直觉在端点约束下不可实现（HighGapToLong 已证伪），其有效成分应重新表述为过渡段内的预算位置问题。
