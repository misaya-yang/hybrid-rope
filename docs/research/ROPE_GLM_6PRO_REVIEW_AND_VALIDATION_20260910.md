# GLM / 6Pro 分析复核与当前验证

2026-09-10。结论：**6Pro 的统一坐标、EVQ 变量替换和兼容性分解可以保留；GLM 的地平线因果论证不能作为已成立机制。6Pro 的校准方案值得做一次完整验证，但仍是待检验的新规则生成方法。**

## GLM：保留问题组织，撤下过强因果表述

1. **守恒量正确，自由度判断错误。** 设 ε_i=m_i−m_{i−1}，固定 m_23=0、m_40=1，确有 Σ ε_i=1，因此新增对数跨度是 ln 4。17 个实际 log-gap 的总和则约为 5.056039，而非 ln 4；其原生部分约为 3.669745。17 个增量在一条总量约束下仍有 16 个自由度。把桥宽设为唯一参数是另加的设计限制，不能从守恒推出。

2. **D_j 不是其声称的未见相位边界。** D_j=W S^{m_j} 精确表示：部署距离 d 在缩放后的未取模坐标中对应 d/S^{m_j}≤W。可是 Native 第 36–39 个频率在 W 内已经转过约 2.199、1.772、1.428、1.151 圈，各自圆周相位都已覆盖。超过 D_j 不等于进入一个从未见过的单频弧。联合频率关系仍可能越出原生轨迹，但那需要联合模型；不能用四个独立 D_j 替代证明。

3. **两端行为是强基线设计，不是零容忍定理。** 少数失败干预不能证明所有高频改动均失败、所有低频必须精确除 S。MrUni 在本轮代码中是同一过渡区内的线性累计压缩，外部与 MrPro 相同；它不是全表 PI。MrPro 自身的 m_q=q(q+1)/[N(N+1)] 也不是均匀分配增量，增量随 q 线性增加。

4. **“所有赢家同方向移动预算”与实际表不符。** 用 ε_i 的真实槽位质心比较：

| 表 | Σ_j m_j | 新增 log-gap 质心 |
|---|---:|---:|
| MrPro | 29.333333 | 34.666667 |
| E1 s28 less | 29.300653 | 34.699347 |
| LBS | 29.560179 | 34.439821 |
| P2 | 34.178915 | 29.821085 |

E1 向后移，LBS 和 P2 向前移。不同方向都可能形成有条件收益，不能据此建立单一方向梯度。

5. **LBS 也没有“完成到 m=1”。** 第 36–39 槽实际 m 为 .625169/.729476/.846534/.979914，对应 D 约 77954/90082/105953/127473。将它标成“只完成危险区”的精确干预不准确。E1 s28 less 更完全没有改变第 36–39 槽的 D，却修复了被举作地平线证据的 89K 行。

6. **Gain 与频率可以分别控制，但效应不正交。** 固定状态下 gain 使 logits 乘 g²；softmax(g² z_ν) 同时依赖两者，通常存在非零交互项。四格对照不能证明幅度与相位机制在实际效果上互不影响。

## 证据距离复核

已读取服务器上的 `planned_controls/evidence_distances_20260910.json`，并用原始 screen.jsonl 与本地 tokenizer 在 CPU 解码核对。

- MK2 关键行的 reference 距离约 88726，作为单条绑定的距离标签有用；它仍不是全部处理步骤的唯一作用距离。
- VT 关键行记录的是 min=20563、max=105880；取 max 后将整条链称为“106K 证据”丢失了其他链节点和节点间跳距。
- MQ 一行可以同时包含 77 与 120934 token 的目标距离。应逐子问题配对计分，不应把 max 距离和整行平均分当一个简单观测。
- **FWE 的距离定义不成立。** 例如 `fwe_131072_0` 的答案词 cyuvqn 出现 10785 次，lobxbq 出现 4793 次，遍布全文。GLM 记录的 128533–128554 对应前端首次出现附近，而非计数所需的全部证据。
- QA 的答案字符串位置可作定位线索；仍需确认相关段落及支持跨度，不能自动等同于全部推理证据。

所以，36 行并非同一种“距离—准确率”样本。现有数据可画分任务的描述性散点或逐行案例；不能据此将 75–112K 宣称为已验证的危险带。内容、任务难度、证据位置和距离混在一起，两条翻盘也不足以估计风险带。后续距离因果验证需要固定内容/绑定结构，配对改变距离，并明确各任务的证据单位。

## 6Pro：可直接保留的数学

**频谱三分解：** 高频端位置 x_0、总跨度 A、归一化间隔 a_i/A。它清楚地区分平移、扩大支持和内部重分配；Σm 只是一项可选额外控制，不等于总跨度。

**EVQ 的精确变量替换：** h(u)=φ′(u)，ρ(φ(u))=1/h(u)，S_ρ(φ(u))=1−u，故

\[
J[h]=\tfrac12\int_0^1[\alpha/h(u)+\beta(1-u)^2h(u)]du,
\qquad\int_0^1h=1.
\]

这确实把给定 EVQ 目标写成间隔预算问题。以 α=1、β=4 的中点积分复核，两个坐标中的目标均约 1.0373147207，差约 1.6e−11；KKT 最大残差约 1.1e−15。64 个端点分位点、固定实际 Native 跨度的首末间隔 .104825834/.391244468，也与 6Pro 数字一致。换成 midpoint 再锚定端点会产生略不同数字，不能混用离散约定。

**带正 ridge 的关系拟合配方分解：** 对 G+ζI 正定的情形，最优可拟合误差加现有系数偏离最优读出的二次成本，等式成立。它适合组织 scratch、冻结替换和适配的区别。它没有证明 EVQ 是真实整网目标的特例；6Pro 对这一点的限定正确。

**仍未完成的核心：** 关系函数及其尺度需求不是由配方自动给出的。第六节的真实 Q/K、完整 softmax-row 校准补上了内容依赖，因而比光滑度或独立 Gram 更具体；但块大小、位置伸缩的假设以及固定状态到完整 prefill 的迁移都必须验证。

## 验证中的实际约束

旧 `calibration/` 是 MrPro 频率与默认 gain 下的状态，任务行还包含正确答案前缀；每行只保留 top/recent/target/support 等有限 keys。例如一个 32K MK2 的第 27 层只有 221 个已存 keys，尽管 total_keys=32123。保存原 LSE 不能重建未保存 keys 在位置改变后的 logits。因此旧数据不能被称为 6Pro 所需的 Native 完整行数据。

用户 11:06 明确告知 GPU 恢复并允许验证。现场确认 RTX 4080 SUPER、32760 MiB、当时空闲。当前开始以下验证，不自动执行 GLM 原来的五个候选：

1. **原生频率完整行采集。** 使用已有自然文本的前 6 篇 32K 文档，前 4 篇拟合，后 2 篇留作校准目标检查；不使用 RULER 答案。每篇每层取最后位置的 4 个 head，四篇轮换覆盖全部 16 个 head。保存全部可见 raw K/V 与所选 raw Q。
2. **固定尺度假设。** 原位置 p 与 p′=4 floor(p/4096)·4096+(p mod 4096) 两种图景等权。4K 是本次明确的假设，不声称由数学唯一决定。虚拟位置跨度为 118784，后续实际 128K 文本才检验完整目标长度。
3. **同资源方向。** 从 MrPro 初始化，拟合完整行 KL；固定实际首末频率、pair 数和 Σx，不预先锁定高/低内部频段。根据所得方向构造匹配幅度的正向与反向控制，所有评估使用相同 gain。
4. **目标行为。** 先跑 128K 长文本尾部 PPL 与 passkey，复用对应基线；若有推进价值，再做少量新的配对长程任务。固定态 KL 改善不替代完整模型结果。

为严格分开 gain，本轮使用 MrPro 默认 gain 作为共同温度；采集状态采用 Native **频率**与该共同 gain。它不是单独的 Native(g=1) 运行参照，二者命名和结果必须区分。
