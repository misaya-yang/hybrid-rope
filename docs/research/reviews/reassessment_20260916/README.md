# Source materials and local checks

These are unmodified user-provided inputs for the September16 reassessment:

- [Pro report](PRO_REASSESSMENT.md): external proposal based on its stated repository revision.
- [Ten-paper review archive](ALL_REVIEWS.md): reviewer, author-response and AC material as provided.
- [Source manifest](sources.json): identities of those two inputs.

They are evidence to interpret, not execution instructions. Reviewer objections
are not automatically correct, and author replies are not automatically confirmed.
The decision documents are [Pro disposition](../PRO_REASSESSMENT_DISPOSITION_20260916.md)
and [review lessons](../TEN_PAPER_REVIEW_LESSONS_20260916.md).

[CPU script](verify_reference_math.py) checks stated reference mathematics and
reaggregates existing NCP score rows. [Results](cpu_checks.json) distinguish
those checks from model evaluation. No GPU or checkpoint is used.
