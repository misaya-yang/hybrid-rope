# Native正收益、既有方法谱系与LeRoPE：重新确定研究起点

日期：2026-09-15。本轮按作者纠正，先审查真实方法和结果，再决定方法问题与实验。
这是CPU研究审查，不修改主稿或GPU队列；覆盖边界与可复算结果在末节。

## 1. 先明确“native正收益”

**Native指输入所处的原生训练/声明窗口，不代表候选必须使用原始频率表。**
参照模型是相同checkpoint使用原始位置编码、原始gain和相同解码/评分。
完整实际提示及生成预算在原生L内，不能靠截断、删除上下文或把更长输入另称native。

应分别定义两个直接终点：

\[
\Delta_{\rm LM}=\mathbb E_D[\ell(W_0,P;D)-\ell(W_0,P_0;D)],\qquad
\Delta_{\rm task}=\sum_t w_t\mathbb E_{x\sim D_t}[S(W_0,P;x)-S(W_0,P_0;x)].
\]

- **原生LM收益：**独立自然文档、同一目标tokens的NLL差为负。这本身是有效的模型质量收益，
  不是“只能算proxy”。把它用作RULER或推理提升的保证时，才出现不充分的代理跳接。
- **原生任务收益：**在事前定义的任务总体、权重与评分下，真实生成的配对任务差为正。
  任务等权/文档等权在输出前固定；不同长度、模型或LM损失不能任意混成一个总分。
- **观测正值、确认正值、可迁移收益分开：**小开发集正点估计保留；独立确认报告效应和区间；
  跨模型泛化需要同一冻结规则在新checkpoint验证。没有统一“必须3pp”的定义，也不要求每项任务都赢。
- “更好的RoPE”应有有意义的质量收益及公开的代价：其他能力、长度响应、延迟/显存一起报告。
  若需无损/非劣，必须事前定义可接受损失；区间跨0不代表已证明无损。

### 不能混为一谈的三种归因

| 主张 | 必须固定什么 | 可以改变什么 |
|---|---|---|
| 冻结模型的native位置编码收益 | checkpoint、输入、评测、允许资源 | 频率、支持跨度、gain或新PE算子；准确命名完整方法 |
| 频率改动的native收益 | 再固定gain、可见集合与attention算子 | 频率表，包括端点；不自动叫pure-z |
| 固定支持pure-z的native收益 | 再固定实际频率端点、槽位及算子 | 内部z |

上一轮把固定Native端点的NCP问题过早当成native增强的唯一问题，遗漏了已有扩大频率跨度但仍在native输入上获益的结果。
纯z是重要归因问题；它不应被误用为排除所有其他原生正结果的定义。

### “零训练”的访问级别

1. 本轮主目标是目标checkpoint不训练、PE也不在目标数据上拟合的冻结规则。
2. 只冻结底座、用文本/梯度优化频率，如Native-Z5，属于PE校准正参照，不称完全零训练构造。
3. 从其他模型学得表后冷迁移，可称目标端免校准；需披露源端训练，不冒称从公开参数解析得到。
4. 读取权重但不优化是另一种training-free算法类别；目前不能默默突破既定公开参数构造边界。
   如果后续选择它，应明确输入、成本和跨checkpoint规则。

## 3. YaRN → MrRoPE → 后续构造真正积累了什么

| 谱系 | 真实设计选择/依据 | 已有结果对理论的约束 |
|---|---|---|
| YaRN / MrPro / MrUni | 高频保留、慢频插值；中间频率混合或累计log位移分配 | MrPro的等差增量是有动机的假设，经模型比较验证，不是先求出真实任务最优目标 |
| BM / Uni | BM是双端增量粗糙度最小解；比MrPro提前更多压缩 | OLMo同剂量BM胜Uni；Qwen3B BM长端低于MrPro。总量、平滑、保守性都不能独占解释 |
| Gap-capped / Smooth(MrBudget) | 更接近Native或固定剂量下最平滑 | Qwen3B 128K分别比MrPro低15.97/9.79pp；已有数学最优性没有给出任务最优性 |
| C42 / C42V24 / Solver | 同支持、band和剂量仍可改变分配；有开发及较宽任务结果 | 保留有效经验配置；局部Solver在自然QA和RULER排序不同，不能以一个目标统一选表 |
| mix075 / exact TailSpline | 历史混合系数与有限网格解析解是不同身份 | 前者存在gain和选型因素；后者clean16K/32K确认及X4支持，不能互相借用结果 |
| P2 / FullLagP2 / 局部槽改动 | 非几何分配、数值采样修复、有限槽干预 | 修复数值不等于提升任务；32K/128K、1.5B/3B方向交叉；有真实局部收益也有确认不足 |
| Carrier / bias / 原生窗口分块 / 双频算子 | 已经尝试改变幅度、内容无关项、形成过程或算子形式 | “新位置编码”并非尚未探索的空白；应复用其有效否证、未完成状态与运行器 |
| Native-Z5 / H / NCP | 校准原生表、解析半周收缩、参考检索风险近端构造 | V1有条件正结果，H未确认；NCP的数学和代码身份完整，但不能因已写代码而优先于所有旧证据 |

特别是YaRN身份：官方index-ramp频率混合、论文turn-ramp表达及仓库旧别名不能互换。
同band下YaRN/MrPro在S4与S16的内部频率排序会交叉，不能将整个谱系讲成“越来越慢”或“越来越保护Native”。
原理和原文核对见[既有中频审查](../next_stage_20260912/INDEPENDENT_MIDBAND_THEORY_ANALYSIS_20260915.md)、
[MrRoPE原文§3.2](https://arxiv.org/html/2601.22181v1#S3.SS2)、[YaRN原文](https://arxiv.org/html/2309.00071v2)。

## 4. 已有机制干预比新一轮机械相位预测更重要

### 4.1 形成状态和最终读取都影响结果，作用随案例而变

Qwen3B两条128K负例，交叉前缀形成表F与读取表R后，成败/召回跟随F。
OLMo两条正例则更细：

| OLMo例子 | Mr形成→BM读 | BM形成→Mr读 | BM形成→BM读 |
|---|---:|---:|---:|
| single_1 | 0 | 0 | 1 |
| qa_2 | 0 | 1 | 1 |

在固定BM读取的K/V来源交叉中，single例只有BM K＋BM V成功；QA例BM K＋Mr V也成功，Mr K＋BM V失败。
这已经提供状态内容与读取规则共同作用的实测约束，不能简化成“全部只靠前缀”或“全部只靠QK相位”。
这些是少数回溯案例，资格回放和失败的早期工程版本在JSON中保留，不外推为所有样本的机制频率。

更早的E1正例又出现读取敏感、形成敏感及阈值叠加等不同模式。
一例的四格首数字margin为-2.125/-1.125/-1.000/+0.250：两个近似可加的改进跨过greedy阈值，
不能从二元0/0/0/1推断巨大非线性交互。该例交换正确/竞争值后两法均错，也不能当稳健绑定修复。

### 4.2 原生窗口独立形成已经测过

服务器`NativeWindowMrPro`不是原始Native基线，它先分块用Native形成，再全局MrPro读取。
本轮重算：Qwen3B32K/128K为62.22/43.75%，相对MrPro为-25.00/-34.375pp；
OLMo4K/16K为51.53/16.49%，相对MrPro为+13.68/+13.72pp，但不能因此称相对Native获益。
Qwen原生32K也差，说明“保留Native前缀后只换读表”并不是通用解决方案。

因此不再提一套同义的“先保Native状态，再加长程读取”新方案；若改算子，需要指出与这些已测干预的实质差别。

## 5. LeRoPE应怎样指导冻结权重的研究

[LeRoPE原文§5–7及附录C](https://arxiv.org/html/2607.10134v1)的关键边界：它训练频率与权重；
Fixed LeRoPE固定另一运行学得的频率，但仍训练新模型，不是把频率冷装到已有RoPE checkpoint。
它观察到中慢频减速、很慢频接近零，以及由学习形成的强位置band；原RoPE模型没有同样的dominant band。
原生NLL与多干扰检索结果都有价值，但它们不直接证明现成Llama/OLMo冷换频率会获益。

### 5.1 缺的不是把学习结果画成另一条曲线

真正缺的比较是
\(Q(W_{\rm RoPE},\theta_{\rm learned})-Q(W_{\rm RoPE},\theta_{\rm RoPE})\)，
而不是已完成训练之间的对角比较。换频率后，上游形成的状态、后层内容系数与最后读取都会变化；
上述本地缓存交叉正好证实其中一些环节有实际作用。

从学得的频率轮廓提取可迁移先验仍有价值，但需区分：

- 哪些规律由共享任务/训练分布稳定形成，哪些来自该网络学会使用一个新band；
- 公开Native几何相同的1.5B、3B也可能反转，不能只按\(L\omega\)匹配便宣称泛化；
- 固定全层共享表值得保留为简单的首选；没有依据自动增加层号/头号搜索；
- 在已有权重上获得独立native收益，才是我们相对学习式路线真正新增的证据。

### 5.2 NCP和LeRoPE的差异必须面对

NCP只允许减速、固定端点，并使极慢端的相对改动趋于零；这与LeRoPE学得轮廓并不等同。
LeRoPE频率更新使用内容、attention、V和下游目标信号；用正例先验对齐与随机负例替代这些量，
形成的是另一个参考问题。其凸性只能说明该问题容易稳定求解。

上一轮“(+,+,-)风险交互→真实accuracy交互”的提升没有先接受这批既有反例的检验。
该JSON保留为参考模型诊断，**撤回它作为当前默认模型行为预测/首要选型依据的地位**。
若NCP之后有真实收益就保留；如果参考风险与任务不符，不再通过修改距离权重救同一解释。

## 6. 全新位置编码的空间：开放，但不绕过已有权重

在连续一维位置、相同线性Q/K变换、\(R(0)=I\)且
\(R(s)^TR(t)=R(t-s)\)的条件下，\(R(t)=\exp(tA)\)，其中A反对称，
经固定正交换基分解为二维旋转与零频块。这是已有表示论/STRING框架的内容，不是本稿新定理：
[STRING](https://arxiv.org/html/2502.02562v1)、[相关ND框架](https://arxiv.org/html/2504.06308v1)。

因此，一维“全新旋转编码”若保留这些条件，常常仍在改变频率和旋转子空间。
换基并同步补偿Q/K投影可以只是精确重参数化，理想函数相同便不能解释新的质量收益；
不补偿则改变冻结权重所用坐标，已有同谱置换结果说明兼容性需要实测。

| 扩展方向 | 与现有RoPE不同在哪里 | 本地已有约束/下一项真正需要的证据 |
|---|---|---|
| 换旋转子空间/稠密正交基 | 改内容坐标与频率的配对 | 同谱置换及学习共适应；先说明固定规则如何保留已有有用计算 |
| 增加相对bias、非单位幅度、双频核 | 改norm/温度或核形式 | 已有SelectiveGain、BiasPosition和E10，不能当作全新未测方向；原生收益需对照幅度与数值实现 |
| 非线性/内容依赖的位置时钟 | 放松普通平移不变性，改变相对关系 | 需要因果定义与KV缓存一致性；固定距离保号不够，已有窗口/动态干预及跨块失败要复用 |
| 分块或改变可见关系 | 改形成历史依赖及计算成本 | NativeWindow已提供反例；不能删上下文后仍称同一native任务或只归因PE |

这张表保持新PE路线开放，同时要求它解决一个已经定位的不足。当前没有证据支持立即挑一个
新基、bias幅度或语义时钟公式作为下一张通用表；现在宣称已有完整新解会重复此前错误。

实现约束也不能反过来定义研究空间：当前NCP/普通static入口要求正频率严格递减；
零频或非单调表需选用相应安装路径并保留原槽位，不能被这个家族guard误判为无效位置编码。
仓库已存在[install_signed入口](../../../scripts/experiments/scale_transport/carrier_ruler_run.py)，
其具体维数与动态RoPE支持范围仍要按目标模型核对，不重新搭一个仅支持NCP的通用评测器。

## 7. 改进后的具体实验安排

### A. 优先解释旧native正结果的来源

固定Qwen1.5B的原108条、两块身份和已冻结mix075 S2频率；补齐：

| 频率 / gain | 1 | 原中点g=1.0340767467 |
|---|---|---|
| Native | 已有108条 | **新增108条** |
| 原mix075 | **新增108条** | 已有108条 |

只需216次新生成即可分别测频率在gain1的效应、gain在Native表的效应及两者交互。
这是对已有有益组合的归因，不是新曲线，也不是独立确认；开发6/追加12仍分别报告。
若两者联合才有益，保留组合收益并准确归因；不能要求频率单独获胜才承认原结果。

[准备器](../../../experiments/native_enhancement_oral_20260915/prepare_native_factorial.py)
只复制既有频率、改这两个明确gain格，复用原prompt tokens；不从得分挑行。
服务器目标根为`native_enhancement_oral_cpu/qwen15_native_gain_factorial`。
此包不自动插入现有队列，GPU仍待授权；历史runtime缺版本字段，未来执行需核对实际实现兼容性。

**CPU准备已完成：**108条真实prompt保持原始tokens/参考答案和32K预算；开发块36条、追加块72条。
两张表只改变指定gain，未改变原mix075频率。见
[准备清单与可执行命令](../../../experiments/native_enhancement_oral_20260915/reports/qwen15_native_factorial_manifest.json)。

### B. 将原生确认建立在多个已有参照上

原生LM与原生任务分别立题。候选来源至少包括已有频率-only正点估计、已有组合正结果，
以及NCP真实结果（完成后）；V1是校准存在性参照。先固定欲确认的一个规则及对应身份，再执行新数据。
不能因为NCP构表有闭式/CPU审计，就跳过这些更直接的模型证据。

跨模型首要检验的是同规则，不是同一数组；但规则迁移需同时记录native L、base、head维数、
QK norm/bias与静态gain。不同checkpoint不是可混池的更多样本。

### C. 机制实验围绕已出现的分歧

1. 复用X4全样本，先解释T/C在32K多key收益和QA代价，16K接近作为已有长度对照。
2. 已有输入/答案互换反例要进入机制面板设计依据；288题包可作辅助，但其风险曲线不选方法。
3. 真要区分形成/读取时，复用已有交叉运行器与资格语义，包含新正、负、平局案例的预先固定集合。
   不重复旧两例来“重新发现prefill重要”，不自动铺全层capture。
4. 同目标full/recent NLL仍可测原生历史利用，但LM差与任务差独立报告。

### D. oral叙事的实质增厚

当前可以增加的认识：从全谱/幅度比较到X4的长端细形状效果，再到内容形成与读取的条件机制；
原生输入已有正信号，尚缺强独立确认。若后续在冻结成熟权重上得到可迁移native改善，
才能把“已有权重不必重新训练也能改善位置计算”作为比扩窗更强的新结论。
