# Qwen256K更新：base、相位尺度与配置价值

## 判断

同一个Qwen2.5-3B、相同base1000000，TailSpline在256K单针检索上取得明确优势。
这改变了需要解释的现象：128K部分任务上的近似同分，并不代表该模型对内部配置普遍不敏感。
目前最有依据的解释是：配置差异一直存在；其任务价值在不同长度、倍率和内容条件下以不同方式显现。

此次只读取已完成报告并进行本地公共参数CPU核验，没有运行模型、读取权重或改变GPU队列。
论文未修改。Pro回复中的“Qwen尚无明确增量”及据此安排的实验优先级，需按新结果更新。

## 2. base到底改变什么

标准网格满足ω_k=b^(-k/K)，所以改变b在固定K时同时改变：

1. 非首槽的频率与周期，以及给定距离上的相位；
2. 相邻log频率间距c=log(b)/K，即有限通道在频率范围内的采样密度；
3. 各槽在训练过程中接触的频率—距离关系，继而可能改变学得的使用方式。

标准几何表的归一化z始终为k/(K−1)。因此增大base改变覆盖范围及尺度，
不会自动穷尽该范围内非均匀配置的设计空间。
对部署后的频率ν_k=ω_k s^(−m_k)，实际相位为

`d ν_k = (d/L) · (L ω_k) · s^(−m_k)`。

固定槽、固定距离、固定m时，大base确实缩小绝对频率差；
按turn边界重新选择band、同时改变L或S时，必须重新分析这三个因子。

## 3. Pro最值得采用的推导：turn锚定

对于几何网格，32/1-turn两边界均在表内且未截断时，设l为最后一个超过32圈的槽，
h为首个少于一圈的槽，n=h−l，c=log(b)/K，u=q/n。
定义η+=log(Lω_l/(64π))、η−=log(2π/(Lω_h))，则0<η±≤c，且

`nc = log32 + η+ + η−`

`Lω_(l+q) = 64π · 32^(−u) · exp((1−u)η+ − uη−)`。

这是直接由几何网格和两个边界得到的精确恒等式。它说明同一turn规则把干预放到近似
相同的原生相位区间；base的剩余作用体现为采样密度、取整、band宽度和槽位身份。
在细网格极限，相同相对距离和S下的过渡区响应不再显式依赖b、L。
这里的细网格极限是c趋零、n增大，并非简单令base增大。

独立CPU复算得到：

## 4. 256K带来的更深入判断

### 4.1 差异显现不等于干预范数突然变大

Qwen从S4到S8的窗口平均旋转RMS仅从0.6731到0.6858，增幅约1.9%，
但单针分数差从观测同分变为53.33pp。这说明RMS可检查干预是否存在，却不是任务收益标尺。
它是有界、周期性的算子距离，长距离下趋于饱和。内容相位、槽位组合和任务成功条件
决定已有结构差异是否变成正确答案。

### 4.2 TailSpline如何随倍率更强地保留距离缩放

目标端d=sL的单槽相位为Lω_k s^(1−m_k)。在相同band内T_k≥P_k：
T的目标端相位随S增长得更慢。完全缩放尾部m=1保持这个量不变；高频m=0保持原频率；
两者之间由m分配增长速度。

例如Qwen槽31(q=8)：P=0.235294，T=0.638655。
S4时P/T波长增长1.3857/2.4239；S8时为1.6311/3.7737。
目标端相位P从117.38到199.43rad，T从67.10到86.20rad。
这给出与新结果相容的具体结构解释：更大S下，T对该过渡通道提供更强的距离缩放。
这些未绕回相位本身不是注意力误差或性能代理；任务结果才确定这种配置的实际价值。

### 4.3 改动不仅是“整体多减速一点”

T/P比较识别完整内部配置的作用，位移总量和形状都属于z的变化。
Llama已有匹配总位移T/C对照提供独立的形状证据。
Qwen256K的新结果不单独把增益分解到“平滑尾部”或某个单槽。

## 5. 训练历史应保留，但换成正确的解释角色

[Qwen2.5官方报告§3.3](https://arxiv.org/html/2412.15115v2#S3.SS3)
记录先4K训练、最后扩至32K，同时base从1e4升至1e6。
固定槽的训练窗口相位跨度比为8×100^(−k/64)，在k≈28.90处跨过1。
Qwen当前band[23,40]跨越这两类槽：部分跨度增大，部分缩小。

因此，最终base不足以描述训练历史，最终相位几何也不足以完全描述学得的内容使用。
这一点合理；“ABF让改z失效”已与256K任务结果不符。
也没有必要把128K接近归因于Qwen训练有问题。
更合理的待检验解释是：训练与原生谱共同决定既有能力范围，额外配置收益因任务和长度而异。

## 6. 对Pro报告的取舍与当前优先级

- 采用：固定槽与turn锚定的区分、精确归一化恒等式、有限采样影响、训练路径分析。
- 更新：旧的“Qwen尚无明确增量”结论，加入256K同模型强检索结果。
- 不升级为性能定律：RMS、展开相位历史包络、单槽相位减小。
- 暂不把短物理序列/长position-ID探针列为最高优先级。新结果已直接回答真实长输入下
  是否存在配置收益；正在运行的128K自然QA会回答收益是否扩展到自然任务。
- GLM仍是不同频率预算与partial RoPE结构的迁移验证，其结果不能单独归因于小base。
- 论文建议：正文一句说明按turn锚定的跨base作用尺度，附录给短命题即可。
  主贡献继续围绕z、零训练质量与原生窗口增强，不新增一套base中心叙事。

## 可用于讨论的概括

**更大的base改变原生相位谱及其学习条件，却不会自动消除内部频率配置的价值。
在turn锚定的扩展中，相近的几何干预可以在不同任务和长度下产生不同收益；
Qwen的256K检索结果表明，强原生长上下文基础仍保留可由零训练配置改善的空间。**
