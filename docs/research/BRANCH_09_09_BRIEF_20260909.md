## 论文当前主线

论文研究“RoPE指数分布如何改变位置几何、学得行为与冻结模型调整”，不是当前重新运行一个RefCarry或通宵GPU项目。

- 固定频率端点，改变内部指数；151.9M三seed、三个外推长度的配对结果承担形状作用的直接证据。
- 通过范围重设及权重×运行表交叉，说明范围、分配与学得权重不能混为同一变量。
- 理论使用完整sin/cos二维子空间，讨论慢频子空间极限；Cosh是指定凸准则下的解析构造，不是无条件的任务最优频率表。
- 成熟模型部分分析相对native表的指数位移，并保留BM在OLMo自然QA的实际正结果、Qwen迁移的负结果和适用边界。

以上是对当前源码和证据映射的理解，本轮没有重新训练或生成验证论文数字。

## 新算子代码在做什么

`OperatorFactors` 联合拟合不同的A/B投影、旋转频率与内容/value latent。持久缓存是 `c,k_R`，不是token top-k稀疏选择；FreqFold/PCA用于初始化。真正的比较是同架构、同初态与优化预算下，score目标是否比attention-output蒸馏带来更好的完整模型表现。

当前目标模型是Qwen2.5-1.5B-Instruct。已有记录使用32篇校准、8篇书籍独立留出，以及一条8189-token关联检索题。后续结果见[原报告](../../experiments/rope_operator_family/FOLLOWUP_RESULTS_20260909.md)：

| 配置 | 8篇自然文本平均NLL↓ | 冻结检索题 |
|---|---:|---|
| 原模型 | 2.651387 | 正确 |
| 原输出蒸馏 | 3.942717 | 未恢复 |
| BKV + 输出蒸馏 | 4.992231 | 未恢复 |
| attention KL + 输出 + value | 3.745052 | 未恢复 |
| 逐层学生输入蒸馏 | 4.567863 | 未恢复 |

首次score拟合的NLL约9.99，弱于输出蒸馏。缓存减半已经有记录；KL目标改善了输出蒸馏的自然文本NLL，但未恢复该检索题。不能把NLL改善叫作检索成功，也不能用一道题的失败否定整个压缩方法族。当前保存的局部数据同时指向attention竞争与value损伤，尚未作完整生成的唯一因果归因。
