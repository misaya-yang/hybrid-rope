# RoPE 频率分配：我们究竟怎样从已有规则推出更好的规则？

## 研究目标

我们研究的是 **RoPE 的非几何频率分配规律**。当前主要目标是：从 EVQ 已有理论与有效分配规律出发，推导出更好的、能够跨模型和任务使用的分配规则，重点增强长程外推。可以付出短程或中程性能代价；不要求所有任务同时获胜。

作者的核心判断是：低频承担长尺度，高频承担短尺度，中频的过渡分配尤其重要；问题的本质是有限频率资源怎样分配。我们需要改进的是这个规则，而不是继续随机造几张频率表，然后报告某次成功、某次失败。

目前希望先把这个问题作为数学研究处理。服务器已经切到无 GPU 模式，可以做推导、CPU 数值计算和既有结果分析；暂不设计或启动大批模型实验。

## 必要的数学与部署背景

对一个 rotary pair，真实 attention logit 中的位置项为

\[
C_j\cos(\nu_j\Delta)+D_j\sin(\nu_j\Delta),
\]

其中 \(C_j,D_j\) 来自内容和模型权重。频率表为 \(\nu_0>\cdots>\nu_{K-1}>0\)。周期 \(T_j=2\pi/\nu_j\) 给出自然距离尺度；高、中、低频应当结合原窗口与目标窗口来定义，而不是永远绑定几个槽位编号。

近期实际部署对象是 Qwen2.5-3B-Instruct：head dimension 128，即 \(K=64\) 个 rotary pairs；原生窗口 \(W=32768\)，目标窗口 \(L=131072=4W\)，原生 base 为 \(10^6\)。近期实验固定模型权重，只替换静态频率表。这个部署阶段与从头训练 EVQ 模型不同，需要明确哪些理论结论能够转移。

为表达相对原生表的压缩，可写

\[
\nu_j=\omega_j S^{-m_j},\qquad S=L/W.
\]

\(m_j=0\) 是保留原频率，\(m_j=1\) 是完整位置插值。中频问题就是怎样决定过渡发生在哪里，以及 \(m_j\) 如何变化。这里也可以放弃这套参数化，但应给出更合适的分配变量。

需要区分三个不同资源：pair 数 \(K\)、频率支持区间的总对数跨度，以及 \(\sum_jm_j\) 表示的总对数压缩量。它们不是同一个“预算”，不能互相替代。

## EVQ 已经给出的规则

仓库原始推导使用 \(\omega=b^{-\phi}\)、\(\phi\in[0,1]\)，以密度 \(\rho\) 分配频率样本，\(\int_0^1\rho=1\)。令

\[
S_\rho(t)=\int_t^1\rho(\phi)\,d\phi.
\]

其中一个明确的变分模型是

\[
\mathcal J[\rho]
=\frac\alpha2\int_0^1\rho(\phi)^2d\phi
+\frac\beta2\int_0^1S_\rho(t)^2dt,
\qquad \alpha>0,\;\beta\ge0.
\]

其唯一最优解为

\[
\rho_\tau(\phi)=\frac{\tau\cosh(\tau(1-\phi))}{\sinh\tau},
\qquad \tau=\sqrt{\beta/\alpha},
\]

对应分位点规则

\[
\phi(u;\tau)
=1-\frac1\tau\operatorname{asinh}((1-u)\sinh\tau),
\qquad \omega(u)=b^{-\phi(u;\tau)}.
\]

因此我们不是没有分配规则，而是需要找出：**相对于已经有效的 EVQ，什么数学机制能够支持一个更好的规则？** 若沿用完全相同的目标与约束，唯一最优性当然不能被另一条手工曲线击败；改进必须明确来自更准确的目标、尺度依赖、资源约束或其他有依据的结构。

有限表的分位点和端点约定也需要明确：\(k/K\) 与 \((k+1/2)/K\)、是否固定实际最低频率，并不等价。

## 已有结果给出的少量约束

以下都是线索，不是要求新理论事后拟合每个分数。

- **中频分配确实有作用。** 在相同模型和 attention gain 下，仅改变 MrRoPE-Pro 的第 28 个零基槽位，就曾在开发集得到 128K 提升。它说明细小位置和方向差异可能重要，但单槽结果还不是通用规则。
- **已有完整规则能形成长程收益与短程代价的交换。** 历史 FullLagP2 规则直接移到当前 3B 协议，128K 六任务开发集宏平均为 81.6667%；MrRoPE-Pro 默认 gain 为 78.1250%，相同 gain 对照为 75.3472%。P2 的收益主要来自 QA、变量追踪，另有 multi-key 等代价；它不是统一胜出。32K 的已知代价较大，作者允许研究这种取舍。
- **P2 不是随意选的 sigmoid。** 它从原生窗口内完整 sin/cos 设计矩阵出发，计算每个 pair 相对其余所有 pairs 的条件残差比例 \(u_j\)，再使用 \(m_j=(1-\widetilde u_j)^2\)，其中 \(\widetilde u\) 是 min-max 归一化，旧实现固定截断阈值 \(10^{-10}\)。它更早、更陡地接近完整插值。这个规则的几何依据与经验映射之间仍有待推导的环节。
- **漂亮的形状目标还不够。** 固定总压缩量再最小化相邻差分粗糙度，或者手工把高频对数间隔挪到某个长周期区间，都没有形成有效改进。不能把“更光滑”“慢频更多”“间隔更大”单独当成充分依据。
- **目标长度的低成本筛查可复用。** P2 与同 gain 对照已有 128K single-key passkey 4/4；四篇真实 128K 文本的末尾 512 token pooled PPL 分别为 5.358 与 5.371，差异很小。这只能说明该点值得研究，不能代替分配理论。新的 QA 小样本在切换无卡模式时未完成，不能作为独立确认。

另一个重要区别：**128K 输入内部同样需要短距离的局部计算。** “专注长程任务”不等于可以忽略长输入内的局部信息处理；但也不意味着必须反复运行一套独立的 32K benchmark。新规则应说明它在同一个长输入中如何分配局部与远距作用。

## 请解决的核心问题与交付

请围绕一个连贯的问题推导，而不是给很多候选曲线：

> **怎样从 EVQ 的频率资源分配思想出发，推导一种更好的分配规则，决定高、中、低频之间的取舍，尤其是目标长程下中频过渡的位置与形状？**

我们希望得到：

1. 一个明确的数学问题：分配变量、目标、资源约束，以及“更好”究竟对应什么量；说明它与真实 rotary 计算的联系。
2. 从这个问题推出的规则或算法，而不是先选曲线再找解释。指出 EVQ 是其特例、近似还是对照，并解释新结构具体改进哪一环。
3. 能够检查的推导、边界情况和小规模数值例子。特别关注：为什么中频应在某处转折，为什么某些资源可以转移，以及转移为何能帮助目标长程。
4. 少量有区分力的预测：以后每个实验应检验哪一步推导，什么结果会要求我们修改哪一项假设。模型验证先做目标长度 PPL 与 passkey，再按需要做少量长程下游。

可以挑战我们对“资源”和频段作用的表述，也可以重建 EVQ 目标中不合理的部分。目标是推进更好的分配规律；请不要把回答停在“还需要更多实验”，也不要把几何代理目标的改进直接写成模型任务必然提升。
