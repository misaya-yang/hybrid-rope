# 非几何 RoPE 分配：给 GPT-6 Pro 的研究问题与证据包

**证据快照：2026-09-10 06:08 UTC。** 本文件整合 Codex 与 Qwen3.8-Max 的并行研究、相互审查和已完成实验；可以单独阅读，不需要仓库或 transcript。请独立判断，可以指出双方都错。我们需要能解释成功与失败、能指导下一步实验的研究结论，而非替已有叙事寻找支持。

## 1. 研究目标与边界

目标是在预训练权重冻结、**零权重训练**条件下，找到优于 **MrRoPE-Pro（下称 MrPro）** 的 RoPE 频率分配方法，尽可能跨模型、跨任务、跨长度泛化，并给出有预测力的理论解释。可以使用少量校准数据选择频率表，但必须区分“一个固定规则直接迁移”与“各 checkpoint 重新校准的算法”；不能用目标测试集调参后称作泛化。

已有成功案例应积极利用；一个负设置也不能否定整条方法。允许重构现有理论、放弃双方提出的机制，静态表优先但并非不可突破的约束。最终判断依据是真实任务表现及必要的自然文本检查，几何指标、attention mass、局部 NMSE 和 NLL 均不能替代下游任务。实验应少量且能区分解释，复用合法 baseline，避免先列大网格或重复几十种近似候选。

## 2. 必要的算子与方法定义

### 基本设置与 MrPro

当前主模型是 **Qwen/Qwen2.5-3B-Instruct**，revision `aa8e72537993ba99e69dfaafa59ed015b17504d1`；36 层，16 个 Q heads、2 个 KV heads，head dimension 128，即 64 个 rotary slots。原生参考长度 \(W=32768\)，base \(b=10^6\)，扩展因子 \(S=4\)。所有 slot 编号均从 0 开始。

原生频率 \(\omega_j=b^{-j/64}\)。静态表 \(\nu_j\) 在所有层和 heads 共享，从 prefill 起部署：

\[
q'_j(p)=gR(p\nu_j)q_j(p),\qquad
k'_j(t)=gR(t\nu_j)k_j(t).
\]

因此 gain 同时乘 Q/K，固定状态的 logits 乘 \(g^2\)，它不改变相位。当前主面板采用 BF16 权重/旋转输出、FP32 相位计算、SDPA、greedy、repetition penalty=1、固定官方任务回答预算和 EOS，完整输入不截断。

MrPro 中段端点 \(l=23,h=40,N=h-l=17\)。令 \(q_j=\operatorname{clip}(j-l,0,N)\)：

\[
m^{Mr}_j=\frac{q_j(q_j+1)}{N(N+1)},\qquad
\nu^{Mr}_j=\omega_jS^{-m^{Mr}_j},\qquad
g_{.1}=1+0.1\ln S\approx1.1386294.
\]

等价 radix 增量为 \(\epsilon_i^{Mr}=2i/[N(N+1)]\), \(i=1,\ldots,N\)。高频 \(j\le l\) 不压缩，慢频 \(j\ge h\) 压缩至原来的 \(1/S\)。MrPro 本身已不是全局等比频率表；“非几何”不是足够的创新性定义。

### E1：实际成功的单槽改动

- **s28_less**：只把 \(m_{28}\) 换成 MrPro 的 \(m_{27}\)，即 \(30/306\to20/306\)；\(\nu_{28}:0.00207001995\to0.00216595642\)。其余频率和 gain 不动。
- **s29_more**：只把 \(m_{29}\) 换成 \(m_{30}\)，即 \(42/306\to56/306\)；\(\nu_{29}:0.00157984428\to0.00148275390\)。其余频率和 gain 不动。
- 这两个点来自 24–39 槽、相邻 exponent 双方向的有限候选。选择器用 baseline 固定 Q/K/V 的有限旋转 replay、目标 key mass 变化和自然文本局部输出扰动预排序；之后才完整生成裁决。replay 固定了省略 keys 的贡献，**不是整网效应的精确预测**。开发任务已用于选择，旧面板上的胜出不是独立确认。
- 当前冻结迁移规则：在目标 MrPro transition 的 \(5/17\) 处取最近 slot \(j=l+\operatorname{round}[(h-l)5/17]\)，用前一个 slot 的 exponent 替换它，保留目标模型自己的 native grid、其余表和 gain。Qwen7B 对应 slot28；OLMo 的边界14/32对应 slot19。此规则仍待结果检验。

### BM：Boundary-Matched 闭式表，具有较强的历史成功证据

BM 只改 MrPro 的严格中段，端点、外频段和 gain 保持一致：

\[
\epsilon_i^{BM}=\frac{6i(N+1-i)}{N(N+1)(N+2)},\qquad
m_q^{BM}=\frac{q(q+1)(3N+2-2q)}{N(N+1)(N+2)},\qquad
\nu_j^{BM}=\omega_jS^{-m_{q_j}^{BM}}.
\]

此解确实唯一最小化 \(\sum_{i=0}^{N}(\epsilon_{i+1}-\epsilon_i)^2\)，约束为 \(\epsilon_0=\epsilon_{N+1}=0\)、\(\sum_{i=1}^{N}\epsilon_i=1\)。这是离散几何定理，尚不是任务最优性定理。严格中段有：

\[
m_q^{BM}-m_q^{Mr}=\frac{2q(q+1)(N-q)}{N(N+1)(N+2)}>0.
\]

BM 在每个严格中段 slot 都增加压缩，同时改变形状与累计预算。内部 \(q=1,\ldots,N-1\) 的 exponent 总和分别为 MrPro \((N-1)/3\)、BM \((N-1)/2\)。MrUni 的 \(m_q=q/N\) 与 BM 有同一总和，可用于排除最简单的总预算解释。

**BM gain074** 使用同一 BM 表，只将 \(g\) 改为 \(g_{.074}=1+.074\ln4\approx1.1025858\)。其相对 MrPro 的差异同时包含表与 gain 两个因素；不能直接归因于 gain。

### FullLagP2：另一条有条件成功的历史构造

它使用 Qwen native grid，而非任务激活或 \(W_Q/W_K\)。在 \(d=0,\ldots,W-1\)、\(W=32768\) 上取因果 lag 权重 \(w_d\propto W-d\)，构造加权列对：

\[
X_j(d)=\sqrt{w_d}[\cos(d\omega_j),\sin(d\omega_j)].
\]

将第 \(j\) 对列对其他全部列做 least-squares，`rcond=1e-10`，得到相对残差能量

\[
u_j=\frac{\min_B\|X_j-X_{-j}B\|_F^2}{\|X_j\|_F^2},\quad
\bar u_j=\frac{u_j-u_{min}}{u_{max}-u_{min}},\quad
m_j=(1-\bar u_j)^2,\quad
\nu_j=\omega_j4^{-m_j}.
\]

\(u\) 按数值容差裁入[0,1]。**全部64槽使用这条构造**，不是只移植中段；历史 gain 为 \(g_{.074}\)。FullLag 修复了旧版每16个 lag 聚合后造成的近似混叠；它与旧表不应混称。P2 的靠前中段比 MrPro 更接近 Native，而较后部分压缩更强，方向并不等于“全中段加压缩”的 BM。成功本身没有证明“条件残差越大越有功能价值”。

## 4. 双方最强解释与必须保留的纠正

**Qwen3.8-Max的核心提议**是“arc restoration vs phase separation”：压回已学相位范围有利短端，保留判别分离有利长端；由此提出双侧敏感度分配、最大化分离的表、shape×budget对照、gain×length对照、row-wise动态和更大MK面板。其有价值之处是把长度取舍转成可研究对象，但目前四个“支持点”不能算机制已证实。

**Codex当前解释**从真实计算出发：带符号的内容竞争、prefix形成、readout、gain/数值实现及最终决策边界共同决定效果。它比纯相位故事更贴近数据，但也还没有导出可迁移的选择规则；“看任务margin”本身不能替代新方法或变成事后万能解释。

### A. 相位分离的方向并不普适

对静态表和固定非负权重，位置特征的平方弦距是
\[
D^2(\Delta;\nu)=4\sum_jw_j\sin^2(\Delta\nu_j/2).
\]
它不依赖绝对位置p；\(\Delta\nu=2\pi\)时距离0，压缩一半后反而为4。实际s28_less在 \(\Delta=1K,2K,4K,8K,16K\) 的改动分别让该槽平方弦距变化 **[+.1623,−.3651,+.5320,−1.5277,−.4050]**；s29_more则为 **[−.1988,−.0022,+.0087,+.0340,+.1255]**。单槽变化也等于全表等权距离的变化。故不能直接把s28胜利解释为普遍增大相位分离。

固定raw Q/K时，正确key与竞争key的分数来自
\[
z_t(\nu)=\frac{g^2}{\sqrt{128}}\sum_j[A_{tj}\cos(\Delta_t\nu_j)+B_{tj}\sin(\Delta_t\nu_j)],
\]
其中A/B含内容、符号和head差异。真实模型的raw Q/K/V还随前面层及prefill改变。需要说明几何结论在什么附加假设下才能预测这些带符号量。

### B. E7不是“一阶近似错了160倍”

相同冻结状态、相同局部key支持上的输出NMSE：linear预测 **7.93668e−8**；理想relative-phase的精确有限改动 **7.93640e−8**；FP32绝对坐标实现 **7.93255e−8**；BF16绝对坐标实现 **1.28074e−5**。约161倍是**平方误差**之比，主要出现在实际有限精度旋转，与线性化误差不同。它也未证明整网E7失利由舍入造成。局部导数正确、部署实现差异、局部目标不能预测任务，是三个不同命题。

### D. 目前不成立的外推

- gain .074只改幅度，不能当arc恢复证据；BM×gain相对Mr的总差不是gain因果效应。
- 用五个已知结果调一个代理叫回顾校准，不能再称独立确认；代理失败只否证该构造，不会关闭所有几何理论。
- 50个MK样本值得做，但“足够功效”需要目标效应和paired discordance；只扩MK也无法验证s29的QA或跨任务能力。
- 有限搜索失败不能证明静态表族无headroom或给出全族上界；慢带ν=0后仍保留内容通道，不能把输出持平叫维度无用。
- 动态 \(G_t=\lceil(t+1)/W\rceil\)、\(\phi(t)=t/G_t\) 在W处向后跳变；token-attached mapping与query-dependent重映射是不同核/cache语义。现有距离双时钟 \(\phi_j(\Delta)=\omega_j\Delta\)（\(\Delta\le w\)）、\(\omega_jw+\nu_j^{Mr}(\Delta-w)\)（\(\Delta>w\)）则连续但有斜率kink。本轮已排 E9_distance 使用 **w=26 tokens**，来自校准数据中完整 primitive 键值记录的最大token跨度，**不是模型参考窗口 W=32768**；不能把两个边界或两类算子混同，也不能把kink直接等同频谱间隙。两类尚未有支持其任务泛化的完成证据。

## 5. 请按优先级回答的十个研究问题

每个重要问题请给出**机制或明确假设 → 可证伪预测 → 最小决定性比较 → 不同结果如何更新结论**。可以合并同一机制的问题；不需要机械为每题增加一套实验。

1. **为什么从YaRN到MrPro都采用高/中/低频，什么统一变量能解释它及成功的方向？** 以r_j=Wω_j/(2π)衡量训练窗口转圈数：高频保持、低频插值、中间过渡，哪些能从局部保真/相位覆盖推导，哪些只是经验选择？为什么是三段、为什么1/32圈能作为边界？单通道已转完整圈并不等于联合相位与内容表示已学会；s28/s29原窗口转圈数约12.37/9.97，均非不足一圈。有限窗口内频率基函数的独立性、学习到的跨频率协作，是否比单圈覆盖更能解释中段？请连接下面的真实成功与反转，而非停在科普层面。BM在OLMo S4有独立大幅收益，在Qwen3B 128K却负；P2在1.5B优于同gain Mr，在3B取舍；相邻槽s28解压和s29加压分别有条件成功。是学习到的频段使用、竞争项内容系数、有效训练长度、phase distribution、gain，还是其他可计算属性？请提出能在看目标任务结果之前预测方向的机制；若不能统一，请给最小必要分区条件，而非逐例补故事。

2. **如何把signed margin变成一个可泛化的分配规则，而不是另一个选择代理？** 能否从少量自然文本或任务无关校准得到slot/head的带符号贡献、value/readout重要性与跨层反馈，导出可计算规则？目标attention mass改善却E8任务退化，否定了哪种充分条件？请明确局部目标通向任务改善需要什么条件、如何最少测试这些条件。
