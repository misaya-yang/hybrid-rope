# RoPE 分配：问题总结、理论分析与下一条规则

**证据更新至2026-09-10 08:42 UTC；LongBridge两个方向均已完成36条任务与48个NLL文档长度单元。** 本附件整合已有构造、实验和外部 Pro 建议，供独立研究。无需访问仓库或历史对话；文中“事实”“推导”“假说”分别注明。

## 1. 我们现在真正要解决什么

**寻找整体上更好的频谱／压缩分配规则，在权重冻结、零训练条件下超过 MrRoPE-Pro，尤其争取明显的长上下文外推收益，同时尽可能跨任务、模型和长度成立。** 高频保留局部细节、慢频支撑更长尺度、中间频率负责分配与衔接，是有依据的出发点，不是已经证明的三种固定任务模块。

请研究如何从这些尺度结构、原生 RoPE 的外推失效和真实成功案例出发，构造**下一张有理由更好的表或下一条可执行规则**。高频不变、低频除S、中频分配及分段边界均是可改的设计选择，不能从baseline概括反推硬约束。允许长短端同时改善，也允许有价值的取舍；不要求所有任务都赢，也不假设 MrPro 已经位于 Pareto frontier。现有 waterbed、smoothness、局部 gap 或 signed margin 分析均可重构，不能把其中任何一个当作最终答案。

当前新做的四槽 Faster/Slower 只是第一步局部诊断，看看面向外推尺度的直接改动能否带来明显收益；研究空间不局限于四槽，也不是“快或慢二选一”。请给机制支持、可执行、可能明显优于 MrPro 的整体分配规则，不只重复一个待优化的抽象指标。

工作约束：复用既有 baseline，后续首轮集中 Qwen2.5-3B；NLL 或 passkey 轻微输仍须看混合 RULER；按最少但能决定下一步的比较推进，不先堆大网格。已有结果应指导候选，但不要求先解释完全部历史现象才允许运行有依据的小实验。实验与我们自己的独立分析会在 Pro 研究期间继续，不等待外部回复才行动。

## 2. 自包含的定义：我们究竟改了什么

主模型 **Qwen2.5-3B-Instruct**：36层、16 Q heads／2 KV heads、head dimension128、64个 rotary slots。参考训练窗口 \(W=32768\)，base \(b=10^6\)，当前扩展 \(S=4\)、目标长度 \(L=131072\)。slot从0开始。部署从prefill起使用同一频率规则；模型权重冻结。BF16、FP32相位计算、SDPA、greedy、repetition penalty=1，任务原回答预算与EOS不改。

原生 \(\omega_j=b^{-j/64}\)，分配用

\[
\nu_j=\omega_jS^{-m_j},\qquad
q'_j(p)=gR(p\nu_j)q_j(p),\quad k'_j(t)=gR(t\nu_j)k_j(t).
\]

固定raw Q/K时gain在logits上产生 \(g^2\) 因子，不改变相位；默认 \(g=1+.1\ln4\approx1.1386294\)。完整模型还会通过前面层／prefill改变raw Q/K/V。

**MrPro。** 边界 \(l=23,h=40,N=17\)，令 \(q=\operatorname{clip}(j-l,0,N)\)：

\[
m_q^{Mr}=\frac{q(q+1)}{N(N+1)},\qquad
\epsilon_i^{Mr}=m_i-m_{i-1}=\frac{2i}{N(N+1)}.
\]

高频端 \(m=0\)，慢频端 \(m=1\)，中间累积递增radix扩张。MrPro本身不是全局等比频率表，因此“非几何”只是研究简称，不足以界定创新。

**BM（Boundary-Matched）。** 保留相同端点、外频段、gain，仅改严格中段：

\[
\epsilon_i^{BM}=\frac{6i(N+1-i)}{N(N+1)(N+2)},\qquad
m_q^{BM}=\frac{q(q+1)(3N+2-2q)}{N(N+1)(N+2)}.
\]

它唯一最小化 \(\sum_{i=0}^{N}(\epsilon_{i+1}-\epsilon_i)^2\)，满足外部零端点 \(\epsilon_0=\epsilon_{N+1}=0\) 和 \(\sum\epsilon_i=1\)。这个几何优化解已验证。严格中段 \(m_q^{BM}>m_q^{Mr}\)，所以BM同时改了形状和累计压缩预算，不能只叫“更光滑”。

**E1。** s28_less只改 \(m_{28}:30/306\to20/306\)，频率0.00207001995→0.00216595642；s29_more只改 \(m_{29}:42/306\to56/306\)，频率0.00157984428→0.00148275390。其余频率和gain完全不变。两点由baseline固定态replay代理从少量单槽候选中提名，再完整生成；旧任务面板参与选择，故旧收益属于开发证据。

**P2的必要背景。** FullLagP2对native频率在所有 \(d=0,\ldots,32767\)、权重 \(w_d\propto W-d\) 上构造列对 \(X_j(d)=\sqrt{w_d}[\cos(d\omega_j),\sin(d\omega_j)]\)。计算每列对对其他全部列的least-squares相对残差 \(u_j\)（rcond=1e−10），将其min-max归一化为 \(\bar u_j\)，再令 \(m_j=(1-\bar u_j)^2\)。完整64槽都用此规则，历史gain为 \(1+.074\ln4\)。它不读取模型权重或任务激活；其几何相关性不是已学功能重要性的定理。实际P2前中段更贴Native，slot30/31的m已达.85056/.99785（Mr为.18301/.23529），32之后近似整段除4，深尾40–63则与Mr相同。这是更早、更陡进入压缩平台的结构线索，不等于“额外修复Mr遗漏的深尾”。

## 3. 从原始外推失败重新看高／中／低

### 数学成立的部分

对固定head，真实logit可以写成

\[
z_{pt}^{\nu}=\frac{g^2}{\sqrt{128}}(q_p^{\nu})^\top R_\nu(t-p)k_t^{\nu}.
\]

旋转保持范数，\(|q^\top Rk|\le\|q\|\|k\|\)，正余弦也不会因超过训练窗口而失定义。因此外推失败并不是RoPE数学上突然发散。可能变化的是：学到的内容与相位对齐、联合频率模式、prefill形成的状态，以及更多distractors下的竞争。

固定内容与距离 \(d\) 时，改频率的精确旋转差为

\[
\|R(d\nu)-R(d\omega)\|_2=2\left|\sin\frac{d(\nu-\omega)}2\right|.
\]

高频被统一缩放，容易改变已学的小距离算子；慢频若训练时 \(W\omega\ll1\)，原本近似常数／线性的相位功能可能在长端转入陌生对齐。完整压缩有 \((SW)(\omega/S)=W\omega\)，恢复最大未取模相位跨度。这支持两端不同处理，却没有证明“三段各自只负责某一类任务”。高频也参与远距相位，慢频也可能支持内容通道；“已经转过一圈”不代表所有内容相关联合模式都见过。

更多候选key本身也造成困难。在一真key、\(n-1\)个同分distractors的简化read中，\(p_*=e^D/[e^D+n-1]\)。保持相同mass需要 \(D\approx\ln(n-1)+\text{常数}\)。四倍上下文可能要求约 \(\ln4\) 更多attention-logit优势；这不是RoPE独有，也不是整网任务失败的充分条件。attention margin与输出token margin不能混作同一数值。

## 4. Waterbed到底约束什么，不约束什么

在**保留高端identity、低端除S这两个端点**的表族中，额外log-frequency gap满足

\[
\log\frac{\nu_{l+i-1}}{\nu_{l+i}}
=\frac{\ln b}{64}+\epsilon_i\ln S,\qquad
\sum_{i=1}^{N}\epsilon_i=1.
\]

因此“额外 \(\ln S\) 放到哪些gap”是正确的条件预算问题。内部累计exponent预算

\[
B=\sum_{q=1}^{N-1}m_q
=\sum_{i=1}^{N}(N-i)\epsilon_i
=N-\sum_{i=1}^{N}i\epsilon_i
\]

还固定了额外gap分布的质心。MrPro在N17时 \(B=16/3\)，BM和MrUni为 \(B=8\)。**固定B是额外选择，不是扩展S必然要求**；端点也可以作为有依据的方法设计变量。若统一PI使全部频率同时除S，总频谱跨度本身不增加，不能无条件套用上述“额外span必须插入”的说法。要求 \(\epsilon_i\ge0\) 同样是一个表族约束，不是正频率或有序频率的全部必要条件。

这些等式、某个几何代理的waterbed，均不证明32K和128K任务正确率守恒。我们需要研究如何把预算放在模型能利用、能提升外推的方向上，而不是先宣布每个长程收益必然付出等量短程损失。

### 两份外部分析及当前反证

用户提供的5.6 Pro分析指出：s28_less与s29_more都增大28–29的gap，可能与finite-window spectral resolvability边界有关，建议G1/G2/G3。其有限窗口Gram相关性解释有数学内容，但“有可分辨几何方向”不等于冻结checkpoint会利用它。

G1/G2在原 \((m_{28},m_{29})=(30,42)/306\) 上改成(24,48)/306与(36,36)/306；保持pair几何中心、B和相同exponent扰动范数，分别放大／缩小中央gap。两者roughness都增大 \(20(6/306)^2\)，还会改变外侧gap，所以并非只隔离中央一个gap。G3=(36,48)/306，保中央gap、移pair速度，同时改变B。这些是局部解释实验，不能代替整体规则研究。

用户此前提供的6 Pro分析建议固定MrPro预算最小化roughness，约束为外部增量端点零、\(\epsilon_i\ge0\)、\(\sum\epsilon_i=1\)、\(B=16/3\)。本项目已独立求解、验证KKT，并实测 **Smooth(MrBudget)**：roughness由MrPro .0130719降到.0048864，约束误差低于1e−15，却在128K比MrPro低9.7917pp。**凸问题确实解对了，但它不是这里任务长程改善的充分规则。** 不能从这一次失败否定全部分配自由度，也不能继续把“再平滑一点”作为已经有任务依据的主线。

历史上还曾用对称中段上的零面积函数 \(\psi(x)=x(1-x)(2x-1)\) 去拟合P2−Mr。它仅解释13.18%的几何差异能量，在重要slot29–31还把方向拟反，未作为模型结果。零面积、对称性或最小二乘下降均不是新规则的能力依据。逐槽相位cost也不能无条件独立相加：完整logit误差平方包含 \(2\sum_{j<k}\mathbb E[\Delta z_j\Delta z_k]\) 交叉项，softmax与后续readout进一步耦合。

## 6. 机制诊断的实际进展与边界

**E7精度拆解。** 同冻结状态／局部支持：linear预测NMSE7.93668e−8，理想relative-phase有限改动7.93640e−8，FP32绝对坐标7.93255e−8，BF16绝对坐标1.28074e−5。约161倍是平方误差之比，不能称线性近似失效160倍，也尚未证明整网失败由舍入造成。

**周期性反例。** 内容无关位置距离 \(4\sum_jw_j\sin^2(d\nu_j/2)\) 对频率不单调，静态表下也不依赖绝对位置。作为单位权重示例（不是实测学习权重），s28_less在距离1024/2048/4096/8192/16384上对平方弦距的影响为+.1623/−.3651/+.5320/−1.5277/−.4050。“少压缩所以分离更好”不是已验证的统一解释。

**MK2真实成功与连续margin。** 原文正确绑定为toothsome-citrus→6683176，MrPro输出另一记录toothsome-scene的9424151。prefill/read表交叉四格(00,01,10,11)得分为(0,0,0,1)，但在相同生成prefix后的正确首digit6减错误9的logit margin为(−2.125,−1.125,−1.000,+.250)。两个约1nat的连续改善近加和跨argmax；不能仅凭二元AND式结果宣称强内部非加性。MQ交叉为(.75,1,.75,1)，VT为(.8,1,1,1)，路径并不相同。

**更严格诊断限制了“绑定恢复”的解读。** 互换两条记录的等token长度数字后，两方法均错，分别输出6624365／6624369，原文不存在。首digit的两值对比仍变化，但不能当完整二选一概率。全局位置ID+1在精确静态RoPE应不改变相对算子，实际却使这条E1成功变失败；E1相对MrPro的full-path首digit margin改善由+2.25变+2.0仍在。可说方向改善存留而argmax胜利脆弱，不能说完全是舍入噪声或已稳健学会绑定。

**QA缓存交叉失去原现象。** 同表E1 full-prefill得分1，切分最后query的cached路径已变0；四格cached均0，不能解释原full成功。重建原始K通过了内部一致性检查，也不能修复“干预执行路径没保留现象”的问题。

因此，signed margin是有用的诊断量，**还不是已经解决的选表算法**。它应帮助排除错误解释、提炼规则，而不是让我们在已知答案上拟合一个新的任务代理。

## 7. 已完成的LongBridge：一项起点诊断

选择实际MrPro周期介于32K与128K的slot36–39。令其

\[
\nu_j^{\pm}=\nu_j^{Mr}\pm\frac1{131072},\qquad j\in\{36,37,38,39\},
\]

其余60槽和gain不变。频率始终正且有序。两方向在固定状态下每槽相位改变量32K为±.25rad，128K为±1rad；Slower周期变为35,446/50,830/74,190/110,764，Faster为32,637/45,245/62,864/87,285。

共同绝对频移还具有一个可核对的性质。固定Q/K，带内贡献记为 \(A(d)=\sum_j[a_j\cos(d\nu_j)+b_j\sin(d\nu_j)]\)，正交相位分量记为 \(Q(d)=\sum_j[-a_j\sin(d\nu_j)+b_j\cos(d\nu_j)]\)，则

\[
A_\delta(d)=\cos(d\delta)A(d)+\sin(d\delta)Q(d).
\]

本轮两臂保留带内所有绝对频差 \(\nu_j-\nu_k\)，因此主要是测试该带共同相位方向；它仍改变与外频段的关系，不是在测试所有可能的带内clock-spacing重分配。该恒等式已用CPU双向六距离核对，误差约8.9e−16；固定态恒等式不保证整网状态或任务分数。

这一rad是显式探索幅度，不是理论最优；B没有固定。它测试“直接调整已处于外推尺度的中后段，是否能获得有用或明显长程改善”，不声称短端整网已被严格保护，也不限定最终规则只改这四槽。即使两臂都输，也只否证这两张表，不能回推“中频不能优化长程”。

## 8. 请 Pro 聚焦的六个核心问题

1. **从失败机制到更好的整体规则，缺的最关键一步是什么？** 原始RoPE长程失败中，哪些可通过频率重分配改善：低频相位分布、联合频率共适应、过渡区外推尺度覆盖、竞争distractors，还是它们的某个组合？请给一个足够具体的解释，能同时容纳BM在OLMo的大幅成功、在Qwen的反转、P2同gain条件收益和Smooth固定预算失败，避免为每个结果单独补故事。

2. **如何把高／中／低的尺度角色变成下一张表的构造原则？** 候选可以改变过渡位置、压缩分布、局部gap、尺度相关性或必要算子，而非必须保留当前23/40边界与B。应使用native／部署周期、有效训练lag分布、频率Gram、已学内容功能中的哪些信息？请给**公式或伪代码**及可获取输入，说明为什么它可能比MrPro明显更好，哪些假设允许推断方向；只写“优化长程margin同时控制短程损失”还不构成方法。

3. **waterbed给我们的应是限制还是自由度？** 在什么条件下额外log-gap守恒，固定累计B到底保留了什么、又排除了什么有用变化？是否有理由让中前段承担更多、或保护周期在目标证据距离附近的中后段；如何避免因周期性及内容符号而给出错误单调结论？需要哪些最少条件才能把几何预算与实际长程能力联系起来，而不是把几何最优当任务最优？

4. **该规则如何使用已有正结果、又不拟合脆弱样本？** s28单点两胜、s29一个QA、组合失利、值互换失败、原点平移翻转，共同允许保留怎样的机制？BM已有独立72条大收益，P2有同gain控制，这些正例应给新规则什么建设性约束？请提出能在看目标输出前冻结的规则与预测；区分固定表迁移和零训练重新校准，允许一种有意义的条件泛化目标。

5. **最少哪几个实验能判定新规则真的走对了，而不只解释过去？** 请优先建议至多3个有独立机制差异的规则／必要控制，明确Qwen3B上比较什么、哪些现有臂复用、看哪些实际任务及长度、结果A/B/C分别意味着什么。LongBridge若出现明显收益，应如何提炼和扩大；若只有取舍或无收益，什么下一步仍沿着“更好规则”推进，而非无目的局部抖动或重新列20候选？NLL与简单检索只能提供辅助证据。

6. **怎样形成可信但不过度声称的理论贡献？** 高频局部保真、慢频相位范围、finite-window相关性、冻结权重兼容性分别有什么可证明结论和具体缺口？能否提出一个条件性命题或清晰可证伪预测，直接约束规则设计、解释适用尺度和checkpoint差异？目标不是预先证明所有任务都优于MrRoPE，也不是只证明我们已有某个几何问题解得正确。
