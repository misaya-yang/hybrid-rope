# PC2 / PM 持续研究记录：2026-09-10

这一轮接续已经结束的一小时比较。目标仍是找到有效修复及其原因；目前没有得到一种新的、低成本且跨条件可靠获胜的位置方法。失败候选不扩测，已完成的同输入对照继续复用。

## 已完成的真实生成

PM 表格各格为八个来源家族的完整字符串加终止 EOS 正确数。同一家族在三种条件下重复出现，不能把二十四行视为二十四个独立家族。所有压缩臂使用相同 25% 每层、每 KV head 名额，保留原生位置及读取器。

| 方法 | 重复背景 / 16记录 | 自然背景 / 16记录 | 自然背景 / 256记录 |
| --- | ---: | ---: | ---: |
| Full（已有） | 5/8 | 6/8 | 6/8 |
| KeyDiff 固定预算适配（已有） | 3/8 | 8/8 | 0/8 |
| Balanced P（已有） | 5/8 | 1/8 | 0/8 |
| Balanced C（已有） | 5/8 | 1/8 | 0/8 |
| Key-novel P（新增） | 4/8 | 0/8 | 0/8 |
| Key-novel C（新增） | 3/8 | 0/8 | 0/8 |
| KVzip 重构评分、固定预算适配（新增） | 5/8 | 1/8 | 0/8 |

Key-novel 比较改变正文 query 的抽样权重，按已知 key 到均值方向的球面距离抽样；H128、M256、raw V norm 和读取器保持原配置。它没有修复自然背景失败，不展开新的几何权重或采样数网格。

KVzip 适配直接调用固定 KVPress 作者的 `prepare` 和 `score_kvzip`。已知前缀被作为重构输入，真实任务问题没有进入选择过程；每个重构 chunk 后，临时 Full cache 裁回原前缀长度。最终按既有固定每 head 预算物理 gather，并自由生成答案。它未复现作者跨层、跨 head 的全局名额分配，也未使用作者 fake pruning 或 KVzip+ 修正，不能把该结果称为原论文完整系统复现。

KVzip 二十四条全部完成，包含加载在内约 **79.78 秒**；三格逐行总耗时中位数分别约 **3.36、3.20、3.15 秒**。实际重构输入合计 **183,548 tokens**，成本已记录。这个总耗时包括原前缀、重构评分、保存保留集合及最终生成；它不是优化后的部署时延或与旧计时字段无条件可比的加速比。

KVzip 与 Balanced P 的三格总正确数相同，但自然背景16记录有 **1胜1负6平**，八条输出全部不同。自然背景256记录也是八条输出全部不同、均未达到完整字符串加 EOS 正确。重复背景八条输出完全相同，尽管保留集合的哈希全部不同。不能把相同总分解释为相同机制或相同错误。

PC2 的新 covariance-tail 比较完成原定16 DEV，四任务各四条。与相同输入的 full-covariance 相比为 **0胜5负11平**。其多键 / 多查询 / 单键 / 变量追踪 recall 为 **.50 / .4375 / 1.0 / .20**，完整协方差为 **.75 / .9375 / 1.0 / .40**。这里沿用 RULER 官方答案项召回，不能与上表 strict exact 合并。

## 已有机制证据及限制

1. 在保存的真实 Q 上，原 PM 的 proxy 相对 C 全部占优，而采用同一 raw V 权重的真实 prefix mass 在九条中七条反向。去掉未来新 token 分母权重后，仍是同样七条反向。因此，分母中的 prefix mass 权重并不足以单独解释错位。九条包含共享家族，且其中六条 Full 记录答案本身错误，不能把接近它们的局部 attention 当成任务正确上界。
2. KVzip 实际保留集合重新核对了原前缀 tokenization 及每行 keep hash。自然背景16记录的 000/001，目标 value token 平均保留率约 **30.6% / 33.7%**；只有 **2/72、3/72** 个层/head 单元保留完整 value。256记录中，即将用于诊断的002/003只有约 **11.1% / 20.2%**，两条都没有层/head 单元保留完整 value。这仍是原文保留证据；其他隐藏状态可能包含相关信息，不能直接推断因果。
3. 单 key 的 Frobenius 准则确实优化了它声明的二阶矩目标，但并不适用于任意查询分布。实际候选代码的64-token有限反例中，整体遗漏协方差平方范数降约39%，一个查询方向的二阶平方误差反而升约74%，且造成真实 logmass 排名反转。一般查询的平方二阶风险需要原始四阶矩；只用均值、协方差不足以在非 Gaussian 情况下确定它。
4. 查询二阶矩子空间、低秩因子、FP4 和 Gram 构造已经在 [COBS §5.4–5.6](https://arxiv.org/html/2607.09052v1) 中出现。当前 NOSA 上的 full-space rank2 适配不是作者完整强方法；查询加权或 Gram 计算本身不能作为新颖性结论。

## 当前正在准备的决定性干预

PM 只取已冻结的002/003_prose_256：它们是按原顺序最先两条 Full 正确的 DEV，故属于有 headroom 的机制诊断，不能估计总体成功率。把实际问题所需的整条原始 Record 在每层/head 中放回原预算，移除 P 最低分且非保护的相同数量 token；另设同移除集合、同插入数量的随机 sham。保持原位置、原 prefill、原读取器，最终仍完整自由生成。使用未来问题来定位记录属于特权 oracle，不能作为合法的 question-blind 压缩方法成绩。

如果 oracle 能救回而 sham 不能，才支持这些输入上的具体信息保留因果解释；如果不能，就不能继续仅靠 span 缺失认定原因。入口和 GPU 回执尚待实际完成，不能把准备工作算作阳性结果。

PC2 同时审查只在排名无法确定时回退 exact 的可行性。需要对 GQA 各 head 的分母同时给界、保持原名额政策，并明确浮点误差；高维上下界可能过松，导致全部回退。因此当前只做有限状态筛查，不自动增加模型生成矩阵。
