## 已有机制证据及限制

1. 在保存的真实 Q 上，原 PM 的 proxy 相对 C 全部占优，而采用同一 raw V 权重的真实 prefix mass 在九条中七条反向。去掉未来新 token 分母权重后，仍是同样七条反向。因此，分母中的 prefix mass 权重并不足以单独解释错位。九条包含共享家族，且其中六条 Full 记录答案本身错误，不能把接近它们的局部 attention 当成任务正确上界。
2. KVzip 实际保留集合重新核对了原前缀 tokenization 及每行 keep hash。自然背景16记录的 000/001，目标 value token 平均保留率约 **30.6% / 33.7%**；只有 **2/72、3/72** 个层/head 单元保留完整 value。256记录中，即将用于诊断的002/003只有约 **11.1% / 20.2%**，两条都没有层/head 单元保留完整 value。这仍是原文保留证据；其他隐藏状态可能包含相关信息，不能直接推断因果。
3. 单 key 的 Frobenius 准则确实优化了它声明的二阶矩目标，但并不适用于任意查询分布。实际候选代码的64-token有限反例中，整体遗漏协方差平方范数降约39%，一个查询方向的二阶平方误差反而升约74%，且造成真实 logmass 排名反转。一般查询的平方二阶风险需要原始四阶矩；只用均值、协方差不足以在非 Gaussian 情况下确定它。
4. 查询二阶矩子空间、低秩因子、FP4 和 Gram 构造已经在 [COBS §5.4–5.6](https://arxiv.org/html/2607.09052v1) 中出现。当前 NOSA 上的 full-space rank2 适配不是作者完整强方法；查询加权或 Gram 计算本身不能作为新颖性结论。
