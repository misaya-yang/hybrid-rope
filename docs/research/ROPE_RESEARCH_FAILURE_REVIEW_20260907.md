- 日期：2026-09-07；状态：基于已有回执摘要的研究复盘，不是新实验结果或启动指令。
- 范围：作者报告长期存在“猜想—失败实验”循环；本文能直接举证的是本轮 Qwen 与已核对的 OLMo E0/E1，不把未逐轮审计的半个月经历全部归因于同一个原因。
- 当前结论：尚无已证实的方法突破、超越 MrRoPE 的结果或可直接升格的论文主贡献。准备、文档与代码完成不能替代这三项。

## 研究失效的具体链条

1. **统计到干预缺少依据。** 分位匹配与合法投影可以数学正确，但未证明或充分支持“观测到的增长应转化为该槽位的压缩”。需要可检验的机制联系，不要求等到完整最优性定理。
2. **改动范围与研究意图脱节。** 意图是结合 MrRoPE、CoPE 与已有分配证据，实际却先大幅重写有效中段，再用 GPU 重新发现兼容性代价。新的中段方案仍可研究，但应有比任意替换更强的理由。
3. **终点不足以区分解释。** 小样本 QA 措辞差异、困难任务地板效应和 EOS 门槛，使一些分数不能回答“哪个频段有问题”。最小有效参照与全面复现矩阵不是一回事。
4. **失败后换候选，未知却没减少。** 组合变了，仍不知道自己的分配比现成 MrPro×CoPE 增加什么。下一轮必须从已有失败得出选择依据，不能只换名字或曲线。
5. **执行停顿放大成本。** 逐次审批、小实验即交接和额外打包浪费连续研究时间；这些规则已修正。但研究判断失误不能全归咎于 AGENTS.md。

这不是对某型号数学能力上限的测量，也不是证明 RoPE 不可改进。我们实际失败在选取可用问题、把理论用于干预、建立可解释实验及连续执行这几个环节。

## 下一轮的核心问题

**以 MrRoPE 的有效分配与 CoPE 的深尾处理为起点，结合本方已观察到的代价和局部收益，什么可计算依据能决定中段、低频和衔接的下一项改动，使它有机会改善实际能力；什么最小实验能区分这种依据正确、实现/协议失败和该候选无效？**

“本方统计是否比 MrPro×CoPE 多做了有用的事”是当前组合的关键未知，不是规定所有未来方法都必须沿用这个组合。Pro 可以否定统计、组合或我们的诊断，但必须指出证据与替代的具体工作。

研究目标仍包含冻结部署、自己的轻量适配、自己的从零训练；先用低成本冻结实验获得有解释力的信号，不把该顺序写成其余两条路线的数学门槛。禁止自动恢复旧 Cosh 搜索、对手微调或 seed42 权重恢复。

## 作者进一步纠正：从有效方法的剩余自由度推导，不重新从零猜

2026-09-07 补充。作者强调已有 MrRoPE 等有效方法，应围绕高频是否可动、中段分配、低频旋转与区域衔接推进。下面是依据原文及当前 Qwen 参数的新增代数分析；不是效果证明，也未运行新 GPU 实验。既有 Pro 提示词已经发送，不静默改写它来冒充对方已收到这些内容。

[MrRoPE §3.2.2](https://arxiv.org/html/2601.22181v1) 将相邻 radix 的对数增量设为等差数列，再归一化得到 MrPro。等差性是设计假设，不是从模型能力最优性推导出的必要条件；高频不动、低频统一插值也不是论文证明的唯一可行分配。Appendix B 有边界实验，不能把重新调边界本身宣称新贡献。

### 高频是否能动，取决于所保护的距离与相位，不是分区标签

设频率改变 δν，在相对距离 Δ 上，额外相位就是 Δδν；单槽旋转差为

\[
\|R_{\nu+\delta\nu}(\Delta)-R_\nu(\Delta)\|_2
=2|\sin(\Delta\delta\nu/2)|.
\]

Qwen K=64、base=10^6，原生 ω_j=10^(−6j/64)。高频边缘 j=23 的 ω≈0.0069783。改变其原频率的 1%，在距离 128 上额外相位约 0.00893 rad，在 32768 上约 2.28665 rad。局部扰动小并不保证全部 Native 距离安全；但这也不支持“高频绝对不能动”。正确研究变量是距离加权下的可用频率改变量，不能以同一相对百分比代表全谱的同等干预，也不能把旋转界当生成保证。

### 过渡应写成相邻 log-frequency 间距，而不是先选光滑曲线

对于正频率，令 ν_j=ω_j s^(−m_j)，h=ln(10^6)/64，则精确有

\[
g_j=\ln(\nu_j/\nu_{j+1})=h+(m_{j+1}-m_j)\ln s.
\]

因此中段累计压缩、低频提升和区域衔接是耦合的。改变 m 的局部差分就改变真实频谱间距；“更光滑”应先说明哪个间距变化影响了哪些模型功能，不能直接视为收益。要求频率降序是当前候选的约定，不是所有 RoPE 必须遵守的数学定理。

具体到 s=4、边界23/40，当前 MrPro m_39=8/9、m_40=1，ν_39≈6.43555e−5、ν_40≈4.44570e−5。若 ν_39 保持不动且 ν_40≤ν_39，则第一枚低频相对 MrPro 的提升上限为

\[
\nu_{40}^{new}/\nu_{40}^{Mr}\le1.44759,
\qquad m_{40}^{new}\ge0.733174.
\]

等号形成等频；若要求严格降序，必须严格小于上限。这仅是几何可行范围，不是推荐值。想把第40槽从 `/4` 改到 `/2`，同时固定第39槽且保持降序，就不可能成立；必须联动上游中段，或明确允许频率交叉并研究其影响。不能先各段独立修改再排序，因为排序会改变权重对应的槽位身份。

当前 MrPro 的 g_39≈0.36990，进入统一低频后的 g_40≈0.21587；其间距确有变化，但没有证据证明这处变化是性能瓶颈。它是可研究的具体自由度，不是预先成立的故障。

### 低频也不是同一种旋转状态

按目标窗口131072计算，MrPro `/4` 后各槽转数为 L0·ω/(2π)，不压缩时为它的4倍：

| 原槽位 | MrPro 目标窗转数 | 不压缩的目标窗转数 |
| --- | ---: | ---: |
| 40 | 0.927406 | 3.709625 |
| 48 | 0.164919 | 0.659675 |
| 63 | 0.006472 | 0.025887 |

这些是精确参数计算的近似显示值，不是有效信息量。同属低频，槽40与槽63的相位覆盖完全不同。固定K时，“增加旋转分量”需要区分提高已有槽位频率、使更多槽位覆盖所需距离尺度、以及改变非旋转内容通道；不能假定多转几圈就增加独立信息。

[CoPE 固定代码](https://github.com/hrlics/CoPE/blob/f8957a1c7e4891f31266ca79299437a672175a1a/modeling_cope.py) 则对末20槽进一步减频，末槽变零。两种方向可能适用于不同槽位/功能，但目前没有证明这种分工。因此可用的研究问题是：哪些较慢槽位值得恢复位置变化、哪些更慢槽位值得保留稳定内容，以及这种分配如何与上游间距共同决定。不能把整段加速或整段减速当答案。

以上缩小了需推导的对象：在有效 Mr 分配周围，研究每槽可用相位改变与相邻间距如何共同分配。它不是新曲线、拟定最优目标或新的实验矩阵；尚欠的关键一步是用现有权重/响应证据确定这些自由度的有益方向，而非仅给几何上合法的取值。


## 继续核查：已有证据能直接纠正哪些方法判断

本节为用户指出再次提前结束后实际完成的研究；复算见 [CPU 结果](ROPE_SCALE_TRANSPORT_ASSUMPTIONS_20260907.json) 与 [复算入口](../../scripts/analysis/diagnose_scale_transport_assumptions.py)。无新模型前向或 GPU 实验，不把这些诊断写成已解决方法问题。

### 当前提案实际做了比“改中段”更具体的三件事

从原 proposal.json 复算：第24–39槽全部比 MrPro 慢，比例为0.28205–0.85724；第40–63槽约为 MrPro 的1–1.71165倍。投影形成8对相邻等频，64槽只剩56个不同频率；槽23→24的 log-frequency 间距由 MrPro 的0.22493增加至1.48037。

因此它同时引入了中段过度压缩、高/中接口大间距和重复频率。重复频率不删除 Q/K 内容通道，但减少不同旋转频率的数量。这些变化不能仅凭当前QA结果分配因果责任；也不应把该提案失败理解为“适当修改中段已经失败”。三个现象都能从已执行数组得到，无需再买一次生成才能发现。

### 独立相位响应与统一换频的响应不是同一个量

Pro 原文定义 χ_i=||∂y/∂φ_i||²，对应每个 key 的独立相位微扰；原文已明确它不是正确答案效用。因此这不是发现其导数公式有误，而是发现我们不应把该量直接当逐频率分配依据。

单个槽位的频率变化同时移动所有 key 的相位。令 u_i=∂y/∂φ_i，则

\[
\frac{\partial y}{\partial\nu_j}=\sum_i\Delta_i u_i,
\qquad
\left\|\frac{\partial y}{\partial\nu_j}\right\|^2
=\sum_{i,k}\Delta_i\Delta_k\langle u_i,u_k\rangle.
\]

只保存 χ_i 会丢失 i≠k 的相干项；给 χ 再乘距离平方也不能恢复它。当前表跨head共享时，还需要相应的跨head输出项；跨layer的最终能力传播更不能由层内能量求和代替。

**精确两key softmax算例：** 距离(1,2)、值(1,0)，在ν₀=0.2处两个logit均为0。取 z₁=8sin(ν−ν₀)，分别令 z₂=+4sin(2(ν−ν₀)) 或 −4sin(2(ν−ν₀))。每个logit均可写成固定C cos(νΔ)+S sin(νΔ)，属于一个合法rotary pair的形式。

两个算例的独立相位能量均为(4,1)，但统一换频的输出导数分别为0和4；直接softmax中心有限差分得到0和3.99999999992。相同的H/归一化距离响应，并不能识别相同的换频作用。该算例只证明统计量的信息缺口，不证明本次全部失败都由此造成，也不否定尺度统计用于其他诊断。

由此应改变构造依据：若继续使用缓存校准，应保留实际频率共享方式下的有符号响应及其相干项，而不是从各槽非负能量分布独立推出β。该信息可从现有原始Q/K/V和输出投影重新计算，不需要为了补这项信息重训权重；当前紧凑本地回执不包含全部缓存，不能声称已经算出真实模型的这些量。即使补全，它首先识别的是局部输出变化，仍须建立有益方向，而不是自动成为最优分配。

### CoPE 的幅度滤波论证不能直接替代频率搬移推导

[CoPE Appendix A.2](https://arxiv.org/html/2602.05258v1) 推导的是频谱幅度乘高通mask。其 [固定代码](https://github.com/hrlics/CoPE/blob/f8957a1c7e4891f31266ca79299437a672175a1a/modeling_cope.py) 则把 inv_freq 乘窗：频率原子的位置发生变化。

对单槽 C cos(νΔ)+S sin(νΔ)，将频率设为0得到常数C；将该谱原子的幅度设为0得到0。Δ=0、C=1时两者分别为1和0，是直接反例。更一般地，频率映射改变谱原子位置；它不是给原谱密度乘一个窗。因此“光滑幅度窗抑制某类振铃”不能不加论证地推出“光滑修改频率一定改善注意力”。这是对理论适用性的判断，不推翻其实际训练结果，也不要求重跑该论文。

研究过渡时应使用完整C/S相位项和真实频率映射；不能从一条更平滑的外观直接认定它优于 MrPro 或 CoPE。

### 已有 Qwen 结果也不支持把降序当不可突破的要求

[历史log-p2结果](../../paper-2027/research/attention-aware-retrofit/results/coupling-transfer/SCALE_CONSISTENT_LOG_PROFILE_RESULT_20260831.md) 记录自构造表的局部频率交叉及有效长任务输出；[后续Qwen 1.5B owner](../../paper-2027/research/attention-aware-retrofit/results/coupling-transfer/LOW_DIM_COUPLING_GPU_RESULT_20260901.md) 和 [紧凑回执](../../paper-2027/research/attention-aware-retrofit/evidence/LOW_DIM_COUPLING_GPU_RECEIPT_20260901.json) 记录去除孤立非单调尖峰后的混合结果。

这是旧Qwen 1.5B研究链的历史证据，不是今日Qwen 3B结果，本节没有重新取得旧逐行原始输出。它足以提醒：槽位身份要保留，但频率必须降序不是已确立的模型规律。上节44.8%上限仍是正确的条件性几何计算，不能用它缩小所有允许的方法。

### 下一步仍然是方法工作，不是追加实验矩阵

这些结果淘汰了三种偷懒替代：用非负响应直接推压缩方向，用光滑外观代表更好的过渡，用排序约定代表模型不可变约束。不能用另一个任意目标函数补位。当前尚未选出能据此改善实际任务的新分配；不把诊断完成登记成整个研究阶段完成。
