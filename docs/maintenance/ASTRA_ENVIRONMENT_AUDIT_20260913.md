## 技能范围

本次检查了仓库指令入口和隐藏技能目录；已有 `.claude` 仅发现调度锁文件，没有项目技能。
全局 `onboard` 的固定阅读顺序、文件数量、输出菜单及日志流程不应成为本项目默认工作流；本项目直接使用根索引的任务路线。该技能为跨项目资源，本次未修改。

新增技能采用独立名称，避免与全局技能同名并存。描述只触发证据核实/登记，不为普通代码修改、排版或错字修复加载科学审计流程。正文按需指向现有索引，没有复制整套研究计划，也没有要求调用额外技能。

全局与插件技能目录仍由用户环境管理；本轮没有宣称已减少整个会话的技能元数据。未改全局模型设置、插件缓存或其他项目技能。技能放在仓库 `.agents/skills`，可随 Git 分发；本次验证文件结构和链接，未声称验证了新会话中的自动选择行为。

## 验收

- 文档检查通过：99个受管理文档、1404个本地链接、30项资产、57次来源检查，零错误；技能 frontmatter 验证和 `git diff --check` 均通过。
- `.gitignore` 原先忽略整个 `.agents/`；现仅为新增项目技能开放 Git 分发，其他本地 agent 状态继续忽略。
- 阅读路线检查：已知文件小改动直接进入文件；核实论文数字进入证据 owner；继续实验进入本地索引并检查实时状态；全文重构才需要大型交接。
- 保留原有未提交工作、证据路径和科学结论；未执行模型实验、下载、远端操作、提交或推送。

本记录是维护结果，不是每次启动必读文档。新增配置应解决实际重复出现的问题；不为某个模型建立第二套科学事实源。
