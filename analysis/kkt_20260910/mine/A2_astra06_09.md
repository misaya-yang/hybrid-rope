## 1. astra06 — 精确有限通道 softmax-mass 分配 + 全局整数 DP

### 1.1 精确陈述（目标 + 假设 + 结论）

**核心主张**（astra06:7–13）：当"被请求的计算"是 **softmax 源质量**时，存在比成对 SNR 更强的共享判据 J = v/2 − μ（μ 为确定性有用源分数，v 为相干干扰分数方差）；在声明的 "shared-bin + nested covariance" 模型下，该判据有**精确整数 DP，可分配 K 个等幅通道**。常数保护 μ 恢复离散 Cosh 律，相干远程源贡献带符号余弦 μ ——即 MrRoPE 的动机项。

**结论 1（mass 界，式 1）**（astra06:27）：
对 0<ρ<1，
```
P[p_* < ρ] ≤ min{1, [ρ/(1−ρ)] Σ_t exp(b_t + v_t/2 − μ)}
```
[已验证-推导]。**无 key 间独立性假设**。

**结论 2（充分条件，式 2）**（astra06:31–35）：若全部干扰 b_t=0 且公共方差 v，则最小化 v/2−μ 精确最小化右端（裁剪到 1 之前）。失败概率 ≤δ 的充分条件：

### 1.2 ★ 本任务重点：整数通道 DP 的**目标函数与约束**完整抄录

**坐标与标记**（astra06:41，原文用词照抄）：
- 声明 B 个 **resolved frequency bins**，间距 Δ=1/B；
- 代表点 x_i = iΔ，i=1,…,B；ω_i = exp(−x_i)（或用归一化指数 b^(−x_i)）；
- 落入 bin i 的 slot **贡献与其他 slot 相同幅度**（等幅假设）；
- n_i = bin i 中 slot 的**非负整数计数**；Σ_i n_i = K；经验计数质量 p_i = n_i/K；
- 支撑是 **[Δ, 1]**（原文明确：若需要精确支撑 [0,1] 须加零点节点并配正确的零 Brownian 增量权重；**不得把右端点 bin 规则静默称作 endpoint-pinned RoPE**）。

**协方差（约束环境，式 3）**：
```
C_ij = (α/Δ)·1{i=j} + β·min(x_i, x_j),    α>0, β≥0
```

**精确均值与方差（式 4）**（astra06:54，用 min-kernel 恒等式 min(i,j)=Σ_r 1{r≤i}1{r≤j} 展开）：
```
μ(n) = K⁻¹ Σ_i h_i n_i
v(n) = K⁻² [ (α/Δ) Σ_i n_i² + βΔ Σ_i T_i² ],      T_i = Σ_{j≥i} n_j
```

**★ 目标函数（式 5）—— 这是"最接近 KKT 的可执行件"**：
```
min_{n_i ∈ Z_+, Σ_i n_i = K}   Σ_i [ (α/(2Δ)) n_i² + (βΔ/2) T_i² − K h_i n_i ]
```
**约束集（完整列举）**：
1. `n_i ∈ Z_+`（**非负整数**计数）—— 整数性是不可放弃的，见 §1.5；
2. `Σ_i n_i = K`（**通道数守恒**：K 个等幅通道全部被分配）；
3. `T_i = Σ_{j≥i} n_j`（尾计数，是 n 的确定性函数，非独立变量）；
4. 端点/占用率/每 bin 最小通道数约束**通过限制 min 的 n 取值范围**施加（astra06:63），**不改变证明结构**；
5. 允许**重复频率**：K 个频率位置由 ω_i 精确重复 n_i 次给出；**重复频率保留其 K 个独立内容坐标对，不删除通道**，只是减少不同旋转的个数。若要求**不同频率或最小间距**，(5) 的可行集就变了，**事后把重复项摊开不是 (5) 的精确解**。
6. B 是**声明的物理协方差分辨率**，不是任意的候选曲线扫描网格；**固定 α 细化 B 会改变局部噪声模型，不是无害的数值细化**。

**★ DP 递推（式 6）**：
```
F_{B+1}(0) = 0;   F_{B+1}(t>0) = ∞
F_i(t) = (βΔ/2) t² + min_{n = 0,…,t} { (α/(2Δ)) n² − K h_i n + F_{i+1}(t−n) }
```
存储最小化 n，从 F_1(K) 回溯。复杂度 **O(BK²) 时间、O(BK) 内存**；**无局部极小、无未知连续求解器条件**。等分 bin 的并列按字典序打破。

**我独立复算（[已验证-本地复算]）**：DP 目标与判据 J 的换算关系恒等 ——
```
K²·J = K²·(v/2 − μ) = Σ_i [ (α/(2Δ)) n_i² + (βΔ/2) T_i² − K h_i n_i ]   ← 与 (5) 完全一致
```
即 **(5) 就是最小化 v/2−μ**。数值：B=16,K=64,α=1,β=4、h=20 时 DP 输出 J = F_1(K)/K² = **−18.8952331543**，而 v/2−μ = 2.2095336914/2 − 20 = **−18.8952331543**，逐位吻合。这是把 (5) 与 (1) 的判据绑定起来的**关键等式**，也是 F 零件可用的理由。

**源项 h_i 的两种情形**（astra06:49）：
- 保护源：h_i = A（常数）→ 线性项为常数，优化只剩二次型；
- 对齐远程源（lag D）：h_i = A cos(ω_i D − θ_i)，**保留真实带符号相位约定**；
- 一般确定性非旋转或 sin/cos 源贡献可并入 h_i。

**冻结带标签变体（§"Frozen labeled channels"）**（astra06:69–73）：计数模型只在**可交换通道响应**或 **scratch 设计**下可用。冻结槽 j 时把 h_i 换成 h_{j,i}，保留原 slot 标签；在声明的单调赋值下，DP 状态 (i,t) 把接下来 n 个连续标签 K−t,…,K−t+n−1 分给 bin i，并把 −K h_i n 换成 `−K Σ_{j=K−t}^{K−t+n−1} h_{j,i}`；任何 slot 频率约束违例则禁止该 n。在协方差 (3)（bin 依赖、label 无关）下协方差代价仍只依赖 n,t ⇒ **仍是精确 O(BK²)，用预算源代价前缀**。**但真实异质 slot 协方差一般会破坏这一分解**（原文自限）。

### 1.3 离散 Cosh vs 连续 Cosh（§4）

常数 h 时 (5) 的线性项是常数；在连续计数质量松弛 p_i≥0, Σp_i=1 下最优解满足 **Cp = λ1**。相邻方程**两次差分**给出
```
p_{i+1} − (2 + βΔ²/α) p_i + p_{i−1} = 0      （外边界条件 p_{B+1} = p_B）
⇒  p_i ∝ cosh[ κ (B + 1/2 − i) ],   κ = arcosh(1 + βΔ²/(2α))      (7)
```
[已验证-本地复算]：我核了差分链 —— 由 (Cp)_i = (α/Δ)p_i + βΔ f(i) = λ，一阶差分给 (α/Δ)(p_{i+1}−p_i) + βΔ T_i = 0，二阶差分用 T_i − T_{i−1} = −p_i 得上式；i=B 处 T_B=0 给 p_{B+1}=p_B。**代数自洽**。
Δ→0 且处于 resolved density regime 时 κ/Δ → √(β/α)，(7)/Δ → Cosh 密度。**精确有限 K 的答案仍是整数 DP，不是 (7)**（原文强调：这防止把幅度权重伪装成物理计数）。

**非恒定 h（关键）**：松弛 KKT 变为 **Cp − h = λ1**（占用 bin）/ **Cp − h ≥ λ**（空 bin）；连续形式极限
```
α ρ'' − β ρ = h'',     α ρ'(1) = h'(1)
```
外加归一化与正性 binding 时的自由边界。[已验证-本地复算]：我从 αρ' + βS = h' + const、S'(x) = −ρ(x) 推出同式与同边界。**结论：有用信号跨频率变化时不存在普适 Cosh 轮廓**。原文自注（astra06:92）：**该式的 h 系数与标准化-margin 问题不同**，因为这里优化的量是**指数矩质量界**，不是齐次 SNR 比。

**对两条直觉的判决**（astra06:94，[叙事-未验证]，但是对本项目有直接价值）：EVQ 的常数有用信号最小化 nuisance 方差；Mr 式远程相干内容使 h 振荡并**有时**倾向保留正的低频信号。**两者都不强制三段中频过渡，也不强制精确的 t(t+1)/[n(n+1)] 指数。**

### 1.5 反例清单（§6，原文自标"整合必须幸存"）

1. **成对 SNR 改善 ≠ 多 key 支配**（astra06:139，[已验证-本地复算]）：均值 .8、方差 1、独立噪声两条高斯边缘 → 全正概率 Φ(.8)²=**0.6211719127**；均值 .5、方差 1、**完全相关** → Φ(.5)=**0.6914624613**。第一种**每一个**成对标准化 margin 都更好，**联合检索更差**。更强的单调排序充分条件：公共耦合 M_A=m_A+DZ、M_B=m_B+DZ（同对角尺度 D、同联合噪声 Z、m_A≥m_B 逐分量）⇒ 成功事件逐样本嵌套。**这是实体结构，协方差摘要不足以推出**。
2. **独立各向同性通道噪声不提供 EVQ 碰撞目标**（astra06:141）：若 A_j,B_j 为 iid 零均值高斯正交分量，Var Σ_j[A_j cos(ν_jd)+B_j sin(ν_jd)] **与 ν,d 无关**。K 个独立每通道误差时通道平均的方差为 K⁻¹∫v(x)ρ(x)dx，**对密度线性，不是 α∫ρ²**。⇒ 必须有共享有限分辨率噪声或其他显式相关模型。
3. **均值/协方差相同不决定非线性任务失败**：Cantelli 是上界不是精确排序；失败上界更小**不证明**真误差更低。
4. **联合环面容containment 强于边缘相位覆盖**：保持每个慢相位在本征边缘区间内**不必**保持联合向量 (ω_1d,…,ω_Kd) 在原一参数轨道上。公共 PI 在 retimed lag 上精确保持该轨道；独立压缩一般不能。
5. **移植刚性是有条件的**：全空间恒等式 AᵀR_new(d)B = R_old(d)（开 lag 区间上）⇒ 谱匹配，但**不排除**在真实使用的低秩内容子空间上补偿、不改未用通道、或学到的适应访问新隐方向；也**不逻辑强制**某个具体位移表（任何正表都可写成 native 相对位移）。
6. **Astra02 的整数-lag 区分**：其唯一有限原子均衡证明对**区间上正的连续距离先验**成立；**有限整数-lag Gram 在符号测度上有限秩、非严格正定**，唯一性证明不直接迁移。q=0 时有限矩向量有 ≤T+1 个点的原子表示（凸包几何），但唯一性可失；[0,π] 上的均匀测度在每个正整数 lag 上余弦矩为零，是该支撑/先验的扩散极小。[假设反例，不是通常的 RoPE [1/base,1] 区间]。

## 2. astra07 — 适应是学习算子；自由系数不辨识密度

### 2.1 核心陈述

共同有用对象 = **指定内容总体上的带符号 源-vs-干扰 margin**；生命周期经**学习其系数的实际映射**进入。零更新时继承带标签系数重要；适应后**均值与协方差必须按该学习映射重算，不能作为标量惩罚贴在一个未变的几何最优上**（astra07:7–8）。

两条严格结果（astra07:10–12）：
1. 仿射-logit softmax 族中，信息投影给出精确的 **approximation + compatibility** 分解，前提是最优解对**同一目标与上下文测度**做矩匹配；凸适应约束加一个显式非负 KKT slack。**一般非线性 Transformer/LoRA 参数化不继承该等式**。
2. 高斯带符号-margin 模型中，指数选择误差界的对数是一个**由 margin 分布导出的二次型**；其有限步适应有**无正则子的闭式**；给出显式生命周期交叉，并说明**更多允许的适应可伤害另一个长程部署总体**。

### 2.2 精确 softmax 分解（§3，式 S1/S2/S3）

符号：固定评估上下文 c 与有限候选集；特征 f_Ω(c,k)、偏移 b_Ω(c,k)、上下文测度 P。
```
q_{Ω,u}(k|c) = exp[ b_Ω(c,k) + uᵀ f_Ω(c,k) − A_{Ω,c}(u) ]
A_Ω(u) = E_P A_{Ω,c}(u);   m_Ω = E_P Σ_k p*(k|c) f_Ω(c,k)
```
除目标熵与偏移期望外，期望前向 KL = A_Ω(u) − m_Ωᵀ u。若**有限无约束**极小 u* 存在，则 **grad A_Ω(u*) = m_Ω**，且对任何继承/部分适应的 u0：
```
E_P KL(p* ‖ q_u0) = E_P KL(p* ‖ q_u*) + E_P KL(q_u* ‖ q_u0)          (S1)
```
证明：差 = E_P Σ_k (p*−q_u*) log(q_u*/q_u0) = (u*−u0)ᵀ[m_Ω − grad A_Ω(u*)] = 0。**偏移自动抵消**（同候选族），**不需特征线性独立**。[已验证-推导；asta07 报 CPU 聚合残差 9.88e−15]

**共享系数跨多上下文时矩匹配是聚合的**：逐上下文恒等式一般**不**成立。CPU：聚合残差 **9.88e−15**，**逐上下文最大残差 0.38397**（astra07:59）→ 论文**不得**把聚合方程写成逐行证书。

**受限仿射适应**：u = u0 + Uv（U 固定）。把 f 换成 Uᵀf、b 换成 b + u0ᵀf；(S1) 对无约束 v 空间的最优解与同仿射空间内每个 v 都成立。**U 描述实际允许的函数方向；其取值不由名义 LoRA rank 单独确定**（astra07:63）。[重要：这是**响应算子**的变量族定义]

**凸约束（S2）**：闭凸可行集 C、u0∈C，u* 在 C 上最小化 KL，则精确恒等式
```
KL_P(p*‖q_u0) = KL_P(p*‖q_u*) + KL_P(q_u*‖q_u0) + (u0−u*)ᵀ[grad A(u*) − m]   (S2)
```
末项由凸一阶条件**非负**，只在可行弦 u0−u* 与剩余矩正交时为零（内部仿射最优）。**这是带 slack 的精确 Pythagorean 不等式**。CPU slack = **.259319883**，与 KKT 表达式吻合。

**非线性（S3）**：一般 logits η(θ)，稳态给 J_η(θ*)ᵀ(q*−p*)=0，**KL 残差却是**
```
E_P (q* − p*)ᵀ [η(θ0) − η(θ*)]            (S3)
```
切线不是有限弦；该式**不必为零或非负**。CPU 例 η(u)=(u,u²,0)、p*=(1/3,.38,.2866667)：严格稳态局部最优 u*=0，u=.5 处残差 **−0.0116667**。**真实 Q/K 乘积、变化的隐状态、低秩分解更新正是仿射等式不可用的弯曲几何。**

**存在性边界**（astra07:83）：若下确界只在发散 logits 处达到（如可分 one-hot 目标），**有限 u* 不存在**；必须改用有界可达集、证明适当极限结果、或报告缺失的有限投影。**任意加 ridge 造出最优解是改变问题，不是 softmax 的推论。**

### 2.3 ★ 可辨识性边界（本任务重点之一）

**边界 1 — 密度/系数规范不变（gauge）**（astra07:175–184，§6）：
连续响应模型 M = ∫ ρ(x) a(x) Z(x) dx，ρ≥0、∫ρ=1。若 a 不受限，且 ρ1,ρ2 在**同支撑**上为正，取
```
a2(x) = ρ1(x) a1(x) / ρ2(x)
```
则**每个已实现 margin 完全相同**，不只是均值或方差。⇒ **任意正密度改变是该无约束连续模型的规范（gauge）**；**不存在唯一的计数分配最优**。数值核验：规范不变性检查的**已实现 margin 最大差 = 0**。
**打破不变性的手段**：对 a 加**物理上可辩护的**界或正则；**有限 K** 也能打破（采样特征字典不同）。
**原文的重要限制**（astra07:184）："这**不**意味着真实分配是惰性的——匹配实验证明相反——而是**过度自由的连续模型抹掉了它本想解释的那个资源**。"

**边界 2 — α∫ρ² 需要"共享噪声 + 等载荷"**（astra07:190–201）：
- **独立通道噪声给的是另一条计数律**：频率轴分宽 dx 的窄 bin，bin 内 Kρ(x)dx 个独立通道，聚合有用载荷须为 w(x)dx，每通道独立噪声方差 σ(x)²；bin 内均分最小化噪声 ⇒
```
V_ind = (1/K) ∫ σ(x)² w(x)² / ρ(x) dx                (C1)
Cauchy–Schwarz ⇒ V_ind ≥ (1/K)[∫ σ(x)|w(x)| dx]²
ρ*(x) = σ(x)|w(x)| / ∫ σ|w|                          (C2)
```
**这是具体的 Neyman 型计数分配，不是 EVQ；不含 α∫ρ²。** [已验证-本地复算：Cauchy–Schwarz 推导与等号条件 ρ∝σ|w| 正确]
- σ 或 w 为零时**零占据可达**；正密度只能取到**下确界**，除非强加占据下界。有限 K 要求整数计数与取整后的精确有限方差。
- CPU 四 bin 例：计数分数 `[.102564, .410256, .025641, .461538]`、K=64 时方差 **1.48535** vs 均匀 **2.33203**。**是连续计数松弛，不是整数 K 通道最优**。
- **共享频率局部噪声场**贡献的是聚合载荷的二次型 wᵀC_shared w。**若 w 本身固定，重排计数不能降低该共享分量。** 若假定**每通道等载荷**，则 w ∝ ρ，共享 bin 协方差确能产生 **α∫ρ² + β∫S_ρ²**。⇒ **"等载荷"是把协方差目标连到频率计数密度的关键限制**。[这是 KKT 推导必须显式声明的结构假设]

**边界 3 — 聚合 vs 逐上下文**（见 §2.2）。经验矩只在**经验测度**上给恒等式，不在新的长上下文上。

**边界 4 — U 不由 LoRA rank 确定**（astra07:63）。

**边界 5 — 理想白噪声场不能在原子点求值**（astra07:220）：K 通道实现前需要**声明的有限 bin 或有限相关宽度模型**。Astra02 进一步说明精确光滑有限窗碰撞核可有**有限原子均衡**，故其 delta 近似不是无害的。

### 2.4 ★ 响应算子（本任务重点之二）

**G1 — margin 的指数矩（生成目标）**（astra07:91–100）：对指定操作/lag 总体，X_Ω ∈ R^K 收集某有限表下**带符号的每通道 有用key−干扰 贡献**，保留实际 cos/sin 相位。实载荷 a 产生 margin **M = aᵀX_Ω**。设 X_Ω ~ N(μ_Ω, C_Ω)（一个精确实现在"固定 query + 高斯 key/系数不确定性"下成立；**任意高斯 Q 与 K 的乘积本身不是高斯**）。则
```
K_Ω(a) := log E exp(−M) = −μ_Ωᵀ a + (1/2) aᵀ C_Ω a        (G1)
```
Markov 给 P(M≤0) ≤ min(1, exp K)。**该界不是精确误差**，但其来源是显式的带符号选择误差；**没有几何 bonus 也没有正则子**。在有效次高斯包络下 G1 是 log-MGF 的**上界**而非等式。按 lag 条件高斯**不**意味着无条件高斯混合；需要时用各类 MGF 的 log-sum-exp。对目标 margin η 用 η+K。**面对 N 个干扰要相加或按类 log-sum-exp；单个随机 key 均值在 128K 不够。**

**G2 — 有限步学习算子（★ 响应算子的核心）**（astra07:105–117）：在总体 A 上训练，a = a0 + Uv，v0=0：
```
H = Uᵀ C_A U;    d = Uᵀ (μ_A − C_A a0)
v_{t+1} = (I − η_step H) v_t + η_step d
⇒  v_n = f_n(H) d,   f_n(λ) = [1 − (1 − η_step λ)^n] / λ,   f_n(0) = n η_step
    a_n = a0 + U v_n                                        (G2)
```
**这是显式学习算子，不是替代未知适应的范数球。** 正曲率上的安全固定步长稳定条件：**0 < η_step λ_max(H) < 2**。有限 n 在域外仍代数有定义，但**不得声称稳定**。

**G3 — 部署（不重拟合长目标）**：
```
K_D(n, Ω_A, Ω_D) = −μ_Dᵀ a_n + (1/2) a_nᵀ C_D a_n         (G3)
```
生命周期情形：n=0（冻结）、固定 U（受限系数适应）、U=I（全系数方向）、公共初值 a_init + 声明 A/Ω_A（简化模型下的 scratch）。原文自限：**这些都是系数模型情形，没有一条是"深度模型像固定特征 GD 那样训练"的定理，也没有一条说自由 gain 适应等于完整 Q/K/V/O 适应。**

**G4 — 同总体无约束最优**：
```
a* = C⁻¹ μ;    K(a) = −(1/2) μᵀ C⁻¹ μ + (1/2)(a−a*)ᵀ C (a−a*)     (G4)
```
⇒ **最大拟合标准化 margin 与最小高斯指数界方向相同（都是 C⁻¹μ）**。G4 是 S1 的高斯二次对应物。**非负载荷需要 active-set 解；裁剪 C⁻¹μ 一般不解约束问题**（与权威文档 §4.2 "不能直接裁剪代替 active-set 求解"一致）。

**G5 — 有限步分配导数（外层必须对学习映射求导）**（astra07:136–146）：对表参数 x_j，固定 a0,U，令 V_tj = ∂v_t/∂x_j：
```
V_{t+1,j} = (I − η_step H) V_tj − η_step (∂_j H) v_t + η_step ∂_j d,   V_0j = 0
∂_j K_D = −(∂_j μ_D)ᵀ a_n + (1/2) a_nᵀ(∂_j C_D) a_n + (C_D a_n − μ_D)ᵀ U V_nj   (G5)
```
RoPE x_j = −log ω_j 时：**∂_x cos(ωd) = ωd sin(ωd)、∂_x sin(ωd) = −ωd cos(ωd)**。
[已验证-本地复算]：G5 的链式求导我独立核过（∂_j a_n = U V_nj，K_D 三项微分一致）；RoPE 两个偏导也正确。
**关键提醒**：若 a0 或 U 本身依赖 x，其导数也须入 G5。**原生保留是以自身 μ_N,C_N 或精确原生任务 margin 评估的硬约束，不因训练目标下降而自动成立。** 连续频率优化**仍非凸**；n=0 情形用 astra03 的认证有限相位内层求解器。**不得称局部稳态表为全局最优，也不得声称未知的目标传输已被此代数推断出来。**

## 3. astra08 — 可辨识角色 margin 与有限源校准分配

### 3.1 核心判决（astra08:7–12）

**存在一个带可辨识标签的具体分配目标，但现有 6 份自然文本 32K capture 无法评估它**：每文档一个 last-natural-token query、四个采样 head、Native 频率配 MrPro 公共 gain、全部因果 key；**既无 question query，也无 target/distractor 角色**。它们只能约束那些行上的兼容性。**把它们的支配 key 称作"正确目标"就是重复本项目的代理替换。**

可用规则 = **用角色标注的源窗反事实任务拟合一张有序有限频率向量，配精确三角重放与完整 normalizer；把提议的注意力改动按源模型实测的答案敏感度加权；保留精确源兼容约束；接受判据是实际全模型输出。** 不经猜测哪个 head 或混合谐波有用；**需要一次小型新标注 capture**。没有该 capture 而返回数值拟合的 Qwen 分配 = **伪造（fabrication）**。这是 64 个频率参数的**监督校准程序**，不是新的普适解析公式，也不是零标签部署。

### 3.2 角色集（可辨识标签，§1）

```
T_e : 被请求的 key+ordinal 记录的 token span（value 与 key span 分开保留）
H_e : 同 key 在其他 ordinal 的记录（硬干扰）
O_e : 其他显式记录
B_e : 其余可见背景与结构 token
Q_e : question token（含重复的 query-key token）
```
**这些是"源关系"的标签，不是隐回路主张**。目标记录的整个 span 不必均匀有用；question key 既不是错答案也不自动无关。⇒ **在每个 head 上最大化 T_e 的注意力是无效的**。构造出处：`experiments/native_sparse_position/prepare_support_oracle.py:14–47`、`experiments/pm_keep/retention_evidence.py:26–52` + `test_target_record_oracle.py:37–51`、`experiments/nosa_position/test_data.py:59–74`（2×2 content/query swap）、`refcarry_audit/prepare_mrcr_pairs.py:55–101`。[部分证据-构造存在，引用未核]
校准标签：用 **last prompt token** 作首个读出 query；从 tokenizer 验证的**不同单 token 答案串**中选源校准值，**拒绝候选共享首答案 token 的情况**；这是**声明的合成校准限制，不是 benchmark scorer**。反事实族**必须留在同一 split**；同时含两个被请求 ordinal 并交换关联 value，使方法不能靠保持偏爱位置或 token 身份来满足目标。

### 3.3 精确有限重放（§2）

对 e = (example, layer, head, query)，split-half pair k，d_j = position(key j) − position(query)：
```
C_jk = q_k k_jk + q_{k+K} k_j(k+K)
S_jk = q_{k+K} k_jk − q_k k_j(k+K)
z_ej(ν; d) = a_e Σ_k [ C_ejk cos(d_j ν_k) + S_ejk sin(d_j ν_k) ]     ← 精确数学 logit
```
a_e 是捕获的有效注意力 score 尺度；`pro_block_calibration.py:60–77` 实现这些系数并记录 **a_e = module.scaling × common_gain²**（**不要把这个 gain 乘两次**）。然后 **p_ej = 对每一因果 key 的 softmax**，o_e = Σ_j p_ej v_ej。**不用小相位或高斯近似。**

**坐标拉伸**：`g_S(p) = S·⌊p/B⌋ + (p mod B)`，B=4096、S=4；d'_j = g_S(p_j) − g_S(p_q)。保持块内距离、乘块起始偏移。**是显式人造坐标变换，不是真实 128K 文本前向**；特别地**不**增加干扰、**不**重算隐状态。

**诊断量**：Z_A = Σ_{j∈A} exp(z_j)；
```
M_{T,rest} = log Z_T − log Z_{all\T}      ⇒  p(T) = sigmoid(M_{T,rest})
M_{T,H}    = log Z_T − log Z_H            ⇒  只给条件质量 p(T | T∪H)
```
**两者要分开报**：源记录与 query-key 副本竞争方式不同，须保留每个 partition 而非藏进一个宏观 margin。

### 3.4 ★ 敏感性（本任务重点）——输出敏感度加权

最强廉价标签是**实际输出答案**，不是最大的 native 注意力 key。单 token 校准 assay 下定义首答案对数概率
```
U_e = log P_model(y_e | prompt_e)
```
用 log P 而非两答案条件 margin，**包含完整词表，包括过早 EOS 与错格式 token**；另外报告对其他记录值的带符号 margin 以识别错-occurrence 混淆。
在源 checkpoint 与源 prompt 上记录
```
g_e,lh = ∂U_e / ∂o_e,lh        （o 为该 head 在选定 query 处的注意力输出，在 concat/W_O 之前）
```
**该导数是一次反向传播得到的可测小向量**；不训练权重、不假定 retrieval head、不需要已知有用模式矩阵；**它包含实际 W_O、残差流与下游计算**。因此 value 奖励 `r_e,lh,j = g_e,lhᵀ v_e,lh,j` **带符号且任务条件化**。
对任意**有限**频率改动：
```
J_lin(ν; d') = mean_e Σ_lh g_e,lhᵀ [ o_e,lh(ν;d') − o_e,lh(ν_0;d') ]
   等价于     = Σ_j [ p_j(ν;d') − p_j(ν_0;d') ] r_j
```
ν_0 = 选定部署参照（如同 gain 的 MrPro）。**用精确有限注意力/softmax 改动，但对下游答案效用线性化。** 原文自限（astra08:77）：**仍是"提议估计量"，不是精确模型级目标** —— 源 Jacobian 在源状态上求值，同时全层改动会相互作用并改变上游 Q/K/V。

**无梯度退路**：只用输入定义的角色 margin，且**仅限源已证实的 head 集**（由配对 target-vs-wrong-record value swap 或源质量干预及其实测输出效应确立）；**注意力图单独不确立该 head 集**。若两者都无，**不得静默替换为投影范数或全 head 等权**。
角色有效性诊断：比较 T,H,O,B,Q 的源敏感度加权 value 贡献与 content/query swap 效应。**若所称的目标干预不改变输出效用，该 head 的目标质量损失就不该驱动分配。允许负号** —— 计算可能识别的是抑制或抵消而非直接复制。

### 3.5 有限变化生成器（§4）

参数化：**x_k = log ν_k**，Qwen 用一张共享 64-向量；初始化 x_0 = log ν_MrPro；保留学习到的 pair 顺序。冻结支撑分配时施加**实际端点约束** x_0 = x_native,0、x_63 = x_MrPro,63，并 x_k ≥ x_{k+1}。**若问题含范围优化，端点改变是显式额外变量，不得称作纯内部（interior）分配。置零某通道是单独干预，在正 log 参数化之外。**

源兼容：`D_src(x) = mean_(natural source rows) KL[ p_native(ω;d) ‖ p(exp x; d) ]`（**精炼完整行散度**）。**一个标量均值可以掩盖罕见目标的损失** —— 须按反事实族保留源任务效用/margin 约束。一个**不需要发明容差**的具体相对预算：`D_src(x) ≤ D_src(x_0)` 且实测源族效用相对 x_0 不恶化。**这只意味着"在这个捕获目标上不比参照差"，不是"相对 Native 安全"。** 用户给保留阈值时用该阈值并报告参照自身代价。

生成：对 −J_lin(x;d') 做投影梯度或序贯约束优化，s.t. 上述约束；**每一步用精确有限三角 logit、完整 softmax 与约束评估**；用基于实际目标改善的信任域/回溯接受规则；**不得仅因局部二次近似好看就接受大步长**。不需要候选格点或手工平滑曲线清单；**Native/MrPro 是控制与初始化，不是可扫描的菜单**。若变量维数允许，可用实际 U_e(exp x; transformed prompt) 替代 J_lin（更贵但移除校准输入上的下游线性化；**源坐标拉伸仍不是真实长文本，除非完整长输入在场**）。冻结表后在 family-disjoint 源任务与真实 128K 输入上评估；先对同 gain 的 MrPro 比，操作 Native 单独在其实际 gain 下比。

### 3.6 ★ 有限变化界（本任务重点）——可保证什么（§5）

**精确局部保证**（固定 Q/K）：对每个有限改动
```
| z_j(ν) − z_j(ν_0) | ≤ 2a Σ_k sqrt(C_jk² + S_jk²) · | sin[ d_j (ν_k − ν_0k)/2 ] |  =: ε_j
```
[已验证-本地复算：由 C cos + S sin = R cos(dν−φ)、差角公式，括号内另一 sine 因子被丢弃，故是**合法上界**]
对任何角色集 A，log Z_A 在 A 上最大 logit 误差下是 **1-Lipschitz**（softmax 的 1-范数为 1）。因此
```
| M_{T,D}(ν) − M_{T,D}(ν_0) | ≤ max_{j∈T} ε_j + max_{j∈D} ε_j
```
**若源角色 margin 超过该界，其符号在该固定状态改动下不能翻转。这是角色排序证书，不是答案保证**；对有限改动与带符号 sin/cos 系数都成立。[已验证-本地复算]

**Pinsker**：若某完整行 KL[p_0‖p_ν] ≤ δ，则 |p_ν(T) − p_0(T)| ≤ sqrt(δ/2)。**对罕见目标可能空洞**；**平均 KL 只给平均界（Jensen），不是逐行或最差 head 证书**。**保留完整归一化是本质的。**

**输出界**：设 ||v_j||≤V，则 ||o_ν − o_0|| ≤ 2V·TV(p_ν,p_0) ≤ V·sqrt(2δ)。**更有用的是直接测实际 o 差**，因为 value 可抵消、范数界可松。

**Taylor 界**：对单个注意力输出干预，若在整个 segment 上有 Hessian 范数界 H，则 `U(o+δo) ≥ U(o) + gᵀδo − (H/2)||δo||²`。**源 capture 不提供这样的 H**，且**叠加局部界而不控制所有上游状态是无效的**。⇒ **J_lin 没有未测量的"保证答案改善"声明。**

**held-out 任务结果支持什么**：固定表在独立抽取、族聚类的源/目标输入上给普通经验配对比较。**token/head 样本不是独立任务单元**；仓库 `position_overnight/report.py:88–104` 已正确做 cluster resampling。到真实 128K 任务的泛化**要求该分布被测试或有辩护的分布漂移模型；没有任何有限频率几何定理提供它**。

**★ 最小信息论阻碍（可辨识性核心）**（astra08:131）：给定 6 份**无标签** Q/K/V capture，**交换"哪个源是被请求答案"的含义而保持 capture 完全不变**。所有几何量、native KL、协方差值**都相同**，但期望的带符号 margin **反转**。⇒ **没有任何这些无标签摘要的确定性选择子能在两个世界中都选对方向。** 这证明的是**在观测接口上缺失任务角色识别**，**不是**从更丰富源数据学出有用表的不可能性。[已验证-推导]

## 4. astra09 — 保持学习通道角色的有限 softmax 频率步

### 4.1 核心规则（astra09:5）

**在频率空间做一次精确有限-softmax 梯度步，受现有频率间隙约束，按下游输出敏感度加权。** 改动每个原始 rotary pair 的**实际频率**；**不改幅度、不在忽略冻结通道标签的抽象计数空间重分配**。oracle-support 损失是**限于 retrieval-qualified head 的次级诊断**；无差别施于每个 head 无效。

### 4.2 精确有限损失与累积量修正（§1）

每 query/head、每个因果可见 key i，捕获**未旋转** Q/K 并保留全部原始 pair 系数；d_i = key_pos − query_pos，split-half 平面 j：
```
s_i(θ) = c_i + Σ_j [ a_ij cos(d_i θ_j) + b_ij sin(d_i θ_j) ]
a_ij = (qx_j kx_ij + qy_j ky_ij) / sqrt(head_dim)
b_ij = (qy_j kx_ij − qx_j ky_ij) / sqrt(head_dim)
```
c_i 是固定 native 加性 bias（Qwen 通常无）；**native 注意力 gain 必须按真实实现原样含进 a,b**。对输入定位支撑 S，
```
L_support = LSE_i(s_i) − LSE_{i∈S}(s_i)        （= S 上精确负 log 注意力质量）
          = softplus( log D − log S )           （D、S 为有限实际指数和）
```
对任意有限集 A：
```
log Z_A = log|A| + mu_A + var_A/2 + R_A
R_A := log mean_{i∈A} exp(s_i) − mu_A − var_A/2    （精确、有限量）
```
**称 R_A 为精确余项不需要无穷累积量级数收敛**；因此支撑/干扰竞争中的修正是 **R_D − R_S**，不是零倾斜处的偏度项；**两个符号都可能**。非均匀 native bias 时可用 native-bias tilted 权重并保留 log Z_bias，或直接把 bias 含进精确分数。

**CPU 反例**（astra09:28）：A=(10,0,…,0)（64 key）、B=(1,…,1)：mu_A + var_A/2 **< 1**，但 **LSE(A) > LSE(B)**。**任何止步二阶的协方差近似（包括完整协方差）都会错排这些块。** 评估实际分数 + 稳定 LSE 消除该近似误差，**而不声称统计尾部泛化**。

[与 astra08 的 `test_full_covariance_probe.py` 反例同源，两报告独立给出同一结论]

### 4.3 ★ 响应算子：输出感知目标 + 闭式步 + 证书（§2–§3）

**输出感知主目标**：从**另一个**校准样例的答案损失取下游 cotangent
```
u_hq = d L_answer / d y_hq,    y_hq = Σ_i p_hqi v_hi
c_hqi = u_hq · v_hi     （冻结 a,b,v,u 后构造表）
F(θ) = Σ_hq Σ_i softmax(s_hq(θ))_i · c_hqi
```
**精确有限梯度**：
```
dF/dx_j = Σ_{hqi} p_hqi [ c_hqi − E_p c_hq ] · (d_i / T) ·
          [ −a_hqij sin(d_i θ_j) + b_hqij cos(d_i θ_j) ],       x = T(θ − θ0)
```
[已验证-本地复算：∂p_i/∂x_j = p_i(∂s_i/∂x_j − E_p∂s/∂x_j)，∂s_i/∂x_j = (d_i/T)[−a sin + b cos]，一致]
性质：**自动处理正、负、零输出影响**；**常数 c 跨 key 时整行频率梯度为零** —— 其 value 混合与输出无关的 head **不被逼向任何源**。⇒ **避免估计普适 retrieval-head 标签。**

**★ 精确一阶连接**（astra09:47）：若在**每一个**受全局共享 θ 影响的注意力应用处捕获 cotangent 与系数，把局部直接参数导数**求和**就等于全网在 θ0 处的梯度 dL_answer/dθ。**上下游效应已由反向模式 cotangent 表示；冻结激活不使该捕获点导数失效。** 但只捕后期 query/层只给**部分梯度**，那只是局部干预代理。
自限：离开 θ0 后的有限 F(θ) 仍冻结 cotangent、隐式 Q/K 与 V，故其**二阶/全局改善不是关于全模型答案损失的定理**；导出表需要 **fresh prefill + fresh generation**（**decode-only key 重旋转不能复现被改变的隐状态**）。

**闭式步与证书**：r_ij = hypot(a_ij,b_ij)，δ_i = d_i/T（T 界住所有绝对距离）：
```
G² = max_i Σ_j δ_i² r_ij²          （全局界住分数-Jacobian 平方范数）
H  = max_ij δ_i² r_ij              （全局界住分数-Hessian 算子范数）
support 损失的合法梯度-Lipschitz 常数 = 2(G² + H)     （两个 LSE Hessian 各范数 ≤ G²+H）
```
对输出感知行 F = E_p c，令 C = max_i c_i − min_i c_i，则
```
Hess F = E_p[(c − E_p c) Hess s] + E_p[(c − E_p c)(grad s − E_p grad s)(grad s − E_p grad s)ᵀ]
⇒ ||Hess F|| ≤ C(H + G²)
```
按与 F **完全相同**的行权重求和/平均得到 L。**无高斯性、无 pair 独立、无低秩闭合假设进入该界。**
[已验证-本地复算：第一项 ≤ C·H；第二项对任意 y，yᵀ E_p[XXᵀ] y = Var_p(y·∇s)，由 Popoviciu 有 Var ≤ (b−a)²/4 ≤ ||y||²G²，故矩阵 ⪯ G²I ⇒ ≤ C·G²。界成立。]

**间隙盒半径**（θ0 递减）：
```
r_j^box = min{ B, 0.49·T·θ0_j, 0.49·T·min( θ0_{j−1} − θ0_j, θ0_j − θ0_{j+1} ) }
```
（缺端点间隙时省略该项。）B 是**在目标长度上的显式最大相位位移，默认 1 弧度；是信任预算，不是导出的普适最优常数**。**最近-间隙盒保证不跨序且正性。原文强调：这一要求是保守的，不是标签保真的数学必要条件 —— 保持 slot 索引不动本身就保标签，即使数值频率交叉。**

**★ 频率规则**：
```
x*_j = clip( −g_j / L, −r_j^box, +r_j^box )
θ*_j = θ0_j + x*_j / T
```
该步在盒上最小化 g·x + (L/2)||x||²。因零可行，
```
F(θ*) − F(θ0) ≤ g·x* + (L/2)||x*||² ≤ 0
```
[已验证-本地复算：一维无约束极小在 x = −g/L；下降界由 ||Hess F||≤L 的标准论证给出]
参考实现返回实际捕获目标变化与这个认证上界**两者**。零梯度 ⇒ 返回原表；a=b=0 的 pair ⇒ 不变。**若单步小到在模型 float32 表导出时被舍入掉，那是"在该保守分辨率下缺少可行动证据"的信息 —— 不得把舍入后的 no-op 重新标记为新方法。**
默认 B=1 rad、W=32768、T=131072 ⇒ **最大附加相位 0.25 rad**（是算子扰动界，**不是短任务保留保证**）。**没有任何固定正 B 能保证所有冻结模型的保留：任意小的 logit margin 可给反例。** 接受比较**必须直接测量 native-window 任务**。

## 8. 死路登记（不得再试 / 不得复活）

> 这些是**四份报告内部点名**的失败机制或已被否决的论证，含失败原因。凡与权威文档 §5 死亡机制登记册重合者，我标注 (∩ 权威 §5)。

1. **"成对 SNR/margin 改善 ⇒ 联合检索更好"**。反例：均值 .8/方差 1/独立 的 Φ(.8)²=0.6212 在**每一个**成对标准化 margin 上优于 均值 .5/完全相关 的 Φ(.5)=0.6915，联合检索却更差（astra06:139，[已验证]）。**单调排序需要公共耦合结构（同对角尺度 D、同联合噪声 Z、m_A≥m_B 逐分量），协方差摘要推不出来。**
2. **"固定通道数 ⇒ 同时改善短/长在信息论上不可能"**。计数守恒**不给出任何任务风险守恒律**（astra06:160，点名 `.agents/worker_empirical_r3/r3_empirical_defense.md` 与 blueprint）。**注意"Σm 不是守恒量"（红线）与这条是同一个错误的两个版本。**
3. **"iid 各向同性通道噪声 ⇒ α∫ρ² 碰撞代价"**。Var Σ_j[A_j cos(ν_jd)+B_j sin(ν_jd)] 与 ν,d **无关**；K 个独立每通道误差的通道平均方差 = K⁻¹∫v(x)ρ(x)dx，**对密度线性**（astra06:141）。(∩ 权威 §5 "iid 噪声→α∫ρ²（旋转不变，无碰撞项）")。**⇒ 任何用无符号几何量当碰撞目标的路径都死。**
4. **"协方差（含完整协方差）足以决定有限 softmax 竞争"**。反例（两个报告独立给出，[已验证]）：64 个 logit [10,0,…,0] 的 **全二阶累积量 log 质量**低于常数分数-1 块，而精确 LSE 排序相反（astra09:28、astra08:136 引 `test_full_covariance_probe.py:69–80`）。**任何止步二阶的近似可错排块。**
5. **"原始/中心化 score MSE（或范数误差）能代理竞争质量"**。layer-0 相对原始分数 MSE 1.305e−5 与 KL 7.196134 **共存**；中心化 MSE 0.48446（astra08:136）。**行公共分量可主导 MSE 分母却不保持竞争。**(∩ 权威 §5 "movement-MAE")
6. **"目标 token 保持 top1 ⇒ 目标没受损"**。output KD 下 layer20/head5 目标区质量 0.50075→0.20339，尽管目标仍可 top1（astra08:137）。**target-vs-top1-distractor 单独漏掉累积干扰质量。**
7. **"attention-only 误差与 value-only 误差可加 / 重置频率能同时修好各层"**。二者逐层变化且**不可加**；重置频率修好一层目标质量但修不好另一层（astra08:138）。
8. **"几何/局部界改善 ⇒ 生成恢复"**。PostMetric4 10/32、PreMetric4 11/32 对更细参照 13/32；native-pair 几何界未蕴含恢复（astra08:139）。

11. **"Cosh 密度唯一"（在自由系数 + 自由密度下）**。gauge `a2=ρ1a1/ρ2` 使**每个已实现 margin 完全相同**（不只矩）；数值差 = 0（astra07:175–184, 258）。**凡不声明加载/幅度界/有限 K 整数计数的密度推导，其"唯一最优密度"结论一律无效。**(∩ 权威 §4.2)
