## 1. sol01 — MrRoPE 的混合基数数学 + 预算化 argmin

### 1.1 精确构造与结论（可作 F 零件）

**P1. 累计压缩指数坐标（全项目部署坐标的代数形式）** [已验证-代数]
sol01.md:7-13 给出 ν_j = ω_j S^{−m_j}, m_j = Σ_{d<j} ε_d, λ_d = S^{ε_d}。"MrRoPE 提供的是一个**累计频率分配的坐标系**，不是一个精确的混合基数编码定理，也不是任务最优分配律"（:5）。

**P2. 混合基数算术 vs RoPE 相位的关键区分** [已验证-代数]
精确 digit 重建 n = Σ_j a_j P_j, a_j = ⌊n/P_j⌋ mod r_j, P_j = Π_{d<j} r_d（sol01:19-32）。RoPE 观察的是 φ_j(n) = (n/P_j) mod 2π —— **没有 floor、模数是 2π 而不是 r_j、βλ_j 一般非整数**（:36-40）。结论句（原文）：
> "任何正的逐槽 RoPE 频率表都可以用相邻累计比来参数化，类比混合基数位权。这是**代数频率参数化**，不是带进位的 digit 表示。"（:43-44）

论文原文自认丢了 floor 和模数差异（primary paper lines 174–203）。**含义：无进位自由范围 Πr_j、唯一解码定理、分配最优性都不能从基数算术迁移到 RoPE 相位**（:46）。

**P3. 索引 off-by-one 约定（可直接用作 F 的边界条件）** [已验证-代数]
论文定义 ν_j = ω_j / Π_{d=1}^{j−1} λ_d（paper lines 305–324, 441–456）⇒
- λ_{D_r} **不影响任何频率**，可观测频率只决定 λ_1…λ_{D_r−1}（:58）；
- λ_d 首次改变的是槽 d+1（:59）；
- 建议改用**频率锚点**约定：设过渡频率 j = l,…,h，m_l = 0, m_h = 1，N = h−l 个 gap 增量 ε_q = m_{l+q} − m_{l+q−1}，Σ_{i=1}^N ε_i = 1，ν_{l+q} = ω_{l+q} S^{−m_{l+q}}（:60-68）。
**这正好是 NEXT_DERIVATION §1.3 的 I1/I2 端点锁定 + Σ_{j=23}^{39}Δ_j=1 的等价写法。**

**P4. MrRoPE-Pro 完整构造（论文侧精确公式）** [已验证-CPU 精确分数]
ε_q^Pro = 2q/(N(N+1)), m_q^Pro = q(q+1)/(N(N+1))（sol01:72-85）。CPU 精确分数复核 Σε=1 for N=2,3,17,18；N=17 端点 ε_1=1/153, ε_17=1/9, Σ_{q=1}^{16} m_q = 16/3（:87）。
**独立第三方交叉验证**：`docs/research/ROPE_MRPRO_BM_CONSTRUCTION_ANALYSIS_20260908.md:14-17` 给出同一式 ε_i^M=2i/(N(N+1)), m_q^M=q(q+1)/(N(N+1))；:44-45 复核 N=17 时 ε_1 由 1/153 增至 1/57（2.684 倍）、ε_N 由 1/9 减至 1/57。**吻合。**

**P5. Pro 相对 Uni 的严格延迟（唯一的严格结论）** [已验证-代数]
m_q^Uni − m_q^Pro = q(N−q)/(N(N+1)) > 0 for 0<q<N（:91-94）。即 **Pro 严格延迟所有内部累计压缩，端点不变**。sol01 明确边界："推导中没有任何东西建立'等差增量最小化某个与模型相关的损失'。"（:96）

**P6. YaRN "regressive" 证明的作用域收窄** [已验证-代数]
A(r_j) = c + (S−1)r_j, c = β − Sα（paper lines 1114–1242）。方向性需要 (S−1)c ≥ 0，即 S>1 时 β−Sα ≥ 0。**在目标部署域 S=4, α=1, β=32 成立；不是对所有 S 或所有 b≠1 成立**（论文 lines 1240–1242 的 universal 量词无效，:104-108）。

**P7. log-频率位置与 EVQ 核的接口** [部分证据]
φ_j(m) = −log_b ν_j = φ_j⁰ + (logS/logb)·m_j（:114-117）。K_L(φ_a,φ_b) 的闭式由余弦积分给出（引 `EVQ_NONLOCAL_KERNEL_CORRECTION_20260910.md:8-43` —— 已核对，见 §2.3）。

**P8. 预算化 argmin（sol01 的核心交付，可作为 F 的**候选**形式）** [假设]
```
m* = argmin_m C_T(m)   s.t.  m_l = 0, m_h = 1, 0 ≤ m_{j+1} − m_j, D_0(m) ≤ δ
```
（:136-143）其中：
- D_0(m) = E_{x,ℓ,h,n≤L_0}[(z_{ℓhn}(m;x) − z_{ℓhn}(0;x))²]，z 是**实际 pre-softmax attention logit**（:121-126）；
- C_T(m) = Σ_{a,b} W_ab K_{L_T}(φ_a(m), φ_b(m))，**W ⪰ 0 必须来自冻结模型的 slot/source 统计（含跨槽结构），不得等于等槽权**（:132-134）；
- δ 取**已接受基线（如 MrPro）实测的原生窗失真**，而不是发明一个标量权衡权重（:143）。

**P9. 信赖域一阶方向（局部版）** [已验证-代数]
g = ∇C_T(m⁰)，D_0(m⁰+u) − D_0(m⁰) ≈ ½u^T H u，投影到保端点切锥：
u* = −√(2Δ/(g^T H^{−1} g)) · H^{−1} g（:145-149）。
给出边际律："把扩展位移花在**每单位实测原生 logit 损害对应精确 EVQ 收益最大**的地方，含跨槽耦合"（:151）。**直接反驳逐槽独立 argmin**（:151，引 transition review lines 107–130 保留交叉项）。

**P10. 从头训练是另一个问题（联合形式化）** [假设]
(θ*,m*) = argmin_{θ,m} E_{(x,y),L∼p_train}[L(f_{θ,m}(x_{1:L}),y)] + γ C_{p_target}(m)（:159-166）。冻结分支的 D_0 在 scratch 无意义 —— **用冻结目标会特权化一个任意初始化**（:159）。

### 1.2 sol01 给出的反例/可证伪检查（可当验收测试）

1. **精确基数反例**：单频率时 Π 为空积 ⇒ RoPE 相位不变而宣称的可表示范围变了 ⇒ 范围缩放不是可观测 RoPE 表的属性（:172）。
2. **索引反例**：D_r=4 只设 λ_2=S ⇒ 频率 1,2 native，3,4 缩放 1/S；把维度 2 叫"被缩放的中段维度"在论文自己的乘积约定下为假（:173）。
3. **渐进极限**：N=1 时 Pro=Uni=单端点跳变；对每个 N>1，Pro 延迟每个内点；在增量上限下 Pro **不**最小化总压缩 —— 项目导出的坐标式延迟解而是"窄化的 MrUni 恒等"（:174，引 construction analysis lines 83–113）。
4. **EVQ 代理检查**：若精确 C_T 改善而配对任务变差 ⇒ 碰撞目标缺必要 source/task 结构；**不得用"几何成功"来救**（:175）。
5. **冻结 vs scratch 判别器**：同一张表在端到端重训后排名不同 ⇒ 支持"学习原生损害"机制而非普适编码几何（:176）。

### 1.3 sol01 的死路登记

- **基数算术定理不迁移**：无进位范围、唯一解码、分配最优性 —— 全部不能从混合基数算术搬到 RoPE 相位（:46）。
- **"几何平滑 ⇒ 更好任务"被 BM 反例阻断**：BM 降低若干几何粗糙度/失真量、且把每个内部槽都挪得比 MrPro 慢、内部累计指数和 +50%，却在配对 Qwen 3B 128K 六任务聚合上**输 7.29 分**；反向地，OLMo 上 BM 大幅胜过 MrPro。⇒ "更小几何失真 / 延迟压缩 / 总指数质量" **没有一个是普适任务效用**（:98）。**独立交叉验证**：construction analysis :67-81 给出同输入 OLMo BM 51.32% vs MrPro 2.78% vs MrUni 32.12%；:67 给出 Qwen 3B 六任务 −7.29pp（多键 −25、QA −25、多查询 +6.25）。
- **论文 universal 量词无效**：YaRN regressive 证明不覆盖所有 S/b（:108）。
- **逐槽独立 argmin 不成立**（:151）。

## 2. sol02 — EVQ 精确分位数 / 间隔泛函

### 2.1 决定性发现

"EVQ-Cosh 有一个干净的精确定理，但它比 'exact EVQ' 这个说法所暗示的**更窄**。cosh 密度是**投影后的纯 tether 泛函**的唯一极小元，**不是**原始有限窗碰撞泛函的极小元——除非核投影是精确的。"（sol02:5-14）

### 2.2 主泛函与证明链 [已验证-数学]

**P11. 投影纯 tether 泛函**（sol02:7-12）
C_app[ρ] = (α/2)∫₀¹ρ² + (β/2)∬_{[0,1]²}ρ(φ)ρ(ψ)min(φ,ψ)dφdψ，ρ≥0, ∫ρ=1；α>0, β≥0。
min 核是 −d²/dφ² 在 g(0)=0, g′(1)=0 下的 Green 核（:38-43）；∬ f min f = ∫₀¹(∫_s¹ f)² ds ≥ 0 ⇒ **强制性 + 严格凸 + 唯一约束极小元**（:45）。

**P12. Cosh 驻点方程与解**（sol02:45-60，与 `docs/research/ROPE_ALLOCATION_THEORY_CORE_20260910.md` §4.1 完全一致）
αρ + βg + ν = 0，g″ = −ρ ⇒ ρ″ − τ²ρ = 0，τ = √(β/α)；ρ′(1)=0, ρ′(0) = −τ²：
**ρ_τ(φ) = τ cosh(τ(1−φ)) / sinh τ**。处处正 ⇒ 非负 KKT 约束**不活跃**（:60）。β=0 ⇒ ρ≡1（= τ→0 极限）。

**P13. Fisher 项破坏纯 cosh（重要边界）** [已验证-数学]
若保留 Fisher 分辨率项 −μ_F∫ρ b^{−2φ}，精确驻点变为 ρ″ − τ²ρ = (4μ_Fc²/α)e^{−2cφ}，特解 P e^{−2cφ}, P=(4μ_Fc²/α)/(4c²−τ²)（共振外）。
"**纯 cosh 律只在去掉这一项后才精确，而不只是投影核之后。**"（:62-68）且 Fisher 增强的驻点**正性不自动成立**，需 KKT 检查。

**P14. 精确分位数与 gap 表示（EVQ=F 的直接零件）** [已验证-数学]
F_τ(φ) = 1 − sinh(τ(1−φ))/sinh τ；Q_τ(u) = 1 − (1/τ)·asinh((1−u)sinh τ)（:74-78）。
Q_τ′(u) = sinh τ / (τ√(1+(1−u)²sinh²τ)) = 1/ρ_τ(Q_τ(u))（:81-84）**严格递增** ⇒
**任何等质量分位网格的指数 gap 向低频端递增**（:86）。
精确相邻 gap（:89-94）：
```
g_k = Q_τ(u_{k+1}) − Q_τ(u_k)
    = (1/τ)[asinh((1−u_k)sinhτ) − asinh((1−u_{k+1})sinhτ)]
```
小 τ 展开：Q_τ(u) = u − u(1−u)(2−u)/6·τ² + O(τ⁴)（:99）—— **点位置向快端移动；低频端间距变大**（:102，明确分离两个常被混淆的断言）。

**P15. 两种有限表约定（口径冲突，必须冻结）** [已验证-记录]
- u_k = k/K：只锚最快端点，不含 u=1（:106）；
- u_k = (k+1/2)/K：**实际实验与有限输运证明用的**，两端都不锚（:107）。
⇒ "**端点锚定命题并不描述已部署的 midpoint EVQ 表**"；与 MrRoPE 比较必须冻结一个约定，改动可大至半个分位格（:109）。权威端一致：`ROPE_ALLOCATION_THEORY_CORE_20260910.md` §4.1 "u=j/K、u=(j+1/2)/K、端点归一化采样是不同有限表，不能混用"。

**P16. 精确 continuum 分位泛函**（:112-124）
E_L[Q] = ½∫∫K_L(Q(u),Q(v))du dv − μ_F∫e^{−2cQ(u)}du，Q 非降。变分导数 = ∫∂_1K_L(Q(u),Q(v))dv + 2cμ_F e^{−2cQ(u)}。
**"这个精确有限窗泛函没有 cosh ODE。"**（:126）—— 即 §2.2 的 cosh 链**不可**延伸到精确核。

**P17. 精确有限 K-对表目标 + gap 梯度（最可复用的求解对象）** [已验证-数学]
E_{L,K}(φ) = (1/2K²)Σ_{i,j} K_L(φ_i,φ_j) − (μ_F/K)Σ_i e^{−2cφ_i}，0≤φ_0≤…≤φ_{K−1}≤1（:129-134）。
令 a=φ_0, g_r = φ_r − φ_{r−1} ≥ 0，则（:139-144）：
```
∂E_{L,K}/∂g_r = Σ_{m=r}^{K−1} [ (1/K²)Σ_j ∂_1K_L(φ_m,φ_j) + (2cμ_F/K) e^{−2cφ_m} ]
```
"内点最优 gap 使这个累计力为零；非负 gap 与端点约束加通常的互补松弛乘子。"（:146）**"这是能优化或对比候选 EVQ/MrRoPE 混合的、具体且判定充分（decision-sufficient）的有限窗推广，没有任意候选网格。"**（:146）

**P18. 核导数可避开对 Ci 求导**（:148-155）
∂_1K_L(φ,ψ) = (cω(φ)/logL)∫₁^L sin(ω(φ)t)cos(ω(ψ)t)dt。

### 2.3 精确核闭式与非局部脊（交叉验证通过）

**P19. 精确 cosine 碰撞核**（sol02:18-36）
K_L(φ,ψ) = ∫₁^L D_L(Δ)cos(ω(φ)Δ)cos(ω(ψ)Δ)dΔ，D_L(Δ)=1/(Δ log L)；
φ≠ψ：K_L = [Ci(Lδ)−Ci(δ)+Ci(Lσ)−Ci(σ)]/(2 log L)，δ=|ω−ν|, σ=ω+ν。
对角：K_L(φ,φ) = 1/2 + [Ci(2Lω)−Ci(2ω)]/(2 log L)。
字面写 δ=0 会 ∞−∞，需取极限 lim_{a↓0}[Ci(La)−Ci(a)] = log L（:32）。
**核对**：`docs/research/EVQ_NONLOCAL_KERNEL_CORRECTION_20260910.md:14-16` 为同一式，且 :19-25 给出 Ci(z)=γ+log z+R(z)、:25 给出分解 —— **一致**。

**P20. 核分解与非局部脊（该脊是"窄桥合法性"的数学许可）** [已验证-数学]
K_L(φ,ψ) = [c·min(φ,ψ) − γ + h_c(φ−ψ)]/log L + E_L，h_c(x) = −½log(1−e^{−2c|x|})（:159-165）。
Fourier 乘子：ĥ_c(k) = (π/2|k|)coth(π|k|/2c) − c/k²，ĥ_c(0) = π²/(12c)（:167-171）。
**"把它替换成 ĥ_c(0)·I 会对每个非恒定密度模态超额收费。"**（:173）一阶长波修正为负：
⟨ρ, h_c*ρ⟩ = A₀‖ρ‖₂² − (π⁴/720c³)‖ρ′‖₂² + ⋯（:175-178）
但该截断泛函在高波数**无下界**、且正有限区间密度有端点项 ⇒ **不能安全优化**；构造性修法是保留完整 K_L（:180）。
**核对**：correction 文档 :41-45（"omitted interaction is a nonlocal, integrable logarithmic ridge; replacing it by a delta..."）、:50-59（h_c 级数、A₀=π²/12c、乘子）、:63（delta 近似对变化过度惩罚）、:91（精确脊对窄变化收费更少）—— **全部吻合**。

### 2.6 sol02 结论（对下一次决策）
