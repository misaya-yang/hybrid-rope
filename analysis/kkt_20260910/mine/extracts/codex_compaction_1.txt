MrPro 的关键取舍，是在完成长端缩放的同时，尽量保留已经学好的位置关系。设中频有 \\(N\\) 步，它的累计压缩指数是：

\\[ m\_q^{Mr}=\frac{q(q+1)}{N(N+1)},\qquad \omega'\_q=\omega\_q S^{-m\_q}. \\]

前面的累计压缩增长慢，后面才承担较大变化。这比均匀分配更保护较快中频。**这是有明确功能动机的设计，但论文并没有证明等差增量就是任务最优解。** [MrRoPE 原文 §3.2](https://arxiv.org/html/2601.22181v1#S3.SS2)

BM 改动的范围比“修边界”大得多。我复算得到：

\\[ m\_q^{BM}-m\_q^{Mr} =\frac{2q(q+1)(N-q)}{N(N+1)(N+2)}>0. \\]

也就是说，**每个内部中频槽都压得更强**，这些槽的累计压缩指数总和增加了 **50%**。当前 Qwen 数组中：

| 零基槽MrPro 保留的 Native 频率比例BM 保留的比例 |       |       |
| -------------------------------- | ----- | ----- |
| 28                               | 87.3% | 73.5% |
| 32                               | 66.5% | 47.2% |
| 34                               | 55.0% | 37.7% |

这里暴露了 BM 理论上的薄弱环节：**我们证明了一个“间距粗糙度”目标的最优解，却没有证明这个目标对应模型真正需要保护的关系。** RoPE 各槽连接着不同的内容投影，计算中没有“相邻槽间距一跳变就出故障”的必然机制。边界更平滑的收益可能存在，但提前压缩的代价也真实存在。[构造与复算](/Users/yang/projects/hybrid-rope/docs/research/ROPE_MRPRO_BM_CONSTRUCTION_ANALYSIS_20260908.md)
