### 1.1 `EVQ_NONLOCAL_KERNEL_CORRECTION_20260910.md`（最核心，A10 必修）

**文档性质（第 3–6 行）**：仅数学注记，CPU-only，不替换完整 sin/cos 计算，不提交新频率表。

#### (a) 精确核与内部分解

原始距离先验不变：`dt/(t log L)` on `[1,L]`（与 `EVQ_COSH_THEORY.tex:80-86` 的 `D(Δ)=1/(Δ ln L)·1_{Δ∈[1,L]}` 逐字一致）。记 `c = log b, ω = exp(−cφ), ν = exp(−cψ)`，精确核（`:13-17`）：

```
K_L(φ,ψ) = [Ci(Lδ) − Ci(δ) + Ci(Lσ) − Ci(σ)] / (2 log L),  δ=|ω−ν|, σ=ω+ν
```

对账：`EVQ_COSH_THEORY.tex:99-102` 的 eq.(exact_kernel_ci) 是同一式（tex 用 `ω_−, ω_+`）。**一致。**

#### (b) 分解出非局部对数脊 h_c（本篇的数学核心）

用 `Ci(z) = γ + log z + R(z)`、`|R(z)| ≤ z²/4`、`|Ci(z)| ≤ 2/z`（`:19-21`），得

```
K_L(φ,ψ) = [c·min(φ,ψ) − γ + h_c(φ−ψ)] / log L + E_L(φ,ψ)
h_c(x)   = −½ log(1 − e^{−2c|x|})
|E_L|    ≤ (1/log L)·[ 1/(Lδ) + 1/(Lσ) + (δ²+σ²)/8 ]
```

推导依据：`δσ = exp(−2c·min(φ,ψ))·(1 − exp(−2c|φ−ψ|))`（`:35`）。
**关键定性结论（`:37-43`）**：被丢弃的交互项是一条**非局部、可积的对数脊**，不是逐频独立噪声；把它替换成 delta 核是**外加的局部性近似**。文档明确限定适用范围：`δ,σ ≪ 1` 且 `Lδ ≫ 1` 的内部区；**刻意不**覆盖对角线、最快端点、未分辨的慢端点（`:37-39`）。

#### (c) 脊乘子的精确形式与一阶修正的符号

```
h_c(x) = ½ Σ_{n≥1} e^{−2cn|x|}/n,    A_0 := ∫_R h_c dx = π²/(12c)          (:49-52)
ĥ_c(k) = Σ_{n≥1} 2c/(4c²n²+k²)
       = π/(2|k|)·coth(π|k|/(2c)) − c/k²,    ĥ_c(0) = A_0                 (:56-60)
```

**这是"窄桥合法性"的数学来源**（`:62-64`）：乘子 **恒正、随 |k| 单调下降、上界 A_0**。因此 delta 近似（= A_0·恒等）**在每一个非零密度波数上都过罚**。

二阶展开（`:66-70`）：

```
⟨ρ, h_c * ρ⟩ = A_0‖ρ‖² − (π⁴/(720c³))‖ρ′‖² + 高阶项
```

**符号由核固定**（`:72-73`）：负号是核自带的；**再加一个正的相邻梯度惩罚会走向相反方向**。

#### (d) 三条硬性限制（构 F 的人必须照抄）

1. `:74-76` **展开只在 `|k|/c` 小的密度变化尺度上成立；截断泛函在大 k 处无下界，绝不能在缺少情景区间限制的情况下优化它。** 完整的非局部正核本身良态。

### 1.2 `ROPE_SOFTMAX_MIXED_FREQUENCY_DERIVATION_20260910.md`（混合频率 / 谐波）

**文档性质（`:3-6`）**：数学在制品；无模型执行、无新候选入队；明确声明"**不宣称谐波生成本身是新的**"。

#### (a) 条件注意力行内的精确计算

固定内容系数（`:9-13`）：`s(d) = Σ_{j=1}^{K} r_j cos(ν_j d − φ_j), r_j ≥ 0`。文档自注：这是**重复固定 Q/K 内容**的精确 rotary logit；任意 key 时系数依赖 d，需另做分析，不能悄悄把平稳 Fourier 模型套到完整 prompt 上（`:14-16`）。

Bessel 展开（`:19-26`，引 DLMF 10.35.2）：

```
e^{s(d)} = Σ_{n∈Z^K} c_n e^{i(n^T ν)d},   c_n = Π_j I_{n_j}(r_j) e^{−i n_j φ_j}
总绝对系数质量 = exp(Σ_j r_j)
```

**结论**：未归一化注意力权重的频率包含**旋转频率的整数组合**，不只是原频率本身。归一化一行只除同一个标量，**不消除其相对空间调制**（`ana:29-31`）。

二阶交叉项（`:33-46`）——**两条各自快速的振荡能造出慢包络**：

```
e^{a cos ωd + b cos ηd} = 1 + a cos ωd + b cos ηd
   + (a²/4)(1+cos 2ωd) + (b²/4)(1+cos 2ηd)
   + (ab/2){cos(ω−η)d + cos(ω+η)d} + R_3(d)
|R_3(d)| ≤ exp(|a|+|b|)·(|a|+|b|)³/6
```

其幅度与符号依赖内容，**抑制一个混合频率不自动是好事**（`:45-46`）。
文献定位：Ye（arXiv 2607.24502v1 §5 + App.B）已分析理想化 RoPE 流中的 softmax/Bessel 谱；Ruscio & Silvestri（arXiv 2410.18067v2 §7）已观察 RoPE 注意力中的谐波生成（`:48-56`）。**novelty 不在谐波本身。**

#### (b) 为什么"单频快"不保证"粗平均"

有限几何级数界（`:60-69`）：

```
|(1/T)Σ_{d∈I} e^{iκd}| ≤ min(1, 1/(T|sin(κ/2)|))     （整数位置；2π 倍数处取 1）
连续版： ≤ min(1, 2/(T|κ|))
```

**后果**：`exp(s)` 的粗平均取决于**显著组合 `κ = n^T ν`**；对 `Tν_j` 逐个下条件**不充分**。分部积分给出慢/快分解的可控形式（`:78-92`）：若保留的非恒定快部有原函数 F，`‖F‖_∞ ≤ B`，慢函数 g 有界变差，则

```
|∫_a^b g(d){e^{s_fast(d)} − μ} dd| ≤ B·{|g(a)|+|g(b)|+TV(g)}
```

（截断则另有尾项；精确共振归入均值 μ）。**失败条件被点名**：一个显著混合模在该区间上**仍然是慢的**，尽管其成分频率都很快（`:92-93`）。

#### (c) 几何网格中的层级（这是本篇最可用于 F 的结构）

对 `ω_j = r^j, r = b^{−1/K}`，q 阶连续差分（`:97-102`）：

```
κ_{j,q} = Σ_{a=0}^{q} (−1)^a C(q,a) ω_{j+a} = ω_j (1−r)^q
```

对应整数组合的 **l1 范数 = 2^q**，在指数幂级数的**第 2^q 阶**才首次出现；它不是新的独立 rotary 对，且高阶幅度可能极小。

`b = 10⁶, K = 64, W = 32768`，半周期条件 `|κ_jq|W ≤ π` 的最早零基 j（`:108-116`）：

| 差分阶 q | 指数阶 | 最早 j |
|---|---:|---:|
| 0 单频 | 1 | 43 |
| 1 相邻差 | 2 | 36 |
| 2 二阶差 | 4 | 28 |
| 3 三阶差 | 8 | 21 |

**限定（`:117-121`）**：π 阈值只是"半周期"，不是普适学习截止；换相位阈值就改边界。结构性的结论是**层级本身及其对 b, K, W 的精确依赖**；表里的索引**不得**当独立预测的最优 cutoff。具体例：`ω28 − 2ω29 + ω30` 周期约 70K token（三个原周期只有几千），零内容相位下其主导余弦幅度为 `a·b²·c/16`（三个 logit 幅度 a,b,c）——**只看新长周期不看幅度会误导**。

#### (d) 频率改动必须保什么、会破什么

`ν = ω/S` 的公共伸缩下，**每一个**混合频率满足 `n^T ν = (n^T ω)/S` ⇒ **完整条件 softmax 剖面（不只线性 rotary 特征）被精确重定时**（`:132-136`）。对**一起缩放**的通道子集成立；**跨子集谐波不必服从任何一个时间坐标**。

两条互相冲突的约束（`:138-149`）：

```
保持重定时：  n^T ν = n^T ω / S
保持本地物理尺度： n^T ν = n^T ω
```

共享通道上二者冲突 ⇒ **具体分配问题**；"慢对计数"这类标量表达不了它。l1 范数为 1 的谐波退化成熟悉的逐频要求；混合 n 耦合中段分配。

#### (e) 最接近"目标函数"的一句（`:151-157`）

> 有限个指定交互目标允许一个**耦合二次局部逼近，矩阵 `Σ_n w_n n n^T`，对 ν 加 box/order 约束**。这可**不先选 ramp** 地从交互需求导出分配。**但是**：挑选有用交互、其权重、其期望尺度仍然必须做。**只最小化所有小混合频率会抹掉潜在有用的长程计算。** 这些选择**不由位置 Gram 矩阵提供**。

### 1.3 `ROPE_EXTRAPOLATION_FAILURE_AND_LIMITS_20260910.md`（外推失败 + 能力上界）

**文档性质（`:3-6`）**：不宣布新方法，不宣布普适上下文上限。

#### (a) 计算对象（`:9-34`）

```
z_ij^ν = (g²/√d_h) · (q_i^ν)^T R_ν(i−j) k_j^ν
```

**两个表依赖**：显式相对旋转 + **由更早计算形成的 q/k**；value 与后续 residual 状态也变。**只讲旋转的理论还不是输出的理论。**
每个块旋转正交：`‖R_ν(d)x‖ = ‖x‖`、`|q^T R_ν(d)k| ≤ ‖q‖‖k‖` ⇒ **外推本身不导致无界范数**；固定范数下仍可通过改变的**对齐**产生远大于训练分布的 logit。
**数值诊断（`:30-34`）**：精确算术下把所有 position ID 同平移常数不改变静态 RoPE 的相对旋转（causal mask 与其他所有操作不变时全模型不变）；**BF16 的旋转/归约可能破坏该实现中的不变性**。这给出一个不改 token、不改相对距离的数值诊断。

#### (b) 为什么分段合理、但三段不是定理（`:36-61`）

训练参考圈数 `r_j = W ω_j/(2π)`；小局部位移 d 下均匀插值的算子变化

```
‖R(dω_j) − R(dω_j/S)‖_2 = 2|sin( dω_j(1−1/S)/2 )|  ≈ |dω_j(1−1/S)|
```

⇒ 保高频有具体的**局部保真**动机。另一极端：`Wω_j ≪ 1` 的慢对贡献近似常数/线性位置函数，改它的绝对局部旋转更小；取 `ν_j = ω_j/S` 恢复其最大相位跨度，因为 `(SW)ν_j = Wω_j`。
**判定**：这是**连续谱的两个渐近区**；中段是二者之间的**工程过渡**，**不是第三种数学上不同的信息**。经验性的 1/32 圈阈值**不证明三个普适功能模块**。此外训练中实际见到的有效距离分布**不必在配置窗口上均匀**。
文献定位：YaRN §3.1–3.2 以高频细节与局部距离保持为动机；MrRoPE §3.2+App.B **自己就始于 YaRN 的经验证据**，保留频带原理、只改中段 radix 换算——**其 radix 指数等差是构造选择，不是任务最优性证明**（`:62-67`）。

#### (c) 为什么"看到一圈"不充分（`:69-90`）

低频覆盖假说指出了分布漂移的**一个**可能来源（学到的近常数内容通道在长距离转到不熟悉的对齐）；**它不证明一旦覆盖一圈，更高频就自动安全**。相位向量、其内容条件系数、竞争 key 是**联合**学的；**逐圈边际覆盖不蕴含那个联合对象的覆盖**。相关 key 的分数也不必随距离**单调**下降（分数含带符号 sin/cos）。
`Round and Round We Go`（arXiv 2410.06205v1 §3–6）给出反例；其单频语义通道定理**不是**对 Qwen 全部头/层的定量界。**部分 RoPE 训练结果也不为"从已训练 checkpoint 冷删频率"提供正当性。**
现 E1 槽位的例证（`:87-90`）：native 槽 28 与 29 在 Qwen 参考窗内分别转 **12.37 / 9.97 圈**，其条件成功**不能**仅由"某个单圈的未访问比例"解释。

#### (d) 一个值得测的联合有限窗量（`:92-121`）

```
G_W(δ) = (1/W) Σ_{d=0}^{W−1} e^{idδ} = e^{i(W−1)δ/2} · sin(Wδ/2)/(W sin(δ/2))
```

⇒ `|δ|W ≪ 1` 的邻近频率产生**近共线的位置列**。这取决于频率**间距**与距离测度，**不只**每个频率各自的圈覆盖；对**全部列的**相关比单一最近邻间隔更有信息量，但**仍不测**附在这些频率上的独立内容坐标。

**回溯比较（`:109-121`）**——一个具体的假说生成结果：

|---|---:|---:|---:|---:|
| 28 | 12.367 | .098039 | .074131 | .065359 |
| 29 | 9.966 | .137255 | .221149 | .183007 |

两者都在这两槽之间**从弱压缩转为强压缩**。**这是假说生成的吻合，不是 P2 残余→指数映射的独立验证**；P2 还改了许多别的槽、部分比较有 gain 混淆、且在任务/模型上有取舍。

#### (e) 更多 key 带来第二个、非位置的困难（`:124-149`）

```
p_* = e^Δ/(e^Δ + N − 1),   Δ = log(N−1) + log(p_*/(1−p_*))
```

把干扰项乘 4 而保持同一目标质量，需要约 `log 4` 的 logit 优势。更一般地，**相关量是目标 logit 减去竞争者的 logsumexp**；这个压力**与 RoPE 无关**。
均匀有界 logit 下 `z_* − z_j ≤ C` ⇒ `p_* ≤ [1+(N−1)e^{−C}]^{−1}`。**固定有界 logit 读出在 N→∞ 时不能对一个唯一项保持常数质量**。**这是条件 softmax 极限，不是"整模型或聚合任务必然失败"的证明**（分布式证据、其他信息通路、logit 尺度变化都有影响；**输出 token margin 与注意力 logit margin 数值上不可互换**）。
⇒ **这就是自然文本 NLL 可以很好而绑定失败的原因，也是 gain 必须作为独立变量测的原因。**

#### (f) 能力上界"能说与不能说"（`:151-185`）——本任务点名的部分

1. **精确局部保持把静态算子钉死。** 若固定 pair 身份、位移 1 处的**所有** Q/K 内积都必须保持，则 `R_ν(1)=R_ω(1)`，故 `ν = ω (mod 2π)`。**非平凡静态重分配不能在精确保持全部旧局部操作的同时改变长距离操作。** 但文档立刻自我限定：**这不禁更好的任务表现**——保持每一个可能 Q/K 强于保持模型在任务分布上实际使用的计算。
2. **有限维有界相位码在无界长度上没有一致可分性。** 把 K 个相位圆各分成 M 格；在 `M^K + 1` 个位置中必有两个落在同一乘积格，其位置特征向量欧氏距离至多 `2π√K/M`。**长度增长时任意近的位置复现必然出现**，即使频率不精确通约。**该界在 K=64 时极松，不能确立 128K 或 1M 的实用天花板**；不同内容与其他头/层仍可区分位置码很近的 token。
3. **标量代理的首零不是普适语言模型上限。** `Base of RoPE Bounds Context Length` Thm.1 的余弦和信号是在**指定随机 q/k 模型**与**特定相似 key 构造**下导出的，其假设必须随之引用；`RoPE Distinguishes Neither Positions Nor Tokens` 也**声明了正则幅度假设**并**使用分布近似**。这类结果**只告知失败假说**，不构成对非均匀学习频带的无条件界。
4. **冻结权重外加一层兼容性问题。** 更好的位置基几何**未必**对已学的 Q/K 投影与前缀计算可达。手稿的精确移植障碍关心的是可逆线性映射下**对所有内容/距离**的算子相等，**不蕴含**有益的有限分布冷替换不可能。**BM、P2、E1 的实测条件增益必须保留，作为对该障碍过宽解读的反衡。**

#### (g) §7 在跑实验的分解（`:187-219`）

5 个问题（冻结规则是否迁移 / 局部过渡是否方向性且可组合 / 计算哪个部分变了 / gain 是否对精确对称的数值实现稳定 / 更大 kernel 是否因其频率而有益）。**"这些测试是选择下一个方法的证据，不是要求在任何有意义正结果之前先有全部失败的完整理论。"** 当前窄候选仍是 E1；更深的假说是"**一个学到的、有限窗的可用位置响应过渡**"。

### 1.5 `COSH_REDESIGN_EVIDENCE_REVIEW.md`

**文档性质（`:3`）**：本轮基于 `09_09`、起始 HEAD `fe10272`；**没有启动模型训练、GPU 推理、远端作业或改动论文**；重算了 Phase16 全部 99 个结果文件、三臂 303 题 QA、重跑既有纯 NumPy 理论核查脚本。

**核心判定（`:7-11`）**：
- 当前结果**证明"分配"这个变量值得研究，但尚未建立能可靠选出更优分配的理论或算法**。
- Cosh 是**由特定 surrogate 选出的单参数曲线族**；某个部署 τ 才是其中一个点。有真实正结果，但 **"闭式可解 / 碰撞减小 / PPL 改善 / 任务能力改善"是四个不同命题**，现有材料没有把它们连成充分因果链。

#### §1 Cosh 推导的断点比"一个近似"更多（`:13-59`）

旧理论入口：`docs/theory/EVQ_COSH_THEORY.tex` §Exact Kernel and Broadband Projection。旧版取距离先验 `p(Δ)=1/(Δ log L)`，以 `K_cos(ω,ν)=E_p[cos(ωΔ)cos(νΔ)]` 为所谓 exact collision kernel，再用 `αδ(φ−ψ)+β·min(φ,ψ)` 近似它。
但真实单 RoPE pair 的 logit 项是（`:27-29`）：

```
f_k(X,W,Δ) = C_k(X,W)·cos(ω_k Δ) + D_k(X,W)·sin(ω_k Δ)
```

**五个不同层级（`:31-38`，逐条）**：
1. 距离先验是否代表**任务相关**的读取需求（token 重复距离 / 因果 pair 计数 / 平均 attention 距离**不是同一个测度**）；
2. cosine-only 核是否表示完整位置对象（**没有包括另外三个 sin/cos Gram 分量**）；
3. 完整位置子空间几何如何进入**有符号的内容竞争**（白化相关**会消去幅度及条件数**，不能直接表示训练模型的使用价值）；
4. surrogate 对所选几何目标的逼近是否**保持最优点**，而不只是矩阵拟合分数高；
5. 几何最优点如何在训练之后改善部署任务——**训练所学的 C/D 系数、跨层状态、softmax 竞争及生成过程都没有被前述静态目标确定**。
⇒ **旧文"唯一近似是 broadband projection"只指其已选定标量模型内部的代数步骤，不能描述从真实任务到 Cosh 的全部假设。**

**§1.1 先验曾被反向选择来提高拟合（`:41-45`）**：3 月 11 日记录——初始合成先验结果低于目标；token co-occurrence 测度约 0.65；GPT-2 平均 attention 测度在所列配置约 0.90；随后扫描先验/base/长度/网格/拟合区域，在 **24,000 个配置中找到 886 个 `R²_mid>0.99`**。⇒ 只说明某些条件下近似好，**不能说明真实 RoPE 需求恰好服从为提高拟合而选出的条件**。GPT-2 attention 统计**也不是**目标 RoPE 模型的任务敏感距离分布。

**§1.2 Cosh 由目标形式选出，不由拟合结果发现（`:47-58`）**：当前稿件写成

```
J[ρ] = (α/2)∫ρ² + (β/2)∫S_ρ²,   S_ρ(t) = ∫_t^1 ρ(φ)dφ
```

单位质量约束下，变分方程微分两次得 `ρ″ = (β/α)ρ` ⇒ 解为 Cosh。**存在性、唯一性与闭式是真实数学贡献；但一旦选定常系数局部平方项与 min-kernel，无论怎样拟合 α、β 都会返回 Cosh 族。这不能作为独立证明"真实 RoPE 应当采用 Cosh"的证据。**
更高的 R² 也不自动给出任务优化保证：**"甚至准确优化完整几何 rank，也存在窗口内正交而窗口外周期混叠的表"**；现有稿件附录的 harmonic-lattice、cosine/full-subspace 排序反例与跨长度反转，**已阻止把"换成更准确的碰撞目标"直接当下一代方法**。

#### (a) §2 一个不能继续使用的简化模型（`:17-27`）——**这是明确被判死的死路**

#### (b) §3 从要求推出一个几何规则，然后在 CPU 阶段被限制（`:29-53`）

不先选曲线，对单个频率提两个一般性要求：原窗口内相同物理距离尽量保真；目标窗口的拉伸距离尽量对应原窗口位置。**明确假设**：两类旋转误差等权、距离分别在各自窗口均匀分布、内容系数固定、gain 不变（**文档自注：这是建模选择，不是自然语言定律**）。
二维旋转的平方 Frobenius 距离为 `4(1−cos(δω·Δ))` ⇒ 两项平均误差除以 4 后**精确**得到：

```
J_q(y) = 2 − sinc(y−q) − sinc(sy−q),   q = ωL₀, y = ω′L₀,   sinc(u)=sin(u)/u
```

`q→0, y=O(q)` 时：`J_q(y) = [(y−q)² + (sy−q)²]/6 + O(q⁴)`，且

```
ω′/ω → (s+1)/(s²+1)
```

**s=4 时比例 = 5/17 ≈ 0.29412，比 PI 的 0.25 少压缩一些尾频。** 文档自注：这只是该明确几何模型的**慢相位极限**。
**CPU 阶段的自否（`:51-53`）**：q 增大后 sinc 目标有振荡与多个极小区；对 OLMo 的 **K=64、base=500000、L₀=4096** 几何参数，逐频率的 **2001 点区间网格最小值产生 11 处输出频率次序交叉**。**网格搜索不是连续全局最优证书，排序约束也可能改变解；这里不声称整个问题无解。**
**关键不足**：该目标**仍只比较旋转函数**，没有内容符号、softmax 竞争与整网输出 ⇒ **接近项目以前已经发现局限的 coverage / displacement 路线**。**"不能因为推出了漂亮的 5/17，就把它作为新候选交给 GPU"**；**也不以平滑、排序修补后宣称问题已解决。**

#### (c) §4 用通用语言模型目标给出实际分配更新（`:55-128`）

输入（`:59-72`）：原模型 W 与实际频率 Ω；初始可行表；**提前固定的通用文本校准集合**（多领域、多长度区间，与最终 benchmark 文档隔离）；**每个集合同一个自监督目标 = 真实下一个 token 的平均负对数似然**；原生窗口各集合的**允许损失增量**（**"这个容差是工程要求，不伪装成数学常数"**）。定义

```
ℓ_i(x,W) = −(1/N_i) Σ_t log p_{W,exp(−x)}(a_t | a_{<t}),    x_j = −log ω_j
```

所有集合的 loss 都以**每 token 的 nats** 计，**不靠任意 1/1/1 混合权重隐藏冲突**。

**§4.2 完整有符号频率梯度（`:74-85`）**：

```
s_j = c_j cos(ω_j Δ) + d_j sin(ω_j Δ)
∂_{x_j} s_j = ω_j Δ [ c_j sin(ω_j Δ) − d_j cos(ω_j Δ) ]
```

与整网损失对每层 attention logit 的 adjoint 相乘并求和得 `g_i = ∇_x ℓ_i`。**"必须通过真实整网求导；不得拿 detached-Q/K 的局部差、Q/K 范数或 Gram rank 替代。"** 文档自注：**梯度原理已有项目推导与 LeRoPE（arXiv 2607.10134v1）支持，不是本轮新发现。**

**§4.3 分配更新由共同下降问题决定（`:87-114`）**：

```
v* = argmin_v { ½‖v‖² + max_i g_i^T v }
λ* = argmin_{λ_i≥0, Σλ_i=1} ½‖Σ_i λ_i g_i‖²,   v* = −Σ_i λ_i* g_i
分配规则：x_new = x + α v*,   ω_j^new = ω_j exp(−α v_j*)
```

**共同下降保证**：令 `u* = Σλ*g` 为凸包中最小范数点，最优性给出 `(g_i−u*)^T u* ≥ 0` ⇒ `g_i^T v* ≤ −‖u*‖²`。**当 u*≠0 时，对有限个可微 loss，足够小的步长会同时降低它们。`u*=0` 表示这些梯度没有严格共同的一阶下降方向，不是全局最优、不是全部方法不可行、不是整个频率空间无法改进。**
文档自注：**这是经典 MGDA 的应用，求解器和上述结论不申报新颖性。**

**§4.4 Native 保护与有限步接受条件（`:116-128`）**：

```
ℓ_{N,d}(x_new) ≤ ℓ_{N,d}(x_0) + ε_d
```

Native 作为**真实容差约束**，而非要求所有短窗 loss 严格下降。通用长文本单元组成下降目标，**Native 集合独立进行实际前向检查和回溯**。Native **若严格有余量**，连续性保证存在足够小的可行步；**恰好在边界时没有这个自动保证，须使用可行方向约束或返回未找到可行步。不能只靠一阶 Native 条件宣称有限步保护。** 有序频率在回溯时直接检查（沿同一已算方向缩小 α，不试多个手造表）。

## 9. 一句话小结

这批六篇文档提供的是 **KKT 目标泛函 F 的零件库**（非局部脊核 `h_c` 与乘子 `ĥ_c`、6Pro 的 `J[h]` 泛函、有符号整网频率梯度、混合频率的重定时冲突约束、读出阈值结构）**加上一份很长的否决清单**（静态几何代理、simplified 旋转对称模型、Cosh 的唯一性叙事、τ 的旧解析规则、锐利过渡定罪、"三段是三类信息"、标量代理首零的上界宣称）；**它们都没有给出能力链接**——所有指向同一缺口 Q9：`L_far` 需要一个"联合谱覆盖/风险带"的可计算形式，而这一步在六篇材料中**都只是被点名，没有被完成**。
