**(D) EVQ 的变分与 Cosh 解（C §4.1，L86–109）** — 本 doc 的**最高价值零件**：

纯 tether 泛函（C L88–90）：
```
J[ρ] = (α/2)∫ρ(φ)²dφ + (β/2)∬ρ(φ)ρ(ψ)min(φ,ψ)dφdψ,   ρ≥0, ∫ρ=1, α>0, β≥0
```
驻点条件与正解（C L94–96）：`αρ(φ) + β∫min(φ,ψ)ρ(ψ)dψ + λ = 0` ⇒ `ρ'' − τ²ρ = 0`, `ρ'(1)=0`, `τ²=β/α` ⇒
```
ρτ(φ) = τ cosh[τ(1−φ)] / sinh τ
```
分位数（C L100）：`Qτ(u) = 1 − asinh[(1−u) sinh τ]/τ`。
C L98：该泛函**严格凸**，归一化 Cosh 是**唯一**最优解。**[已验证]**（sol02.md L186 独立列出 strict convexity/existence/uniqueness/cosh minimizer；`docs/theory/EVQ_COSH_THEORY.tex` L370 给出含 Fisher 项的通解）。

J[h] = (1/2)∫₀¹ [α/h(u) + β(1−u)² h(u)] du,   h(u)=Q'(u) > 0,  ∫₀¹ h = 1

### 1.3 S — 联合谱关系推导（CPU，无模型）

**(A) 要保的对象与"联合性"（S L9–27）**
`x_ω(d)=(cosω₀d,sinω₀d,…,cosω_{K−1}d,sinω_{K−1}d)ᵀ`；条件 rotary logit 是它的**线性泛函**。
S L16–20：一个频带可能含有在源窗上**分辨很差的方向**——这是频率的**联合性质**，**不是**每个通道可以零代价独立移动的陈述。
S L22–27：病态系数表示**不自动**意味着被表示的函数差（引 Adcock–Huybrechs–Martin-Vaquero, *On the numerical stability of Fourier extensions*, §1.2）。**[建模立场+文献支撑]**

**(B) 初等相消计算（S L29–55）** — 精确公式，可直接复用：
```
f(d) = ω₂ sin(ω₁d) − ω₁ sin(ω₂d)
     = ω₁ω₂(ω₂²−ω₁²)/6 · d³ + O(d⁵)          （线性项相消）
```
- 两个频率同除 S ⇒ `f_new(Sd) = f(d)` **精确**（S L43–44）。**[已验证=代数，本 digest 同意]**
- 分别乘 a、b ⇒ `f_new(d) = ω₁ω₂(a−b) d + O(d³)`（S L46–48）：**不等分配会给原本三阶起效的组合引入一阶响应**。**[已验证=代数]**
- S L51–55 自带边界："large relative change need not imply a large absolute logit change…The result identifies a mechanism to preserve, **not a model-accuracy theorem**"。**[建模立场]**

**(C) 有限窗版本（S L59–119）** — 本 doc 的数学主体：
- `G₀ = E_{d~p₀} x_ω(d)x_ω(d)ᵀ`；`N` = 指定低能量特征子空间的正交投影，`P=I−N`；部署表的远距暴露
```
U(ν) = E_{d~p_far}‖N x_ν(d)‖² = tr(N G_far(ν))
```
（S L62–71）。S L74–77 自限：**它的阈值是建模/数值分辨率选择，不自动是模型的学习精度**。
- **Uniform-PI 界（S L79–91）**：p0 均匀 [0,W]、p_far 均匀 [W,SW]，则
```
G_far(ω/S) = 1/(W−W/S) ∫_{W/S}^{W} x_ω(t)x_ω(t)ᵀ dt ⪯ S/(S−1) · G₀
⇒ U(ω/S) ≤ S/(S−1) · tr(N G₀)
```
证明 = 变量替换 t=d/S + 源积分被舍去部分的正性（S L88–90）。**[已验证=证明；本 digest 独立核对代数链：∫_{W/S}^W ⪯ ∫_0^W = W·G₀，除以 (W−W/S) 得 S/(S−1) ✔]**
  S L91 自限："operator statement about source-weak directions, **not** about task accuracy or whole-network states"。
- **Selective-PI 恒等式（S L93–106）**：H 选保留通道、T=I−H 选被压缩 S 的通道（每对两个坐标一起选），则
```
N x_ν(d) = N x_ω(d/S) + N H { x_ω(d) − x_ω(d/S) }
```
S L102–106：若 `NH=0`，selective PI 与 full PI 的未分辨响应**完全相同**，同时保留高频块原频率；`NH` 小时附加项有显式范数界（Minkowski）：
```
√U(ν) ≤ √U(ω/S) + √{ E‖NH(x_ω(d) − x_ω(d/S))‖² }
```
S L106 的**结论性断言**："一个有意义的过渡边界与**联合弱子空间的支撑**有关，而不只看单个频率是否转满一圈。" **[假设-待验证]** 这是 S doc 对 KKT 的最重要主张，但它**尚未被任何模型实验证实**。
  S L116–119 明确切割旧仓库：`rope_transport/nullband.py` 用的是另一种"转满一圈"安全条件，**其"已缠绕通道可自由移动"的断言不是本推导的假设**。**[已验证=自我切割]**
