## 2. 可作 F 零件的公式/定义/假设（本 digest 的核心产出）

### 2.1 【精确恒等式】倾斜（tilted）reader 的 logmass 分解

> `logmass_b(q) = log Σ_{j∈b} e^{c_j+t_j} = log Z_cis,b + log E_{j∼w}[e^{t_j}]`，
> 其中 `c_j=cis_j`、`t_j=q^Tk_j/√d`、`Z_cis,b=Σ_j e^{c_j}`、`w_j=e^{c_j}/Z_cis,b`。

出处：`TWO_CORE_ROUTE_EVALUATION_20260909.md:472–482`；同一式另见 `TWO_CORE_ONE_HOUR_DECISION_20260909.md:17` 与 `THREE_PARTY_RESEARCH_HANDOFF_20260910.md:47`（三处独立书写，逐项一致）。
证据等级：**[已验证-代数]**（本轮重算：Σ_j e^{c_j}e^{t_j} = Z_cis·Σ_j w_j e^{t_j}，逐项相消，恒等；w≥0 且 Σw=1）。

**原文自带的边界条件（不得省略）**：
- 倾斜权重"逐窗口归一化，不能用跨窗口权重直接套此式"；且"窗口常数 log Z_cis,b 也不能省略，否则会抹掉窗口间的真实 bias 质量差别"（`ROUTE_EVAL:482`）。
- "若 c_j=c 常数，则 w=1/B 且 logZ=c+logB，回到普通 cumulant 公式加精确常 bias"（`ROUTE_EVAL:488`）。
- "指数倾斜恒等式**是精确恒等式，不是 bias 近似**"（`ROUTE_EVAL:482`）。

**对 KKT 的可迁移点**：这是"把某个每窗口常数（logZ）从 query 相关部分里**精确分离**出来"的记账模板。`NEXT_DERIVATION_KKT_PROBLEM.md §5.5` 要求"gain 独立记账、F 不含 gain 自由度"；本条给出的是**同类记账纪律的一个已验证范例**——常数项必须显式保留，否则误差会被错归因（"否则块长度、cis 总质量或不完整块导致的误差会被错归因于 covariance"，`ROUTE_EVAL:804`）。

### 2.2 【精确误差分解】二阶截断 = 缺失协方差项 + tilted 三阶余项

> `L_B − L̂_B^{PC2} = q^T(Σ−𝒟Σ)q/(2d) + ½∫₀¹(1−t)²K'''(t)dt`，
> 其中 `K(t)=log E_w e^{tY}`，`Y=q^T(x−μ)/√d`，`K(0)=0`，`K'(0)=0`，`K''(0)=q^TΣq/d`，
> `K'''(t)=E_{w^{(t)}}[(Y−E_{w^{(t)}}Y)³]`（tilted 测度下的三阶中心矩）。

出处：`ROUTE_EVAL:874–905`；条件化界 `|L_B−L̂| ≤ |q^T(Σ−𝒟Σ)q|/(2d) + M_{3,B}(q)/6`（`:907–920`）。
证据等级：**[已验证-代数]**（Taylor 积分余项标准形式；因 K(0)=K'(0)=0，`L−L̂ = ½K''(0) − ½·q^T𝒟Σq/d`，即上式。K''(0)=q^TΣq/d 由 Y 中心化直接得）。

**原文自带的"不能偷换"条件（这是本条最有价值的部分）**：`ROUTE_EVAL:938–946`
1. 只控制 t=0 的第三矩不够；稀有正尾在 t→1 被 exponential tilt 放大 ⇒ 需 0–1 **整条 tilt 路径**的界。
2. "原始分布 skewness=0 不使余项为 0"（对称 ±a 在 t=0 三阶矩为 0，但 tilted 分布一般不再对称）。
3. 小 covariance Frobenius 误差**不保证**具体 query 方向误差小（query 可对齐被删掉的 cross 项）。
4. 有限块必有某个 M₃，**不意味着这个界有用**；score range 大时界可远大于 topK margin。
5. 这些误差量一般需要更多 token 信息或离线审计 ⇒ "**不能宣称…以 O(d) 摘要自动给出了低成本 topK 可靠性证书**"。

**另有**：`𝒟(Σ)−Σ` 一般**既非 PSD 也非 NSD** ⇒ "不保证方差只低估或只高估"（`ROUTE_EVAL:872`）；同理二阶层 `½ a^T(Σ−Σ̂)a` "可正可负"（`:399`）。
**对 KKT 的可迁移点**：任何把 F 写成**截断展开**（水床/二次型）的做法，其误差项结构就是"缺失项 + 沿 tilt 路径的三阶余项"，且**符号无保证**。这给 `NEXT_DERIVATION §1.4` 的 L_near 二次载体（`Σ w_j(ν_j−ω_j)²`，本身非负）一个明确警告：**非负的是 F 的项，不是 F 的近似误差**。

### 2.3 【可证命题】top-K 稳定只在 margin 足够时成立

> 若对所有块 `|L_B−L̂_B| ≤ ε_B`、真 topK 集合 S 无并列、且 `L_i−L_j > ε_i+ε_j  ∀i∈S, j∉S`，则近似 topK = S。
> 统一误差 ε 下的充分条件：**第 K 与第 K+1 真 logmass 间隔 > 2ε**。
> 区间分离形式：`min_{i∈Ŝ}(L̂_i−ε_i) > max_{j∉Ŝ}(L̂_j+ε_j)`。
> value 侧条件性界：若 `‖v_j‖≤V`，则省略块后重归一化的 attention 输出与完整输出之差 `≤ 2V(1−P_S)`。

出处：`ROUTE_EVAL:948–966`。证据等级：**[已验证-推导]**（证明一行：插入 L̂ 并用 min/max 分离）。
**原文自带的边界**：只证明**相对真实 block mass 目标**的选集稳定，"既不证明 native NOSA 选集相同，也不证明答案正确"；`2V(1−P_S)` 界"不保证深层残差、MLP、autoregressive 生成或完整答案；**最重要的答案 token 也未必拥有最高总体 attention mass**"（`:966`）。

### 2.4 【不可加性反例】跨对象聚合的两个严格否证

(a) **各 head 未归一化 logmass 不能相加**。CPU 反例：两块 A/B，两 head logmass 分别 (100,99) 与 (0,4)。
   - 每 head 归一化后 A/B 平均 mass = **0.374522/0.625478** ⇒ 应选 B；
   - 未归一化求和被 head1 压倒 ⇒ **选 A（错）**。
   出处 `ROUTE_EVAL:1013–1020`。证据等级：**[已验证-算术]**（本轮复算：head1 A=e/(1+e)=0.7310586；head2 A=1/(1+e⁴)=0.0179862；均值 0.3745224 ✓；B 侧 0.2689414/0.9820138 → 0.6254776 ✓；两者和=1 ✓）。
   配套：若每 head 误差 ≤ε_h，则 group mass 误差保守界 `|M̂_B−M_B| ≤ Σ_h α_h A_{hB}(e^{2ε_h}−1)`（`:1024–1030`）。
(b) **二次项不可交换期望**：`E_h[q_h^T C q_h] ≠ (E_h q_h)^T C (E_h q_h)`，"再叠加 softmax 后差别更大"（`:1022`）。证据等级：**[已验证-代数]**（Jensen/凸性方向即可看出一般不等）。
(c) **`E softmax(s) ≠ softmax(E s)`**：两 anchor logits 各 [10,0]、[0,1]、概率各 1/2 时，正确混合的第一 key 概率 `0.5(σ(10)+σ(−1))≈0.63445`；对平均 logit [5,0.5] 做 softmax 得 `σ(4.5)≈0.98901`。出处 `ROUTE_EVAL:686–694`。证据等级：**[已验证-算术]**（σ(10)=0.9999546, σ(−1)=0.2689414，均值 0.634448 ✓；σ(4.5)=0.989013 ✓）。

**对 KKT 的可迁移点**：F 必须在**角色/来源层定义之后**才允许聚合；任何"先平均再取非线性"的写法必错。与 `INTEGRATION §4.1` 的"带符号、按槽标签、带内容系数——三缺一即死（L1/L2/L4）"同族，可作其算术级佐证。

### 2.5 【坐标不变性】等变命题，以及它**不**给出什么

> 令 `𝒟(Σ)=Σ_f P_f Σ P_f`（P_f 为各 RoPE 二维不变平面上的正交投影）。共同平移原点 a 时 `U=R(a)=⊕_f U_f`，每个 P_f 与 U 交换，故 `𝒟(UΣUᵀ)=U𝒟(Σ)Uᵀ`；固定 pre-RoPE 内容、块成员与 b_j 时 `μ'=Uμ, Σ'=UΣUᵀ, Z'=Z, L̂'_B(q')=L̂_B(q)`。

出处 `ROUTE_EVAL:826–848`。证据等级：**[已验证-推导]** + **CPU 回执**（64 个 8 维随机向量、非均匀 cis 权重、split-half 配对：blockdiag 共轭等变最大差 **0**，原点平移 score 差 **0**，full-space rank2 PCA 同 score 差 **3.33e−15**；`ROUTE_EVAL:1084–1087`）。
**原文自带的关键限制（这是"不变性≠优势"的判决先例）**："**Full-space per-block PCA 也正交等变**"（`:852–858`）⇒ 等变**不**构成 PC2 的独占优势。另外：它"不等于在实际文本前面插入 filler 后模型输出不变"（`:846`）；实现必须按实际 pair 配对（split-half 是 (r, r+d_rot/2)，不是相邻 (2r,2r+1)，`：848`）。
**对 KKT 的可迁移点**：与 `STARTING_POINT_YARN_VS_MRPRO.md §6 F7/F8`（"两个恒等式拼不出全网精确重演"）**同向且互补**——两条独立材料都得出"算子级不变性/恒等式不能升级为能力定理"。

### 2.6 【proxy vs 真实需求】精确差值分解与 regret 界（来自 PM 线）

> 固定共同参考轨迹、`a=Eα`（α 为 prefix 占全 attention 分母的份额）、`ρ_j = E_real[α(q)b_j(q)]/a`（真实需求）、`π_j=E softmax`（代理）、`d_j=1_{j∈S_P}−1_{j∈S_C}`，则真实保留 mass 差**精确**等于
> `Δ_{P,C} = a ρᵀd = a·πᵀd (代理位置决策收益) + a·(ρ−π)ᵀd (真实需求错配)`。

出处：`TWO_CORE_SOL_HANDOFF_20260909.md:263–277`。证据等级：**[已验证-代数]**（把 ρ 拆成 π+(ρ−π)，线性分配即得）+ CPU 有限算例（第一项 +0.30、错配项 −0.95、a=0.6 ⇒ 实际差 −0.39，`SOL_HANDOFF:277`）。
> regret 界：`a[ρ(S*)−ρ(Ŝ)] ≤ 2ar‖ρ−π̂‖_∞ ≤ 2ar(‖ρ−π‖_∞ + ‖π−π̂‖_∞)`。

出处 `SOL_HANDOFF:281–289`。证据等级：**[已验证-推导]**（插入 π̂、用 Ŝ 对 π̂ 的最优性、余两组各至多 r 项误差）；原文自标"通常很松，**不作为 M=256 的排序认证**"。

**另有 value 侧的精确式**：`F_S − F = Σ_{j∈D} a_j (F − v_j)/m`（删除集合 D、剩余质量 m）。出处 `SOL_HANDOFF:295–296`、`THREE_PARTY:79–82`。证据等级：**[已验证-代数]**（重归一化 attention 输出的直接展开）。原文结论：mass 只能给带 V_max 的上界，"**不能识别 value 方向、抵消、W_O 与后续网络对该方向的敏感性**"。
配套反例：`raw V norm` 不是最优性保证——"给全部 V 加同一向量不改变上述输出差，却可改变 norm 排名"（`THREE_PARTY:83`、`SOL_HANDOFF:298`）。**对 KKT 的可迁移点（最重要的一条）**：这是把"**最小化 in-window 损失（代理）同时最大化外推能力（真实需求）**"这一双目标**精确拆成"代理收益 + 错配项"**的现成模板。它直接影响今天要攻的 KKT：F 是代理泛函；本条告诉你代理上的 Δ 与真实 Δ 之差恰为 `(ρ−π)ᵀd`——所以**任何"在 F 上更优"的结论都必须显式讨论错配项**，而不能靠"代理更准"升级。

### 2.7 【Jensen 下界】细分/分段结构的严格性质

> `log|B| + q^T mean_B k ≤ F_split(q)=log Σ_m |S_m| exp(q^T mean_{j∈S_m} k_j) ≤ log Σ_{j∈B} exp(q^T k_j)`，
> 且**逐级细分使这一下界不减**。但"任意两套不同分区没有这个单调保证"。

出处 `ROUTE_EVAL:738–742` 与 `:1049`。证据等级：**[已验证-代数]**（Jensen 两次）。
**对 KKT 的可迁移点**：这是"分段/桥宽"问题里**唯一一条现成的、无需假设相位是坏的严格单调性质**（原文强调"该性质对包含 RoPE 的实际 k 成立，不需要假定相位是坏的"）。它给"桥的细分"一个合法下界工具，但原文立刻限定"最终 top-k ranking 仍可能变化而不一定更准确"。

### 2.8 【成本判据】摊销阈值（成本侧的唯一量化式）

### 2.9 【明确禁止的转移】哪些 PC2/PM 构件**不可**进 F
