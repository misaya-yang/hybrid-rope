## 1. 五个解法的共同骨架（跨文件一致，可作为 F 的坐标系共识）

（同一对象在五份里逐字近似，出处：sol06:7-26、sol07:56-60、sol08:7-11、sol09:12-22、sol10:96-111）

- 有序 log 频率向量 `x_k = -log ω_k`（native），部署表 `ν_j = ω_j S^{-m_j}`，`m` 单调非降、`m∈[0,1]`。
- 增量单纯形：`Δ_j = m_{j+1}-m_j ≥ 0`，`Σ_j Δ_j = 1`（= 过渡段总跨度锁定 `ln S`）。
  等价 radix 形式（sol09:14-20）：`b_i ≥ 0, Σ b_i = log s, m_j = (1/log s) Σ_{i≤j} b_i`。
  边增量形式（sol10:104-111）：`ε_r = m_r - m_{r-1} ≥ 0, Σ_{r=ℓ+1}^{h} ε_r = 1`。
- 端点锁定：`m_j=0, j≤23`（高频恒等）、`m_j=1, j≥40`（尾部精确 ÷S）。sol06:14-16 把它写成"frozen Qwen deployment 的 presently evidenced feasible face"，并显式声明"这是本 checkpoint 当前被测的可行面，**不是普适定律**"——这条**与权威文档一致**（`INTEGRATION_20260910.md:30` R3：端点与 gain 是设计面，不是被证定律）。
- **两 regime 是两种优化**：scratch（权重可共适应，效用内生于训练）+ frozen（权重固定，须付 checkpoint 兼容成本）。五份全部主张此二分，且都以"权重-表交叉"实验为机制理由（sol08:26、sol10:53-61，见 §6 数字表）。

**跨文件一致的中层结论（可作 KKT 问题的先验）**：
> 静态几何 / 无符号代理**不能**作选择子（只能作正则或诊断）；选择子必须是 signed、checkpoint-specific、full-model 的 task utility。

### 2.2 sol07 — 贪心 donor→recipient 边际决策效用转移（本批的"非可加性解释器"）

**结论**（sol07:3-7）：几何-only 规则不被支持；最能解释真实胜利的可测量计算是**冻结模型下 signed answer-decision margin**，分解为 prefix-formation + readout。构造规则 = 按 **cross-fitted marginal decision utility** 分配 log-frequency gap。MrRoPE 给 frozen 基线；EVQ 给 scratch 初始化/正则；gain 是独立幅度坐标。

**公式**（sol07:34-68）
- 目标答案 y* 与竞争者 C 的 margin：`M_t(ν,g) = ℓ_t(y*;ν,g) - log Σ_{c∈C} exp ℓ_t(c;ν,g)`
- 候选 a 的 delta margin：`ΔM^a_{e,t} = M_{e,t}(ν^a,g) - M_{e,t}(ν^0,g)`
- 前缀/读出分解：`P = M(a,0)-M(0,0)`，`R = M(0,a)-M(0,0)`，`I = M(a,a)-M(a,0)-M(0,a)+M(0,0)`
- **转移效用**：`Û_a = Q_{0.2,e}[Σ_t w_{e,t} ΔM^a_{e,t}] - λ_N[ΔNLL_a - ε_N]_+ - λ_S Regress_a - λ_B BF16Mismatch_a`
- 转移算子：`a=(i→j, η)` 从 donor gap i 取 η 加到 recipient j，再**累积重建频率**（sol07:60）

**算法（sol07:71-77，5 步）**
1. 从 target-checkpoint MrPro 出发，保留已验证端点与 gain；
2. 用既有 adjacent exponent step / declared physical phase quantum 定 donor→recipient 转移大小；
3. 按 cross-fitted utility 排序（**不是** target mass / NLL / chord distance / roughness）；
4. 应用最佳正转移并**重算**——"failed 28+29 pair forbids additive composition"；
5. 无正下置信效用即停，冻结并在未触碰样本上测。

**实验面板（sol07:13-26 表，数字见 §6 表）**——关键几行：
- E1 pair 28+29：32K tie；**128K −4.167 pp, 0/1** → "Individual gains do not compose. Utilities must be recomputed after every edit."（sol07:17）
- E7 local projection：32K +2.778 pp；128K **−9.514 pp, 6/7** → "Local-output preservation failed as downstream selector. Ideal finite math is sound; deployment arithmetic differs."（sol07:21）
- E8 zero slot 51：12-row long subset **−13.889 pp** → "Strong conditional target-mass score did not predict generation."（sol07:22）
- Smooth(MrBudget)：32K tie；128K **−9.792 pp**；HighGapToLong：**−17.083/−10.764 pp, 0/7**（sol07:24-25）

**E7 数值诊断（sol07:50；已在 transfer 文档 :150-156 对账）**
`linear predicted NMSE 7.9366844e-8`；`exact ideal finite 7.9364028e-8`；`FP32 absolute-coordinate 7.9325473e-8`；`BF16 absolute-coordinate 1.2807392e-5`。→ **BF16 算术产生约 161 倍平方误差（=12.7 倍幅度）**。
对账：`NONGEOMETRIC_MECHANISM_TRANSFER_20260910.md:150-153` 给 7.93668e-8 / 7.93640e-8 / 7.93255e-8 / 1.28074e-5、":153-154 … roughly 160-fold discrepancy … dominated by finite-precision rotation"。**一致（[已验证]至文档层；receipt 原件本地缺失）**。原代码见 `experiments/nongeometric_screen/local_precision.py:41-50`（本文件实读）。

**selector 实现史（sol07:46,52）**：`select.py:24-68` 的条件 selector 提名了两个 E1 winner，**也**提名了 E2/E8 loser 与 layer/group tie，无法解释 E1 pair → "It is a proposal filter, not an objective"。旧 `old_probability × exp(delta)` 归一化会 underflow；log-weight 归一化（`select.py:49-58`）修复后 E5 runner-up 从 layer 27 变 32。

### 2.3 sol08 — 失败记录审计 + 构造性统一（失败清单最完整的一份）

**结论**（sol08:3-17）：支持共同**坐标系与条件优化问题**，**不支持** EVQ–MrRoPE 行为族闭合。物理对象 = 有序 log 频率向量 `x_k = -log ω_k = a + R z_k`，`0=z_0<⋯<z_{K-1}=1`；`(a,R)` 是采样支撑，`z` 是内部配，**slot 身份属于成熟对象**。明确否认："does not claim that EVQ is a limit of MrRoPE, that MrRoPE is a discretization of EVQ, or that their published rules form a closed optimal family"（:19）。

**EVQ 实际证明了什么（5 条，sol08:23-27）**
1. 因果坐标而非普适曲线：三 seed 151.9M 干预只改内部频率，Cosh−uniform NLL `+0.026/-0.281/-0.176/-0.146` @256/512/1K/2K。
2. 方向比 Cosh 宽：M4 记录说 deformation-matched exponential 有竞争力（引 `TIMELINE.md:67-77`）。
3. 支撑与分配**交互**：两网格重定标后 OOD 排序反转 `+0.060/+0.227/+0.460` → `z` 与 `(a,R)` **不可加**。
4. 行为是共适应的：frozen 50M PPL `7.14/76.20/23.05/7.16`（Geo/Geo, Geo/EVQ, EVQ/Geo, EVQ/EVQ）；static rank 在最差 cell 从 `4.57` 升到 `12.54` 而 PPL 崩 → **直接否决 static-rank 选择子**。
5. 冻结敏感性存续但"详细 profile 必要性"不存续：OLMo 同支撑从 `0.56%` 变 `60.47%`，但粗 ramp 达 `61.04%`。

**已闭合的选择子（sol08:39-47）**：cosine-only collision、full-subspace rank/logdet、任何无符号几何统计量的单调组合、`kappa` attention-measure（一阶与有限交换排序不一致 → Branch C）、`ρ ∝ w^{1/3}` 的 LeRoPE oracle（`alpha=-0.957`）、从假设距离先验导出的通用密度、arcsine 主张、改写静态表下的"普遍短窗无伤"、从 emulation rank 界推 re-adaptation。

**幸存因果坐标（7 条，sol08:49-58）**：① 有序物理表 `x`（非自由 base/exponent 文本对）；② 支撑 `(a,R)` 与内部配 `z` 需分开（干预可分离、结果交互）；③ slot 关联（同多重集置换崩）；④ lifecycle（scratch/frozen/adapted 梯度不同）；⑤ signed task/data risk（含 Pareto 向量）；⑥ native 兼容预算 + 序/支撑约束；⑦ operator 场（gain/routing 须单独记）。

**公式**
- 混合先验：`q_η(t) = (1-η) q_E(t) + η q_M(t)`，`0≤η≤1`；初值 `z_k^{(0)} = F_{q_η}^{-1}((k+1/2)/K)`（分位数规则，**是初始化，不是任务成功定理**）（sol08:63-75）
- scratch 双层：`x*_scratch ∈ argmin_{x∈X} E_{S,ξ} L_deploy(W_T(x;S,ξ),x) + λD(x,x^{(0)})`（`D` 只是弱先验，可为 0）
- 精确超梯度：`∇_x R_out = ∂_x R_out + J_T^T ∇_W R_out`，`J_{t+1} = ∂_W Ψ_t J_t + ∂_x Ψ_t`；孤立可微内点最优处化为 `R_x - R_W H_WW^{-1} H_Wx`（"第二项 = 共适应响应，不可省"）（sol08:88-101）
- **frozen 带梯度**（sol08:117-121）：
  `g_k = E Σ_{ℓ,h,i,j} (∂ℓ/∂s_{ℓhij}) ω_k Δ_ij [c_{ℓhij,k} sin(ω_kΔ_ij) - d_{ℓhij,k} cos(ω_kΔ_ij)]`
  → "unsigned Q/K norms, Fisher magnitudes, or Gram statistics cannot replace it"（引 `ROPE_OPTIMALITY…:316-362`）。
- **frozen 局部凸程序**（sol08:125-141）：
  `min_h g_L^T h + ½ h^T H_L h + (β_E/2)‖h-h_E‖²_{W_E} + (β_M/2)‖h-h_M‖²_{W_M}`
  `s.t. ½ h^T F_N h ≤ ε`，`x^N + h ∈ X_ordered`。
  若 `H_L=0` 且无激活序约束，**闭式**：`h* = -sqrt(2ε / (g_L^T F_N^{-1} g_L)) · F_N^{-1} g_L`；有序约束下解 cone KKT 投影。

## 3. 重点 A：sol07 的"每次编辑后重算完整前向"为什么是必须的

这是本次任务点名的重点。四层理由，**全部有出处**，且要区分"任务准确率层非可加"与"logit 层近乎可加"：

**(1) 事实层：单槽收益实测不可组合。**
- E1 slot 28（predecessor exponent）128K `78.125→83.333%`，2 胜 0 负；E1 slot 29（successor exponent）32K `+8.333 pp`；但 **E1 pair 28+29：32K tie、128K −4.167 pp、0/1**（`sol07.md:15-17`；对账 `INTEGRATION_20260910.md` 面板 "pair(28+29) 87.2/74.0"）。sol07 明写 "Individual gains do not compose. Utilities must be recomputed after every edit."（`sol07.md:17`）

**(2) 机制层：非可加性发生在"阈值/决策"层，不在"margin"层——这正是"必须重算"的正确解释器。**
- sol07 的关键测量：slot-28 multikey 四格 correct-minus-competitor margins = `-2.125, -1.125, -1.000, +0.250` nats；prefix formation 贡献 `+1.125`、readout `+1.000`、factorial remainder 仅 `+0.250`（`sol07.md:5,44`）。对账 `NONGEOMETRIC_MECHANISM_TRANSFER_20260910.md:129-141` 原文一致，并自注 "It is incorrect to infer a large nonadditive internal mechanism from the binary success pattern alone."
- sol10 独立重申同一判读："threshold crossing is a sufficient explanation"（`sol10.md:90`）。
- **所以：** 目标函数若取"任务正确率/greedy argmax"这类**阈值函数**，"两个单槽各自 +X"根本不蕴含"合并后 +2X"——阈值把连续 margin 的微小交互放大成离散翻转。效用是**当前表状态**的函数，任何逐槽列表法先天失效；只有**每次接受一个转移后重跑完整前向**，才能得到该状态下的真实 ΔM。
- ⚠️ **口径提醒（与权威文档的措辞差）**：`INTEGRATION_20260910.md:79` 把它简写为"slot 级收益**非加性** ⟹ 逐槽列表法先天失效"。这句话在"任务准确率层"成立；但若被读成"底层 logits 强非可加"就**过头**了——sol07 与 sol10 都明确说连续 margin 近乎可加（sol07:5 "Nearly additive continuous changes cross a discrete greedy boundary"；sol10:90）。**引用时应写全："阈值层不可加（margin 层近乎可加）"。**

**(3) 通路层：不能分解为固定 Q/K 读出，必须整段 prefill。**
- 成功的 E1 行为**同时**依赖 prefix formation 与 readout（`sol07.md:5,44`；`sol10.md:153`）："Full prefill is required because successful E1 cross-cache behavior depended on both prefix formation and readout. A one-query frozen-state gradient may propose a direction but cannot certify it."
- 反证：QA same-table cached path **丢失了 full-prefill 的 E1 成功**（`NONGEOMETRIC_MECHANISM_TRANSFER_20260910.md:125-127`）。
- 对账：`INTEGRATION_20260910.md` §5 "attention≠generation（cross-cache：BM 读 MrPro 前缀能对，MrPro 读 BM 前缀仍错）"。
- ⇒ 任何**局部/单向**代理（一阶 Taylor、局部 Fisher、固定态重放）只能**预排序**，不能认证。sol07:69 原话："Use complete forward passes for a small grounded set of adjacent-step transfers; conditional replay only pre-orders them."

**(4) 数值层：部署算术会吃掉小步收益，故"理想有限数学"与"部署前向"必须分开测。**
- E7：理想/FP32 都 ~7.93e-8，BF16 是 1.28e-5（**约 161× 平方误差 / 12.7× 幅度**）；`sol07.md:50`。这就是效用里必须有 `−λ_B·BF16Mismatch_a` 项的理由（`sol07.md:67`）。
- sol09 的独立补充：长期 horizon 用局部二次/Fisher 近似会失真（slot 19 的极端 Taylor 误差；有界正弦算子不允许无约束二次增长）——"Use exact finite-path replay/integrated gradients or direct endpoints."（`sol09.md:63`）

**结论**：`sol07` 的算法骨架（`sol07.md:71-77`）之所以是"完整前向 + 接受后重算 + 下置信停止"，不是工程保守，而是 **F 的验收量本身是阈值化的、且扰动跨 prefix/readout 两条通路** 的直接后果。
