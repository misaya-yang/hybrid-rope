## 1. ★ sol15 的"统一陈述"：精确对象与概率证书（完整抄录）

这是任务点名要求逐字抄出的部分。以下公式为标准 LaTeX 照抄，行号对应 `agents/sol15.md`。

### 1.1 每行精确对象 `z_t(ν)` 与角色 margin `M_r(ν)`（sol15:31–39）

设定：query 固定；`S_r` = 角色限定的**有用键**集合，`D_r` = 相关**竞争者**集合；已标注的旋转槽 `j=1,…,K`，频率 `ν_j`，带符号 lag `d_t`，内容系数 `A_{tj},B_{tj}`。

```
z_t(ν) = c_t + Σ_j { A_tj · cos(ν_j d_t) + B_tj · sin(ν_j d_t) }          (1a)

M_r(ν) = log Σ_{t∈S_r} e^{z_t(ν)}  −  log Σ_{t∈D_r} e^{z_t(ν)}            (1b)   [原文标号 (1)]
```

sol15:42 的性质断言（**逐条**）：
- 对**固定行状态**是**精确**的；
- 保留 source 标签、hard-key 竞争、带符号 sin/cos 相位、槽身份、经系数进入的 gain、干扰项计数；
- 单源时 `p(S_r | S_r ∪ D_r) = σ(M_r)`；
- 因此**强于**：无符号碰撞能、first-zero horizon、pairwise SNR、频率多重集。

### 1.2 概率证书（sol15:44–58）

设有用源分数**确定**为 `μ(ν)`，每个干扰项满足联合 MGF 界

```
E e^{D_t(ν)} ≤ e^{ b_t(ν) + v_t(ν)/2 }
```

则对目标源质量 `q ∈ (0,1)`，Markov 不等式给出

```
Pr[ p_* < q ] ≤ min { 1 ,  q/(1−q) · Σ_t  e^{ b_t + v_t/2 − μ } }        (2)
```

证书的**适用范围断言**（sol15:57–58，逐条）：
- **不需要**跨干扰键的独立性；
- 若源本身是随机的，(2) 需要 `E e^{D_t − S}`；**用 `S` 的均值替换是无效的**；
- **等零均值/等方差情形下，正确的标量目标是 `v/2 − μ`**，并带一个**不可避免的 `log |D_r|` 阈值**；
- **pairwise SNR `μ/√v` 可以单独改善而 softmax 源质量恶化**；多个 pairwise SNR 不决定联合检索概率。

### 1.3 EVQ 出现的精确条件（sol15:60–78）

EVQ 的精确碰撞能（(3)）：

```
⟨ρ, Kρ⟩ = E_Δ [ ∫ cos(ω(x)Δ) ρ(x) dx ]²                                  (3)
```

sol15 的**归约条件**（这是"EVQ 何时成立"的精确答案，sol15:70 起）：
1. 它是**相干聚合响应的平方**；
2. 它**只在下述 nuisance 模型下从 (2) 流出**：有用均值被保护且**与分配无关**，且每个干扰项在频率上共享**一个标量载荷**，故其方差 = 平方后的求和余弦响应；
3. **独立同向 sine/cosine 噪声逐通道是旋转不变的 ⇒ 不产生任何频率相关碰撞项**；
4. **独立通道误差给出的是"线性于密度的方差、缩比 1/K"，不是 `α∫ρ²`**。

Cosh 泛函需要的额外协方差近似：

```
C_app = α I + β G ,     G(x,y) = min(x,y)
```

- `αI` 必须代表已解析的**共享频率局部噪声场**或**声明的有限 bin 模型**；
- **对连续白噪声在原子通道频率上做点求值是未定义的，且有限通道极限与白噪声极限不可交换**；
- 常数有用信号下，逆协方差律 `ρ ∝ C^{−1} 1` 给出 Cosh 密度；
- **带频率相关有用信号 `h` 时，active-set 律是 `C w ≥ λ h, w ≥ 0`，占据支撑上取等；不存在普适 Cosh 曲线**。

### 1.4 ★ 四对象分离（sol15:82–88，逐条抄）

必须分开、不可混同的四个对象：

1. **精确连续-lag 碰撞测度最优**——在 Astra02 的假设下是**有限原子**的；
2. **光滑代理密度最优**——在常数信号 + 共享局部+嵌套噪声下是 **Cosh**；
3. **有限 K、等幅表**——其原子质量必须是**整数通道计数**；
4. **冻结带标签表**——槽特异的学习系数使"可交换计数归约"**一般失效**。

sol15:80 强调 Astra02 的精确有限窗口结论**必须与此结论分开保留**，并给出三条边界：
- delta-ridge 代理引入的 anti-concentration 项才制造了光滑密度；
- **原子定理不直接迁移到有限整数-lag Gram**（严格正定性与唯一性都可能失效）；
- **它也不意味着 LM 应该重复使用少数几个频率**。

### 1.5 Astra06 的整数计数分配器（sol15:91–122）

把指数空间分 `B` 个宽 `Δ` 的 bin，bin `i` 放 `n_i ∈ Z_+` 个等幅通道，`Σ_i n_i = K`。

```
C_{ij} = (α/Δ)·1{i=j} + β·min(x_i, x_j) ,     T_i = Σ_{j≥i} n_j
```

有用单位通道均值 `h_i` 下，(2) 的等方差目标**精确地**变成

```
min_n  Σ_i [ (α/(2Δ)) n_i²  +  (βΔ/2) T_i²  −  K h_i n_i ]                (4)
```

后向递推

```
F_i(t) = (βΔ/2) t²  +  min_{0≤n≤t} { (α/(2Δ)) n² − K h_i n + F_{i+1}(t−n) }    (5)
```

以 `O(BK²)` **全局**求解 (4)，回溯产出整数计数。

**声明前提（sol15:122，逐条）**：噪声在 bin 内共享且具**嵌套布朗协方差**；`B` 是**物理相关分辨率，不是任意的候选网格**；允许重复频率；若要求严格互异/最小间距/端点占据/槽特异协方差，**可行问题改变**；冻结有序槽下 DP 只在"协方差依赖 bin/计数、且槽特异均值 `h_{j,i}` 对连续指派可加"的特例下可能；**一般异质跨槽协方差摧毁递推**。

**常数 `h` 时**：实松弛满足离散 Cosh 递推，在 resolved-density 极限收敛到连续 Cosh 律；**有限 K 时整数 DP 才是最优者**。

## 2. ★ 稀释项 `η_r`：sol12 / sol13 的等价式与四家口径

任务点名要求核实这一条。**结论：sol12 与 sol13 写的是同一个量，只差一个记号替换。**

### 2.1 两份原文（照抄）

- **sol12:87–99**：设 `+` 为合法源、`h=1,…,H_r` 为内容混淆干扰项，要求成对 margin `η_r`，则
  ```
  Pr[ ∃h : D_rh(x) ≤ η_r ] ≤ Σ_{h=1}^{H_r} exp[ − (m_rh(x) − η_r)² / (2 s_rh²(x)) ]
  ```
  并称"对目标源注意力质量 `1−a_r`，一个**充分的共同成对要求**是
  ```
  η_r = log [ H_r (1 − a_r) / a_r ]
  ```
- **sol13:52–56**：
  ```
  z_r(x) = ( μ_r^T f_r(x) − ε_r‖f_r(x)‖ − η_r ) / ‖L_r^T f_r(x)‖ ,
  η_r = log [ (M_r − 1)(1 − a_r) / a_r ]
  ```
  文字："`η_r` 是**在所有 `M_r` 个 key 中，源注意力质量至少为 `1−a_r` 的充分成对 margin**"。

### 2.2 等价性（我方代数核验，只为确认两记号不是两个对象）

sol12 的 `H_r` = 干扰项个数；sol13 的 `M_r` = **key 总数**（= 1 个源 + 干扰项），故 `H_r = M_r − 1`。**两式恒等。**

顺带核验 `η_r` 本身的来源（两处都只写"sufficient"，未给推导，此处补齐以便 F 使用）：

softmax 源质量 `p_* = e^{s} / (e^{s} + Σ_h e^{d_h})`，要求 `p_* ≥ 1−a` ⇔ `Σ_h e^{d_h − s} ≤ a/(1−a)`。
若要求**逐项** `d_h − s ≤ −η`（即 `e^{d_h−s} ≤ e^{−η}`），则 `Σ ≤ H e^{−η} ≤ a/(1−a)` ⇔

```
η ≥ log [ H (1−a) / a ]
```

**⇒ sol12/sol13 的 `η_r` 就是"逐干扰项统一 margin ⇒ union bound"这条**充分**路径。**它是充分条件、不是必要条件**（union bound 粗糙），这一点两份原文的用词（"sufficient common pairwise requirement"／"充分成对 margin"）都正确。

### 2.3 四家口径（`INTEGRATION_20260910.md:65` 并列，我方逐条回原文核对）

| 报告 | 写法 | 是否含 `log((1−a)/a)` 项 | 备注 |
|---|---|---|---|

| sol12 | `log[H(1−a_r)/a_r]` | ✅ | `H` = 干扰项数 = `M_r−1`；**与 sol13 恒等** |
| sol19 | `J_r = μ_r²/(2v_r) − log N_r`（`agents/sol19.md:89`）、`min_r J_r ≥ eta_r`（:125） | ❌（只留 `−log N_r`） | 高斯尾形；`N_r` 为干扰计数 |

**⇒ 口径差异（重要，会直接影响 F 的形状）**：
1. **`log(计数)` 稀释项四家共有**——这是本批材料最稳的"结构性事实"：**源质量要求随干扰数对数增长**。它与 sol11 的 `G` 输运式"干扰指数和乘 q ⇒ `G` 恰好掉 `log q`"是同一事实的两种写法（sol11:71）。**⚠ 注意 `INTEGRATION §4.2:65` 称四家"同式"，严格说只同"稀释项"，`log((1−a)/a)` 只在前两家显式出现**——引用时勿把两家约等成四家恒等。
2. **"标量目标"的形状不一致**：sol15 给 **`μ − v/2`（线性惩罚 v）**，sol19 给 **`μ²/(2v) − log N_r`（比值/高斯）**。两者不同源：(a) 是 Markov/MGF 路线（`E e^{D} ≤ e^{b+v/2}`，无需独立性），(b) 是高斯尾路线。**同 v 下两者对候选表的排序可以不同**（`μ−v/2` 线性、`μ²/2v` 对 μ 二次）。sol15 自己明确警告"pairwise SNR `μ/√v` 单独改善而 softmax 源质量恶化"——**若采纳 sol19 的 `J_r` 作为 F 分项，须先处理这条自警**。
3. **不确定性的进入方式也不同**：sol13 从**均值**里减 `ε_r‖f_r(x)‖`；sol14 把 `ε_r²` 加进**方差**（见 §3）。同一"估计/上游输运不确定度"，一家做均值平移、一家做方差膨胀。

## 3. ★ sol14 的盒装优化模板（KKT 直接模板）

### 3.1 冻结分支的 boxed 规则（sol14:22–29，照抄）

严格 pre-RoPE 固定 margin：

```
m_r(ν; u) = Σ_j a_rj(u)·cos(d_r ν_j) + b_rj(u)·sin(d_r ν_j) + c_r(u)
```

`u` 索引内容实例，`r` 标识"一个有用源 vs 一个竞争 key"。令 `μ_r(ν) = E m_r`，`v_r(ν) = Var m_r`。规则：

```
max_{ν ∈ F}  min_{r ∈ R_far}   μ_r(ν) / sqrt( v_r(ν) + ε_r² )

s.t.   μ_q(ν) − γ_q · sqrt( v_q(ν) + ε_q² ) ≥ 0 ,   ∀ q ∈ R_native
```

- `F` 固定：端点/支撑政策、正性、保序、以及任何声明的位移限；

- 定位："**条件化注意力结论，不是生成答案定理**"。

## 4. sol11 的构造："Compatible Competitive Transport"（CCT）

### 4.1 对象与精确公式（sol11:43–71）

有序膨胀场：`ω'_j = ω_j · s^{−m_j}`，`0 ≤ m_j ≤ 1`。
边增量：`p_i = m_i − m_{i−1} ≥ 0`，`Σ_i p_i = 1`。

```
B = Σ_{q=1}^{N−1} m_q = N − Σ_i i · p_i                                        (sol11:52)
G(m, g) = LSE_{r∈R} ℓ_r(m,g) − LSE_{d∈D} ℓ_d(m,g) = logit A_R                  (sol11:66–69)
```

`G` 的性质（sol11:71）：含 softmax 竞争；**在"干扰指数和被整体复制 q 倍"下恰好掉 `log q`**；项目把它记为**条件恒等式而非外推律**（引 `SINGLE_TABLE_ROPE_OPEN_PROBLEMS_HANDOFF_20260904.md:270–300`）。

> **⚠ 措辞风险（红线 R4）**：sol11 把 (52) 式称为 "A conserved log-dilation budget"。`B = Σ_q m_q` 就是 **Σm 型量**。而 `INTEGRATION_20260910.md:30`（R4）明确：**"Σm 质心是自由决策变量"**；`NEXT_DERIVATION_KKT_PROBLEM.md:107` 亦写 **"Σm（质心）不是守恒量，是自由决策变量"**。严格读：真正被端点锁定的守恒式是 `Σ_{j=23}^{39} Δ_j = 1`（跨度锁定）；`B = Σm` 是 `p` 的一阶矩，**随 `p` 的放置而变**，不是不变量。sol11 紧接的一句"total compression and the center of mass of added log gaps are coupled"其实是对的（B 由 p 决定），但**标题里的 "conserved" 必须降级**为"在 Σp=1 固定下的**一阶矩恒等式**"。**引用 sol11 (52) 时不得写成守恒律。**

### 4.2 CCT 的两个程序（sol11:94–128）

- **Scratch / bilevel**（sol11:99）：
  ```
  min_p  R_deploy( W_T(p), p )  +  λ D(p, p_E)
  ```
  其中 `W_T(p)` 是固定训练算法的结果；**hypergradient 含权重响应项；省略它就把问题退化成被 crossing 结果证伪的那个冻结代理**。
- **Frozen 规则**（sol11:120–126）：
  ```
  max_{h,g}   Ĝ_T(h,g) − λ_E‖h − h_E‖² − λ_M‖h‖²
  s.t.        D̂_N(h,g) ≤ ε ,
              0 ≤ m_M + h ≤ 1 ,  p(m_M + h) ≥ 0
  ```
  基 `h` 的三个方向：① 端点匹配的 EVQ−Mr 方向；② FullLagP2−Mr 方向（因为产生了真实 128K Pareto 信号）；③ 常数 gain 坐标（**与频率移动分开**）。正则系数**须在打开任务结果前固定**。输出一张有序表 + 一个 gain，**再由真实 128K 生成端点接受/否决；优化目标不是成功定理**。

### 4.3 sol11 的 7 条前置检查（sol11:146–154，可直接做验收清单）

sign mirror（等范数 `−h` 对照）／combination check（联合评估，不得逐槽求和）／distractor replication（固定证据、加干扰块，实测 `G` 退化应追随指数和比值而非名义长度）／slot permutation（保频率多重集、打乱槽指派，崩溃即确认 checkpoint 耦合）／gain cross（表×gain 四格）／lifecycle cross（scratch 自洽权重、frozen 固定权重）／complete endpoint（严格任务输出 + EOS + native 保持，NLL/注意力诊断次要）。

## 5. sol12 / sol13 的构造函数

### 5.1 sol12 的 SRI 程序（sol12:66–114）

```
ν_j(x) = ω_j e^{−x_j}
D_rh(x) = Σ_j c_{rhj}^T f_{rhj}(x) + b_rh
m_rh(x) = μ_rh^T f_rh(x) + b_rh ,   s_rh²(x) = f_rh(x)^T Σ_rh f_rh(x)
```

概率界：**中心化对比为 sub-Gaussian** 时

```
Pr[ ∃h : D_rh(x) ≤ η_r ] ≤ Σ_{h=1}^{H_r} exp[ −(m_rh(x) − η_r)² / (2 s_rh²(x)) ]
```

**仅有限二阶矩**时用单边 Cantelli 替换指数项。源质量 `1−a_r` 的充分共同要求 `η_r = log[H_r(1−a_r)/a_r]`。

SRI（标号 `(SRI)`）：

```
max_{x ∈ F}  min_{r ∈ R_target, h}  ( m_rh(x) − η_r ) / s_rh(x)

s.t.  ( m_rh(x) − η_r ) / s_rh(x) ≥ z̄_rh    ∀ r ∈ R_protected
```

`F` 只含**架构要求**与**实测矩包络的有效域**。**"局部 trust box 只有在需要控制上游统计漂移或 Taylor 余项时才被证成，它不是'小改动更好'的一般偏好。"**（sol12:114）频率顺序、端点、high/native 块、`/s` 尾**只有在所选算子或保留证据要求时才进 `F`**。

- **Scratch**（sol12:118–124）：通道与权重共适应、有用归一化信号可交换且与分配无关时，最大化 SRI 归约为最小化干扰协方差，取 **EVQ 形 `α∫ρ² + β∫S_ρ(t)²dt`**；**Cosh 只对该近似连续模型成立**；精确有限窗口核下最优是原子的；有限等权通道下还留一个量化问题。
- **Adapter**（sol12:126–128）：`(x, adapter)` 交替或联合优化同一 SRI，**适配后重测 `μ,Σ`** 并保留 native 保护集；"这不是'给我们的臂更多预算然后叫它频率胜利'"；可归因声明是**共适应分配方法**，除非跑了匹配的适配对照。
- **Frozen**（sol12:130–132）：冻结 checkpoint，从合格源依赖操作估 `μ,Σ`（含**实际 hard 干扰、前缀态、GQA 共享、gain、带符号 lag**）；从 MrPro 出发局部解 SRI 并做**有限变动认证**，然后精确评估三角 margin。

### 5.2 sol13 的规则（sol13:30–67）

```
q_j^T R(ν_j d) k_j = A_j cos(ν_j d) + B_j sin(ν_j d)
Z_r(x) = c_r^T f_r(x)
‖E c_r − μ_r‖ ≤ ε_r ,   Cov(c_r) ⪯ L_r L_r^T          （显式估计的输运包络）

z_r(x) = ( μ_r^T f_r(x) − ε_r‖f_r(x)‖ − η_r ) / ‖L_r^T f_r(x)‖
η_r    = log [ (M_r − 1)(1 − a_r) / a_r ]

max_{x ∈ F} min_{r ∈ R_L} z_r(x)
s.t.  z_r(x) ≥ z̄_r ,   r ∈ R_N
```

`F` 保留槽标签、固定端点/声明界；**保序只在它是所选部署面的一部分时才进 `F`**。首个 Qwen 32K→128K 计算推荐的面 = **MrPro 面 + 16 个内部变量**（理由："不是 23/40 普适，而是它是距强基线**最小的完整偏离**"，sol13:65）。

### 5.3 sol14 的 scratch 分支（sol14:9–13）

```
ρ*(x) = [ C^{−1} h(x) ]_+  /  ∫ [ C^{−1} h(y) ]_+ dy
```

positivity 绑定时走 **active-set KKT**（`INTEGRATION §4.2:70` 引 astra10 修正：**不能直接裁剪代替 active-set 求解**）。EVQ-Cosh 只是其"常数信号 + 嵌套慢尾协方差"特例；**是训练期初始化/设计律，训练后的响应律会随分配改变**。
