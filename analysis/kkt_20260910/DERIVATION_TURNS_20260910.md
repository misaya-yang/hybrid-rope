## 0. 一页结论

1. **正确坐标不是槽位 j，是"窗口内圈数" r_j = W ω_j / 2π。** 部署给每个通道一个
   压缩 m_j ∈ [0,1]，于是该通道的圈数被分拆成
   **r_j = q_j + e_j**，其中 q_j = r_j S^{−m_j} 是"部署后窗口内圈数"，e_j = r_j − q_j 是"让出的圈数"。
   这是一个**恒等式**（每通道），不是守恒律。`[已验证]`

2. **三段结构在两个不同模型上、零自由参数地对齐**：以 m=0 结尾（bank）与以 m=1 开头（tail）
   的分界，恰好落在 **r_j = 32** 与 **r_j = 1**。Qwen2.5-3B 得到桥 = 槽 [24,39]；
   Llama3-8B 得到桥 = 槽 [19,34]。**两者桥宽都是 16 槽**，且
   **N = K·ln(R_hi/R_lo)/ln θ**（Qwen 16.05，Llama3 16.90）解释了 MrRoPE 的 N=17 从何而来。`[已验证]`

3. **目标函数在 m 上可分（separable）**：F = Σ_j f_j(m_j)，没有跨槽耦合。
   因此 **Σ_j Δ_j = m_h − m_l = 1 是端点导致的恒等式，不是约束**；
   "预算/水床"语言的正确坐标是**总对数频率跨度**（被端点锁死），
   而**桥内的分配不存在预算约束**——桥的形状由逐通道一阶条件逐点决定。
   全局自由度只有两个：**桥的两端位置 l、h**。`[已验证-代数]` 这也正是红线 R4 要求的"先点名坐标"。

4. **近端代价可导出**：窗口内相位误差的 L² 范数给出 **C(e) = e²/3**（单位：圈）。
   这与 F3 的局部分辨子 Σ(ν−ω)² 同源（后者是 d→0 极限），但它是**动态算子量而非静态几何代理**，
   不触红线 R2。`[已验证-推导]` **关键**：我特意检查了"对窗口内所有 lag 取精确 2(1−cos) 平均"的版本，
   它回到振荡（sinc 零点）——那正是红线 R1 禁入 F 的根理论量，**故弃用**。

5. **一阶条件 C′(e_j) = Ψ(q_j)**，其中 Ψ 是远端边际收益。从 MrPro 表反演出的 Ψ(ρ)
   （ρ = S·q = 目标长度上的圈数）是**单峰**的：峰值在 **ρ ≈ 19**，值 1.20；
   两侧为 ρ^{0.4} 上升、ρ^{−2.8} 衰减。`[已验证-反演]`
   注意这只辨识出 **组合** C′(e)=Ψ(q)；单独一张最优表**不能**分离 C 与 Ψ。

6. **bank 与 tail 不是普通角点解，而是两个"精确结构点"**：`[已验证-数值]`
   - bank（m=0）：R(dν) = R(dω) **恒等** ⟹ 原生局部计算逐字复用；
   - tail（m=1）：R(dν) = R((d/S)ω) **恒等** ⟹ 原生计算在 1/S 尺度上逐字复用。
   桥内两者都不精确。这与 SUBSPACE_DERIVATION 的 Selective-PI 恒等式一致，是 tail 取 m=1 的
   结构性理由（而不是边际计算的结果）。

7. **未导出的一项**：**R_hi = 32 我没有推出**。它是 YaRN 的 β_fast 默认（"32 圈"），
   被 MrRoPE 继承；两套模型的表只是与它一致，不构成独立验证。这是目前最尖锐的开放子问题，
   §7 给出判决实验。

## 1. 坐标：把 RoPE 表看成"时钟圈数"

native 表 ω_j = θ^{−j/K}（0-based，j = 0..K−1）。定义**窗口内圈数**

    r_j := W ω_j / (2π)          （该时钟在 native 窗 W 内转过的整圈数）

部署 ν_j = ω_j S^{−m_j}，m_j ∈ [0,1]，于是

    q_j := W ν_j / (2π) = r_j S^{−m_j}     "保留的窗口内圈数"
    e_j := r_j − q_j                        "让出的圈数"
    ρ_j := L ν_j / (2π) = S q_j             "该时钟在目标长度 L 上的圈数"

`r_j = q_j + e_j` 恒成立。**"搬运"的精确含义**：压缩把圈数从窗口内搬到目标长度上；
搬走 e_j 圈，目标长度上就得到 (S−1)q_j 圈的相位跨度。

Qwen2.5-3B（W=32768, θ=10⁶, K=64）：r 从 5215 降到 0.0065。
Llama3-8B（W=8192, θ=5×10⁵, K=64）：同类量级。

**这不是静态几何代理。** r_j 是 native 表自身在**该模型的训练窗口**上的圈数，是"这个时钟在本模型里到底在做什么"的坐标；
选择子仍是代价/收益的比较（§4–5），r 只负责定位。这是我对自己触红线 R2 风险的显式声明，见 §8。

## 3. 可分性：预算是什么、不是什么（回应红线 R4）

设 F = Σ_j f_j(m_j)，f_j(m) = C(r_j(1−S^{−m})) − μ B(r_j S^{1−m})。
m_j ∈ [0,1] 逐槽独立，唯二的耦合是 (a) 单调性 m_j 非降、(b) 桥两端 l、h 的选择。

于是：

- **Σ_{j∈桥} Δ_j = m_h − m_l = 1 是端点恒等式**，在任意 (l,h) 下都成立。它**不是**约束，
  因此**不能**从中读出任何"水床/守恒"结论。
- 真正的守恒量是**总对数频率跨度** Σ_j a_j = ln(ν_0/ν_{K−1}) = (63/64)lnθ + ln S，**被两个端点锁死**。
  桥内 17 个增量分摊其中新增的 ln S = 1.3863 nats。
- **桥内没有预算约束**：把预算从槽 i 挪到槽 j 不需要"从别处扣"，因为每个槽的最优 m 只由自己的 r_j 决定。
  桥的形状由一阶条件逐点给出，**不是**分配律。

这解释了为什么"分配规律"这一路（搬运/水床）始终无法闭合：**它在错误的坐标上找约束**。
真正的全局决策只有 l 和 h 两个整数。

在用户的"log-frequency 间隔预算"坐标下：

    a_j = ln(ν_j/ν_{j+1}) = ln θ/K + Δ_j ln S,   native 间隔 ln θ/K = 0.215867 nats

各方法就是同一张预算的不同摆法（`[已验证]`，桥内增量 Δ_q，q=1..17）：

| 方法 | Δ 的首/末 | 比值 | 形状 |
|---|---:|---:|---|
| MrUni | 0.05882 / 0.05882 | 1.00 | **常数**（线性 m） |
| MrPro | 0.00654 / 0.11111 | 17.00 = N | **等差**（二次 m） |
| YaRN | 0.03255 / 0.11723 | 3.60 | 对数式增长（更陡，前段过冲） |
| PI | Δ=1 于全部 K−1 个间隔 | — | 无桥（全表 ÷S） |
| NTK | Δ = 1/(K−1) 于全表 | — | 全谱均匀 |
| EVQ-Cosh | Δ_j 由 Cosh 密度的分位数给出 | — | 密度型 |

**统一命题**：所有方法都是"桥内 Δ 分布"的一个特例；最优性问题是逐点一阶条件，不是分布律。

### 3.1 可分性的适用层级（**后续修正，必须与 §3 同读**）

§3 的 F = Σ_j f_j(m_j) 有明确前提，不是普遍成立的。设旋转算子 R_ν(d) 为 2×2 块的块对角阵：

- **等权/各向同性载波下，可分性成立。** 若 q、k 协方差为单位阵，则
  E[(qᵀ(R_ν−R_ω)k)²] = ‖R_ν−R_ω‖²_F = 2Σ_j (1 − cos(d δ_j))，
  Frobenius 范数按 2×2 块分解 ⇒ **逐槽求和，无交叉项**。§4 的 C(e)=e²/3 就是这个载波下的结果。
- **训练后的 Q/K 权重下，可分性失效。** 实际 q、k 各向异性且跨通道相关，
  E[(qᵀAk)²] = tr(A Σ_k Aᵀ Σ_q) 按块**不分解**。仓库自己的 `scripts/analysis/rope_qk_operator_gram.py`
  正是这个量（A_j = q₀ⱼᵀk₀ⱼ + q₁ⱼᵀk₁ⱼ，B_j = q₁ⱼᵀk₀ⱼ − q₀ⱼᵀk₁ⱼ），
  `ROPE_ALLOCATION_SUBSPACE_DERIVATION_20260910.md` 的耦合项 ½‖[M,P]‖²_F = Σ_{i<j}‖P_ij‖²_F(m_i−m_j)²
  就是交叉项的显式表达。

**因此，§5 的一阶条件 C′(e_j) = Ψ(ρ_j) 是"对角部分"的条件**，前提是交叉项可忽略或已被吸收。
把它当成完整的 KKT 解是越界。

一条被判死的补丁：把等权相位权重换成 Q/K 投影矩阵范数**并没有**闭合解释缺口——
`ROPE_ALLOCATION_SUBSPACE_DERIVATION_20260910.md` 记录 Smooth 在该加权代价与 U 上**同时**优于 MrPro（36 层全部），
而其 128K 分数更差（87.2/68.3 vs MrPro 87.22/78.13）。**所以"换成正确的二次型权重"这条路已被实验否掉，
不是尚待尝试的方向。**

R1 digest §10.6 提出的判决性反例是 `E1_pair28_29`（槽 28 与 29 同时手术 → 收益不可加）。
但该反例的三点（s28_less +5.21pp、s29_more −0.21pp、pair 合成 −4.17pp）**全部是 1–2 行翻转**（见 §10），
在本面板的噪声内，**不足以判定可分性失效**。可分性的失效目前只有算子级论证（上面的交叉项），没有面板证据。

## 4. 近端代价 C(e)：从窗口内相位误差导出

窗口内 lag d 处，该通道相位从 dων 变到 dν_j，误差 d·δ_j，δ_j = ω_j(1−S^{−m_j})。
在圈单位下 e_j = Wδ_j/(2π)，即"窗口内累计误差圈数"。

对 d 取 **L² 范数**（而不是逐 lag 的 2(1−cos) 再平均）：

    C(e_j) = (1/W)∫_0^W (d δ_j / 2π)² dd = (1/3)(Wδ_j/2π)² = e_j² / 3

**故 C(e) = e²/3。** `[已验证-推导]`

**两条必须记录的检查**：

- `[已验证-排除]` 若改用精确平均 (1/W)∫2(1−cos(dδ))dd = 2(1 − sinc(2πe))，函数**振荡**且非单调
  （在 e≈1.8 处导数为负）。这**正是红线 R1 禁入 F 的根/零点结构**。故弃用精确平均版。
  **这说明"R1 禁根"与"用 L² 而非逐 lag 均值"是同一件事的两个说法**——这是本稿对红线的一处正面解释。
- C 与 F3 的 Σ(ν−ω)² 关系：Σ_j(ν_j−ω_j)² 是 d→0 极限，本式是窗口内积分。
  两者形式同源（都是 (δ)² 型），但本式带 r_j 权重（e_j = r_j(1−S^{−m_j})），
  所以**自动具有"高频槽要让出很多圈才等价于低频槽让出很少圈"的性质**。

这个权重是**关键**：纯 Σω_j²(1−S^{−m})²（F3 未加权形式）在 Qwen 上给出
ω_24²/ω_39² ≈ 650 倍的成本比，会把压缩全部推到尾部——与 E2_tail_more（100/54.72）、
HighGapToLong（70.1/67.4）的结果**直接冲突**。`[已验证-读表]` 故 F3 载体**不能**单独成 F，
这与 STARTING_POINT §8.1 的 F6 警告一致，而 C(e)=e²/3 给出了原因。

## 5. 一阶条件与远端边际收益 Ψ 的反演

最小化 f_j(m) = C(r_j(1−S^{−m})) − μ B(r_j S^{1−m})。内部解满足

    d/dm:   C′(e_j) · r_j lnS S^{−m} = μ S B′(ρ_j) · (−r_j lnS S^{−m})
    ⟹      C′(e_j) = −μ S B′(ρ_j)  ≡  Ψ(ρ_j)

**r_j 完全约掉了。** 条件只联系 (e_j, ρ_j)，两个量通过 e+q=r 绑定。`[已验证-代数]`

从 MrPro 表反演（取 C(e)=e²/3）：

|---:|---:|---:|
| 1.343 | 0.5435 | — |
| 1.926 | 0.6311 | +0.405 |
| 3.857 | 0.8233 | +0.355 |
| 7.449 | 1.0162 | +0.275 |
| **18.682** | **1.2008** | **+0.051** |

**Ψ 单峰，峰在 ρ ≈ 19，值 1.20；小 ρ 侧 ∝ ρ^{0.4}，大 ρ 侧 ∝ ρ^{−2.8}。** `[已验证-反演]`

读法：**远端能力不是"越慢越好"**。Ψ(ρ) 是"让该时钟再慢一点的边际收益"，
它在 ρ≈19 最大——即该时钟在目标长度上转约 19 圈时，再减速的收益最大；
到 ρ≈116 收益只剩 15%，到 ρ≳130 基本消失。

### 5.1 辨识性：单表只能给出组合（正式回答 K2 的一半）

一张最优表只给出 **C′(e_j) = Ψ(q_j)** 这一个关系在 16 个 ρ 上的采样。
**无法分离 C 与 Ψ。** 本稿用的是**独立导出的 C(e)=e²/3**（§4），才使 Ψ 可读。
若 C 改为 e²/2，Ψ 整体乘 1.5；若 C 改为 e^p/p，Ψ 被重新参数化。
**所以 §5 的表是"在 §4 的代价模型下"的条件结论，不是无模型的观测。** 
分离 C 与 Ψ 需要：同 q 匹配下比较两张不同 μ 的表（比值应为常数），或独立导出 B。`[未导出]`

## 6. 两个精确结构点：bank 与 tail 为什么是 m=0 / m=1

`[已验证-数值]`

    bank（m=0）: max_d |R(dν) − R(dω)|      = 0.000          （恒等）
                 max_d |R(dν) − R(dω/S)|    = 0.988
    tail（m=1）: max_d |R(dν) − R((d/S)ω)|  = 0.000e+00      （恒等）
                 max_d |R(dν) − R(dω)|      = 1.278

**m=0 与 m=1 是设计空间里仅有的两个"精确"点**：前者使原生局部计算逐字复用，
后者使原生计算在 1/S 尺度上逐字复用（Selective-PI 恒等式：慢块精确 ÷S 时新增未解析响应为 0）。
m ∈ (0,1) 的任意值都**不**对应任何精确的复用关系——它把该时钟变成一个既非原生、也非缩放原生的新时钟。

这条给出了 tail 边界 r ≤ 1 的一个结构性理由：
**能成为 [0,L] 上无别名里程计的通道，恰好是 r_j ≤ 1**（因为 m ≤ 1，需要 r_j S^{1−m} ≤ 1 有解 ⟺ r_j ≤ 1）。
r_j ≤ 1 的通道被整体设到 m=1，慢块成为原生的精确相似变换，一套计算服务两个尺度。`[推导]`

**但 bank 上界 r=32 没有对应的导出。** 它只能由"远端收益在 ρ≳130 处消失"（§5 的 Ψ 衰减）
加上 y 轴截断给出，而 Ψ 的衰减本身就是从 MrPro 反演来的——**循环**。这是本稿最大的未闭合处。

## 7. 未导出项与判决实验（K1 的剩余部分）

### 7.1 R_hi = 32

三个候选解释，都可判：

| 候选 | 内容 | 判决方式 |
|---|---|---|
| (a) 经验常数 | 继承 YaRN β_fast=32，无更深的理由 | 在**没有**继承 YaRN 约定的模型上测桥上界 |

| (c) R_hi = K/2 | 与通道数绑定；d_head=128→K=64→32 | 用 d_head=64（K=32）的模型，预测上界落到 r=16 |

**判决实验（CPU 可算，GPU 一次即可）**：取 Qwen2.5-3B，构造桥上界 r ∈ {16, 24, 32, 48, 64}
的五张表（桥下界固定 r=1，形状用 MrPro 二次式），只测 128K。
- 若 (a)：分数在 32 附近无峰、平坦；
- 若 (b)/(c)：32 处有峰，且峰位随 S 或 K 移动。

## 10. 面板经验基础审计（**对 K2 的否决性修正**）

本节独立复核 R1 digest（`mine/R1_panel_data.md`）并给出与 R1 一致、但由本稿单独复算确认的结论。
**它改变的不是某个数字，而是"这些数字能支撑什么"。**

### 10.1 面板的真实分辨率

`worker.py:177` 用 `row_id.endswith('_0')` 定义 `panel='small'`；`ruler_bench.summarize`
给出 `macro_accuracy = 六任务准确率的等权平均`。直读唯一幸存的逐行原始数据
`results/bm_transfer_20260908/run_qwen3_01/{MrPro,MrProBM}.jsonl` 得：

| cap | 行数 | 任务数 | 每任务行数 | **1 行翻转 = 宏平均移动** |
|---|---:|---:|---:|---:|
| 32768 | 12 | 6 | **2** | **8.33 pp** |
| 131072 | 24 | 6 | **4** | **4.17 pp** |

"36 行"= 12 + 24（两个长度合计），**不是每个长度 36 行**。
`correct` 是分数（取值 {0, 0.2, 0.667, 0.75, 0.8, 1.0}），单行本身又是若干 probe 的均值。
**所以 32K 的宏平均是 6 个"2 行均值"的平均。**

### 10.2 唯一干净的配对对照及其区间

MrPro vs MrProBM（同一 gain 1.1386294、同一 prompt 集、行 id 逐一相同），
用仓库自己的 `paired_summary.py` 分层配对 bootstrap（seed=20260910, draws=10000）：

| cap | Δ 宏平均 | paired-stratified CI95 | 由几行驱动 |
|---|---:|---|---|
| 32768 | **+4.44 pp** | [0.00, +8.89] | fwe 1 行 + vt 1 行 |
| 131072 | **−7.29 pp** | [−21.67, +5.56] | multikey_2 1 行 + qa_1 1 行 − multiquery 1 行 |

**128K 的区间含 0。** 支撑"BM 在长端是净负资产"（R1 §8）的全部证据是 3 行。
32K 的区间勉强不含 0，且只有 2 行。**这不是"效应小"，是"没有分辨率"。**

Smooth_MrBudget（87.2/68.3 vs MrPro 87.22/78.13）、E1_s28_less（+5.21pp = 2 行）、

### 10.3 12 行子面板不可与 36 行混排（复现 R1 旗标 F1 并补上假落差的量）

12 行基线（MrPro 表）实测 **100.0 / 64.4444**，36 行基线 **87.2222 / 78.1250**。
E2_tail_more（100.0/54.7222）与 E8_zero51（100.0/50.5556）只有 12 行：

- **错误读法**（本稿早前版本、以及任何把两者放进 36 行表的写法）：
  54.7222 vs 78.125 = **−23.40pp**。**这是凭空造出的落差，量级翻倍还多。**

且 12 行子集在 32K 上**全员满分 100.0** ⇒ 该维度无区分度，12 行点只贡献 128K 一维。

### 10.4 被漏掉的一整个自由度：gain（**对目标函数本身的修正**）

gain 的实现是旋转后 Q 与 K **同时**乘 g ⇒ 固定状态下 logits ×g²；
**它不改频率、不改角跨度**（`PARALLEL_NONGEOMETRIC_20X10_AUDIT_20260910.md:44`）。
因此 gain 是**与频率分配正交的独立变量**——而面板里存在它的两个析因：

| 表 | gain | 32K | 128K | 行数 |
|---|---:|---:|---:|---:|
| BM | 1.0000 | 89.5833 | 58.8194 | 36 |
| BM | 1.1026 (=1+0.074·ln4) | **100.0000** | 70.0000 | 36 |
| BM | 1.1386 (=1+0.1·ln4) | 91.6667 | 70.8333 | 36 |
| MrPro | 1.1026 | **98.3333** | 75.3472 | 36 |
| MrPro | 1.1386 | 87.2222 | 78.1250 | 36 |

两张**独立**母表给出一致结构：

- **32K 对 gain 有内部最优**，两者都落在 g≈1.10（BM: 89.58→**100.00**→91.67；MrPro: 98.33 vs 87.22）。
- **128K 在 [1.0, 1.14] 上随 gain 单调上升**（BM: 58.82→70.00→70.83；MrPro: 75.35→78.13）。

**后果（这是本节最重要的一条）**：
在 36 行同一面板上，**动 gain 带给 32K 的幅度（+10.4pp 或 +11.1pp）大于任何一张表的改动**。
所以 `L_near` 与 `L_far` **不是频率表的函数**，而是 (表, gain) 的函数。
**KKT 问题必须写成 min over (m, g)，而不是 min over m。** 本稿 §5 的一阶条件只覆盖 m 方向；
g 方向的驻点条件尚未写出，且 g 不是逐槽量而是全局标量。

顺带否掉一个自然猜想：**gain 不能由"窗口内旋转方差守恒"导出。**
令 v_j = 1 − sinc²(π q_j)（该通道窗口内 2D 旋转方差），V = Σ_j v_j，
则原生 V_ω = 44.3881，所有压缩表的 V/V_ω ∈ [0.856, 0.909]，
匹配式 g* = (V_ω/V)^{1/4} 只给出 **1.032–1.040**，与观测最优 ≈1.10 相差甚远。
（且 V 跨表几乎不变 ⇒ 它也不可能当选择子，与红线 R2 一致。）
仓库现存的两条 gain 律 —— `1+0.1·ln4`（官方）与 `1+0.074·ln4`（p2）——
其系数 0.1 与 0.074 本身就是被调过的拟合量：**面板说 32K 偏好 ≈0.074，YaRN 官方值 0.1 偏在远端一侧。**

### 10.5 对 K1–K6 任务的直接后果

- **K2（14 点场拟合 + LOOCV）应当判"不可辨识"，且理由不是场的形式，是测量分辨率。**
  自变量 `(Δ_j, gain)` 侧可精确逐位复算（表是静态的），
  因变量侧 32K 只有 12 行、128K 只有 24 行，单行权重 8.33/4.17pp。
  在 1–3 行的效应上做 14 点拟合，得到的是噪声的主成分。
