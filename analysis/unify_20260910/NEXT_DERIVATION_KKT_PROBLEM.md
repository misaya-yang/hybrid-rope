## 0. 目标（用户修正后的原话结构）

> 在有限的 RoPE 频率通道和频谱预算下，怎样把频率最优地搬运、分配到不同距离尺度，得到比 MrRoPE 更好的长上下文分配规则，并用同一套数学原理统一**所有**频率分配方法——EVQ 与 MrRoPE 是两个例子，YaRN 也是。
>
> 或者说：**我们根本不是搬运。** 业界最强的是**分段**：高频不动、中频过渡、低频 ÷S，这是主流办法。"搬运"是我们的理论视角，它出现水床不等式。那么就很简单：**RoPE 这个非均匀离散傅里叶变换，是否有最优解？这也是一个 KKT 问题：高频（native、近距离）损失最小，低频获得最强能力。**
>
> 具体要回答：高频的冗余在哪里；中频为什么关键；低频需要多少资源；资源究竟从哪里搬到哪里、搬多少。交付 = **推导出的分配规律 + 具体频率表 + 实际效果**。

两个论断的合并读法：分段规则与守恒搬运是同一事物的两面——**分段是 KKT 解的结构形式，水床是它的约束形式**。统一数学 = 一个带端点约束的采样密度优化问题；EVQ / YaRN / NTK / MrRoPE-Uni/Pro / 我们的候选 = 该问题的近似解/可行点/错误方向外推点。

## 1. 问题的精确形式化

### 1.1 对象：非均匀傅里叶采样表的部署重排

RoPE 把位置 p 映到 64 通道复指数 {ν_j p}，Qwen2.5-3B：ν_j = ω_j = b^{−j/64}，b=10⁶，原生表是 log 频率轴上的等距采样（间隔 c/64，c=ln b）。零训练扩展 = 保持通道数不变、在"训练只见过 [0,W) 弧"的条件下重排这 64 个采样点。

部署表坐标（全项目已统一，勿再换元）：

- ν_j = ω_j · S^{−m_j}，m 单调非降，m∈[0,1] 由端点不变量强制（见 1.3）；
- λ 坐标（MrRoPE）：λ_j = S^{Δ_j}，Δ_j = m_{j+1} − m_j，∏λ = S；
- 增量单纯形：Δ = (Δ_23,…,Δ_39) ∈ R¹⁷，Δ_j ≥ 0，ΣΔ_j = 1（见 1.3 守恒）。

[已验证] λ↔m↔Δ 三坐标互换恒等，含 MrPro ε_j=2(1+j−dl)/((1+n)n) ⇔ m_q=q(q+1)/(n(n+1)) 的复算吻合（digest_mrrope-evq §3.1/§5，面板存盘数组反算一致：MrPro m24=.0065…m39=.8889，E1_s28 m28=.0654，P2 m36–39=1，E2 m40=1.1557）。

### 1.2 决策对象 = NUDFT 的采样密度

以密度语言：h(u) = 1/ρ(u) 为 log-频率轴上相邻采样的间隔轮廓，u = j/64。水床不等式（EVQ tex 原形 ∫ln E ≥ ln b − ln c，取等 iff 均匀）在路径形下就是 ΣΔ=1：**任何窄化一处间隔必以拓宽他处为偿**。所以"频谱预算"不是修辞，是恒等式。[已验证=数学]

用户问题的严格转写：

> 给定 64 通道、端点带 [0,23]/[40,63] 锁定（1.3）、总间隙预算 ln S，log-频率采样密度 h(·) 的中间 17 段应取何形状，使"近处已学计算损伤 + 远处能力缺口"之和最小？

### 1.3 约束：端点锁定与守恒
