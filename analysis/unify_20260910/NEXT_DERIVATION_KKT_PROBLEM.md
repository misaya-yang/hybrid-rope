## 0. 目标（用户修正后的原话结构）

> 在有限的 RoPE 频率通道和频谱预算下，怎样把频率最优地搬运、分配到不同距离尺度，得到比 MrRoPE 更好的长上下文分配规则，并用同一套数学原理统一**所有**频率分配方法——EVQ 与 MrRoPE 是两个例子，YaRN 也是。
>
> 或者说：**我们根本不是搬运。** 业界最强的是**分段**：高频不动、中频过渡、低频 ÷S，这是主流办法。"搬运"是我们的理论视角，它出现水床不等式。那么就很简单：**RoPE 这个非均匀离散傅里叶变换，是否有最优解？这也是一个 KKT 问题：高频（native、近距离）损失最小，低频获得最强能力。**
>
> 具体要回答：高频的冗余在哪里；中频为什么关键；低频需要多少资源；资源究竟从哪里搬到哪里、搬多少。交付 = **推导出的分配规律 + 具体频率表 + 实际效果**。

两个论断的合并读法：分段规则与守恒搬运是同一事物的两面——**分段是 KKT 解的结构形式，水床是它的约束形式**。统一数学 = 一个带端点约束的采样密度优化问题；EVQ / YaRN / NTK / MrRoPE-Uni/Pro / 我们的候选 = 该问题的近似解/可行点/错误方向外推点。

## 1. 问题的精确形式化

### 1.1 对象：非均匀傅里叶采样表的部署重排

RoPE 把位置 p 映到 64 通道复指数 {ν_j p}，Qwen2.5-3B：ν_j = ω_j = b^{−j/64}，b=10⁶，原生表是 log 频率轴上的等距采样（间隔 c/64，c=ln b）。零训练扩展 = 保持通道数不变、在"训练只见过 [0,W) 弧"的条件下重排这 64 个采样点。

部署表坐标（全项目已统一，勿再换元）：

- ν_j = ω_j · S^{−m_j}，m 单调非降，m∈[0,1] 由端点不变量强制（见 1.3）；
- λ 坐标（MrRoPE）：λ_j = S^{Δ_j}，Δ_j = m_{j+1} − m_j，∏λ = S；
- 增量单纯形：Δ = (Δ_23,…,Δ_39) ∈ R¹⁷，Δ_j ≥ 0，ΣΔ_j = 1（见 1.3 守恒）。

[已验证] λ↔m↔Δ 三坐标互换恒等，含 MrPro ε_j=2(1+j−dl)/((1+n)n) ⇔ m_q=q(q+1)/(n(n+1)) 的复算吻合（digest_mrrope-evq §3.1/§5，面板存盘数组反算一致：MrPro m24=.0065…m39=.8889，E1_s28 m28=.0654，P2 m36–39=1，E2 m40=1.1557）。

### 1.2 决策对象 = NUDFT 的采样密度

以密度语言：h(u) = 1/ρ(u) 为 log-频率轴上相邻采样的间隔轮廓，u = j/64。水床不等式（EVQ tex 原形 ∫ln E ≥ ln b − ln c，取等 iff 均匀）在路径形下就是 ΣΔ=1：**任何窄化一处间隔必以拓宽他处为偿**。所以"频谱预算"不是修辞，是恒等式。[已验证=数学]

用户问题的严格转写：

> 给定 64 通道、端点带 [0,23]/[40,63] 锁定（1.3）、总间隙预算 ln S，log-频率采样密度 h(·) 的中间 17 段应取何形状，使"近处已学计算损伤 + 远处能力缺口"之和最小？

### 1.3 约束：端点锁定与守恒

- **I1**：m_j = 0，j ≤ 23（高频恒等）。证据：HighGapToLong（槽0–23反向放大）32K −17.1 / 128K −10.8、36 行 0 提升；E8 单槽置零 → 128K 50.6；MrUni 带内左倾（m28=.294）→ 32K 64.6。[已验证=面板] 强度口径按 6Pro 修正：**强基线设计约束，非零容忍定理**——少数违例证明代价高，不排除某个小位移自由度的存在（s28_less 恰暗示槽 28 附近有 ~0.033 的可回收量，见 2.2）。
- **I2**：m_j = 1，j ≥ 40（尾部精确 ÷S 平台）。证据：E2 推深至 ÷4.93 → 128K 崩至 54.7。[已验证=面板，12 行面板口径]
- **守恒**：m_40 − m_23 = 1 ⇒ Σ_{j=23}^{39} Δ_j = 1。注意正确表述是 **17 个过渡 gap 的总跨度锁定为 ln S**（原生 3.6697 + 额外 1.3863 = 5.0560 nats），不是"17 个 gap 之和等于 ln S"——两种口径不可混用（6Pro 澄清）。可行域 = 16 维单纯形（最后一个 Δ 由等式消去）。[已验证]

### 1.4 目标泛函（用户两项的具体化）

F[Δ] = L_near[m(Δ)] + L_far[m(Δ)]，其中 m(Δ) = 累计和（Δ→m 是线性双射，问题无需双坐标）。

- **L_near = 近处/已学计算损伤**。机制内容（部分证据）：bank 槽（原生窗内缠绕数 r_j ≳ 8–10）承载整数对齐的锐利局部判别，位移的边际代价 ∂L_near/∂m_j 巨大；arc 槽窗内只受轻微弧压缩，边际代价小。外部佐证：Decoupling 论文（20805）的因果干预——位置型头行为需大频率访问、符号型依赖低频率，p≤1e−4（训练态证据，非冻结外推证据）。[部分证据]
  已知锚点（拟合 L_near 梯度的面板数据）：m28 .098→.065 得 32K 平/128K +5.2（纯增益）；.098→.294（MrUni 形）得 32K −22.6；pair 在 gap28/29 叠加（洞 1.46×）→ 128K −4.1；Smooth 末 gap 削到 .042 → 128K −9.8。
- **L_far = 远处能力缺口**。机制内容：D_j = W·S^{m_j} 为时钟 j 的地平线；r_j>1 的槽超 D_j 后圆周已覆盖（6Pro 修正，"未见弧"只对 r<1 成立），故 L_far 不能按单槽弧语言定义，须按**联合谱覆盖/风险带**定义——这是下一次推导要闭合的核心建模步骤（Q9：兼容成本的可计算形式未完成）。已知锚点：MrPro m36–39 = .51/.63/.73/.89（欠完成）对应 128K 78.1，其方法特异失败行 mk_2@89K、vt_0@106K 落在地平线带 75–112K；LBS 完成 .625/.729/.847/.980 → 80.1（修 106K VT，但 32K −6.6）；P2 m36–39 全=1 → 81.7（但 32K −14.3）。[已验证=面板；行级因果=描述性，holdout 未回]

KKT 结构预言（待证明，不预设结论成立）：若 F 在单纯形上可微凸，则存在 μ 使所有内点 Δ_j 满足 ∂F/∂Δ_j = μ，边界段由符号条件钉死——

> **最优解形态自动是三段：Δ_j=0 的 bank 平台（∂F/∂Δ_j(0) > μ）、Δ_j>0 的过渡桥（边际率相等 = 水填充）、Δ 之后 m=1 的尾部平台（能力饱和）。**

即：**业界主流的分段规则 = KKT 解的结构形式**；MrRoPE-Pro 的线性 ε 阶梯、YaRN 的回归阶梯、P2 的巨洞极端点都是这个单纯形上的特殊点；我们的领先不是换机制，而是解这个 KKT 系统时把 ∂F 的异质性（r_j、距离带）放对了位置。该预言的可证伪版本：若面板回归给出的 ∂F 场在单纯形上的极小点 ≠ 已测赢家的 (j_b, j*) 坐标邻域，则目标建模错误，回炉。

## 2. 四个子问题 → KKT 语言的转写与当前已知

### 2.1 高频的冗余在哪里

冻结模型上：bank 的"冗余"不是可压密度，而是**已学锐利滤波的位移禁區**；EVQ 的冗余主张只在可重学极限成立（HighGapToLong 字面移植 = 全负；P2 实际只从高频取 0.0008，比 HighGapToLong 少 280 倍——它的预算来自桥的渐进性本身）。残余的真问题：槽 24–28（bank 边缘/arc 交界）的边际代价有限，s28_less 的 +5.2 说明那里存在一个可回收的零-近距离代价自由度。[部分证据]
KKT 转写：问的是 ∂L_near/∂m_j 在 j=24–28 的实际曲线——D1 代理正在量化。

### 2.2 中频为什么关键

中频（槽 24–39）是可行域中唯一的自由度（端点锁定后 16 维单纯形全在其中）；同时其 r_j∈[1.15,2.2] 恰是"完成与否决定 128K 安全、放置与否决定 32K 洞比率"的双敏感带。MrPro 的全部方法特异失败都在此带欠完成。[已验证=表结构；"双敏感"=待 D2 的覆盖矩阵复算确认]

### 2.3 低频需要多少资源

尾部（槽 40–63）在守恒式上**零预算**（Δ 只在 17 个过渡 gap 上分配；m=1 平台不耗额外预算——它是恒等重参数化：块内成对旋转=原生 1/S 处成对旋转，[已验证=恒等式]）。低频"需要"的是资格不是数量：全部 24 槽完成到 m=1、且不得推过（E2）。资源问题的答案雏形："低频要的钱 = 0，要的东西 = 24 个时钟全部落地 m=1 + 不多不少"。D3 正在把它定理化（含 c≠1 偏差→失真的定量式）。

### 2.4 从哪搬到哪、搬多少

守恒下"搬运"是恒等式改写：预算 = ln S = 1.3863 nats 的 gap 总质量（或等价 1 单位 m 行程），来源=桥的放置形状本身（不是高频密度），去向=危险区右段的完成（m_36–39→1）与 bank 边缘卸载（m_28 回原生）两个可分离方向——注意 6Pro 已推翻"所有赢家同向"的强表述（质心 Σm：P2 34.18 > MrPro 29.33，P2 是右移还是左移取决于坐标），故正确表述是：**赢家都在减少 bank 边缘累计压缩、和/或完成危险区右段**。搬多少 = KKT 内点条件的解 μ 决定，D4/T1 在算。

## 5. 否决约束（F 的建模红线，来自失败谱系 + 6Pro）

1. 任何静态几何/代理量（根、碰撞核、effrank、Gram、曲率、平滑度）不得作为 F 的分项或选择器——只可作窗口内诊断。（D10/审计判决 3/双反例：Smooth 的 U 优于 MrPro 而 128K 68.3）
2. "所有赢家同向移预算"不得复活；方向表述只用弱版（bank 边缘卸载 ∪ 危险区右段完成）。
3. 行级证据距离故事是描述性 [部分证据]，holdout（0450/0451）前 F 不得声称逐行预测力；开发面板 n=36，过拟合风险显式处理（留一交叉验证为最低要求）。
4. "17 个 log-gap 之和=ln S" 的错误口径不得再写；正确 = 总跨度锁定 + 原生部分分开计。
5. 线性读出/固定态代理算子（J_r、校准-KL、E7 160×）只配假设生成，不入 F 主链；gain×相位不正交（6Pro 第 6 点），F 不含 gain 自由度。
6. 交付的"实际效果"分三档：已测（面板 14 点）/结构性质（CPU 可判）/待 GPU（队列判决标准预注册）；不得合并为单一"预测精度"。
