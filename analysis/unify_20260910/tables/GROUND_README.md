## 2. 指标定义（全表逐槽数据在 JSON 中）

- \(m_j\)：由 fp32 部署 \(\nu_j\) 反演 \(\log_4(\omega_j/\nu_j)\)；
- \(T_j=2\pi/\nu_j\)，\(D_j=W\,4^{m_j}\)（识别地平线），\(r_j=W/T_j^{\text{nat}}\)（原生格点数，对全族相同）；
- \(\mathrm{gap}_j=\ln(\nu_j/\nu_{j+1})\)（0-based，j=0..62）；
- **水床和（代数恒等式，非能力命题）**：
  \(\Sigma_{\text{trans}}=\sum_{g=23}^{39}(\mathrm{gap}_g-\tfrac{\ln b}{64})=\ln 4\,(m_{40}-m_{23})\)，
  端点固定表恒等于 \(\ln4=1.386294\)；全表口径 \(\Sigma_{\text{all}}=\ln4\,(m_{63}-m_{0})\)；
- **洞比率** \(\rho=T_{g+1}/T_g\)（UNIFIED §1-2 定义；原生 \(\rho=1.2410\)），报
  max（过渡段内与全表两个口径）。依据否决清单（SYNTHESIS §7 C5），洞/粗糙度/平滑性
  只作为**被测量**记录，不据其排序方法或推断能力。

## 4. 不变量数值核验（126 项核对全清单在 JSON `reconciliation`）

1. **水床恒等式**：17 张端点固定表 \(\Sigma_{\text{trans}}=\ln4\)（最大偏差 <1e-4，
   P2 除外，见 3）；18 张表 \(\Sigma_{\text{all}}=\ln4\)（含 NTK——它端点不固定但
   \(m_{63}{-}m_0{=}1\)）。HighGapToLong \(\Sigma_{\text{trans}}=\ln4+\tfrac{\ln b}{64}=1.6022\)
   而 \(\Sigma_{\text{all}}=\ln4\)：EVQ"运输"确实是从带外（gaps0–22）注入——文档
   "预算 \(=\ln b/64=0.2158674\)"重算吻合 [已验证]。E2 两和皆 1.6022 = 尾部违例的
   定量表达。
2. **P2 双源闭合**：部署表重算 \(\Sigma_{\text{trans}}=1.3855186=\ln4-0.00077543\)，
   与 `planned_controls/p2_gap_comparison.json` 的 `gap_delta_sums["0:23"]=+0.00077543`
   逐位（1e-7）一致 [已验证]。
3. **预算和 Σm**：MrPro = Smooth = 29.3333（\(B=16/3\) 的**同预算重排**——这正是
   Smooth 臂的定义，且 KKT 粗糙度证书重算 0.004886399 与文档逐位一致）；
   BM = MrUni = 32.000（\(B=8\)）；P2 = 34.179、s28 = 29.301、LBS = 29.560 与
   GLM 质心表一致 [已验证]。径向族预算解析式 \(B(N')=\tfrac{N'+2}{3}+\ldots\)：
   N16→6.000、N15→6.667（即收窄过渡**增加**总预算占用，见 §6）。
