### 3.1 EVQ 变分目标的确切数学（交付物 a）

**3.1.1 设定**（tex §I，50–74 行）
- 频率参数化 ω(φ)=b^{−φ}，φ∈[0,1]（φ=0 最高频 ω=1；φ=1 低频边界 ω=b^{−1}）。
- 通道密度 ρ(φ)≥0，∫₀¹ρ=1；离散位置由逆 CDF 定：F(φ_k)=u_k，u_k=k/N（tex）或 (k+0.5)/N（论文/现行代码）。
- 距离先验 D(Δ)=1/(Δ ln L)·1_{[1,L]}。
- 精确核 K(φ₁,φ₂)=∫₁^L D(Δ)cos(ω(φ₁)Δ)cos(ω(φ₂)Δ)dΔ（等价 Ci 闭式见主张表 #1）。

**3.1.2 变分目标（完整四项）**（tex 164–173 行）

𝒥[ρ] = (α/2)∫₀¹ ρ(φ)² dφ
     + (β/2)∫₀¹∫₀¹ ρ(φ₁)ρ(φ₂) min(φ₁,φ₂) dφ₁dφ₂
     − μ_F ∫₀¹ ρ(φ) b^{−2φ} dφ
     + λ (∫₀¹ ρ(φ)dφ − 1)

- 项 1 = 对角脊/局部自干涉惩罚（Tikhonov）；项 2 = 全局跨频干涉（Brownian/min 核）；项 3 = Fisher 保真奖励（μ_F 控强度，b^{−2φ}=ω(φ)² 是标准正弦频率估计 Fisher 标度）；项 4 = **唯一等式约束**：归一化 ∫ρ=1。
- 注意：**泛函里没有显式 ρ≥0 不等式约束**——正性由解自动满足（cosh 密度 τ>0 时恒正；Fisher 特解项正），这一点四文件与后续审计均未讨论，写论文时是一个可被审稿人问的小空子（[假设]级风险）。
- 等价写法（IRONCLAD §7.0 / COSH_REDESIGN 引用的形式）：项 1+2 即 (α/2)‖ρ‖₂² + (β/2)‖S_ρ‖₂²，其中 S_ρ(t)=∫_t¹ρ（生存函数）；(α,β)>0 时二次型正定（min 核是正算子 A=−d² 之 Green 函数，PSD），𝒥 严格凸 ⇒ 驻点唯一全局最小。
- (α,β) 的地位：不是解析常数，而是 K 在 {αδ+βmin} 上的（经验校准的）投影系数（主张表 #17/#20）。

**3.1.3 一阶条件与 cosh 解**
- 积分驻点条件：αρ(φ) + β∫₀¹ρ(ψ)min(φ,ψ)dψ − μ_F b^{−2φ} + λ = 0（tex 180–183 行）。
- 求导一次：αρ′(φ) + β∫_φ¹ρ(ψ)dψ + 2μ_F ln b·b^{−2φ} = 0 ⇒ 边界条件 ρ′(1)=−(2μ_F ln b/α)b^{−2}。
- 求导二次：**ODE ρ″−τ²ρ = γ_F b^{−2φ}**，τ=√(β/α)，γ_F=μ_F(2 ln b)²/α。
- 通解（τ≠2ln b）：ρ*=C₁cosh(τφ)+C₂sinh(τφ) + [γ_F/(4(ln b)²−τ²)]·b^{−2φ}；C₁、C₂ 由 ρ′(1) 与 ∫ρ=1 定。
- 物理解读（IRONCLAD 2.3）：双分量竞争——cosh tether（全局干涉抑制）+ Fisher pulse（高频端分辨率脉冲，τ=O(1) vs 2ln b≈20–30 时其幅度 P=γ_F/(4(ln b)²−τ²) 极小且集中在 φ≈0，故宏观形状由 tether 主导）。
- 纯 tether 特例（μ_F=0，论文主公式来源）：ρ_τ(φ)=τcosh(τ(1−φ))/sinhτ（BC ρ′(1)=0 强制 sinh 分量为零；归一化 A=τ/sinhτ）。
- CDF 反演（EVQ warp）：φ(u;τ)=1−(1/τ)asinh((1−u)sinhτ)，ω_k=b^{−φ(u_k;τ)}。N=d_head/2（公式表 352–358 行）。
- 局域展开：φ(u;τ)=u−u(1−u)(2−u)τ²/6+O(τ⁴) ⇒ τ>0 时所有内点通道 φ<u（向高频移动），但**间隔被不对称重分**：低频 gap 增大、高频 gap 缩小（tex 296–305 行——这正是"把预算给慢端"的连续版本，见 §3.3）。
- Waterbed（配套不等式）：见主张表 #9。
- τ* conjecture：τ*(L)≈d_head/√L（tex 明示 Conjecture 状态）。

**3.1.4 同一目标的"间隔预算"重写（与预算模型的严格对应，交付物 a 的补充）**
变量替换 h(u)=φ′(u)=1/ρ(φ(u))（u 是通道分位坐标，h 是第 u 分位处的对数间隔）。两条初等恒等式：
- ∫ρ(φ)²dφ = ∫₀¹ du/h(u)（密度换元）；
- ∬ρ(φ₁)ρ(φ₂)min(φ₁,φ₂)dφ₁dφ₂ = ∫₀¹(1−F(t))²dt = ∫₀¹(1−u)²h(u)du（用 min(a,b)=∫1_{t≤a}1_{t≤b}dt 与分位坐标下生存函数 = 1−u）。
⇒ **J[h] = ½∫₀¹[α/h(u) + β(1−u)²h(u)]du，约束 ∫₀¹h(u)du = 1**。
- 约束 ∫h=1 ⇔ 对数跨度守恒（端点锚定下 φ 从 0 到 1 扫过固定总跨度）——这正是预算模型"额外 ln S 总量不可变、只能放"的水床恒等式连续版。
- 代价结构：α/h = 拥挤项（把间隔压没要付超线性代价，处处同权）；β(1−u)²h = 间隔放置项，权重 (1−u)² 在高频端（u→0）最贵 ⇒ 最优解把间隔从高频端挪向低频端。
- KKT：−α/(2h²)+β(1−u)²/2+λ=0 ⇒ h(u)=√α/√(β(1−u)²+2λ)。代入 cosh warp 的显式间隔 h(u)=(sinhτ/τ)/√(1+sinh²τ·(1−u)²)，逐点核对成立当且仅当 β=ατ²，即 **τ=√(β/α)**，且 λ=ατ²/(2sinh²τ)——两种坐标精确自洽（[已验证]：GLM 文档数值 1.6e−11 + 本 digest 独立数值核对，见 §1 末尾；λ>0 满足约束符号）。h(0⁺)=tanhτ/τ<1、h(1⁻)=sinhτ/τ>1：高频间隔压缩、低频间隔扩张，τ 越大不对称越强，与 Taylor 展开一致。
- 边界情形：τ→0 ⇒ h≡1（均布 = geometric）；τ→∞ ⇒ h 在 u→1 端发散式集中（全部额外预算堆在最低频端，对应 P2 式"单巨洞 + 提前完成"）。[已验证（极限计算）]

## 4. 失败机制清单

1. **"唯一近似"叙事膨胀**。IRONCLAD 第 48 行"每一步都有完整数学证明，不存在假设→验证 gap"——但链条里 (i) cos-only 核不完备、(ii) δ 局部化是第二近似（T8 给出显式被丢项 h_c）、(iii) 先验→任务需求、(iv) 代理→训练后能力四个断点没有一步有证明。复发模式：把"选定标量模型内部代数步骤全对"复述成"整个方法有证明"。
2. **渐近式的全域化**。O(1/ln b) 残差、o(1) 措辞——小参数展开在其失效端（φ→0，b^{−φ}≈1）被当界用（VALIDATION §3.2）。T8 的正确做法：给出**带适用 regime 的**界（δ,σ≪1, Lδ≫1，并明说"不打算在对角/两端一致"）。复发警告：任何"界"必须与适用域同句出现。
3. **代理拟合可以被选出来**。2026-03-11 扫描 24,000 配置找 886 个 R²>0.99；GPT-2 attention 测度≈0.90 vs token co-occurrence≈0.65（T7 §1.1）。R² 高≠真实先验落在拟合配置。
4. **目标形式预选择被误当发现**。α、β 怎么拟合都返回 cosh 族（T7 §1.2）；更高 R² 也不给任务最优保证；"窗口内正交而窗口外周期混叠的表"已被构造（harmonic-lattice/cosine-vs-full-subspace 排序反例，见 COSH_REDESIGN 引 FULL_ROPE 报告 20260819）。
5. **代理 τ 与部署 τ 脱节**（T7 数字：比值 4.42/5.70）。静态 surrogate 定理给不出可部署超参；learnable τ 的"自动补偿残差"叙事（IRONCLAD §7.0.3）从未有回执支持。
6. **公式选点不可靠**（Phase16：公式 vs pilot 邻点 +0.0221 NLL）。教训：指数律复现 ≠ 常数律复现；"near-optimal law"曾因混用 stage 评分与 seed 数而虚高。
7. **离散约定漂移**。tex k/N、论文 (k+0.5)/N、旧代码 k/N（IRONCLAD §6.3 已⚠️）、现代码 midpoint=True——历史数字标注的 τ（1.5/1.14）绑定哪个网格未逐一考古；GLM 复核再次警告"不能混用离散约定"（端点再锚定会改变数字）。
8. **定理编号双轨制**（知识库 Theorem1-3 vs 论文 Proposition1-3，IRONCLAD §9）；IRONCLAD 文件自身还有两个"## 9"重复节号（344、358 行）与失效指针"INDEX.md §1"。引用纪律：以论文口径为准，但指针文件本身也要有人更新。
9. **Proxy Metric Trap 的理论化版本**（Prop 3）：双模态评估分布触发共振消零 → Sigmoid 代理上"看似优秀"、真实 power-law 先验下崩溃。与项目级失败复盘（USER_INTENT_GUIDE / OVERNIGHT_FAILURE_POSTMORTEM 线）同构。复发警告：**任何在合成/双峰评估上调出来的分配形状，先问它在真实先验下爆炸的 φ* 在哪。**
10. **方向梯度过度解读**：UNIFIED §3"所有赢家都在右移…不太可能是噪声"同日即被 GLM 复核用质心表拆掉（E1 后移、LBS/P2 前移都赢）。复发模式：8 个构造的"单方向一致"在小面板（36 行、含难度主导行）上不成立。
11. **gain 与相位不正交**（GLM 复核 #6：softmax(g²z) 一般存在非零交互项）——E3 四格"gain 只改幅度不改弧"的读法过强。
12. 硬错误已修记录：submission 附录 ODE RHS 符号（VALIDATION §4）；Prop 2 的 Ci 渐近 regime 混淆（Appendix C 标题自带 "corrected Ci asymptotics"）。
