## 2. 任务时间线

### 2A. MrRoPE 论文自身的任务线（按其正文顺序）

1. **目标：为 RoPE 扩展找统一理论**（§1）。动机：现有扩展策略"高度多样且缺乏统一理论基础"。结果：提出进制转换视角（成功，见下）。
2. **RoPE = 有偏 β-进制编码**（§2.2, Eq.4–7, Fig.2）。构造：θ_j = b^{-(j-1)/Dr}，(4) 与进制位 (5) 共享 m·β^{-(j−1)} 项；恢复估计 m̂ = Σ β^{j-1}[(mθ_j) mod 2π]（Eq.7）。结果：Fig.2 显示 m̂ 线性随 b 增大而扩展至全窗口 [已验证-论文，图形证据]。注意 Su (2023) 的假设本是他们引用的猜想，他们"reintroduce the ignored components"把它做成有偏估计。
3. **λ 参数化统一**（§3.1, Eq.9–12）。任意逐维频率缩放 = 混合进制转换：θ'_j = θ_j / ∏_{d<j} λ_d。NTK 为特例 λ_j = S^{1/(Dr−1)}（Eq.11）；YaRN 中频段满足 ∏_{d=dl}^{j−1} λ_d = r_j S（Eq.12），且两端 λ=1。**YaRN 是 regressive 的证明**（App. A.2.1, Eq.21–25）：用 r_j 等比性 r_j² = r_{j+1}r_{j−1} 得 λ_j/λ_{j−1} ≤ 1，对 b>1 恒成立 [已验证-数学；我方 §5.1 独立代入数值复核通过]。
4. **两个新方法**（§3.2）：MrRoPE-Uni λ_j = S^{1/(dh−dl)}（Eq.13，常数）；MrRoPE-Pro λ_j = S^{ε_j}，ε_j = 2(1+j−dl)/((1+dh−dl)(dh−dl))，Σε=1（Eq.14，等差递增=progressive）。端点带公式 Eq.16；实现技巧与 YaRN 一致（含 mscale t = 0.1·ln s + 1，App. A.2）。
5. **实验**（§4）：
   - PPL（ProofPile 128K+，float32，Table 1/4）：Llama3-8B@128K：YaRN 2.38、Uni 2.41、**Pro 2.34**；Qwen2.5-3B@128K：YaRN 2.222、Uni 2.224、Pro 2.221；NTK >10 崩（8K→128K）。Llama2-7B@64K：YaRN 4.03、Uni 4.15、Pro 3.88。
   - NIAH（Fig.4，LLaMA3-8B S=16，ROUGE-1）：Pro 有效窗口至 ~96K；120K（15×训练长）多数深度 **>85% recall**。
   - RULER 13 子任务（Table 2）：Llama3-8B 8K→128K：Pro 96.2/94.2/94.3/91.3/86.6 vs YaRN 95.5/92.1/92.7/89.5/79.9（64K→128K 处 YaRN 89.5→79.9 急坠）。**Qwen2.5-3B（S=4，与我们同一模型！）**：Pro 82.3/82.9/78.5/70.4/53.2 vs YaRN 78.1/77.7/75.6/63.2/50.1。
   - InfiniteBench（Table 3，100–128K 各 100 样本）：Pro avg 49.8% vs YaRN 44%；KV 检索 27% vs 9%、QA对话 22% vs 10%；PassKey 100%。LongBench-V2（Table 5）Pro ≥ YaRN。[已验证-论文自报；样本量小、ROUGE 型，按铁律只当外部能力证据、不与我们面板数字混用]
6. **理论分析**（§4.4）：Fig.5 RoPE-bound（Men et al. 2024 传统）：B_θ(m)=Σ_j cos(mθ_j) 的根 = "有效窗口上界"；b=10⁴ 下 native 1K、YaRN 6K、**Pro 28K**（约 5×）。Fig.6 中间维注意力随相对距离的分布（每距离 50 随机 token 对）："Pro 振荡更小、单调区更宽、更接近预训练分布"。[结果：成功支撑其叙事，但我们判定其解释力有结构性缺口 → §4.1]
7. **超参扫描**（App. B.1，Fig.7/8）：Llama3-8B 以 dh=35(β=1) 为参考，dh∈[34,39] PPL 保持低、Pro 恒优于 YaRN；dl 同理不敏感。**Qwen2.5-3B-Instruct 最优 (dl,dh) = (23,40)**，原文标注"对应 α=32 和 β=1"（与其 Eq.26 的 α/β 角色标注互换，见 §7-Q2）。结论 α=32/β=1 为跨模型强默认。[已验证-论文，但其指标是 PPL]
8. **局限**（App. A.1/E）：PI 不能写成其 Eq.16 的带内形式（他们视为归一化而非进制转换）；radix 概念能否迁移到 T5-bias/ALiBi 是开放问题；无微调对照。

### 3.5 输出(4)：统一表述——radix / 预算 / 碰撞核是同一对象的三个投影

**同一对象**：有序部署频率多重集 ν = (ν_1 ≤ … ≤ ν_64)（等价地 log 网格上的单调重参数化曲线）。在冻结扩展问题上它约化为**一条从 0 到 1 的单调曲线** m_j = log_S(ω_j/ν_j)（端点条件 m_j=0 (j≤23)、m_j=1 (j≥40)、总升高 ln S 守恒——三个框架共享这个形状，见下）。

| 框架 | 它把对象读成什么 | 它读取的泛函 | 守恒律的形态 | 目标函数 | 适用范式 |
|---|---|---|---|---|---|
| **MrRoPE（radix 投影）** | 位置→多位数编码的进制转换；λ = 每位基数 | 累积积 s_d = ∏_{j<d}λ_j = S^{m_d}（其 Fig.3 即 m 曲线） | ∏ λ_j = S（可表示范围 ×S） | 无显式目标；"低外推/高内插/中带达 S"是端点描述 | 冻结部署；**坐标系**——它给图不给路标 |
| **统一预算（我方投影）** | 守恒预算在周期梯子上的**放置**（水床） | gap_d = ln S·ε_d、地平线 D_j = W·S^{m_j}、洞比率 ρ_g、质心 B=Σm_j | 17 个带内 gap 之和 ≡ ln S = 1.386 | 已学计算兼容成本：bank 无穷贵 / arc 便宜 / 危险区必须完成（I1/I2 + 二分法） | 冻结部署；**规则与预测**（方向预测 + 失败行定位） |
| **EVQ/谱预算（碰撞核投影）** | 二维子空间族的 Gram 几何 | c_ων、r₂ = 2K/(1+(K−1)c̄)、精确 Ci 核 K_L(φ,ψ)（非局部对数脊）、变分 J[ρ] | ∫ρ=1（密度守恒，水床不等式即 Jensen 步） | 表征条件数/冗余（可重学网格先验） | 训练期分配 [已验证]；冻结移植被 Thm.3+Table1 判死 [已验证-我们训练系] |

**精确对偶关系**：三框架的守恒律是同一等式的三种写法——
∏_{d∈band} λ_d = S ⟺ Σ_{d=23}^{39} gap_d = ln S ⟺ ∫₀¹ h(u)du = 1（间隔密度）；
MrRoPE 的 ε 序列（Eq.14）与我方的"预算份额"是同一组数（gap_d = ε_d·ln S，我方 CPU 复核 ε_23=0.0065→0.0091 ln 单位 … ε_39=0.1111→0.154 ln 单位；Uni 恒 1/17→0.0815 ln 单位）。
碰撞核投影是对象的**静态容量测度**（不含已学内容 C/D 系数与弧学习）；radix 投影是对象的**坐标图**（任何放置都合法，但无成本函数）；预算投影是在 radix 坐标上放了**兼容成本**后的优化问题——这正是 audit :115 要求的"新分配规则+预测理论"位置：我方贡献不是发明坐标系，而是 I1/I2 端点不变量 + D_j 地平线 + 完成/桥最小化规则。
**同一现象的三句话**：MrPro 赢 YaRN ⟹（radix）中带形状 progressive 优于 regressive ⟺（预算）ln S 后移至慢端 = 危险区完成度更高 ⟺（核）其 Gram 变化在冻结权重下代价更低——第三句目前只有方向 [假设]，因 Smooth 反例表明现有核泛函（U、C_T、J_r）在带内形状排序上**已失效** [已验证-我们CPU：Smooth 的 U 与 J_r 全面优于 MrPro 而能力崩 68.3]。

## 4. 失败机制清单

### 4.1 输出(2)：MrRoPE 理论的缺口——为什么 Fig.5/Fig.6/RoPE-bound 解释不了"窗内外同时好"、也给不出 LBS/s28 型修复的预测

**(i) Fig.5 的 B_θ(m) 是均匀相位的静态余弦和，是"可重学网格"式量**。它对所有维等权、不含内容系数、不含训练弧。我们的直接否证模板：Spectral Budget Table 1（换表使 r₂ 4.57→12.54，PPL 反崩 76.2 [已验证-我们训练系]）与 2026-08-19 审计（静态碰撞≠外推机制）。B_θ 与 r₂ 同族（都是静态 Gram 聚合），因此同样**原则上不能预测冻结模型的已学行为**——它预测的是"编码势"，不是"被使用的计算"。

**(ii) 其解释目标本身错位**：窗内好（32K PPL/检索）由**已学局部计算的保持**决定（bank 恒等 + gain 补幅度，我方 UNIFIED §5：gain 四格证幅度与相位弧正交 [已验证-我们面板]）；窗外好由**弧安全完成度**（D_j ≥ L）决定。B_θ 对两者都盲：它对 bank 的扰动不敏感（高频 cos 在 m≥256 处准随机混叠，聚合里被平均掉——恰是其"良性退化"的部分），又只测根的位置不测根以下的**逐槽地平线结构**。他们 28K-bound vs 自己 128K NIAH 实测（>85% recall @120K [已验证-论文]）相差 4.6×——bound 与能力之间无桥。

**(iii) "窗内外同时好"在其框架内是不可表达的命题**：radix 理论只有"把 OOD 角度压回训练范围"一种失败模式（§3.1 incomplete-cycle 论证），没有"压缩本身破坏已学整数对齐判别"的第二种失败模式，因此无法陈述"为什么压缩高频侧在训练模型上免费、在冻结模型上致命"。我方窗内外双优的完整解释（bank 恒等 + 整块 ÷S 是**精确重参数化**（块内成对几何 = 原生 ¼ 位置的训练流形逐点重演）+ 桥锚点重放 + gain 正交补，UNIFIED §5）里没有任何一步需要"稳定注意力分布"假设。

**(iv) 给不出 LBS/s28 型修复的预测——信息结构缺失**：
- 其设计空间确实包含我们的解（λ 全 1 除 4 个 gap 集中即 LBS；P2 = 悬崖形；甚至 PI = M4 的 λ=(1,S,1…)）——**坐标系容纳我们，理论不选择我们**。它的评估指标（PPL、B_θ 根、中带注意力曲线）对"把 0.045 ln 单位的 gap 从 27 挪到 28"（s28_less，+5.2pp 128K [已验证-我们面板]）的扰动变化量级 ~O(10⁻³) 聚合，任务上不产生任何可检测信号；
- 缺三个我方对象：**D_j = W·S^{m_j}（识别地平线）、洞比率 ρ_g（覆盖代价）、危险区 r∈[1,2.2]（恶性未学习带）**。其 Eq.26 的 dl/dh 只由 r=32/1 两个学习阈值定端点，带内部只谈"形状"（均/递/进），从不谈"放置到哪一段已学时钟上"；
- 因此其理论连自己方法的缺陷都无法陈述：Pro 的 m_36–39=0.59–0.89 → D=75–112K **全部 <128K**（我方 CPU 复核，§2B-8），即 Pro 在目标长度内自留 4 个弧不安全时钟；这预测了它的特异性失败行 mk_2@89K、vt_0@106K 落带 [部分证据：开发集 n 小，holdout 0450/0451 排队中]，并精确给出两类修复分工（s28 前端保真、LBS 危险区完成）。MrRoPE 的任何泛函都不产生这组预测。**其全部赢点恰好发生在我们模型的两个可修点上——它的叙事是事后聚合，不是前向规则**。

**(v) 其自身数据的排序在其框架内是反常的**：YaRN regressive 的累积 m 在带内**更高更完成**（我方 CPU 由 Eq.21 复算：YaRN m_31≈0.62、m_39≈0.97、D_39≈125.8K，均优于 Pro 的 0.235/0.89/112K），若"中带稳定/完成"是机制，YaRN 的长端应不输——但它输（其 RULER Qwen 63.2→50.1 vs Pro 70.4→53.2 [已验证-论文]）。radix 叙事只能引用其直觉"低维被过早转换破坏局部信息"（§4.2 讨论），无定量。我方模型吸收此反常：YaRN 用中带前段（槽 25–33，bank 邻接、r≈10–30 的半危险时钟）的过压缩换尾部完成，代价 > 收益——排序由**放置位置**决定，不由累积完成度单独决定 [已验证-我们CPU复算 + 论文数字方向一致]。

**(vi) 端点"不敏感"是其 PPL 度量的盲区，恰是我方 I1/I2 的对照**：Fig.7/8 在 dh∈[34,39]（±2 槽）内 PPL 平坦 → 端点**位置**微调确实钝感；而我们的证据说预算**跨端点迁移**是悬崖（HighGap 32K −17.1、E2 平台 ÷4.93 → 128K 崩 54.7、E8 单槽归零 −13.9pp [已验证-我们面板]）。一个只会看 PPL 的理论会把悬崖当平地，从而把"任何跨端点重分配"都判为可行——这正是其框架会犯、我们的 I1/I2 先验排除的错误类型。

**总结（缺口清单）**：无兼容成本函数（无目标）；无内容/系数概念（Fig.5-6 静态）；无地平线/距离分解（不可定位失败行）；排序反常吸收失败（§4.1(v)）；PI 否定命题过窄（M4）；α/β 与索引约定不自洽（见 §7-Q2，工程可修，不动摇数学）。

### 5.4 输出(3)：EVQ 原始动机 vs MrRoPE 的 source-sink 对比

**EVQ 原始动机**（`docs/theory/EVQ_COSH_THEORY.tex` 2026-03-05 + Spectral Budget §3.2/3.4）：几何表慢端冗余税——23 对慢通道占 46 维而有效秩 2.00 [已验证-我们CPU]；慢时钟"更分散/更多对数空间"可改善表征条件数；密度换元后等价于 J[h]=∫[α/h+β(1−u)²h]/2, ∫h=1（UNIFIED §8.1-2 的严格化），cosh 解把通道推向快端（K=64,τ=4 时 55/64 分位在快半区）——**同一件事的两面：快端加密 ⟺ 慢端间隔拉大**。原始动机语句（UNIFIED §6 引）："压缩高频侧 log-间隔，让给低频侧，使慢时钟更分散"。

**逐维对表**：

| 维度 | EVQ（原始/spectral-budget 版） | MrRoPE | 我方统一模型 |
|---|---|---|---|
| 作用坐标 | 原生表内部的 z（训练前重排网格） | 已训表的冻结重参数化 m_j（带内形状） | 同一 m_j 路径 + 端点不变量 |
| **sink（慢端）** | 慢端拉大间隔/降密度（少而分) | 慢端吃满累积 ∏λ=S（尾部整块 ÷S） | 两者方向一致且都对：**P2/LBS 的"把间隔给慢端"都赢 128K** [已验证-我们面板] |
| **source（快端）** | 快端加密（压缩高频 log-间距） | 快端**一根手指都不碰**（λ_j=1, j<dl；其 Uni/Pro 的 bank 全原生） | 冻结部署下 EVQ 字面 source = HighGapToLong → 两端全输 [已验证-我们面板]；MrRoPE 的"快端恒等"直觉被 I1 升为定理 |
| 优化范式假设 | **可重学网格**：权重将在新基上重学系数（表征先验 β(1−u)²） | 无目标函数（形状比较，PPL 裁决） | **已学计算的保持**：兼容成本符号由二分法给出（bank ∞ / arc 0） |
| 守恒 | ∫ρ=1（水床/Jensen） | ∏λ=S（范围膨胀） | Σgap=ln S（同一守恒） |
| 端点观 | support 固定是实验设计（anchored 版）；端点本身非约束 | dl/dh 由 r=32/1 学习阈值定，(23,40) 最优 | **I1/I2 = 硬约束**，由崩溃事件钉死；其最优值与我方硬界重合（§5.2） |
| 冻结部署可行性 | 训练线成立（3 seed 全长胜、MLA −31.1%…）；**冻结推断被其自身移植障碍定理 Table1/Thm.3 判为不可**——而该定理恰恰解释了 HighGap 失败：非均匀表改变不能被固定 Q/K 线性补偿吸收，权重只有在训练时才重学系数 | 原生冻结适用（train short test long） | MrRoPE 是"冻结版对的 EVQ 方向修正"：sink 保留、source 换成"桥的渐进性"（P2 从高频只取 0.0008，比 HighGap 少 280 倍）|

**核心和解（比 UNIFIED §6 再进一步）**：EVQ 与 MrRoPE 表面上方向相反（一个动快端、一个禁动快端），实为**同一守恒在不同范式的两处落点**——EVQ 优化"重学情形下的基条件数"，MrRoPE 描述"冻结情形下的范围重参数化"；把 EVQ 的表冻结移植，移植定理保证失败（[已验证-我们训练系]），把 MrRoPE 的表拿去训练前重排，则其 sink 方向（慢端拉大）恰好是 EVQ 想要的方向。**两者共享 sink，在 source 上被范式符号分开**；我们的规则给出符号表。
