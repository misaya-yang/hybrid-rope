## 4. 失败机制清单

（每次失败：试过什么 → 为什么失败 → 对复发的警告。09-07T12:22 总复盘（§6#23）给出四原因，是后续所有规则的母版。）

1. **代理指标→能力幻觉**（总病根）。数学上能定义的量（平滑性、相位覆盖、曲率、重构误差、能量占比）被反复当作改善理由。实例：通用分配慢相位极限（#6）、one-turn D*=0.0192 但 8K RULER=0、C2 MAE 0.001223 未过门。警告（09-08T03:05）："我们在构造更容易优化的数学对象，却没证明优化它改善实际决策；失败后给对象加结构/精度/自由度"——加结构就是复发动作，识别信号是"候选变了，关键未知没有减少"。
2. **不站在有效方法上做改进**。首轮 GPU 提案直接改 MrPro 中段（某槽 0.0065→0.912）把强基线拆掉重造（09-07T11:05）。警告：任何候选先答"保留了 MrPro 的什么、只动了什么"。
