# Beyond the Base: Exponent Allocation in RoPE — manuscript supplement

The current archive is `exponent-allocation-source.zip`, generated by
`python3 paper-2027/package_source.py` from the repository root. It contains the
active TeX, bibliography, style files, figures, compiled PDF, selected numerical
summaries and CPU verification scripts, plus `SHA256SUMS` for its contents.
Earlier archives under the spectral-budget title are historical artifacts.

## Rebuild the paper

Extract the archive into an empty directory. From that directory run:

```bash
bash compile.sh
```

The build requires `pdflatex` and `bibtex`, or `tectonic`. Poppler utilities enable
the PDF metadata/font checks. The build script checks the body page count,
references, layout overflow and anonymity.

## Inspect numerical summaries

The archive's `README.txt` lists the available figure and verification commands.
For example, with Python, NumPy and Matplotlib available:

```bash
python3 figs/allocation_design.py
python3 figs/make_allocation_value.py
python3 figs/verify_explicit_geometry.py
python3 figs/verify_profile_diagnostics.py
python3 figs/verify_recovered_assets.py
python3 figs/verify_routing_schedule.py
```

These check the packaged mathematical examples or recorded numerical summaries.
They do not rerun training or model generation. Figures already included in the
archive are sufficient to compile the manuscript.

## Experimental evidence

The appendix reports the per-experiment model, frequency table, data, training,
metric and comparison protocol, with source identities where recorded. The
manuscript source archive does not include training/evaluation entrypoints,
checkpoints, token caches or complete raw generation streams. Model experiments
therefore require their separately maintained code and data; the source archive
supports manuscript rebuilding and the listed numerical checks.

Run `make_allocation_value.py` last if also running legacy figure builders. TailSpline inputs are reported aggregates with original-source identities; this check independently verifies discrete optimization and AUC arithmetic, not raw generation.

`figs/allocation_design.py` includes the model-independent TailSpline constructor (native frequency array, native length, scale), plus independent checks of the finite objective and density-to-gap identity. It does not load weights or execute model evaluation.
