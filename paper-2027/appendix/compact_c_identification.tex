\label{sec:identification-details}
\subsection{Intervention identities}
With the native fast endpoint fixed and its slow endpoint divided by $s$,
$z'_k=(Rz_k+\log s\,m_k)/(R+\log s)$. Fixing the cumulative increment mass
$\sum_q\epsilon_q=1$ fixes the added log span; fixing total displacement
$D=\log s\sum_km_k$ further constrains the interior allocation. In particular,
\begin{equation}
\sum_{q=1}^n q\epsilon_q=n-\sum_{q=1}^{n-1}m_q,
\qquad D=Ka'+R'\sum_kz'_k-\sum_kx_k^N.
\label{eq:displacement-centroid}
\end{equation}
Thus equal total displacement already fixes the increment centroid. A
frequency-multiset permutation instead keeps the spectrum and changes its
coordinate assignment. Gain is controlled separately in every matched comparison.

\subsection{Crossed weights and runtime tables}
\label{sec:crossing-151m}
For seeds $137,256$, each Geo- or Cosh-trained checkpoint installs a factor-four
table derived from either training allocation. The derivation uses
$L_0=256$, $\Delta_j=2j$ for $j=0,\ldots,127$, and grouped causal weights
$p_j=(2L_0-4j-1)/(L_0(L_0+1)/2)$. Let $X_k$ contain the weighted sine/cosine
pair and $X_{-k}$ the other pairs. Define
\[
U_k=\frac{\|X_k-X_{-k}X_{-k}^{\dagger}X_k\|_F^2}{\|X_k\|_F^2},\quad
\bar U_k=\frac{U_k-\min_iU_i}{\max_iU_i-\min_iU_i},\quad
\omega'_k=\omega_k[1-3(1-\bar U_k)^2/4].
\]
The pseudoinverse cutoff is $10^{-10}$; zero normalization span gives
$\bar U_k=0$. Tables are FP32 with endpoints overwritten to $\omega_0$ and
$\omega_{K-1}/4$, and gain $1+0.1\ln4$. Evaluation uses the same anchors and
tail-NLL metric at $512/1024$ tokens. The $1024$-token mean crossing is:

\subsection{Frozen fixed-support and equal-displacement interventions}
\label{sec:frozen-fixed-support}\label{sec:four-method-control}
Frozen OLMo-$2$-$1$B and Qwen-$2.5$-$1.5$B use $64$ pairs, their native fast
endpoint and the native slow endpoint divided by four. Matched-support arms
share gain $1+0.1\ln4$, inputs, greedy decoder and precision. Uniform $z$
is log-linear between these endpoints. The derived arm computes residual
fractions $U_k$ as above over native integer separations weighted by $L-d$,
grouped in pairs at rounded weighted centroids, then uses
$\omega'_k=\omega_k[1-3(1-\bar U_k)^2/4]$ and exact endpoint overwrite.
The coarse arm enumerates integer linear-ramp bounds, minimizing MSE to
$(1-\bar U_k)^2$ with lexicographic tie-breaking: bounds are $(20,22)$ for
OLMo and $(28,31)$ for Qwen. These are geometric, label-free controls.

On OLMo's nine held-out tasks ($20$/task, $16$K), uniform/coarse/derived
score $0.56/61.04/60.47\%$; Qwen's four development tasks ($20$/task,
$64$K) score $57.75/64.00/66.50\%$. The sampled support is identical
within each three-arm block.

\subsection{Spectrum-preserving coordinate reassignment}
\label{sec:slot-protocol}
A block permutation obeys
$\mathcal R_{\pi\Omega}(d)=P\mathcal R_\Omega(d)P^\top$, so jointly
permuting Q/K and frequencies preserves the bilinear kernel exactly.
With weights fixed, permuting only interior frequency assignments changes
model performance. The historical OLMo log-law table uses $L_0=4096$,
$b=500000$, $K=64$, $s=4$, gain $1+0.074\ln4$, and fixes slots $0,63$.
Its $20$-document PG-19 tail NLL changes from $3.10423$ to $6.86493$.
Qwen-$2.5$-$1.5$B recomputes the same profile at $L_0=32768$, $b=10^6$;
on $20$ inputs per task at $64$K (single-key, multikey-2, multikey-3,
tracking), macro changes from $70$ to $0\%$. These fixed-spectrum
interventions isolate coordinate assignment; their table is distinct from
TailSpline. Source identities remain in the numerical supplement.
