\section{Clean Transfer, Natural Tasks and Native Allocation}
\label{sec:completed-evidence}
This section gives the complete new task comparisons and the NCP construction.
Clean RULER panels retain source order without content padding or depth
selection. All reported T/P comparisons use frozen weights and the same inputs,
gain, decoding and scorer within each panel. The public RoPE grid determines
the TailSpline band. Source-order generation and official scoring follow the
RULER implementation revision stated in Appendix~\ref{sec:clean-confirmation}.
The bundled numerical inputs retain per-row scores, report identities and the
native/NCP frequency arrays; the verification script performs no model execution.

\subsection{Cross-model clean confirmation on OLMo}
\label{sec:olmo-clean-new}
OLMo-$2$-$1$B-Instruct uses native length $4096$, $64$ rotary pairs, base
$500000$, $s=4$, band $[14,32]$ and gain $1+0.1\ln4$. The clean $16$K panel
contains $200$ inputs per task ($2{,}600$ paired prompts). Both arms use BF16,
Flash-SDPA, batch $1$, greedy decoding and $8192$-token chunked prefill.
Inputs are generated with seed $20261101$ and QA source offset $5600$.
The primary endpoint is the single-length task-equal mean. With $20{,}000$
paired within-task bootstrap draws (seed $20260923$), T/P score
$50.6506/9.2314\%$, giving $+41.4192$ points and interval
$[39.9865,42.8090]$. All thirteen task means increase.

The family differences and intervals are retrieval $+60.19$ $[58.30,62.03]$,
tracking $+9.70$ $[7.00,12.60]$, aggregation $+16.13$ $[13.86,18.42]$ and
QA $+7.50$ $[2.75,12.25]$ points. T/P have $1{,}251/1{,}392$ EOS-terminated

\subsection{Native Contrastive Proximal allocation}
\label{sec:ncp-construction-new}
NCP improves task performance within the native context by reallocating the
interior frequencies while fixing both sampled endpoints. Let
$\phi_k=(L-1)\omega_k$ and $\omega'_k=\omega_ke^{-u_k}$.
The reference problem is a binary target--distractor comparison with unit
amplitudes, aligned target phase and uniformly random distractor phase:
\begin{align}
r(\theta)&=\frac{1}{2\pi}\int_0^{2\pi}
 \log\!\left(1+\exp(\cos\psi-\cos\theta)\right)d\psi,\\
\mathcal R(\phi)&=2\int_0^1(1-t)r(\phi t)dt.
\label{eq:ncp-reference-risk}
\end{align}
The triangular distance weight is the distribution of absolute separation
between two uniform positions on a continuous unit interval. The aligned
reference comparison supplies a public design objective. The Transformer task
scores below evaluate the resulting fixed construction.

We minimize the objective in Eq.~\eqref{eq:ncp-main}, with fixed
$\lambda=9/4$ (quadratic coefficient $\lambda/2=9/8$), subject to
\begin{equation}
u_0=u_{K-1}=0,\quad 0\le u_k\le 2/9,\qquad
\log\frac{\omega'_k}{\omega'_{k+1}}
 \ge\frac12\log\frac{\omega_k}{\omega_{k+1}}.
\label{eq:ncp-constraints}
\end{equation}
The endpoint constraints keep support fixed; the gap condition preserves
ordering and at least half each original adjacent log gap.
Writing $r(\theta)=a_0+\sum_{j\ge1}a_j\cos(j\theta)$ gives
\begin{equation}
\mathcal R(\phi)=a_0+\sum_{j\ge1}a_j
 \operatorname{sinc}^2(j\phi/2),\qquad
\operatorname{sinc}(x)=\frac{\sin x}{x},\quad\operatorname{sinc}(0)=1.
\label{eq:ncp-fourier}
\end{equation}
This follows by integrating each cosine against $2(1-t)$.
With $q(\phi)=d\mathcal R/d\log\phi$, an interior scalar solution satisfies
$\lambda u=q(\phi e^{-u})$. We compute $r$ on a $1024$-point angular grid,
retain $32$ Fourier modes and solve the scalar stationary equations by
bisection, using zero shift when the native gradient is nonpositive. The two
endpoint shifts are reset to zero. On the deployed OLMo grid all resulting
log-gap constraints are inactive, so the scalar solutions are feasible jointly.

The deployed grid has $64$ pairs, base $500000$ and native length $4096$.
It changes $46$ FP32 entries, reaches maximum relative slowdown $16.7164\%$
and retains a minimum log-gap ratio of $0.7681$. The maximum scalar stationarity
residual is below $10^{-11}$. The mean reference risk decreases from
$0.614082$ to $0.609641$; the penalized objective is $0.611853$.
These are reference-model quantities, separate from model task scores.
The table and unit gain are fixed across layers and inputs; construction reads
no checkpoint weights, activations or evaluation outputs. The source archive
includes the original constructor and an exact FP32 table reproduction check.
