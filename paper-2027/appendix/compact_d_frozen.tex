\subsection{Shared models, tables, scoring and uncertainty}
Llama-$3$-$8$B-Instruct uses native length $8192$, $K=64$, base $500000$
and band $[18,35]$; OLMo-2-0425-1B-Instruct uses $4096$, $K=64$,
base $500000$ and band $[14,32]$. T/P share frozen weights, sampled endpoints,
outer bands and gain $1+0.1\ln4$, while using their respective static $s=4$
interior tables. Tables are installed in FP32 after loading BF16 weights and
are fixed across layers and input lengths. Evaluation uses Flash-SDPA and
greedy decoding. No table is fitted using model outputs.
The gain multiplies both cosine and sine, hence contributes $g^2$ to the
rotated Q/K logit. Clean panels reuse the tables fixed for the classic runs;
changing input selection does not refit the allocation.

Clean RULER pins revision \texttt{c3f5e3b4f87f}, selects source records in
order, and uses neither content padding nor depth selection. Both arms use
identical prompt tokens, references and generation caps: $128$ for NIAH,
$30$ for tracking, $120$ for common words, $50$ for frequent words and $32$
for QA. The endpoint is the official within-task score averaged equally
across the $13$ tasks. All outputs, including empty and capped answers,
remain in the score. Intervals use $20{,}000$ paired resamples within task
and length, with tasks fixed; all reported intervals are $95\%$ percentile
intervals. Source-record intervals for RULER and
source-context clustered intervals for natural QA are separate estimands.

\subsection{Classic length curves and supplementary controls}
\label{sec:current-controls}
Classic Llama and OLMo use $10$ RULER inputs/task at $L,2L,4L$
($390$/arm), with output-independent depth selection and prefix padding.
Single-evidence prompts have two examples at each $10/30/50/70/90\%$ depth;
multi-evidence prompts alternate dispersed and middle-cluster targets.
A repeated irrelevant-record prefix fills the input to cap minus $128$ tokens.
The shared task-specific decoding budgets above are retained. Preparation
seeds are $20260924/20260925$ (Llama/OLMo), with fixed length/task offsets;
the bundled entrypoints specify the deterministic construction.

PPL uses $32$ Proof-Pile arXiv test documents and $14$ PG-19 test-book prefixes
\citep{azerbayev2022proofpile,rae2019compressive}. At each length it is the
exponential of summed whole-prefix loss divided by scored tokens.
Normalized trapezoidal log-length AUC has weights $(1/4,1/2,1/4)$;
PPL AUC integrates PPL itself. The document bootstrap resamples document IDs
jointly across lengths; task bootstrap resamples within task--length cells.

\subsection{Direct three-method evaluation across four model families}
\label{sec:three-method-complete}
The additional models are Qwen-2.5-3B-Instruct \citep{qwen2024qwen25} and
GLM-4-9B-0414. Their native reference is $32768$ tokens; bases are
$10^6$ and $10^4$, respectively. Qwen uses $64$ rotary pairs. GLM uses
GQA with $32$ query and $2$ key/value heads; each $128$-dimensional head
rotates $64$ coordinates, giving $32$ rotary pairs. Tables are installed only
in this rotary subspace, retaining its adjacent-pair convention and the
nonrotary coordinates. Its TailSpline/MrPro band is $[17,30]$, versus
Qwen's $[23,40]$. Both use the public $s=4$ rule and shared gain.

The YaRN baseline is the official static frequency map, installed without
fine-tuning, with its public $32/1$ correction and amplitude rule. Its native
reference, rotary dimension and base are read from each model configuration.
Unlike the matched T/P allocation control, YaRN retains its own boundary
rounding and blend. Every method uses the same prompts, official task scorer,
greedy decoding and BF16 weights. NIAH uses five source-order inputs for each
of eight tasks, selected before execution-order sorting. Llama/OLMo reuse
these exact inputs from their clean large-panel T/P outputs; GLM reuses the
NIAH subset of its Full-13 panel. These overlapping subsets provide direct
baseline comparisons, not additional independent replications.

PPL uses the same first five documents at the same token length for every
method in a row. Llama/OLMo select from their classic Proof-Pile/PG-19 manifest;
Qwen/GLM use InfiniteBench LongBook. PPL is the exponential of token-pooled
NLL, and uncertainty concerns the mean paired document NLL difference.
PPL values are not pooled across model-specific corpora and tokenizations.
Batch is one with Flash-SDPA. NIAH prefill chunks are $8192$ for Llama/OLMo,
$65536$ for GLM, and direct prefill for Qwen; the five-document LM runs use
direct prefill. Llama/OLMo/GLM intervals use $10{,}000$ paired resamples;

\subsection{Complete-book natural QA at 128K}
\label{sec:infinite-qa-new}

with complete prompts between $100$K and $128$K tokens, no input truncation,

$100907$--$127946$ for Qwen and $100844$--$127811$ for GLM.

Flash-SDPA and $65536$-token chunked prefill.

The official English-QA adapter computes normalized token F1 against the
accepted references; it is not RULER's answer-containment score. All generated
answers remain in the mean. The paired bootstrap keeps questions from a
sampled source context together, using $20{,}000$ draws and seeds
