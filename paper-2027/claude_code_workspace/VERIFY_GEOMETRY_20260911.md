# 独立复算：论文最核心的几何数字（2026-09-11）

**动因**：`r_2 = 2.00013` 是论文 §3.2 承重的定量主张（"23 对慢频提供 46 个坐标维度，
block-whitened 有效秩只有约 2"）。承重数字必须独立复算，不能只信原稿。

**方法**：从论文附录 A.1 给出的 cross-Gram 闭式独立实现（不 import 论文的脚本）：

```
H_{ωv} = ½[[a(d)+a(s), b(s)−b(d)], [b(s)+b(d), a(d)−a(s)]]
  d=(ω−ν)L, s=(ω+ν)L, a(t)=sin t/t, b(t)=(1−cos t)/t
S_ω = H_{ωω};  Q_{ωv} = S_ω^{−1/2} H_{ωv} S_ν^{−1/2}   （对称 2×2 用 eigh 求逆平方根）
c_{ωv} = ½‖Q_{ωv}‖_F² ;  r_2(Γ) = (tr Γ)² / tr(Γ²)
```

配置：`b = 500000, K = 64, L = 4096`。

**结果**

| 量 | 论文 | 我独立算 | 判 |
|---|---|---|---|
| `ωL ≤ 1` 的 pair 数 | 23 | **23** | ✅ |
| **block-whitened `r_2`** | **2.00013** | **2.00013** | ✅ 逐位 |
| 平均 `c̄`（论文未给） | — | 0.999930 | — |
| 一致性检查 `46/(1+22c̄)` | — | **2.00013** | ✅ 自洽 |

**旁证**：最弱自-Gram 特征值 `λ_−(S_ω)` 跨 `8.4e-6 … 6.7e-2`——比强方向小 4～5 个数量级，
正是论文"原始坐标下弱方向尺度如 `(ωL)²/12`"那句话的来源。**block whitening 去掉的正是这个
尺度差**，所以 `c` 度量的是方向重合而不是数值尺度——论文对此的表述（"invariant under
invertible basis changes"）与实测一致。

**⚠ 一个过程中的自查**：我第一版实现有两处错误——(i) 用 `S**(-0.5)`，那是 numpy 的**逐元素**
幂而不是矩阵幂；(ii) 把 `L` 误传为 1 而不是 4096。两次都给出了**看似合理但错误**的数
（0.00000、2.00000）。**若不复算到"逐位相等"就接受，就会把一个错误当成验证通过。**
记为此类核验的纪律：**先让实现复现【已知的】数字，再用它去验未知的**。

**结论**：该数字成立，论文可以放心继续使用。
