\subsection{Weight compatibility and table crossings}
\label{sec:coadaptation-finding}

The frequency table defines a basis in which query and key projections are learned. In a $50$M pair with perplexities near $7$, installing Cosh frequencies into Geo-trained weights raises PPL to $76.20$; the reverse swap raises it to $23.05$ (Fig.~\ref{fig:weight-table-crossing}). A separate crossing at $151.9$M repeats the effect across two training seeds using derived factor-four runtime tables: both frozen weight sets strictly prefer the table derived from their own training allocation. This distinguishes learned compatibility from static basis geometry without claiming that frequency modifications are universally harmful.
