\section{Introduction}
\label{sec:intro}
As native context windows grow, the largest extension ratio is only one aspect
of positional-encoding quality. For a model with native length $L$ deployed up
to $sL$, we seek useful task quality across the intended range and ask whether
performance within $L$ can improve over its native encoding. We study frequency
allocation $z$: the placement of rotary frequencies within a chosen log-frequency range.

RoPE's base selects a geometric table. YaRN and MrRoPE redistribute scaling
for extension, while LeRoPE learns frequencies
\citep{peng2024yarn,tian2026mrrope,karypis2026lerope}.
What does internal placement contribute beyond choosing the range? Matched
interventions show that it can improve quality even at fixed endpoints and
equal total log-frequency displacement. Its value depends on the chosen range
and the model's learned use of frequencies.

Frozen extension must work with the model's learned frequency use. We therefore
construct TailSpline around the native table by solving a discrete gap-smoothing
problem that connects the transition to the interpolated low-frequency tail.
Fixed-support native interventions examine in-window quality; Cosh transport
tests allocation when weights can adapt.

Our contributions are:
\begin{itemize}
\item \textbf{Allocation matters beyond frequency range.}
Fixed-support and equal-displacement controls identify placement effects;
changing the range can reverse the preferred allocation.
\item \textbf{Learned frequency use affects allocation quality.}
Complete sine--cosine pairs characterize positional overlap; reassigning the
same spectrum across learned coordinates changes task performance.
\item \textbf{Explicit allocations improve practical quality.}
TailSpline improves long-context quality across model families and scales.
Native-window language modeling and Cosh training show that allocation is
useful both within the original range and when weights adapt.
\end{itemize}
