\section{The Allocation Coordinate across Model-Building Regimes}
\label{sec:experiments}

We intervene on the allocation rule at three stages of the model lifecycle.
With a mature checkpoint fully frozen, only the installed allocation changes;
under matched low-rank adaptation and from training, the resulting weight
changes are responses to that allocation rather than separate method variants.
We keep likelihood, capability, and uncertainty units separate throughout.

%% =========================================================================
\subsection{Frozen mature models: pure-\texorpdfstring{$z$}{z} zero-training intervention}
\label{sec:exp-frozen-support}

\paragraph{Allocation alone changes a mature model.}
At matched support, amplitude, checkpoint, rows, decoder, precision, and
hardware, changing only interior $z$ raises OLMo nine-task RULER at $16$K from
$0.56\%$ to $60.47\%$; a coarse label-free allocation reaches $61.04\%$.
On Qwen at $64$K, the corresponding fixed-support change raises core-four
RULER from $57.75\%$ to $66.50\%$ (Fig.~\ref{fig:frozen-fixed-support}).
The intervals for derived minus uniform allocation are $[54.88,64.80]$ and
$[0.25,17.50]$ points, respectively. These uniform, coarse, and derived mature
tables are three values of the same fixed-support coordinate; they are not
\evq{} tables, and the coarse-versus-derived comparison does not identify a
unique profile (App.~\ref{sec:frozen-fixed-support}).

\begin{figure}[h]
  \centering
  \includegraphics[width=\linewidth]{fig_frozen_fixed_support.pdf}
  \caption{\textbf{Changing only interior allocation can transform a frozen
  checkpoint.} Grey reference rows retain their own support or transport;
  the shaded block holds support, amplitude, checkpoint, rows, decoder,
  precision, and hardware fixed while changing only $z$. Derived minus uniform
  allocation is $+59.92$ points ($[54.88,64.80]$) on OLMo and $+8.75$ points
  ($[0.25,17.50]$) on Qwen. Each task has $20$ rows; intervals condition on
  each fixed checkpoint and task set through evaluation-row resampling. Exact
  values and the coarse-control contrasts are in
  App.~\ref{sec:frozen-fixed-support}.}
  \label{fig:frozen-fixed-support}
\end{figure}

For implementation, given Native frequencies $\omega_k$, extension factor $s$,
and fixed displacement weights $m_k\in[0,1]$, the mature intervention installs
\begin{equation}
\widehat\omega_k=\omega_k\big[(1-m_k)+m_k/s\big],\qquad
\widehat z_k=\frac{-\log\widehat\omega_k-\widehat a}{\widehat R},
\label{eq:movement-allocation}
\end{equation}
with the fast and slow endpoints pinned. Equation~\eqref{eq:movement-allocation}
defines the pure-$z$ block above; the complete deployment policy below is a
separate bundled intervention.

\subsection{Zero-training downstream capability and native-window retention}
\label{sec:exp-zero-training-system}

Building on the pure-$z$ result, the zero-training system bundles one frozen
factor-four long table, a fixed long attention amplitude, and a session-static
Native/long route chosen before prefill. It adds no learned parameters or
training tokens, but its combined gain must not be assigned to allocation
alone. Table~\ref{tab:zero-training-system} separates its likelihood,
capability, downstream, and routing endpoints; none of these metrics is pooled.

The route retains the exact Native path when a request fits the model window;

\subsection{Matched adaptation: length transfer and causal source use}
\label{sec:exp-capability}

Matched adaptation asks whether pretrained representations can learn to use an
\evq{} allocation. Starting from protocol-matched Native and \evq{} Stage-A
parents, the $1.485$B selective-Q/K arms freeze inherited V/O LoRA and continue
only Q/K for $300$ steps with identical data, order, optimiser, trainable count,
and phase exposure. On $200$ held-out 2WikiMultiHopQA rows per length,
Native/\evq{} token-F1 is $0.07/21.48\%$ and $0/8.57\%$ at $8/16$K, versus
$25.99/24.84\%$ at $4$K \citep{ho2020twowiki,bai2024longbench}. An independent
$13$-family RULER continuation gives the same task-family crossover:
$2.02/31.63\%$ and $0.38/5.03\%$ at $8/16$K, versus $72.19/42.44\%$ at $4$K
\citep{hsieh2024ruler}. Training and evaluation rows are disjoint within each
task family (App.~\ref{sec:mature-details}).

At $8$B, a single matched rank-$64$ Q/K/V/O LoRA pair provides a complementary
causal endpoint. At true $16$K, the \evq{} arm raises median target-block
hit@16 from $18.75\%$ to $64.06\%$; position-preserving removal of the remote
gold block changes answer NLL by $-0.0095/+1.5055$
(Fig.~\ref{fig:8b-causal-source-use}). Thus the adapted \evq{} model uses the
remote source in these cases; this routing/probability result is distinct from
autoregressive task accuracy.

\begin{figure}[h]
  \centering
  \includegraphics[width=\linewidth]{fig_8b_causal_source_use.pdf}
  \caption{\textbf{Matched adaptation converts the new basis into causal
  remote-source use.} In one matched trained pair, ten frozen true-$16$K cases

\label{sec:exp-mature}

fixed-support causal claim. The studies in
Table~\ref{tab:allocation-routes} instead test whether an installed allocation

from-initialisation full-parameter training, and bidirectional video. The
fixed-support studies own causal attribution; these rows test stage-specific
persistence, with each protocol's execution boundary retained in the table and
appendix.
