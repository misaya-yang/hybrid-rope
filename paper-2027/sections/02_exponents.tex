\section{Exponent Allocation}
\label{sec:exponents}
\label{sec:identification}

Let $K=\drot/2\ge2$ be the number of rotary pairs. Standard RoPE uses
\begin{equation}
\omega_k=b^{-\phi_k},\qquad \phi_k=\frac{k}{K},\qquad k=0,\ldots,K-1,
\label{eq:exponent-rope}
\end{equation}
for a base $b>1$. For an arbitrary strictly ordered positive table $\omega_0>\cdots>\omega_{K-1}>0$, write
\begin{equation}
x_k=-\log\omega_k=a+Rz_k,
\qquad
z_k=\frac{x_k-x_0}{x_{K-1}-x_0},
\qquad z_0=0,\ z_{K-1}=1.
\label{eq:table-decomposition}
\end{equation}
The pair $(a,R)$ specifies the sampled log-frequency support, while $z$ specifies how the finite rotary budget occupies that support. Every geometric table has $z_k=k/(K-1)$, irrespective of its base. Thus changing $z$ while fixing $(a,R,K)$ is an intervention on interior allocation. The standard grid $k/K$ in~\eqref{eq:exponent-rope} and the endpoint-normalized shape $k/(K-1)$ are two descriptions of the same geometric table, not interchangeable installation rules.

A continuous density over normalized exponents can be discretized through its quantiles. At finite $K$, midpoint quantiles, endpoint-inclusive quantiles, and affine anchoring produce different installed frequency tensors. We specify the grid and anchoring convention for each protocol. In the fixed-support experiments, the nonuniform quantiles are affinely mapped to the baseline's actual sampled endpoints. In mature checkpoints, we instead express an installed table through its displacement from the native tensor; \S\ref{sec:mature-adjustments} develops that form. These conventions prevent nominally identical bases or extension factors from concealing changes in the actual sampled range.
