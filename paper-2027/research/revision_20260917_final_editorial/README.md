# 写作技能固化与最终逐章审核

## 本轮任务与基线

按作者要求提炼历次写作纠错为可复用skills，然后由主代理逐章审核现稿并修复实际问题。
上一轮已交付，本次在编辑前把当时的main.pdf原样保存为[history/v3.pdf](../../history/v3.pdf)。
本轮中间修复继续使用v3，未增加历史编号。标题、章节结构及实验截点保持。

## 固化的写作要求

已创建并校验两个个人技能，保留自动发现：

- `research-paper-editing`：论文写作与逐章修改；项目专属决定放在单独参考文件中。
- `research-paper-regression-review`：版本存档、Astra/Sol独立PDF审稿、实质问题判别和回归验收。

技能位于用户的`~/.codex/skills/`，不进入匿名投稿源码包。技能正文和默认提示词用英文。
它们保留的核心判断是：

1. 论文面向读者，先说问题、发现、方法与价值，不写研究执行流水账。
2. 充分表达强结果，同时保留准确的比较条件；不把不overclaim等同于逐句自我否定。
3. 按章节职责、段落因果关系和阅读障碍改稿，检查全篇不等于改写全篇。
4. 证据服务主张，正文承担完整论证；不能变成结果拼盘或附录索引。
5. 保留核心图表和Cosh完整证据链；固定端点是识别手段，NCP与NTS2按当前作者决定处理。
6. 缺少本地路径不等于实验不存在或质量有问题；取样遍历、服务器迁移等执行历史留在代码与内部记录。
7. Pro意见、前辈审稿经验与子代理评语都需要判断适用性；不凭审稿分数反复追改，不导入他文的全部实验负担。
8. 每轮先保存当前未改稿，再与本轮基线对读；PDF公式提取错误须看渲染，提交源码须匹配交付PDF。

技能在本轮实际使用后补强了两点：审稿必须逐endpoint核实基线样本量；比较提示词明确新稿与改前基线身份，避免把方向当成内容变化。
