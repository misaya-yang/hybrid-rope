## 1. 我理解的中心贡献

论文把 RoPE 的采样频率区间与内部配置分开：即使实际最高、最低频率相同，内部位置 z 仍会改变训练后外推能力和冻结模型表现。作者以完整 sine–cosine 二维子空间描述有限窗口中的重叠，同时指出频谱几何不能代替模型学习到的频率—坐标关联。主要方法 TailSpline 保留 MrRoPE 的外围频段，通过显式离散平滑目标重新配置过渡带；Cosh 是支持“配置有用”这一更广结论的另一种构造。

核心贡献不是新 rotary 算子，也不是证明几何秩越高任务效果必然越好。它是控制实验支持的设计变量识别，以及一个无需训练或校准的具体部署改进。

## 2. 最强贡献与证据

- **核心识别实验有说服力。** 第 2–3 页、B.1（第 25–27 页）的 151.9M 三种子实验匹配初始化、训练数据顺序、预算和实际频率端点；固定训练 support 时，所有种子在三个外推长度均改善。重新设定 support 后所有种子方向反转也完整保留。这既支持内部配置的作用，也明确显示它依赖使用策略。
- **TailSpline 的主要任务收益显著，且控制清楚。** 第 7 页、H.7/H.10（第 54–57 页）同一静态 s=4 表在 clean RULER 上，于 16K/32K 分别获得 +3.39/+11.72 个百分点。32K 包括 2,600 个配对输入，12/13 任务均值改善，去掉任何单一任务后总体仍为正；两个 arm 匹配 batch、prefill、输入、gain 和 scorer。该证据直接支持论文实际提出的 TailSpline–MrPro 比较。
- **数学结论基本正确且适用范围交代充分。** 第 4–6 页、A.1/A.6/H.1 给出的 Gram 有效秩恒等式、低频子空间极限、整数位置谱判据和离散平滑问题解均有可核查证明。作者承认其使用主角、frame potential 和相似变换等经典工具，并在附录区分了白化后的方向、原始特征尺度以及完整 Transformer 的响应；没有把精确核不等价误写成不可重新训练适配。
- **反例与负结果提升了可信度。** A.3/A.4 指出高秩与长程覆盖不同；B.3 的指数控制与 Cosh 相近；H.8 的等位移对照不支持细粒度优越性；H.9 的自然 QA 近乎持平；F.3 的一些 Cosh 适配结果相当差。这些没有被隐去或与主方法结果混合。
- **方法改动小，复现描述具体。** TailSpline 是 O(K) 静态构造，不改变 rotary 计算。PDF 提供了频段边界、gain、安装方式、数据选择、评分和不确定性单位。无需假定训练或校准即可理解其使用方法。

## 3. 决策相关的主要弱点

### W1. 实用收益的外部适用范围仍较窄

**类型：实验支持范围有限，不是已证伪或虚假结论。**

**位置与证据：** 第 7–8 页 §6.1；H.4/H.5（第 51–53 页）、H.7/H.9（第 54–56 页）。最强 clean 结果来自 Llama-3-8B、s=4、MrPro 这个比较对象。第二模型 OLMo 使用较小的 classic 深度选择和前缀填充协议。自然 QA 的 631 题总体为 +0.20 点，区间 [−1.53,+1.89]；其中真正超过 Llama 原生 8K 的 315 题为 −0.94 点，区间 [−4.15,+1.95]，且最长约 16K，并未覆盖 32K 目标窗口。

**附录反证/缓解：** OLMo 的 classic 改善很大，所有任务 AUC 方向为正；自然 QA 采用同批次、无填充运行和 source-context 聚类区间，结果可信。其他附录包含 YaRN、BM、Qwen 等对照，但它们是不同构造/协议，不能直接补成 TailSpline 的 clean 比较。H.7 已明确承认没有在该面板比较 YaRN。

**对实际主张的影响：** 不削弱“TailSpline 在这两个 clean 长度胜过 MrPro”，也不要求达到 SOTA。但“实用设计维度”的意义已有证据，而 TailSpline 作为一般部署选择的比较优势目前只能有限确认；自然任务收益尚不能从 RULER 推出。

**最小有用修复：** 在现有 clean Llama 输入上增加一个直接相关的冻结基线（如按其明确公式安装的 YaRN 或 MrRoPE-Uni），无需扩大为大规模榜单。结论集中保留“该模型/尺度下的 RULER 收益”，并直接写明自然 QA 未观察到明确收益。另一模型的 clean 复现会加分，但不是证明本文现有条件性结论的必要前提。

### W2. 原生窗口“小代价”的任务估计精度不足

**类型：支持较弱的精度判断；作者已限定为 observed。**

**位置与证据：** 第 1 页摘要、第 7 页 native-window 段落；H.8（第 55 页）。原生任务对照仅 130 个 classic padded 输入，T–Native 为 −2.14 点，但区间 [−6.14,+1.92] 仍容许明显更大的损失；它与主要 clean 长上下文面板也不是同一种输入构造。原生 PPL 增加 0.37% 的估计更精确，却不是生成任务保持性的替代指标。

**附录反证/缓解：** 原始 Native 对照确已执行；作者给出完整区间，明确没有非劣效界限，且同一张表用于所有长度。不能说本文没有测原生窗口，也不能说其声称无损。

**对实际主张的影响：** 当前证据支持“小的观测点估计”，尚不能稳健支持“部署中只需付出小代价”。由于静态表同时服务原生和扩展窗口，这个精度问题影响性能取舍的实用判断。

**最小有用修复：** 增加与 clean 协议一致的原生长度 Native/T 配对输入，获得更有用的损失界限；若不增加实验，摘要可将其表述为“观测到原生窗口代价，其任务估计仍有较大不确定性”。不需要事后设置非劣效阈值。

### W3. TailSpline 的专属设计理由尚未获得超出一般重新分配的经验支持

**类型：构造解释的证据缺口，不是数学错误，也不是已经提出但失败的普适最优性定理。**

**位置与证据：** 第 5–6 页 §5.1；A.9（第 21–22 页）、H.1/H.2/H.6/H.8（第 50、53–55 页）。平滑目标与未惩罚的高频入口是主动选择的 boundary prior。TailSpline–MrPro 同时改变总位移和形状；真正隔离其残余形状的 T/C 比较为 −0.41 点，区间 [−2.63,+1.82]，且 batch 1/2 不一致。因此“尾部更平滑”虽被严格证明，为什么这一优先方向会改善任务尚未被独立验证。完整子空间几何也没有直接导出该边界选择。

**附录反证/缓解：** G.8 的 BM–Uni 在固定总位移时仍改善 19.20 点，支持一般形状效应；H.2 的等位移构造正确。H.6 明确说任务机制需要独立干预且未声称已经完成，§5.1 也明确没有把 T/P 收益归于单独的平滑因素。这些显著减轻了问题。

**对实际主张的影响：** TailSpline 作为有用闭式方案的证据成立；其理论贡献应主要评价为“精确解决一个合理而自选的配置目标”，不能把当前任务收益视为该特定平滑原则的验证。因此方法层面的新颖性和解释性强度低于一个已验证的设计准则。

**最小有用修复：** 用与 T 完全相同的运行条件补齐 C 对照，沿用 Full-13 主终点。若仍无可辨别优势，明确把 T 和 C 视为同样有竞争力的前置位移方案，收紧关于特定平滑先验的解释；无需证明普适任务最优性，也无需开展大范围搜索。

## 4. 可选建议（不作为接收门槛）

- 主文图表整体清楚；图 3 正确保留了 multivalue 的负收益。可在主文加入一个精简表，把 clean RULER、自然 QA、原生代价放在一起，标注不同输入协议，方便直接判断收益与代价。
- 附录包含大量历史构造和协议，虽有导览，仍有阅读负担。可减少 B/G/J 中重复叙述，把“支持主结论”与“历史探索”进一步分开。
- Cosh 的短训练 factorial 对“跨家族也有用”提供支持，但绝对 NLL 较高、效应很小。将这部分始终定位为受控补充证据，比强调配置胜率更准确。

## 5. 总体建议

**建议：弱接收。内部评分：6/10。信心：4/5。**

决定性理由是：固定实际端点的三种子识别实验与 clean 冻结任务比较，已经支持一个明确、非空泛的结论；TailSpline 构造简单、数学可核查、主要配对收益足够大。作者对反向结果、协议差异、经典理论来源和机制边界的披露较好，没有必要按不存在的 SOTA 或普适最优性主张拒绝它。

尚不足以更高评分的原因是：最强部署证据的模型/基线范围较窄，自然 QA 未显示明确改善，原生任务代价精度有限，TailSpline 专属平滑先验的价值仍未从总位移效应中验证出来。这些约束贡献的广度与解释力度，但目前不推翻主文的条件性主张。未发现足以改变接收判断的已确立数学错误。

以上为内部独立判断，不是官方会议评分。
