## R1：新颖性与意义

### 中心贡献理解

本文把固定频率范围内的内部配置作为可辨识的设计变量，以配对训练和冻结模型控制建立其实际价值；完整正弦—余弦子空间刻画位置方向的重叠，防止把单一 cosine proxy 当作充分描述；TailSpline 则提供一个可直接安装、无需训练或校准的离散构造。贡献是控制性证据、结构认识和有用规则的组合，并非声称首次发现频率可调。

### 最强证据与整体评价

- p3 §3.1、p26–29 B.1–B.3：固定实际端点，三组约 500M-token 配对训练在全部三个延长长度上同向改善；改变支持策略后全部种子的排序反转。这比孤立的非均匀频率胜出更有知识价值：范围与配置是可区分而相互作用的因素。
- p4、p19 A.4、p64 K.2：给出 cosine proxy 严格排序反例，并展示 TailSpline 在完整位置有效秩更低时仍改善任务。论文因此提供了“可以解释的几何对象”和“不能据此推断的模型性能”的清楚边界。
- p7 表2：单一静态表在两种扩展长度改善 clean RULER，最大主对比 +11.72 pp，且无需额外参数或训练预算。即便不证明全局最佳，这仍是值得社区使用和继续研究的结果。

## R2：理论与方法

### 中心贡献理解

本文理论有三个层次：完整 rotary pair 的有限区间几何；频率谱与固定换基的边界；一个明确离散平滑目标下的 TailSpline 精确解。Cosh 则解决另一个密度先验目标。这些定理是对所声明对象的正确数学陈述，实际任务效用由实验提供。

### 最强证据与整体评价

- p15–16 A.1 的 block whitening 和 trace 恒等式正确处理相位与基变换；慢频率极限使用重新缩放后的两维子空间，而非错误地断言 rotary 算子失去秩。
- A.4 的显式例子是有力的教学和研究工具。我复算得到 A 表 `r2=6.29477775`、B 表 `r2=7.99971208`，与文中一致。
- p51 H.1 的二次型正定性、三对角驻点、n=1 边界和正性共同支持 Theorem 2。我的有理数核对未发现不一致。
- p64 K.1–K.2 明确区分位置函数重叠与内容坐标可辨性，并对连续/整数距离、FP32 和 causal weights 做了文内敏感性报告。没有把有效秩降低当作增益机制。

### 决策相关关注

1. **几何分析与 TailSpline 目标之间主要是设计动机，而非推导链。分类：解释性问题。**
   - **位置/受影响主张：** p3–6 §4→§5，特别是 §5.1 的 tail-connection objective。
   - **具体证据：** Eq.(7) 平滑 extra log-gap 且只罚尾端；它不是从 Eq.(4) 的 canonical overlap 或 Eq.(5) 的 effective rank 推导出的风险最小化。Cosh 的密度二次型又是另一先验。p64 的成功例子甚至降低 rank。
   - **反证/已有回答：** p6 清楚解释入口故意不罚；p51 解释实际平滑对象；p54 H.6 承认没有已完成的机制干预。Theorem 2 只承诺 Eq.(7) 最优，未承诺任务最优。这些边界是正确的。
   - **最小修订：** §5 开头加一句：几何刻画设计变量，两个构造分别采用声明的工程先验，任务证据验证其效用而非证明该先验是注意力损失。无需为接受再发明一个普适理论。

2. **TailSpline 的特定尾端形状价值尚未与总位移效应充分分开。分类：解释性问题；若升级为独特机制主张则证据不足。**
   - **位置/受影响主张：** p5 图3、p6 §5.1 的 smooth-tail 设计解释；p51–56 H.2/H.6/H.8。
   - **具体证据：** T/P 不仅尾端跳跃不同，所有内部 T 指数不小于 P，最大 wavelength 比达到 1.766。等 dose T/C 的 Full-13 AUC 是 −0.4103 pp，区间 [−2.6282,1.8205]，且 T batch1/C batch2。
   - **反证/已有回答：** 文中明确说完整 allocation 同时改变 dose 和 shape；H.8 不声称 equivalence。G.8 的 BM/Uni 已证明在另一控制对中 shape 在相同 dose 下可影响性能。因此不能把当前结果写成“allocation 仅仅是 dose”，也不能宣布 TailSpline 没有价值。
   - **最小修订：** 把等 dose 的实际结果及 runtime 限制前置到 §5.1 的控制说明。若坚持“TailSpline 特殊平滑形状优于同 dose 简单规则”的更强结论，才需要完整 runtime-matched C 对照；这不是现有 T/P 改善主张的必要补跑。

3. **Cosh 强度规则的理论地位需避免被密度定理光环放大。分类：解释性问题。**
   - **位置/受影响主张：** p6 §5.2，p24 A.13 的 reference strength。
   - **具体证据：** 精确密度解依赖给定 τ；`dhead/sqrt(Ltrain)` 来自小 τ、diffuse attention 等假设下的局部平衡，系数仍依赖 Q1 与 λ。文中还报告 τ=4 时四次项误差因子约 3.52，factorial 最佳邻域强度随配置变化。
   - **反证/已有回答：** A.13 已详述这些限制，主文称 reference 而非最优规则，MLA 使用明确的 architecture-specific 1.414。无需否定 τ 固定后 Cosh 精确分位数或它的配对收益。
   - **最小修订：** 主文明确一短句“τ 是协议预设强度，不由该定理保证任务最优”，并保留现有邻域结果即可。

### 建议

**倾向接收，7/10；置信度 4/5。** 数学没有发现中心性错误；定理深度适中但服务于正确区分和可计算构造。最重要的修订是统一“结构刻画—设计先验—模型证据”三者的因果地位，不是要求理论预测一切。

## R3：实验与实践价值

### 中心贡献理解

实验首先证明实际端点不变时仍有有用的内部配置自由度，然后评估无训练 TailSpline 静态表。证据不是单一训练/评估大表，而是不同控制问题的组合：训练配对、固定权重、相同 dose、槽位置换、native 成本和自然任务。

### 最强证据与整体评价

- p26–28 B.1 的实验控制细致：每个种子内相同初始化、数据顺序、token budget 和执行几何；在相同末端目标上增加历史上下文，避免把不同长度目标当成同一个问题。
- p55 H.7 的 clean RULER 保留全部输出，2600 unique prompts、batch1、相同表和 decoder；+11.72 pp 区间明确为固定任务下条件性 uncertainty，12/13 task means 改善，leave-one-task-out 仍正。不是依赖单个有利子任务。
- p57–58 H.9/H.10 提供了自然 QA cluster bootstrap、真实长度、无空输出、16K 完整任务分解；正负结果俱全。这显著提高证据可信度。

### 决策相关关注

1. **clean 主实验尚不足以决定 TailSpline 相对于常用冻结方案的选择价值。分类：可选扩展，但影响我对实践贡献广度的评分。**
   - **位置/受影响主张：** p6–8 §6.1 的零训练部署价值。
   - **具体证据：** clean 16K/32K 只比 MrPro，且 Llama 使用 s=4，不是 MrRoPE 论文的 Llama s=16 场景；OLMo MrPro 的绝对分数非常低。
   - **反证/已有回答：** 主文主动交代尺度差别；p42/p50 有官方 YaRN 和 Uni 的其他固定支持/小面板控制，不过不是同一个 TailSpline clean 比较。当前声称“优于 MrPro”仍受到直接支持，不能因没有全基线胜出而抹去它。
   - **最小有用修订：** 先在结果摘要注明比较范围。若添加一次高价值实验，复用现有 Llama clean 32K 输入增加官方 YaRN 静态对照最直接；不需要广泛排行榜或训练型方法的大规模复现。这是提升选择依据的扩展，不是纠正已知实验错误。

2. **native 代价的“小”是点估计，不能当作保留性能保证。分类：解释性问题。**
   - **位置/受影响主张：** p1 abstract、p7–8 Native-window trade-off，p56 H.8。
   - **具体证据：** 130 条 classic padded native task panel 的 T–Native 为 −2.14 pp，区间 [−6.14,1.92]；尚无法排除约六个百分点损失。whole-prefix PPL 增加 0.37%，但任务保留与 LM 平均损失并非同一指标。
   - **反证/已有回答：** 文中确实写 observed、报告宽区间和不同 panel，并未声称 noninferiority；H.8 明说没有预设等效界限。这不是把“非显著”当“相等”的错误。
   - **最小修订：** 摘要或结论用“native 点估计代价较小，任务不劣性未建立”即可。若把部署承诺升级到稳定保留 native tasks，再补与 clean 主实验同类的更大 native panel。

3. **自然任务验证限制了收益解释。分类：解释性问题；远端自然任务是可选扩展。**
   - **位置/受影响主张：** p8 Natural-QA、p9 的 chosen-window quality。
   - **具体证据：** 自然 QA 631 条中 316 条在 native 内，315 条超过 8K，最大仅 16304 token；扩展子集 T/P 为 37.43/38.37，区间跨零。没有自然输入达到 32K 主目标的 TailSpline 证据。
   - **反证/已有回答：** H.9 准确称有限 pool，使用 source-context cluster，保留少量独立长 NarrativeQA/Qasper context 的不确定性；主文也不声称自然 QA 提升。RULER 16K 的 QA gain 与自然 QA 不是互相否定的同一个实验。
   - **最小修订：** 结果结语区分“RULER retrieval/QA 改善”与“自然 QA 未观察到明确排序”。只有在声称自然长文应用收益时，才需要 32K 自然上下文验证。

### 建议

**边界以上、弱接收，6/10；置信度 4/5。** 控制性实验和 clean RULER 已构成实际贡献，但最强部署收益尚集中于一个 clean 模型/benchmark/比较基线。不是因没有 SOTA 而压低评分；是因为读者依据现有结果做部署选择的范围仍窄。现稿的诚实负结果和协议限定使我更倾向接收而非要求大量补实验。

## AC Meta-review

### 综合判断

**整体建议：接收倾向，内部 7/10，置信度 4/5。** 这不是四个分数的平均。决定性理由是存在一条相对坚实且有社区价值的证据链：实际端点固定的配对训练识别配置效应；改变支持策略造成一致排序反转；完整 rotary pair 几何提供了 cosine-only 描述遗漏结构的明确反例；一个只用公开 RoPE 参数的有限离散规则，在同一静态表下取得两个 clean 延长长度的任务收益。方法不需要训练更新，计算和安装成本小，因此其效果即使限定于被测场景也有实际意义。

R3 更保守的判断合理反映了部署比较范围，而不推翻 R1/R2 所认可的控制性知识贡献。本文并未承诺所有自然任务受益或一个 universally optimal allocation，故不能用这些未承诺的目标作为拒稿门槛。

### 对争议事实的 PDF 复核

1. **“全部效果可能只是端点变化”应丢弃。** B.1 Eq.(51) 固定实际端点，Table 7 三 seed 结果支持内部配置效应；MLA unanchored 结果是独立的 supporting evidence，不是拿来替代该识别实验。
2. **“TailSpline 只调尾端，因此平滑机制已经证实”应丢弃。** p6、K.3 明确 T/P 在整个过渡区重新分配 slowdown、同时改变 total dose。H.8 的 T/C 结果跨零且 runtime 不同。现有证据证明完整配置有效，尚未识别特殊尾端平滑的独立任务贡献。
3. **“缺少等 dose 控制”应丢弃。** H.2/H.8 已有 C；G.8 也有 BM/Uni。正确问题是 T/C 的效力与 runtime 限制，不能抹除已做控制，也不能把 BM/Uni 的结果挪用为 TailSpline 的独特形状胜利。
4. **“有效秩理论与性能相反，所以理论错误”应丢弃。** p4、A.1、K.1–K.2 明确 effective rank 是归一化位置函数的性质，非内容算子秩或任务性能预测器。TailSpline 更低秩的正任务结果本身就是论文的重要边界知识。
5. **“没有自然 QA”或“自然 QA 已证明提升/等效”都应丢弃。** H.9 有真实 TailSpline 631-question 比较和 cluster intervals；均值接近且区间跨两种排序。BM 的较早正自然 QA 不能替换这项结果；也不能据中性结果断言方法对自然任务无价值。
6. **“native 保留已被证明”应丢弃。** p56 H.8 的 −2.14 pp 是有宽区间的观测值，未作 noninferiority；论文已明示。clean 长端收益与 classic native 成本不可拼接成一个同分布保证。
7. **“未报告即未做”不能成立。** 本报告仅评估 PDF 建立的证据，不判断未附细节的实验是否实际执行。源代码可复现性和全部先前文献新颖性仍在本次 PDF-only 范围之外。

### 决定性问题与可选提升

**当前最需要修订的是解释而非补跑：** 将 T/C 中性且跨 runtime 的限制前置；明确几何不推出 TailSpline 任务最优；把 native 的“小代价”保持为观测点估计；把图中 derived tables 标清。这些可用现有材料完成，没有中心性数学错误需要抢救。

**最高价值的可选实验：** 若作者希望强化部署选择依据，在相同 Llama clean 32K panel 增加官方 YaRN；若希望强化独特 shape 的归因，完成 runtime-matched C；若希望声称自然长文应用收益，再增加接近 32K 的自然上下文。这三个目标不同，不应把它们全变为当前稿件的强制清单。

**已经建立的新知识和实践价值：** 频率范围不足以决定模型行为，配置的最佳选择随支持策略变化；完整 pair overlap 与 learned coordinate use 必须区分；不必最大化归一化位置秩也能改善任务；TailSpline 是一个可立即复用且有 clean 配对支持的静态延伸表。本文的意义来自这些结论的结合，而非一个排行榜宣称。
