# ICLR 2027 模拟评审：Beyond the Base: Frequency Allocation in RoPE

## 评审范围与总体理解

本评审的唯一实质来源是冻结稿 `input.pdf`。我阅读了完整主文（PDF pp. 1–14，含参考文献），并查阅了全部补充材料的结构及与核心论点直接相关的附录：A（完整旋转对几何、反例与谱/坐标结论）、B（固定支持域识别、权重×频率表交叉、短训练 factorial）、C（学习频率比较）、D–F（训练与适配协议）、G（冻结 profile 与自然 QA）、H（TailSpline 证明、完整冻结评估、clean RULER、equal-dose、native、Natural-QA）、I（支持域、频率谱与坐标分配干预）、J（区间目标与探索性诊断）、K（内容坐标、effective rank 与有限相位）。同时逐页渲染并目视检查了全部 65 页的图、表、公式和版式。

我对论文核心问题的理解是：在 RoPE 的频率端点/支持域给定后，内部频率如何分配仍是一个独立设计自由度；这一自由度既改变有限窗口内完整正弦–余弦子空间的重叠，也会与模型学到的频率—坐标对应关系相互作用。论文用固定支持域干预识别这一点，并提出无需训练或校准的闭式 TailSpline 分配用于冻结长上下文扩展，另以 Cosh 作为训练/外推场景的补充构造。

## R1：新颖性与意义

### 中心贡献

论文把“频率范围”与“范围内部的分配”明确拆开，并用固定端点、等总位移、频率表交叉及槽位置换等干预说明：内部配置并非 base 或频率范围的同义改写，而是会影响训练后外推与冻结模型表现的实际设计变量。它进一步给出 TailSpline 这一闭式、无需模型观测的冻结部署规则。

### 最强证据

最有说服力的是三组互相补足的证据。第一，§3.1 / App. B.1 的 151.9M 三种子配对训练严格固定端点、初始化、数据顺序和近 5 亿 token 预算；保留训练支持域时，Cosh 在 2×/4×/8× 长度的三种子均优于 Geo，而把支持域改成目标长度后排序全部反转。这直接表明 allocation 与 support 是不同且交互的变量。第二，§6.1 / App. H.7、H.10 中同一静态 TailSpline 表在 Llama-3-8B-Instruct clean RULER 上于 16K、32K 分别比 MrPro 高 3.39、11.72 个百分点，区间均不跨零。第三，App. I 的 crossed-table 与 slot permutation 表明模型学到的频率—坐标对应不能被“同一范围”概括。

### 决策相关问题

1. **同协议竞争基线范围较窄（类别：不受支持的主张；PDF p. 7 §6.1，p. 55 App. H.7）** 受影响的主张是 TailSpline 的实际方法价值有多广，而不是 allocation 是否重要。clean 16K/32K 主结果只与 MrRoPE-Pro 比较；App. H.7 明确写道该结果“does not yet compare YaRN”。PDF p. 37 Table 21 确有另一模型/另一协议的 YaRN 比较，但不能替代 Llama clean 面板的同协议基线。因此，现有证据足以支持“在该冻结协议下优于 MrPro”，不足以支持对主流静态扩展方法的广泛领先。**最小修复：**在摘要、引言和结论中始终把方法性结论限定为“相对 MrPro 的同协议改进”；若作者希望强化竞争性，再增加同一 Llama、同一输入、同一 gain 的 YaRN/PI 基线。后者是强化而非证明 allocation 核心命题的必要条件。

2. **PDF-only 无法完全判定外部新颖性（类别：解释性问题；PDF pp. 8–9 §7）** 论文把新意定位为三者的组合：固定实际端点的识别干预、完整旋转对反例、闭式 tail transition；并明确不把 MrRoPE 的坐标重写本身声称为新参数化。相关工作覆盖了 FMRoPE、MrRoPE、YaRN、LeRoPE、STRING 等，定位诚实且具体。然而，仅凭投稿 PDF 无法验证是否存在未引述的同期或更早工作已提出同样的内部配置识别或同一闭式 profile。**最小修复：**增加一个紧凑对照表，逐项比较“固定端点识别、是否读取权重/校准、闭式规则、冻结模型验证、完整 pair 几何”，让可核查的新知识边界更清楚。

3. **实践意义在任务类型上呈条件性（类别：解释性问题；PDF p. 8 §6.1，pp. 56–57 App. H.9）** clean RULER 提升很强，OLMo classic 面板也显示大幅迁移；但 Llama Natural-QA631 的总体差异仅 +0.20pp，95% 区间跨越两种排序，>8K 分层点估计为 −0.94pp。作者已经如实报告“close observed F1”并未宣称自然 QA 获益。**最小修复：**在摘要或贡献列表中直接说明实践价值当前主要建立在 RULER/长上下文检索与受控外推上，自然 QA 的 TailSpline–MrPro 差异未分辨；这样会提高而非削弱论文的可信度。

### 建议与评分

**建议：弱接收。内部评分：7/10；置信度：4/5。** 决定性正面理由是它提出并识别了一个容易被 base/范围掩盖、但对模型质量确有影响的设计变量，知识增量清楚；TailSpline 又给出低部署成本的具体实例。保留意见主要是方法比较面尚窄、自然任务价值呈条件性。PDF-only 对绝对新颖性不能作最终裁决。

## R2：理论与方法

### 中心贡献

理论部分用完整二维旋转 pair 的子空间，而非仅余弦列，定义规范相关 overlap；由 block-whitened Gram 得到 Rényi-2 effective-rank 恒等式，并证明慢频率子空间在有限窗口小相位极限下趋向 `span{1, Δ}`。方法部分将冻结扩展的额外 log-gap 分配写成离散平滑问题，得到 TailSpline 唯一闭式解。

### 最强证据

Eq. (3)–(5) 的定义与 App. A.1 的 cross-Gram、基变换不变性和迹恒等式相互吻合；Proposition 1 在 App. A.1 给出四阶 chordal separation 展开。App. A.4 给出相同端点的显式四-pair 反例，证明 cosine-only 排序可以与完整 pair effective rank 排序相反。TailSpline 的 Eq. (7) 是严格凸二次型，App. H.1 明确证明 Hessian 正定、KKT 驻点、正增量和归一化和式，Eq. (8) 与边界条件一致。就 PDF 中打印出的数学而言，我没有发现决定性的推导错误。

### 决策相关问题

1. **几何统计量不是性能机制，主线偶尔靠得过近（类别：解释性问题；PDF pp. 4–5 §4.2–4.3，pp. 63–65 App. K）** 受影响的主张是 full-pair overlap 对任务增益的解释力度。Table 46 恰好显示 TailSpline 在 16K/32K 的 effective rank 更低而任务分数更高，故 rank 最大化不是目标；App. K.2 已明确说这“不识别 rank reduction 为原因”，App. H.6 也明确没有声称完成机制干预。这些是重要反证/自我限定。问题在于主文仍使用“connects positional structure to explicit constructions”等措辞，读者容易把描述性几何读成 TailSpline 的性能因果解释。**最小修复：**在 §4.3 与 §5.1 之间加入一句醒目的逻辑桥：几何只说明 allocation 改变了什么，不从该统计量推导 TailSpline 最优性或性能方向；TailSpline 的任务价值由冻结实验单独建立。

2. **TailSpline 的边界目标是合理先验，但并非由模型任务目标推出（类别：解释性问题；PDF pp. 5–6 §5.1，pp. 51–52 App. H.1–H.2）** Eq. (7) 只惩罚 transition 内部和低频 tail 接口的 gap 变化，刻意不惩罚高频入口，因而得到较大首跳、较小末跳。论文透明说明这一选择，且证明只针对该离散目标的唯一最优解，没有声称任务全局最优。App. H.2 的 equal-dose T/C 诊断区间跨零，且存在 runtime 不匹配，因此还不能把全部 T–MrPro 增益归因于更高阶 shape。**最小修复：**把 Theorem 2 前后的“design principle”表述再限定为“一个 tail-junction smoothness prior”，并在主文紧邻结果处提及 T/C 尚未分辨 residual-shape 贡献；无需新增理论。

3. **离散/连续 measure 的选择需要更早解释其用途（类别：可选扩展；PDF p. 4 §4.1，pp. 15–18 App. A.1–A.2，p. 64 App. K.2）** overlap/effective rank 取决于 separation measure。主文主例使用 `[0,L]` 均匀测度，App. K.2 还检查整数位置与 causal 权重并保持 rank 排序，已显著缓解任意性。仍然，实际注意力的距离分布和内容相关权重不等于这些测度。**最小修复：**在首次定义时列出“均匀测度用于结构诊断；causal-weighted 是稳健性检查；二者都不是实际注意力分布估计”。学习任务相关测度属于后续研究，不应作为当前接受门槛。

### 建议与评分

**建议：接收。内部评分：7/10；置信度：4/5。** 数学对象定义清楚，核心恒等式与闭式优化有完整证明，且作者对因果与最优性边界总体谨慎。主要改进空间是把“结构描述—设计先验—经验性能”三层关系在主文中分得更开。

## R3：实验与实践价值

### 中心贡献

实验体系试图把三个问题分离：allocation 本身是否有作用；训练后权重是否依赖具体频率/槽位关系；一个无需训练的闭式 allocation 是否能改善长上下文部署。最重要的工程产物是一张可在 prefill 前安装、跨层和输入长度固定、构造复杂度 O(K) 的 TailSpline 频率表。

### 最强证据

clean RULER 的协议尤其扎实：32K 使用每任务 200 个 source-order 样本、共 2,600 对提示，不用内容 padding 或深度筛选；16K 另有每任务 50 个样本；两者均使用官方 scorer、成对 bootstrap，并保留 cap-hit/empty 输出。TailSpline 在 12/13 个 32K task mean 上获胜，leave-one-task-out 差异仍为正。OLMo 的 prospective frozen comparison 在 4/8/16K 的 Full-13、NIAH 和 PPL 都给出一致的大幅优势。Native-window 成本、PPL、自然 QA 中性结果和输出健康状况均有披露，这比只报告峰值长上下文结果更可信。

### 决策相关问题

1. **主方法跨模型的“干净”确认不对称（类别：不受支持的主张；PDF pp. 7–8 §6.1，pp. 52–55 App. H.3–H.7）** Llama 有 clean source-order 16K/32K 确认；OLMo 的巨大提升来自 classic depth-balanced、prefix-padded 面板。附录明确把两种协议分开，并没有把 OLMo 叫作 clean。受影响的是对跨模型可迁移强度的解读，而不是 Llama 主结果本身。**最小修复：**在主文把 OLMo 证据称为“不同输入构造下的跨模型支持”，避免与 clean confirmation 并列暗示同级复现；若要建立强跨模型泛化，再为 OLMo 补同样 source-order clean 面板。

2. **输出健康差异可能是效果的一部分，也使机制解释更复杂（类别：解释性问题；PDF p. 55 Table 40）** 32K clean 面板中 TailSpline 的 empty/cap-hit 为 240/27，MrPro 为 310/83，且生成 token 数不同；全部响应都被计分，没有后验排除，因此任务分数本身仍有效。反面是，改进可能部分来自更好的终止/生成稳定性，而不是仅“检索正确率”。论文未声称二者可分。**最小修复：**在主文结果段增加一句：官方整响应分数包含这些生成行为，因此结果衡量端到端实用质量；另附一个将空输出、cap-hit 与正常终止分层的描述性分解即可，无需改变主 estimand。

3. **native-window 成本尚不能作非劣结论（类别：不受支持的主张；PDF pp. 7–8 §6.1，p. 56 App. H.8）** 任务点估计相对 Native 为 −2.14pp，但配对区间 `[−6.14, 1.92]`，且没有预设 non-inferiority margin；PPL 则有小但区间为正的恶化。作者准确称其为“small observed trade-off”，没有声称非劣。**最小修复：**保留“observed”措辞，并在摘要首次提及时注明任务不确定区间跨零、PPL 有 0.37% 相对增加；如果部署决策需要保证，再预设可接受边界并扩大 native 面板，这是后续验证而非当前核心命题的硬要求。

### 建议与评分

**建议：弱接收。内部评分：7/10；置信度：4/5。** 该论文不是只靠单一 leaderboard 点数：它有严谨的配对干预、两个 clean 长度、跨模型支持、自然 QA 与 native 成本披露。实践价值明确但边界也明确：主要强证据在 RULER，相对基线主要是 MrPro，真实 QA 对 TailSpline 未显示可分辨优势。

## R4：论证与叙事

### 中心贡献

论文试图形成一条三段论证链：固定支持域实验确认 allocation 是独立变量；完整 pair 几何说明它改变有限窗口中的位置方向结构；TailSpline/Cosh 展示如何把这一自由度变成可用构造。

### 最强证据

引言的贡献列表与 §2 的控制定义比较准确；Table 1 清楚区分不同权重状态、是否固定 support 和每个协议回答的问题。补充材料开头的 Tables 3–4 提供 claim-to-evidence 路由，并反复声明不同协议不合并。讨论与结论没有把 Natural-QA 中性结果隐藏掉，也没有声称普适最优性。这种论证纪律是本稿的重要优点。

### 决策相关问题

1. **主文同时承载 Cosh 与 TailSpline，中心对象略显分叉（类别：解释性问题；PDF pp. 1–3、5–9）** Cosh 用于固定支持域识别和训练外推，TailSpline 用于冻结部署；两者的网格、端点和训练状态不同。Table 1 与补充 Tables 3–4 已回答协议混淆，但读者仍需频繁切换“证明变量重要”与“主方法有效”。**最小修复：**在引言末给出一句明确角色分工：Cosh 是 identification/supporting construction，TailSpline 是 primary deployment method；并按“识别→结构→主方法→补充训练证据”重排 §6.2 的地位。

2. **重要限定多藏在附录，主文的阅读成本偏高（类别：解释性问题；PDF p. 7 §6.1；pp. 54–57 App. H.6–H.10）** equal-dose T/C 的 runtime mismatch、Natural-QA >8K 点估计略负、clean RULER 尚未比较 YaRN、native 非劣边界未预设，附录都写得很清楚；主文只呈现部分限定。**最小修复：**把这四点压缩成 §6.1 末尾的 3–4 句“scope of evidence”，无需增加实验即可显著改善可审计性。

3. **版面可读但补充材料过密（类别：可选扩展；PDF pp. 15–65）** 我逐页渲染检查，没有发现裁切、公式重叠、坏字形或不可辨图表；主文图 1–5 清晰。补充材料大量页面是满版小字号表格/协议文字，尤其 D–H，使关键复核路径不易扫描。补充开头的 Guide 已是有效反措施。**最小修复：**在每个大型附录开头增加一句“本节验证哪条主张”和关键表编号，或把历史探索性结果移到独立补充文件。这是表达优化，不影响正确性。

### 建议与评分

**建议：弱接收。内部评分：6/10；置信度：4/5。** 论证总体诚实、证据路由完整，主线也可恢复；扣分来自两个构造和大量异构协议造成的叙事负担，以及若干关键限定需要读到深附录才能看到。

## AC Meta-review

### 争议复核与共识

四个视角的共同判断是：论文最稳固的新知识并非“TailSpline 普遍最好”，而是“在给定频率支持域后，内部 allocation 是独立且有后果的设计变量”。这一点由固定端点三种子训练、range retargeting 排序反转、同频率 multiset 的 slot 干预以及冻结模型 fixed-range 控制共同支撑。它既有科学意义，也为 RoPE 设计提供了一个可操作坐标。

我重新核查了三项容易误读的事实并舍弃了相应过度批评：

- **没有发现 TailSpline 定理的打印数学错误。** App. H.1 给出严格凸性、驻点和归一化证明；定理只声称是 Eq. (7) 的唯一最优解，而非任务损失最优。
- **论文没有把 effective rank 降低说成性能原因。** App. K.2 明确否认因果识别；因此“低 rank 却更高分”是反例式结构观察，不是理论矛盾。
- **论文没有声称 Natural-QA 获益或 native 非劣。** 主文称自然 QA 分数接近，附录给出跨零区间；native 只称 observed trade-off，并说明没有 non-inferiority margin。

真正的决定性弱点是方法层面的外部比较范围：TailSpline 的 clean 主实验相对 MrPro 很强，但 PDF 自身确认尚无同协议 YaRN 比较。它限制了“竞争方法优越性”的广度，却不推翻 allocation 的识别贡献。OLMo classic 的大幅改善是有价值的跨模型证据，但输入构造与 Llama clean 面板不同，应保持层级区分。自然 QA 近似持平说明实用价值具有任务依赖性；这应成为论文结论的一部分，而非拒稿理由，因为稿件的核心知识并不要求所有任务都提升。

理论方面，完整 sine–cosine pair 的 phase-invariant overlap、effective-rank 恒等式和 cosine-only 排序反例构成了有意义的分析增量。它们解释 allocation 改变了什么，但没有从几何统计量推出性能方向；论文附录已经承认这一点。将这一边界前移到主文即可。TailSpline 的平滑目标是一个清楚、可解、无需权重/校准的设计先验，其价值最终来自实验，而非普适最优性定理。

### 新知识与社区价值

论文带来的社区价值有三层：

1. 一个可复用的实验识别框架：端点、总 log 位移、频率 multiset 与槽位关联分别控制；
2. 一个比 cosine-only proxy 更完整的 RoPE pair 几何对象，以及对慢频率有限窗口冗余的清晰刻画；
3. 一个 O(K)、零训练、静态安装的闭式冻结扩展规则，在两个 clean 长度上带来明确 RULER 增益，并报告了 native 与自然 QA 的边界。

这些贡献不依赖 leaderboard 第一或普适最优性。即便 TailSpline 的竞争优势尚未覆盖所有基线，论文仍建立了值得社区保留的新知识和方法论。

### 总体建议
