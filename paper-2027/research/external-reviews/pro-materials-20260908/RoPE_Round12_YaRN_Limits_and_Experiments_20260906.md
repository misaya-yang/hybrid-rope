# RoPE 指数分配：Round 12 结果、YaRN 微调、适配上限与新增实验

日期：2026-09-06  
研究对象：`frequency = base ** exponent` 中的 exponent allocation。EVQ-Cosh、既有 Z 表和几何表是干预实例。  
资料范围：本次 Round 12 附件、当前论文中的历史实验、上一份统一方案，以及 YaRN 原论文、作者实现、官方模型卡和相关原始研究。下文没有把附件报告当成已独立复现的实验，也没有执行新的 GPU 训练。

## 1. 决定优先顺序的判断

目前最值得投入的是两个正向实验：**把非几何分配与调过 base 的几何分配比较，测量原生能力与长程能力的性能边界；在约 1.5B 成熟模型上做相同预算的全参数继续训练，测量分配是否提高适配效率。** 前者主要使用 5090 做推理，后者利用 Pro 6000 的显存。二者可以形成独立于“零训练或 LoRA 已完全解决 4× 联合目标”的论文贡献。

附件还存在一个会影响新对照组的关键问题：**把 YaRN 的 cos/sin 幅度从 `1 + 0.1 ln(s)` 改成其平方根，不符合作者默认实现。** 按附件描述，这个所谓“忠实 Y2”还不能承担标准 YaRN 对照。需要核对整个 attention 路径的实际乘数，而不是继续按符号名称判断。[P1，第 38–42 行；R1–R2]

对用户三个问题的回答是：

1. YaRN 全参数微调没有得到“不发生灾难性遗忘”的保证；论文显示的是部分短任务保持较好，同时存在可见退化。它的训练量、监督密度、底模类型和评价标准与当前实验不同。
2. 零训练换表和 LoRA 都有受模型、数据、参数空间与原生约束影响的可实现边界。目前没有证据把 OLMo 的 4× 失败宣布为任一方法类别的普遍上限。ZF 连训练远端样本都未拟合，首先说明当前协议未完成学习。
3. 新增实验应当让审稿人看到指数分配带来的具体收益，例如**同一原生代价下，超过已测试的几何 base 选择；相同继续训练预算下更早达到目标性能；在固定证据距离下对更多干扰保持正确生成。** 这些结论有可执行检验，不需要先解决所有长程生成问题。

## 2. 附件中的 YaRN 判定需要更正

### 2.1 幅度、温度和 logit 乘数

YaRN 的注意力写作

$$
\operatorname{softmax}\left(\frac{q^\top k}{t\sqrt d}\right).
$$

原论文给出的推荐式是

$$
\sqrt{1/t}=1+0.1\ln s.
$$

令

$$
a(s)=1+0.1\ln s.
$$

作者代码把 `a(s)` 乘到 cos/sin 上，因而旋转后的 Q 与 K 都乘以 `a(s)`。在全部 head 维度使用 RoPE、且没有另外叠加缩放时，最终 attention logit 乘数是 `a(s)^2`。[R1，式 14–15；R2，`get_mscale` 与 cos/sin cache]

在 $s=4$ 时，由上述公式计算：

| 量 | 数值 | 含义 |
|---|---:|---|
| $a$ | 1.1386294361 | cos/sin 的幅度乘数 |
| $a^2$ | 1.2964769928 | 全维 RoPE 下的 logit 乘数 |
| $\sqrt a$ | 1.0670658068 | 附件给 Y2 的乘数 |
| $t=1/a^2$ | 0.7713210536 | 原式中的 temperature |

附件把 `1.1386` 命名为 `t`，继而要求 logit 只乘 `t`，混淆了这些量。**如果 Y2 的唯一修改确实是 cos/sin 乘 `1.0671`，它是较弱增益的 YaRN 变体，不能称作者默认 YaRN。** 若其余路径还有显式 logit 缩放，需要把所有乘数合成后判断；本次没有读取服务器上的实际实现。

这项更正不证明旧 Y 整体正确。附件中旧 Y 在第 15 个频率对以后全部除以 4、没有过渡带，这仍与作者常用实现不同。[P1，第 38–42 行]

### 2.2 Ramp 的具体坐标也要固定

作者代码使用频率对索引上的 clipped linear ramp。它没有使用通常称为 smoothstep 的三次曲线。对于 `head_dim=128, base=500000, L0=4096, s=4, beta_fast=32, beta_slow=1`，按作者公式计算，未取整边界约为 14.7005 与 31.6035，取整后是 14、32。于是 0–14 不变，15–31 过渡，32–63 完全插值。[R2；本次公式计算]

论文文字的 ramp 以旋转次数 $r$ 为自变量，作者代码的 ramp 以索引为自变量，两者也应记录清楚。推荐直接固定作者代码的 commit、频率数组、实际增益和实现容差，作为主要工程基线，不把几种离散化混称为逐元素相同。

下面是本次配置的 CPU 参考，作用是核对张量，不是重写模型 attention：

```python
import math
import numpy as np


def yarn_reference(head_dim=128, base=500000.0,
                   native_length=4096, scale=4.0):
    if head_dim <= 0 or head_dim % 2:
        raise ValueError("head_dim must be a positive even integer")
    if base <= 1 or native_length <= 0 or scale < 1:
        raise ValueError("invalid base, length, or scale")
    pairs = head_dim // 2
    idx = np.arange(pairs, dtype=np.float64)
    original = base ** (-idx / pairs)

    def boundary(rotations):
        return (head_dim * math.log(native_length / (2 * math.pi * rotations))
                / (2 * math.log(base)))

    low = max(math.floor(boundary(32)), 0)
    high = min(math.ceil(boundary(1)), head_dim - 1)
    high_float = float(high if high != low else high + 0.001)
    interpolation_fraction = np.clip((idx - low) / (high_float - low), 0, 1)
    inv_freq = original * ((1 - interpolation_fraction)
                           + interpolation_fraction / scale)
    amplitude = 1.0 if scale <= 1 else 1.0 + 0.1 * math.log(scale)
    return inv_freq, amplitude
```

正式比较前，使用同一 Q/K 张量同时通过基线与项目实现，核对最终 attention logits。只比较 `inv_freq` 不足以发现增益重复乘、后置缩放或 partial RoPE 的差别。

### 2.3 对当前结果的影响范围

Z 在其自身配置上的分数仍是附件报告的观察。Z 优于旧 Y/M 的结果不能自动变成“优于标准 YaRN/MrRoPE”。EOS 极低说明生成异常，单独不能识别异常是否由增益、频率、模型模板或其交互造成。[P1，第 69–85 行]

另外，附件第 31 行把 N/Z/Y/M 写成相同扩展端点，第 58 行又将 N 作为原生模型解释。这两个 N 可能来自不同清单，资料没有明确映射。正式表应使用 `Native-original` 和 `Geometric-matched-support` 两个独立名字，并由频率张量确认身份。

## 3. 为什么 YaRN 的全参数微调可以保留较多原生能力

### 3.1 原论文没有证明零遗忘

Llama-2-7B 的 MMLU 从原始 43.8 变为 YaRN s=16 的 42.5、s=32 的 41.7。论文展示了部分短任务的有限退化，不能据此推出所有原生行为无损。[R1，表 3]

尤其不能把这些知识与推理 benchmark 的分数，等同于你们要求的“短答案完整精确匹配、两个反事实世界都正确、正常 EOS、广泛原生输出保持”。模型卡对应 Llama-2 base 模型；它不是在证明已经完成指令对齐的模型经扩展后仍逐项保持原行为。[R3；P1]

LongReD 的研究直接以长上下文扩展带来的短文本退化为对象，说明这种风险是位置扩展研究中的实际问题。[R4]

### 3.2 400 steps 与 128 steps 不是可比的训练量

官方 64K YaRN 模型使用 400 steps、global batch 64 和 64K 长序列。按满长输入估算为

$$
400\times64\times65536=1,677,721,600
$$

即约 16.8 亿 input token presentations。官方模型卡记录了相应训练配置与 PG19 数据。[R3；计算]

对你们的训练，需要同时列出三个计数：输入 tokens、实际计算 loss 的 tokens、独立语义实例。若一个 16K prompt 只监督数个答案 token，它的训练信号密度与自然文本的 next-token continued training 明显不同。增加背景 token 并不自动增加相同数量的监督目标。

这不表示扩大到十几亿 tokens 才能产生有效结果，也不表示答案监督天然无效。它说明当前结果尚不足以构造“全参 400 步就好，LoRA 128 步为什么不行”的同预算矛盾。

### 3.3 全参数更新可能修复换表造成的功能偏移

记 $R_N(W,\Omega)$ 为固定原生评测分布上的 NLL，$W_0,\Omega_0$ 为原模型，$\Omega_1$ 为新表，$W_1$ 为适配后的权重。下式是精确记账：

$$
\begin{aligned}
R_N(W_1,\Omega_1)-R_N(W_0,\Omega_0)
={}&[R_N(W_0,\Omega_1)-R_N(W_0,\Omega_0)]\\
&+[R_N(W_1,\Omega_1)-R_N(W_0,\Omega_1)].
\end{aligned}
$$

第一项是立即换表后的代价；第二项是训练在新表上的响应。第二项可以为负，抵消第一项。因此，全参数更新的某些变化是在恢复旧计算；参数变化更广，不代表函数偏离原模型必然更大。

对 RoPE，已学计算是

$$
s_{ij}=q_i^\top R_{\Omega}(p_j-p_i)k_j/\sqrt d.
$$

频率改变后，同一 Q/K 子空间受到新的位置调制。完整适配可通过 Q/K、V/O、MLP 等多条路径调整这种调制及其后续影响。LoRA 限制每个映射允许的更新集合，可能无法用同样低的原生代价达到同一个修复目标。

这是一种可解释的可能性，不是对 YaRN 成功机制的唯一识别。继续训练的数据分布、学习率和训练时长同样会影响遗忘。已有研究观察到 LoRA 在若干协议下学习较少、遗忘也较少；另一些研究揭示其更新会产生不同的谱结构与顺序适配行为。这些结果都不能压缩成“LoRA 永远更保真”或“全参永远更保真”。[R5–R6]

### 3.4 对论文的含义

**全参数继续训练值得作为指数分配的独立证据路线。** 它使用成熟 checkpoint，不需要承担从随机初始化学成语言模型的全部费用。比较双方都用相同全参数训练时，新增收益仍可来自固定频率分配。

这个建议已有项目依据：750M 历史实验从同一 2K checkpoint 出发，进行 500M-token 的 4K 继续训练，报告 16K PPL 45.1→24.4、8K 严格生成 0→77.5%。它是一个旧分配实例、一对训练和有限检索样本的证据，不能直接推广为所有 z 或所有成熟模型均有效；但它比再次凭直觉重组旧 LoRA loss 更能支持一个正向实验。[P2，附录 B.3]

## 4. LoRA 与零训练是否有上限

### 4.1 必须先明确“上限”的条件

本节把用户的“令参数”按上下文理解为零新增学习参数、冻结权重的静态换表。

在固定底模、频率候选空间、任务分布和原生约束下，可定义

$$
U_r^*=\sup_{\Omega,\Delta W\in\mathcal A_r}
U_L(W_0+\Delta W,\Omega)
\quad\text{s.t.}\quad D_N(W_0+\Delta W,\Omega)\le\epsilon.
$$

$\mathcal A_0=\{0\}$ 对应零训练，$\mathcal A_r$ 是各目标矩阵 rank 不超过 r 的更新集合。相同模块与约束下，理论可实现集合满足

$$
\mathcal A_0\subseteq\mathcal A_r\subseteq\mathcal A_{r'}
\subseteq\mathcal A_{\rm full},\qquad r\le r'.
$$

所以理想最优值不会因放宽更新空间变差。有限数据、有限步数优化得到的实际结果没有这个单调保证。不同初始化的 from-scratch 模型也不能直接放入这个固定底模的嵌套关系。

这种上限依赖模型与约束，不能由一次 4× 失败推出一个通用长度数字。

### 4.2 零训练的限制在于固定内容映射

一张非几何表可以大幅改变模型的注意力竞争。它不需要学习新权重就能改变行为，但也没有独立自由度去修复每一个受影响的内容关系。

对固定的单层输入，令 $Q_k,K_k$ 是第 k 个旋转对的内容投影，得到矩阵值 kernel：

$$
K_W(\Delta)=\sum_k
Q_k^\top K_k\cos(\omega_k\Delta)
+Q_k^\top J K_k\sin(\omega_k\Delta).
$$

零训练移动 $\omega_k$，保留这些矩阵系数；不同内容关系可能要求相互不一致的频率移动。无序频率集合的静态几何无法完整表示这种约束。完整模型的深层输入还会随前层干预变化。

“不同频谱不能由固定可逆 Q/K 映射在所有连续距离上精确吸收”的结果，只限定一个非常严格的函数等价问题。你们要求的是有限分布上的极低损失与更好的外推，它仍可能存在，不应被该结果提前宣布不可行。

附件的 7B Z 在 8K near 上有 90/128 行严格成功、37/64 组成功；原生模型为零，compact 行级 58/64→57/64。它支持继续检验有限工作区间，但目前不能当成广泛原生无损，也不能将 near@8K 直接写成 far@8K 的长距离检索证据。[P1，第 69–79 行]

### 4.3 LoRA 的 rank 限制没有直接给出最大上下文长度

每个更新矩阵为

$$
\Delta W=BA,\qquad \operatorname{rank}(\Delta W)\le r.
$$

它限制每一层能怎样改变线性映射，并不表示完整深层网络只能学习 r 种关系。已有表达能力研究给出了在特定模型假设下的充分 rank 条件，不能把这些条件读成当前 OLMo 的最小必要 rank。[R7]

一个与 RoPE 直接相关的局部说明：在固定隐藏输入、仅改 Q/K 时，

$$
\begin{aligned}
\Delta K_W(\Delta)
={}&\Delta Q^\top R_\Omega(\Delta)(K+\Delta K)
+Q^\top R_\Omega(\Delta)\Delta K.
\end{aligned}
$$

因此在每个固定距离处，矩阵修正的秩至多 $r_Q+r_K$，而同一组更新还要同时满足不同距离上的目标。这说明某些全内容 kernel 修正可能超出低秩 Q/K 更新的范围。它不适用于证明所有多层 all-linear LoRA 都失败：隐藏状态、V/O 与 MLP 的变化还提供其他路径。

低秩也不等于影响小。对 rank 不超过 r 的矩阵，

$$
\|\Delta W\|_2\ge \frac{\|\Delta W\|_F}{\sqrt r}.
$$

在相同 Frobenius 范数下，更新集中在少数方向时，最大方向的扰动不能任意小。因此保留原生功能需要测实际函数变化，不能用参数量小作为保证。

### 4.4 当前不能称为“碰到 LoRA 上限”

附件称 ZF 训练远端本身未拟合，正在读取各 checkpoint 的 CE、最差 margin、greedy 和原生 KL。[P1，第 12–16、92–104 行]

这些读数先区分以下情况：

| 观察 | 支持的判断 | 还不能推出 |
|---|---|---|
| 训练 CE 高、答案 margin 仍负 | 当前训练未完成所需修正 | rank 太小或模型太小是唯一原因 |
| 训练正确、验证失败 | 泛化、实例或位置覆盖有缺口 | 同一 LoRA 类别不可能泛化 |
| 不带原生约束可学会，带约束失败 | 约束与目标或优化存在冲突 | 总体上不存在联合可行点 |
| 匹配全参数能学会、LoRA 未学会 | 当前协议中全参有实际优势 | 该次全参解的高秩是所有可行解的必要性质 |

ZF 的几个汇总数在附件中属于不同口径：第 15 行出现 4/32，末尾合同出现 2/128 与 groups 1/32。需要沿原始行集合确认，不能平均或择大。这项核对已属于 E1，本文不把它再算作新的科研实验。

### 4.5 一个适用于 attention 的长度压力，不等于 LLM 能力定理

一个正确 key、n 个干扰 key 时，

$$
P_* =\frac{1}{1+\sum_{j=1}^n e^{s_j-s_*}}.
$$

记 $\ell_B=\log(n^{-1}\sum_j e^{s_j})$，则

$$
P_*\ge p
\iff
s_*-\ell_B\ge \log n+\log\frac p{1-p}.
$$

在干扰分数分布和其他条件近似不变时，干扰数量乘四需要额外 $\log4$ 的分数优势；由 2× 数量到 4× 数量则是 $\log2$。实际长输入会改变分数分布，因此需要测 $\ell_B$，不能只代入序列长度。

若这个 head 的所有分数都被固定常数界定、正确 key 数量固定，随着干扰数无限增加，保持固定正确质量会越来越困难。但完整网络可能通过其他头、层、状态与证据副本完成任务，该单头结论不提供“所有 RoPE 模型最多 4×”的证明。

## 5. Round 12 的新读数真正增加了什么信息

### 5.1 从“远端没读到”收窄到“总长度与背景竞争也重要”

附件中 near@16K 将证据贴近结尾，仍然很差；near@8K 则明显改善。这使“只有答案到证据距离太远”不足以解释全部失败。[P1，第 48–54 行]

但两种布局同时改变了背景数量、query 的绝对索引及它与 BOS/其他内容的相对距离、前层形成的隐藏表示。现在还不能把全部差异唯一归因于 softmax 分母。

最少缺少的有效数据是：在 7B 的同一任务与评分口径上，补齐 far@8K 与 near@16K；将 8K/16K × near/far 四格列全。它能直接判断当前 2× 正结果主要体现背景容忍、真正的远距离读取，还是二者都有。

### 5.2 高背景 attention mass 不等于错误写入

对某个固定 head/query，设背景占总注意力质量为 $\beta$，其加权平均 value 为 $\bar v_B$，相关来源集合 S 的加权平均 value 为 $\bar v_S$。则

$$
o=(1-\beta)\bar v_S+\beta\bar v_B.
$$

在相同 Q/K/V 下，只允许 S 的注意力输出为 $o_S=\bar v_S$，故

$$
W_O(o-o_S)=\beta W_O(\bar v_B-\bar v_S).
$$

背景达到 no-op 可以来自投影后的 value 差异小、后续网络抵消，也可以来自背景质量减少。**强迫所有背景 attention 接近零，不是唯一正确的训练约束。** 如果对背景分类本身不准确，还会删除有用信号。

附件的 mass 恢复、写差缩小值得保留，但“筛选没学会”的机制判断需要与 value、输出投影及完整生成共同核对。[P1，第 18–22、45 行]

### 5.3 对数分解能消去纯数量因素

对单个 head/query，令前景、背景 key 数量为 $n_S,n_B$，分数的 log-mean-exp 为 $\ell_S,\ell_B$，则

$$
\log\frac{M_S}{1-M_S}
=\log\frac{n_S}{n_B}+\ell_S-\ell_B.
$$

$\ell_S-\ell_B$ 表示消去 key 数量因素后的分数偏好。记录它可以区分“背景只是更多”与“单个背景在模型中也更有竞争力”。先逐 head/query 计算再汇总；先平均 attention mass 再代入不再等于平均分解。

这是一条基本 softmax 恒等式，其新价值来自能否解释分配干预的真实生成差异，不能只因公式成立就写成新理论贡献。

### 5.4 深层表示漂移仍可能由位置干预造成

97.6% 的 logit 变化位于背景，首先要对背景和前景数量做归一化。深层 98% 属于表示漂移，并不说明位置编码没有起作用；前层频率干预完全可能通过表示传播成为深层漂移。[P1，第 36–37 行]

同理，Z0 与 ZF 使用同一 $R_{new}-R_{old}$ 不代表其直接 logit 改变量相同。后者是

$$
q^\top(R_{new}-R_{old})k,
$$

LoRA 改变 q、k 后它通常会变。若报告的 direct 定义只计算旋转算子本身，应该保留这个定义，不能进一步宣称两模型在内容条件下的直接相位贡献完全一致。

## 6. 在两项联合目标解决前，论文可以拥有怎样的强贡献

### 6.1 不把所有贡献绑定在一个最困难工作点上

一个科学上完整的指数分配结果，可以是：

> **固定旋转维数、采样范围、算子和适配协议，非几何分配在明确的条件下提高了有效上下文或适配效率；这种改善不能由已测试的几何 base 调整重现。**

这个命题能独立成立。零训练和 LoRA 的极低原生损失、强 4× 生成仍然是实际目标；它们尚未联合成功，不抹掉受控发现。

目前“分配重要”“几何表可以改变”已有文献基础。FMRoPE 研究 base 与训练长度，LeRoPE 已展示非几何频率、固定学得频率和不同干扰数的检索效果。[R8–R9] 因此，新实验应增加以下至少一项：更严格的干预识别、有用的性能边界、受控机制或可复现的适配成本收益。

### 6.2 审稿人可能被说服的三种结果

| 结果类型 | 需要的证据 | 不足以支撑的替代证据 |
|---|---|---|
| 分配突破所测几何调整的性能边界 | 公平测试多种 base/范围，比较同等原生代价下的真实生成 | 只赢一个失效的 uniform 或原生超窗基线 |
| 分配降低继续训练成本 | 同模型、同数据、相同 loss、相同 token 预算的学习曲线与独立测试 | 不同训练规模之间拟合一条“效率曲线” |
| 分配改变对干扰竞争的容忍 | 固定证据距离/采样范围，控制可见背景；真实生成随之改变 | 只画背景 attention mass，或仅说明更多干扰更难 |

新成功标准“4× 赢未微调 YaRN”适用于零训练比较。LoRA 或全参数臂的主要外部基线必须得到相同种类的训练；训练后的 Z 赢未训练 YaRN，不隔离指数分配的价值。[P1，第 6–10 行]

## 7. 5090 上的首选：base/范围与 exponent allocation 的性能边界

### 7.1 要回答的问题

**允许几何 RoPE 公平选择 base 后，非几何分配是否还带来可见收益？**

这直接针对“你只是换了频率，调 base 是否也行”的审稿疑问。它能够产出正向结果，而且主要是推理。

### 7.2 最小矩阵

固定 checkpoint、K、attention 实现、生成器、precision 和共同实际 logit gain。先把已冻结 Z 归一化为形状 $z_Z$；几何形状为 $z_G=k/(K-1)$。

选择三个事前固定的 log-span：

$$
R\in\{R_0,R_0+\ln2,R_0+\ln4\},\qquad a=a_0.
$$

每个范围都有两个形状：

$$
\omega_k(R,z)=\exp[-a_0-Rz_k],\quad z\in\{z_G,z_Z\}.
$$

共六格。这里变化的是相同形状在不同范围上的嵌入；这个小范围集合不等于几何 base 的全局最优搜索。若已有 base 开发结果表明某个更强的范围，应事前纳入，不能故意遗漏已知强基线。

另列原始 Native 和标准 YaRN 作为完整方法参考，各自保留其原始增益身份。**六格内的 pure-z 对比使用共同增益；完整方法比较不能拿它替代。** 为防增益偶然有利于某形状，主结果出现后只对两个最终形状增加一个共同第二增益，不展开新温度搜索。

### 7.3 模型与数据

1B 可以用于核对路径；主要能力确认优先使用已经出现 8K 正结果的 7B。同家族 1B/7B 证明规模上的可重复性，不是跨模型家族证据。Qwen 可作外部模型，但必须明确其预训练窗口；Qwen 原生 32K 内的 16K 结果不能冒充 4× 外推。

使用相同语义实例的 compact、near@8K、far@8K、near@16K、far@16K。前期 32 个旧开发实例只用于检查，正式使用新 128 个独立语义实例及其合法反事实版本；正式集不得调表或增益。

原生评价至少包含两个自然文本领域与短生成。`compact 57/64 versus 58/64` 是一个小任务切片，不能覆盖所有 Native 功能。主要报告绝对差和配对区间，不把已有 0.88 retention gate 自动改名为“几乎无损”。

### 7.4 主图与主张

横轴为预先选择的原生损失指标，例如 held-out ΔNLL；纵轴为固定长程任务的完整答案成功率。原生任务准确率另列约束，不把不同指标任意合成一个分数。画六个实测点及区间。

核心证据是：**Z 的某个工作点在相同原生代价内，超过所有已测试几何点。** 在独立数据和第二模型上保持这种关系，才可提升主张。若 8K 成立、16K 不成立，应分别展示。这仍是有效的条件性收益。

不根据六个点插值，声称已经求出了全局 Pareto frontier；使用“所测范围/预算内的性能边界”。不从已知失败配置重复采样直到方法显著。

### 7.5 预算

给这个研究块设置 10–16 GPU 小时的支出上限，具体行数与长度成本通过短吞吐测量确定。先补 7B 缺少的两个布局，确认正结果是否包含远距离读取，再做其余六格。它是有限对照设计，不是新曲线搜索。

## 8. 利用同一批输入补充：指数分配是否改变背景容忍

### 8.1 与已有实验的差别

附件已经有 branch/readout 和写差分解，本实验增加的是一个干预：**在证据位置和输入 token 位置不变时，改变允许参与注意力的背景集合。** 这样能对“总长门槛”作更具体的检验。

### 8.2 固定位置的控制

构造一个 16K 输入，标记必要证据、问题、结构 token 与背景。保留所有原始 position IDs，按嵌套集合允许 0、约 4K、全部背景 key 被读取，必要 token 始终允许。

遮蔽必须作用于每层相关 attention，而不仅是最后一层或 decode 阶段，否则早期表示已受到背景影响。保持 causal mask 与原有生成规则。记录位置保留和可见 key 数量。

这是知道相关来源的 **oracle 诊断控制**，不能作为真实部署成绩。它还会改变多层表示，因此另用固定 Q/K/V 的单层重计算测量纯分母效应；两种结果不能混称。

为控制长位置本身，可另加一个短物理输入、保留长距离 position IDs 的诊断格。它只用于区分距离与竞争，不能代替真实长文本能力测试。

### 8.3 要测的结果

主结果仍然是合法双证据版本上的完整生成。只额外保留 query/答案位置的前景质量、消去数量后的 $\ell_S-\ell_B$，以及投影后的写差。不导出所有层完整 $L\times L$ attention 矩阵。

如果删除背景竞争后各表都恢复，且 Z 在增加可见背景时更慢退化，支持其在该条件下提高了干扰容忍；如果即使遮蔽背景仍失败，4× 问题还包含位置诱导的表示/读取异常。若 oracle 只修复部分实例，保留这个部分范围。

LeRoPE 已经比较了不同干扰 key 数量的检索。[R9] 本实验的新增价值需要来自**固定频率范围、固定证据距离、受控可见性下的因果分解，并且与真实生成收益一致**。单独“非几何频率更抗干扰”仍然容易与先前研究重叠。

预算上限 6–8 GPU 小时，尽量复用实验 7 的输入与已有 Q/K/V。机制读数不支持明确结论时，不自动升级为新背景筛选 loss。

## 9. Pro 6000 上的首选：约 1.5B 模型的全参数继续训练

### 9.1 主要科学问题

**在同样的成熟模型、相同数据和继续训练预算下，改变 exponent allocation 是否能让模型更快获得长程能力，并达到更好的原生—长程折中？**

这条路线研究适配效率。它不需要先证明 LoRA 可以完成同样修正，也不依赖重新训练一个成熟基础模型。

### 9.2 三个训练臂

最低因果对照为两臂：

- G：固定范围的几何分配 + 全参数继续训练；
- Z：完全相同范围与增益的冻结非几何分配 + 相同继续训练。

为了形成有竞争力的实用方法比较，再加 Y：作者标准 YaRN + 同一训练数据、预算与算法。G/Z 承担纯分配归因，Y 承担外部方法比较。Y 与 G/Z 的增益不同须明确写出，不能把 Z–Y 全差归因于 z。

不训练位置参数，不为三臂分别发明损失。初始化、顺序、optimizer、监督目标、token presentations 和评估行完全一致。使用共同训练配置衡量这一算法下的分配效果；不声称已为每种方法求到各自最佳优化器。

### 9.3 从哪里开始、训多长

优先复用当前约 1.485B 的成熟 checkpoint。完整读取实际参数数、训练配置、显存和速度。

一个可预先冻结的初始预算是每臂 32M input tokens，最长物理序列 8K，所有 position IDs 不超过 8K，使用 4K/8K 混合，8K 占约 80% input tokens。32M、80% 都是工程预算，不是理论最优值。根据任何结果产生前的吞吐测量决定采用 32M 还是另一个所有臂相同的可承担总量。

以自然文本 next-token continued training 为主要监督，短输入中加入已有可靠指令回放以监测和保留原生行为。三臂相同。需要记录自然文本与指令实际参与 loss 的 token 数，不能只报告总输入。

这与旧答案微调的区别是明确的：更多查询位置受到监督，所有模型参数能协调适应新 kernel。它仍不保证学会长程检索；背景文本预测可能改进而证据使用不改进，所以任务生成始终是必要评价。

主要评估 4K/8K；16K 在模型选择冻结后评估。这样 8K 衡量学习到的扩展能力，16K 衡量超出继续训练长度的迁移。若以后改成训练包含 16K，应另立协议，准确称为原预训练窗口的 4× 扩展；不能沿用“微调未见 16K”的表述。

### 9.4 学习曲线与预算收益

固定保存点为输入 token 预算的 0、1/4、1/2、3/4、1。每一点记录原生 ΔNLL、原生生成、8K NLL、8K 生成及训练状态。选择 checkpoint 只使用 Native/≤8K validation。

两个直接可发表的效果是：

- 在同等 token 预算下，Z 提高 held-out 8K 能力且原生代价不更差；
- 在事前确定的能力/损失目标与原生约束下，Z 在更早的**实际保存点**达到要求，G/Y 在更晚保存点达到或未达到。

若某臂未达到阈值，报告“在本预算内未达到”，不给它虚构一个连续外推到达时间。不要用跨模型 scaling 曲线代替实际适配效率。

16K 是额外的未见长度测试。8K 的效率收益可以成立而 16K 仍失败，论文必须保留后者。

### 9.5 重复与停止

第一种子三臂都完成同样预算后再比较。若有实际收益，追加第二个配对种子和独立任务族确认；两种子可以报告各自结果，不能假装精确估计了所有训练随机性。若只有 NLL 好看而生成与原生保留没有形成工作点，降低能力主张，不立刻更换曲线或目标重启同一实验。

对总体“学习更快”的结论，两个配对种子及独立实例证据比一个大模型单种子的更大百分比更有价值。没有统一最低种子数能自动保证接收。

### 9.6 显存与时间

作为保守的内存规划，若每个训练参数使用 BF16 权重和梯度各 2 bytes、FP32 master 4 bytes、Adam 两个状态各 4 bytes，总计约 16 bytes/parameter。那么 1.485B 参数约 23.8GB，7B 约 112GB；还没有加入激活、临时缓冲区和 CUDA 工作空间。

这是所声明精度与状态布局下的估算，不是所有实现统一的占用。**96GB 能使 1.5B 全参长序列更现实，不能据此直接承诺 7B 常规 Adam 全参长序列可放下。** 用更低精度状态、offload 或不同 optimizer 会改变占用和比较条件。

三臂首种子给 24–36 GPU 小时上限，第二种子及确认给 16–24 小时上限。先用 20 个稳定训练 steps 测量 tokens/s 与峰值显存，再冻结共同 token 预算。时间是支出限额，不是已测吞吐。

## 10. 一个可选的基础研究实验：独立改变旋转频率数量

如果论文仍要以“finite spectral budget”作为主要解释，则已有改变 head 数量/宽度的 factorial 与 MLA 结果尚不能独立识别 K：它们同时改变了其他架构因素。[P2]

可做一个小模型 2×2：固定模型宽度、层数、head 数量与 head_dim，令旋转对数 $K\in\{16,64\}$，其余维度为不旋转维度；每个 K 内固定相同频率端点，比较几何与一个已冻结非几何分配。三种子共 12 次训练。

这不是默认新增项目。只有论文准备主张“分配提高了有限旋转通道的利用效率”，才值得挤出预算执行。它不需要成为 7B 实验；选用已有 100–200M 训练器和既有数据，预算根据吞吐预先限定。

强结果可以是较少旋转对的非几何模型达到较多旋转对几何模型的实测性能；普通结果只是形状效应在两个 K 上存在。**不提前假定收益一定随 K 减少而增大。** 位置冗余与内容通道用途可以相互作用，现有理论不足以强制这一单调关系。

减少旋转维数而保持 head 宽度不变，不自动减少 KV cache 或整体计算量。不能将位置通道效率宣传成已经得到的推理加速。LeRoPE 已包含 partial RoPE 比较，因此新意仍取决于明确的固定范围与 K 的干预及结果。[R9]

若总预算只能支持两个研究块，优先实验 7 与实验 9；这个 K 实验不与它们同时展开。

## 11. 如何把这些结果放进一篇统一论文

### 11.1 核心问题

> 固定旋转维数与采样频率范围后，exponent allocation 怎样改变 attention 中的位置—内容计算，以及模型需要多少适配才能把这种改变转化为长程收益？

三条原路线的关系是：从初始化训练观察不同分配下共同形成的 Q/K 耦合；零训练观察固定耦合可承受的分配变化；LoRA 观察受限参数更新能修复多少。全参数继续训练提供另一个成本可控、表达范围更广的参照。

### 11.2 主文中真正需要的三组图

**图一：独立分配效应。** 复用已有 fixed-support 三种子结果，附相同位移幅度的另一种非几何形状，避免把贡献收束成一个 Cosh 实例。

**图二：成熟模型的性能边界。** 展示 base/范围经过公平比较后，非几何分配在原生代价与真实生成上的实测位置；同时明确 2× 与 4×。

**图三：适配过程与背景竞争。** 展示相同预算的全参数学习曲线，辅以固定距离、改变背景可见性的受控结果。只有测得其预测力，才把背景竞争写成机制解释。

LoRA 的失败与原有成功都保留在实际范围内。它可以说明受限适配的困难，并为理论边界提供证据；不用给每条路线强行安排同样大的成功数字。

### 11.3 竞争力判断

仅有“z 是独立坐标”与“改表可能提升长 NLL”，不足以压过已有非几何频率、base 调整和频率学习工作。[R8–R9]

如果指数分配在调过 base 的几何边界上得到可复现收益，并在成熟模型上降低适配成本，已有多种子因果实验就能与新收益构成完整的经验论文。它不依赖证明一个任务无关最优频谱，也不要求宣称零训练在任意上下文长度有效。

若新增实验最终没有出现这种增量，写作无法凭“理论漂亮”补出方法收益；应按真实证据决定主张强度。这里没有接受概率保证。
