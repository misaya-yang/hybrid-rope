# ICLR 2027：非几何 RoPE 分配的大修研究档案

日期：2026-09-06。

依据：用户附件《THEORY_EXPERIMENT_SYNTHESIS(2).md》与 31 页《ROPE HAS A SPECTRAL BUDGET》，相关历史研究约束，以及 MrRoPE、YaRN、LeRoPE、AdaRoPE、How Data Shapes RoPE Frequency Usage 的原文。附件内所引用的底层实验回执未逐个提供；本文不将附件摘要视为已经独立复核的原始日志。

## 1. 投稿判断与主线

现稿最主要的 novelty——“把频率拆成支撑与内部 allocation，并证明 allocation 重要”——不足以独立承担主贡献。MrRoPE 已经在共同延展端点之间比较内部频率分配。继续推进有价值，但需要把贡献推进到：

> 在有限 rotary pair 数量下，非几何分配如何改变位置关系的可学习性、成熟权重的适配代价，以及保持原生能力时可达到的长上下文表现？

目标成果必须包含：能够区分分配方案的理论预测，以及对 MrRoPE-Pro、可靠 YaRN 和有竞争力几何方案的实测改进。改进可以体现为更好的长任务表现、达到同一表现所需的更少训练、或更小原生功能损伤。只增加符号、诊断图和案例不足以建立这一贡献。

建议工作标题：**Non-Geometric RoPE Allocation under Finite Adaptation Budgets**。其中“有限适配预算”包括零更新、LoRA、全参数继续训练；从零训练负责检验频率基底本身的学习效应。

## 2. 与 MrRoPE 的数学关系

令 Native 频率为 ω_j，修改后频率为 ω'_j。MrRoPE 的累积 radix 因子满足

    ω'_j = ω_j / ∏_{d<j} λ_d。

定义 x_j=-log ω_j、h_j=x'_j-x_j，则

    h_j = ∑_{d<j} log λ_d，
    log λ_j = h_{j+1}-h_j。

在固定首频率的条件下，h 和 λ 是累积量与相邻差分的两种参数化。固定末端位移相当于固定 ∑log λ。MrRoPE 的 Uni/Pro 在高、低频保护区都存在的标准设置下，共享 Native 高频端点和 Native 低频端点/s，而中间分配不同。附件论文成熟模型 pure-z 区块也使用这样的目标端点。

因此，“他们调 radix，我们调 exponent”和“我们固定端点”不足以承担主要区别。允许 λ<1 的一般参数化与论文具体的扩展策略要区分；本文不声称所有 Cosh 表都等于其实际 Pro 方法。

MrRoPE 的具体实验主要是零训练延展。新的研究要增加它尚未被当前证据回答的内容：同一有限频率表在不同学习预算下为什么发生排序变化，以及如何利用这种规律做出更好的选择。这里还必须考虑 LeRoPE 已研究可学习频率与从零训练、AdaRoPE 已研究频率与 LoRA 共同适配、Wu 等已研究数据依赖尺度与频率使用的关系。

历史研究中考虑过的 scale 复合一致性也需要正确定位：固定分段时，MrRoPE-Pro 可写成 ω_j(s)=ω_j(1)s^{-q_j}，已经具备乘法尺度的复合性质。该性质可作为构造约束。

## 3. 现有证据的重新定位

### 3.1 应保留的证据

1. 151.9M、三种子、相同支撑、相同初始化与 token 顺序的实验，是现有最干净的训练证据。它证明该协议下内部节点分配会改变训练后的结果。
2. 完整 sin/cos 二维子空间的分析，优于只比较 cosine 切片；慢频极限和 block-whitened rank 恒等式可作为基础引理。
3. 权重×频率表交叉和槽位置换，显示成熟权重确实依赖所学频率分工。
4. OLMo 上已有真实零训练恢复；现有 Z/coarse 表值得作为成熟模型候选保留。
5. Native 代价、总长度失败、正常 EOS 下错误实体、充分训练后排序改变，都是限定理论适用范围的证据。

### 3.2 主张必须与证据同步收紧

- 151.9M 主因果实验的训练长度只有 256，不能独自支持成熟长上下文的普遍规律。
- 50.9M factorial 每臂仅约 8.4M tokens；公式 Cosh 对 Geo 为 7/12 配置改善，与匹配指数曲线未拉开差距。它支持某些非几何形状有效，不能证明 Cosh 必要或默认强度最优。
- 1.485B 从零训练比较使用了不同 trainer，且仅一组配对；其作用是补充规模证据。
- 750M 的结果来自共同 Geo 父模型的继续训练，应归入全参数适配。
- 原生能力经 Native/long routing 保留，是路由策略的结果。主线固定表实验需要实际测量其 Native 损伤。
- Qwen 64K 旧结果使用开发任务集合，不能充当独立确认集。
- 原文的固定支撑和推理时支撑重定向比较，不等于识别了训练支撑×分配的普遍交互规律。

## 4. 六项会改变实验决策的核查

### 4.1 Y2 与 YaRN 原文不一致

附件 MD 将 smoothstep ramp、cos/sin gain=sqrt(1+0.1 ln s) 的实现称为“论文约定”。YaRN 原文定义的是旋转圈数 r 上的分段线性 ramp，并给出

    a(s)=sqrt(1/temperature)=1+0.1 ln s。

同时缩放 Q/K 后，attention logits 乘 a(s)^2。s=4 时 a≈1.13863，logits 乘子约 1.29648。按 MD 的描述，Y2 只乘约 1.13863，同时 ramp 也变化。因此其具体结果可以保留为一个变体，作为“忠实 YaRN”的归因需要纠正。

应冻结官方实现的版本与实际频率、振幅张量；另列论文公式复现作为核查。两个变体都零分，仍然不能推导这项约定无影响。

### 4.2 物理目标长度训练的必要性尚未确立

2K 与 16K 训练同时改变物理 token 数、相位跨度、可见竞争项和监督分布。该对照只否定了已测试的短训练配方。YaRN 原文还报告 64K 训练后评估 128K，故“训练物理长度必须达到测试长度”不是普遍必要条件。

旧稿 LoRA 使用显式 position IDs，4K 物理长度已经暴露 16K 相位。应分别记录 L_native、L_physical、L_phase、L_test。训练 16K、测试 16K 是对原生 4K 模型的上下文延展；训练后外推还需要评估超过适配暴露范围的长度。

### 4.3 p 值与小样本

3/64 与 14/64 的行级 Fisher 检验是否适用，取决于配对和组内依赖结构。现有摘要不足以验证这一点。主分析应使用真实随机化单位、配对提示与组结构。Qwen 20/32 与 23/32 未显著不同，也不能建立等效性或“不需要长数据”。

### 4.4 旧版 RULER 与新版严格成功不同

旧稿 OLMo 16K 的约 54–60% RULER 与新 MD 的 2/64 严格成功，涉及不同任务、评分、模式、可能不同频率表。用同一批输出同时计算官方分数、答案正确、格式正确、EOS 合规和联合成功，然后追踪差异来源。

### 4.5 同一个 Z 名称可能覆盖不同变换

历史对话出现过 ω'=ω s^{-m}；PDF Eq.8 使用 ω'=ω[(1-m)+m/s]。s=4、m=1/2 时分别为 0.5ω 和 0.625ω。名称不足以确定方法，应保存实际 inv_freq、gain、position IDs 规则和配置哈希。

### 4.6 “外部上界”与欠训练标签

Qwen1.5B 的 29/32 表明这个 checkpoint 在该评测配置下可行。其官方模型卡列出的该模型完整窗口为 32,768。现有来源不能证明这一结果由与拟议 OLMo 500M 预算等价的训练产生，因而不能推出本项目必能达到约 91%。

loss/EOS 持续改善、答案仍错，与欠训练相容，也与目标错配、优化困难、数据覆盖不足相容。DID_NOT_LEARN 是描述结果的标签，不能提前证明延长训练即可解决。

## 5. 理论主线：从位置基底转向可学习的有限分配

### 5.1 几何分配有一个明确的条件最优性

令 x_0=a、x_{K-1}=a+R。相邻 log-frequency 间隔 d_k=x_{k+1}-x_k 满足 ∑d_k=R，故

    max_k d_k ≥ R/(K-1)。

等号在所有间隔相等时达到。几何频率因而是固定端点下最小化最大对数尺度空隙的分配。此命题解释不偏重特定尺度时使用几何表的理由。

非几何分配将采样密度从一些尺度移到另一些尺度，需要说明任务、训练暴露或参数适配为什么使后者更值得占用有限通道。

### 5.2 当前慢频定理与主实验存在适用范围缺口

151M 主实验使用 b=L_train=256、K=32，其最慢通道相位为

    L_train ω_min = 256 × 256^{-31/32} = 256^{1/32} ≈ 1.1892。

这一配置没有 ωL≤1 的通道，更没有覆盖所有慢频通道的 ωL≪1 渐近区域。因此，慢频塌缩可以解释某些大 base 配置，却不能直接解释主因果实验的全部收益。主理论必须处理有限相位、训练支撑与目标支撑的联合关系。

所有纯位置几何依赖无量纲相位

    Lω_k = (L e^{-a}) exp(-Rz_k)。

因而跨 support 的设计原则至少要保留 K、L e^{-a} 和 R。τ=d_head/sqrt(L) 可以是特定约定下的经验参考，不能自动成为跨支撑的普遍定律。

### 5.3 一个可严格检验的有限学习模型

固定内容条件，令位置目标函数为 g(Δ)，所有候选表面对同一 g。定义

    Φ_z(Δ) = [cos(ω_1Δ), sin(ω_1Δ), ..., cos(ω_KΔ), sin(ω_KΔ)]^T，
    f_z,c(Δ)=Φ_z(Δ)^T c。

对训练距离分布 μ_tr 定义

    G_tr(z)=E_tr[Φ_z Φ_z^T]，b_tr(z)=E_tr[Φ_z g]。

训练损失为 1/2 E_tr[(f-g)^2]。连续梯度流的精确解是

    c_t = exp(-tG_tr)c_0 + G_tr†[I-exp(-tG_tr)]b_tr。

这里 b_tr 总在 G_tr 的值域中；零空间初值保持不变。目标距离分布 μ_L 上的误差精确为

    R_L(z,t)=E_L[g^2]-2 b_L(z)^T c_t+c_t^T G_L(z)c_t。

该式不要求 g 在每个候选表中都可精确表示。它显式保留了训练数据、目标任务、初始系数、有限训练时间、分配改变后的表示误差。t 是数学上的优化时间，不能未经校准换算成训练 tokens。

在可实现的特例中，e_t=exp(-tG_tr)e_0，目标误差等于

    e_0^T exp(-tG_tr) G_L exp(-tG_tr) e_0。

即使一个表在目标区间有较高 rank，只要目标使用的方向在训练中很弱，有限训练仍可能学不出该方向。

这个线性模型本身不是完整 Transformer 定理。真实 Q/K 系数依赖内容，深层网络还会改变特征。论文必须明确固定内容或线性化条件，并用完整模型检验预测的排序与失效边界。

### 5.4 慢频的有限学习代价：一个更具体的推论

取 m 个慢频率 ω_j L=εr_j，r_j 为互异正数且随 ε 固定。t=Δ/L∈[0,1]，距离测度有正定的 2m 阶中心多项式 Gram，例如均匀分布。使用物理 sin/cos 坐标，分别去除均值，组成中心化特征向量 Ψ_ε。

记 G_ε=E[Ψ_ε Ψ_ε^T]，特征值按从大到小排序。固定 m、r_j 后有

    λ_j(G_ε)=Θ(ε^{2j})，j=1,...,2m，ε→0。

于是最小特征值为 Θ(ε^{4m})，条件数为 Θ(ε^{-(4m-2)})。

证明概要：中心化 sin 的首项依次生成 t,t^3,...，中心化 cos 的首项依次生成 t^2,t^4,...。对 r_j² 的两个 Vandermonde 系统做常数可逆列变换，可逐项消去更低次数项，得到 ε^j[p_j(t)+O(ε²)]，j=1,...,2m。中心多项式 Gram 正定，使变换后的 Gram 与 diag(ε²,ε⁴,...,ε^{4m}) 在固定常数意义下可比；常数可逆变换保持这些渐近阶。

固定学习率的平方损失梯度流，学习最弱方向需要随 1/λ_min 增长的有效时间。使用随谱缩放的学习率或预条件器会改变时间关系；不能把这条结论直接当作 Adam 或 LoRA 的 token 下界。

这是聚簇 Fourier/Vandermonde 条件数理论在 RoPE 特征上的具体化。相关数学已有成熟文献，不能把幂次病态性本身宣传成首次发现。潜在的新贡献是：把它与任务相关方向、Native 适配成本和 finite-K 分配结合，并预先预测实际分配排序。

本次进行了 80 位精度 CPU 检查。ε 从 0.2 变为 0.1，最小特征值的 log2 比值分别为：m=1 时 3.998454，m=2 时 8.000094，m=3 时 12.000196，符合 4m 的渐近阶。附带脚本和 JSON。检查对象是解析位置 Gram。

### 5.5 统一零训练、LoRA 与全参数

在上述可控模型中令 c=c_0+B_A u。B_A 指定可更新的系数子空间。定义

    H_A=B_A^T G_tr B_A，d_A=B_A^T(b_tr-G_tr c_0)。

从 u_0=0 出发，有

    u_t=H_A†[I-exp(-tH_A)]d_A，c_t=c_0+B_Au_t。

零训练对应 u=0；受限适配对应受限 B_A；全参数系数适配对应 B_A=I；从零训练改变 c_0 和训练分布。

真实网络中，LoRA 的局部可更新函数空间由具体模块和当前 A/B 因子的 Jacobian 决定，不能仅由名义 rank 推出。历史 Fisher 结果可以用来描述局部补偿：

    H_eff=H_zz-H_zA(H_AA+λI)^{-1}H_Az。

它描述小扰动中适配后剩余的 Native 损伤。对大的 4× 频率修改，应使用实际函数变化验证；该局部式不保证全局可行或全参数成功。

### 5.6 Cosh 的地位

保留 Cosh 的明确 surrogate 与唯一解，删除“唯一正确频率分配”的暗示。原文高分辨量化公式给出

    D_K[ρ]≈(1/(12K²))∫ w(x)/ρ(x)² dx。

在正权重、给定同一失真模型的条件下，最优密度为 ρ∝w^{1/3}；均匀密度仅对应 w 常数。该公式与 Cosh 的二次 surrogate 具有不同假设，不能拼接成同一个严格推导。

理论工作的关键是让 w 或有限表风险来自明确的位置任务及训练条件。先对既有 Geo、Cosh、Z、coarse、MrRoPE 表作预测，使用未参与构造的支持范围或模型验证。理论可以只给有效条件下的排序或方向，但需要比 rank、位移 RMS 和简单旋转圈数更有区分力。

## 6. 总长度、相位跨度与干扰负荷

设证据 logit 为 s_*、干扰 logits 为 s_i，则证据注意力质量

    p_*=sigmoid(s_*-log∑_i exp(s_i))。

对于近似相同的干扰 logit μ，保持 p_*≥q 需要

    s_*-μ ≥ log N + log(q/(1-q))。

这是精确 softmax 关系在特例下的结果。它解释为何证据距离不变、总长度增大仍会降低注意力质量。完整回答还取决于 values、深层残差与输出决策，22.1% 证据质量不能证明全部几何问题已经解决。

用于区分解释的最低成本训练对照：

- A：2K 物理序列，连续原生 position IDs。
- B：相同内容和可见 token 数，position IDs 暴露 16K 相对距离。
- C：16K 物理序列，控制证据距离、答案形式和监督数量，增加真实干扰项。

B-A 识别已测试任务中的长相位暴露作用；C-B 仍需控制内容分布及竞争项差异，才能解释为负荷作用。可在固定 16K 输入上以受控可见键掩码做推理诊断，但训练成本、掩码和 position ID 影响要单独记账。

该实验的价值在于判断怎样的训练暴露足以完成适配，从而降低不必要的长序列训练成本。

## 7. 实验主矩阵

### 7.1 同一张表跨适配预算

成熟模型以 OLMo-2-0425-1B-Instruct 为主。初始频率表候选：

- 可靠官方 YaRN、MrRoPE-Pro；
- 现有冻结 Z/coarse；
- anchored EVQ-Cosh；
- 相同目标支撑的几何表；Native 作为参照。

零训练先覆盖候选。完整适配优先比较最强外部基线与预先选定的本方候选；其余方案共享较短里程碑。方法筛选的开发集和最终确认集分开。

主表所有方法使用一张为 4× 构造的静态表，在 1×、2×、4× 评估。任何动态缩放或路由作为另一个协议报告。每个训练表保存精确张量，LoRA/全参数阶段保持该表固定。

同一成熟 checkpoint 的零训练、固定一档 LoRA、全参数继续训练，使用相同训练数据、顺序、token 预算和评测。训练学习率可各自合理调节，但调参预算对称。训练消耗同时记录 GPU 时间与 token 数。

### 7.2 从零训练

复用已有 151M 三种子训练管线，最优先增加 MrRoPE-Pro 诱导的固定分配表，与 Geo/Cosh 在相同端点、相同 trainer、相同数据上比较。“诱导的训练表”是本项目对其频率表的使用，不能称为原论文已提出的预训练算法。

第二优先级是以一个更长训练窗口或另一个 support 验证理论提前预测的排序变化。避免把所有 K、base、长度、形状、种子一起展开。

从零训练主分析要提供随预算变化的曲线。现有充分训练后 Geo 反超的历史结果，是检验收益来自学习速度还是最终表示能力的关键对照。

### 7.3 外部确认

选择一个额外家族进行冻结表确认，或已有 7B 模型作规模确认；优先保留真正独立的任务集合。Qwen 按其原生 32K 记录 64K/128K，OLMo 按原生 4K 记录 8K/16K。不同绝对长度不汇成一个无条件“4×成功率”。

## 8. 评测与训练协议

主方法比较保留官方任务分数，另外给答案正确率、格式与停止行为、联合严格成功。自然任务报告对应 EM/F1；答案之外出现正确实体不自动等于任务成功。

Native 用静态长表实际评估 NLL 和生成任务，声明允许损失的绝对非劣界。置信区间按配对提示、文档或生成组计算；训练随机性用独立训练种子体现。组内多个答案不是多个独立种子。

主继续训练阶段用通用文本与 Native replay 建立能力；对特定 QA/RULER 家族的 SFT 可作为后续同配方比较。主确认任务应尽可能避免与专门训练的生成器同族。

教师 KL 应按被监督 token 数归一化。若张量形状为 [B,L,V]，某些 batchmean 实现只除 B，会使不同 L 的有效权重变化。先检查 reduction、mask、预测位置和缓存精度。Native 教师适用于原生保持目标；不应默认它对超出能力范围的长任务提供正确目标。

## 9. 优先顺序与预算

### P0：至多约 8 GPU 小时的资格核查

- 构造 MrRoPE-Pro、官方 YaRN、现有 Z 的精确表，核对 ramp、gain、位置索引、KV cache 和 chat template。
- s=1 行为一致性；相同频率表、相同模板下 logits 一致性；实际张量保存。
- 将旧、新评分应用于相同生成输出，查明 16K 能力差异。
- 检查 derived Z 的其他频率投影：float64/更高精度、伪逆阈值、正则和距离测度是否显著改变 U_k 与最终 m_k。已有 coarse≈derived，使这一核查尤其必要。
- 测量完整训练步的峰值显存和稳定 tokens/s，包含 backward、optimizer、CE、KL 和 checkpointing。

### P1：成熟模型关键比较

训练计划使用 16M/32M/64M 等可负担里程碑，具体总量由实测吞吐反推。对同一组候选读出零训练、LoRA、全参数的长任务与 Native 曲线。至少使最强外部对手与本方主要候选得到相同终止预算。

早期读出可以支持有限预算内的方案比较。边际仍负或 EOS 改善不能自动证明最终失败或必将成功。

### P2：理论判别实验

利用 P1 的已有检查点和 151M 管线验证提前冻结的预测。优先相位暴露 A/B/C 或 support 排序反转中信息增益最高的一项。理论相关性必须在新的 support、任务尺度或模型上保留。

### P3：复现与外部确认

预算优先补关键训练重复、外部确认和实际生成任务。追加大模型长训练与视频新实验的优先级低于这三项。

### 100 小时规划示例

- 8 小时：构造和训练资格核查。
- 48 小时：成熟模型主比较。
- 24 小时：从零训练补充与最关键机制对照。
- 20 小时：关键重复、外部模型与最终评测。

这是资源上限划分，实际 token 数取决于测量。500M tokens 三个臂合计 1.5B tokens；即使 100 小时全部用于训练，也需要平均约 4167 tokens/s。若 16K micro-step 为 60 秒且处理一条序列，则约 273 tokens/s，单臂 500M 就约 509 小时。显存放得下不等于项目预算内可完成。

## 10. 论文结构建议

1. **Introduction**：明确承认非几何分配已有工作。提出有限预算下何时有效、怎样选择、需要多少适配。
2. **Finite-table setup**：x=a+Rz、频率槽位约定、主方法与比较表；用 MrRoPE 映射说明共同设计空间。
3. **Learning theory**：几何覆盖的条件最优性；训练与目标 Gram；慢频条件数推论；适配空间的作用。正文保留能支持实测预测的结果。
4. **Allocation selection**：既有 Cosh/Z/coarse 的明确构造、适用条件、选择规则与独立验证。所有选择信息来源可追踪。
5. **Experiments**：同表×适配预算主矩阵；从零训练固定支撑验证；关键暴露实验；外部确认和 Native 保持。
6. **Limitations**：有限模型理论的范围、预测失效配置、真实计算预算与未实现的目标。

原有视频结果、较弱 factorial、单种子大模型 scratch 和复杂附属定理按对主结论的作用裁剪。主文应把空间让给 MrRoPE 正面对照、同表学习曲线和理论的独立预测。

建议三项贡献：

- 解释并预测有限分配在训练暴露与适配约束变化下的效应。
- 用共同频率表、共同数据、共同任务验证零训练到适配的关系。
- 在可靠基线前建立实际长上下文质量、数据效率或 Native 保持的优势。

## 11. 成稿判断

支持强投稿的证据组合应包含：至少一个明确的新增预测、强基线下具有实际意义的收益、独立确认，以及正确的统计和实现。只有同支撑因果效应、Cosh surrogate 唯一解和若干成功案例，尚不足以消解与 MrRoPE/LeRoPE/AdaRoPE 的重合。

若冻结能力接近而适配更省 tokens，这本身可以形成有价值的结果；若长上下文得分上升但 Native 大幅下降，需要考察是否真的改善了共同约束下的表现。每个结论均限定于完成的预算与模型范围。
