## What this directory is

[`../../README.md`](../../README.md) owns research routing, and
[`../../../HANDOFF.md`](../../../HANDOFF.md) owns live manuscript state. This
external-review bundle preserves three things:

1. an **independent recomputation** of every number in the current retrofit
   owners, done from raw `examples.jsonl` and from first principles rather than
   by reading `results.json`;
2. a **theoretical reframing** of what the retrofit result actually identifies,
   with the coordinate algebra worked out and verified numerically;
3. **plans** — experiments, manuscript changes, and a defect list — kept
   separate from evidence so neither contaminates the other.

Nothing here supersedes a canonical owner. Where this directory disagrees with
`../../attention-aware-retrofit/results/zero-training-deployment/SESSION_BINARY_S4_REAL_CONTEXT_RESULT_20260823.md`, the disagreement is about
*framing and completeness*, not about the numbers: every scalar in that owner
reproduced exactly.

## Epistemic labels used throughout

Every claim in this directory carries exactly one of these:

- **VERIFIED** — recomputed here from raw rows or from first principles, with the
  source file and hash recorded. Reproducible without trusting any prior summary.
- **RECEIPTED** — read from a run receipt whose file hash was checked, but not
  independently recomputed (e.g. peak GPU memory).
- **DERIVED** — an algebraic or numerical consequence of VERIFIED quantities,
  computed here.
- **HYPOTHESIS** — a mechanism proposal consistent with the evidence but not
  established by it. Never promote without the experiment that discriminates it.
- **PLAN** — not run. Has no evidentiary weight of any kind.
- **DEFECT** — a concrete error, gap, or unsupported claim found in existing
  material.

A plan, a preflight, a launch log, a probe, and a partial run are **not results**
and are labelled as such wherever they appear.

## Recomputation contract

`evidence/OPUS_RECOMPUTATION_20260823.json` was generated by a script that reads
only raw `examples.jsonl` rows and rebuilds every frequency table from the model
config. For each stored aggregate it records both the recomputed value and the
value found in the run's `results.json`. **All comparisons matched with zero
mismatches** (see `01`). Regenerating it requires the raw run trees on the
evaluation host; the file records the host-side `results.json` SHA-256 for each
run so drift is detectable without the trees.
