# ⚠ 本目录快照的 `qwen4x_power_read.py` 含有【反向判决】

**2026-09-11** · 由 Claude 在扫查撤回主张时发现

**本目录是审计快照，是历史记录，因此没有被改写。** 但读者必须知道：

本目录的 `qwen4x_power_read.py` 第 123 行写着

```python
print("  NEGATIVE: MrRoPE genuinely beats BM on Qwen at 4x. ...")
```

**这是错的。** `dd = BM − MrRoPE` 是 **NLL，越低越好** ⟹ **`dd < 0` 表示 BM 更好**。
这份快照会在判决分支上打印出与事实**相反**的结论。

**成因**：与造成"符号翻转"那个撤回主张的是**同一个符号错误**
（见 `../../CORRECTION_SIGN_20260911.md`）。

**已修复的版本**（含显式符号约定行、直接印出"谁更好"）在
`experiments/zerotrain_20260910/qwen4x_power_read.py`。
**若要从本目录取用脚本，请取修复版。**

**核对记录**：`diff` 过两份文件，**差异仅在我修正的那几行**——所以把修复版推回服务器
不会覆盖任何其它改动（这一点已核实，不是推测）。

**教训**：**撤回一个主张时，必须扫【代码与注释】，不能只扫 `.md`。**
自动化的读数器带着旧结论是最危险的残留——它不需要人再读一遍就会印出错误答案。
本次全仓库 `.py`/`.sh`/`.json` 扫查，该类措辞仅命中两处（本处与 `patch_dose.py`），均已处理。
