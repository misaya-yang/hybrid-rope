## 三·补 ★★★ **样本外检验：覆盖序【不】跨模型迁移**（本核验最重要的一条）

**做法**：理论是在 **OLMo**（θ=5e5, W=4096）上标定的。`ground_truth_tables.json` 里有
**28 个 Qwen2.5-3B 方法**带实测 RULER 分数——**模型、tokenizer、θ(1e6)、窗口(32768)
全都不同，且没有任何一个被用来构造该理论**。用 **Qwen 自己的常数**重算 `n_int`，
问它是否仍能排序。脚本 `oos_qwen.py`（**自带实现，不 import 理论的模块**——
以免它的 bug 被继承）。

| 分层 | n | `spearman(n_int, 128K accuracy)` | `n_int` 范围 |
|---|---|---|---|
| **36 行面板（基线 78.125）** | 14 | **−0.147** | 6.92 – 13.49 |
| **12 行面板（基线 64.444）** | 13 | **−0.473** | 0.00 – 8.62 |
| ~~合并两份面板~~ | 28 | ~~+0.487~~ | 0.00 – 13.49 |
| （理论自报的 OLMo 值） | 17 | **+0.926** | 9.08 – 18.26 |

> ## ⚠ **合并两个面板会造出一个虚假的 +0.487——这是 Simpson 悖论。**
> **两份面板基线不同（78.125 vs 64.444），12 行臂系统性偏低且 `n_int` 也偏低，
> 于是"把两堆不同的东西叠起来"就产生了正相关。分层后两块都是【负】的。**
> **⟹ 任何重复此分析的人都会踩到这个陷阱。已在此写明。**

**36 行面板的明细**（按 `n_int` 升序）——**覆盖最低的那个分数并不差，覆盖最高的那个分数最差**：

| 方法 | `n_int` | 128K % |
|---|---|---|
| `HighGapToLong` | 6.92 | 67.36 |
| `E1_s28_less` | 8.55 | **83.33**（面板最高） |
| `MrPro` | 8.58 | 78.12 |
| `LongBridgeSlower` | 8.80 | 80.07 |
| `MrUni` / `E3_BM_gain074` | 11.34 | 73.33 / 70.00 |
| **`E3_BM_gain1`** | **11.34** | **58.82**（面板最低） |
| `FullLagP2_Transfer3B` | 13.49 | 81.67 |

**⟹ 判决：`n_int` 在 Qwen 上没有预测力。**

### 这对下一步意味着什么（不是结论，是核验后的意见）

1. **该理论是【OLMo 族】的理论，不是跨模型定律。** 不应被当作"整场战役的统一解释"引用
   ——它的 ρ=0.926 是**族内**数字，族外是 −0.147/−0.473。
2. **P1 仍然值得跑**（8× 上 `n(1.5)` 是 0 与 7 的对比，那是 OLMo 内的干净判决），
   **但它的结论将是一条 OLMo 结果，不是一条律。** 预注册的措辞应据此限定。
3. **这独立复现了本战役反复出现的同一件事**：**结论不跨模型迁移**。
   我先前测到的"优势幅度差 112 倍"与这里的 ρ 从 +0.93 掉到 −0.15 是同一现象的两个侧面。
4. **★ 一个方法学收获**：**分层必须先做，再合并。** 本战役已有多次"合并/分层给出不同答案"
   （180 行 held-out 的 pooled +2.57pp 是 −5.37 与 +6.54 的加权平均）。
   **这一次是反向的：合并不是掩盖了信号，而是【造出】了一个不存在的信号。**

## 五、给下一步的建议（不是结论，是核验后的意见）

1. **P1 照原判据跑，是干净测试。加跑 `shift8x_wide`**（覆盖更高但有空洞）——
   两臂一起才能分开"覆盖"与"空洞"两条判据。
2. **不要把 `b4_wide` 当"覆盖越多越好"的证据**——它是该趋势的**上端反例**。
   理论的可操作区间是 `n_int ∈ [9,15]`。
3. **若 P1 主臂非零**，则 8× 上还应立刻测**内区代价**：`scale8x_wide` 把覆盖
   从内区搬到外推区，窗内（4096 行）应当掉——预注册已预测落在 [0.50,0.78]，
   那是这条理论的第二道可证伪关口。
