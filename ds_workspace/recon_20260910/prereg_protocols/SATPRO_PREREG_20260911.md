## 1. 协议（五臂共用）

- 面板：350 行选择面板 → 180 行 holdout 确认，两段串联（step42 教训：
  选择面板偏置实测 ~10pp 摆幅，**一切判决以 holdout 为准**，选择面板只作参考）。
- 主统计量：holdout pooled paired Δ vs BM（`holdout180/beta_b1p0.jsonl` 同行配对），
  辅以 length_cap 分层（4096 / 16384）。
- **guard（显式的取舍选择，用户可否决）**：4096 窗内层 Δ ≥ −5pp（BM 窗内 0.797）。
  GPT 建议 88%-of-native 更严，等价约 −8pp；取 −5pp 是因为我们目前没有
  holdout 上的 native 参照臂。此 guard 把 4K/16K trade 单方面定在
  "最多让 5pp 窗内"——这是价值选择，不是测量结果。

## 2. P9 exact_yarn（补上"论文转数变体 YaRN 从未上过任务面板"的洞）

- 盲预测（覆盖/面积账）：选择面板 ∈ [0.46, 0.60]，与 a1_b64 配对 |Δ| ≤ 4pp。
- 判决含义：≥ BM → A_m 账在 OLMo 上成立，Pro 灾难是 Pro 特有（支持不足）；
  < 0.40 → 面积账对前置形状失效，order 有独立代价（前置伤害）。
- **身份修正（2026-09-11 H1 审计后补）**：官方索引 YaRN 已测过且是灾难
  （72 行复核 16K=6.94%；fresh_72=0.1406，与 MrRoPE-Pro 同级）；官方实现是
  后置 ramp（sum_m 38.49），与本臂（论文 A.2.1 转数混合、前置、sum_m 42.91）
  是**两个不同算子**。本臂补的洞仅是"论文变体从未上过任务面板"，
  不再表述为"首次真 YaRN"。FOUR_CORNERS 的"YaRN 顶点"= MrRoPE-Uni 仍成立。

## 3. P10 reverse_pro（order 的最强探针，承认与 A 混杂）

- 两个竞争预测：纯面积账 → ≈ a1_b64/yarn（[0.46,0.60]）；
  前置失真代价 → 低于同面积均匀表。盲预测：[0.42, 0.58]。
- 干净读数是与 a1_b64（42.0 vs 43.33，同高 A、不同序）的配对差：
  |Δ|≤3pp → 高 A 区 order 不重要（OLMo regime 只看支持面积）；
  reverse_pro 显著低 → 前置失真可见，均匀/后置加载优先。
- 注意：本臂**不能**干净分离 order——带内单调 ε 族做不到等面积换序；
  它只是 2D (A, front-load) 散点里最远的第三点。

## 4. P11 step 阶梯 hi23/hi24（threshold vs 渐进，GPT 实验一的槽级版）

- 已有端点：hi25 (A=39) = 0.1121，hi22 (A=42) = 0.4893。
- 盲预测（渐进/覆盖剂量）：hi24 ∈ [0.20, 0.38]，hi23 ∈ [0.32, 0.46]，单调上升。
- 判决含义：两臂都 ≤ 0.18 → 槽 22 是阈值（r_sat 必须 ≤ 8 圈，GPT margin 阈值
  故事成立）；单调铺开 → 覆盖剂量故事成立，部分缩放（m<1）可用，
  Sat-Pro 的"早饱和"不再是必须。

## 5. P12 satpro_rs8_w3 vs a1_b64（全场最干净的等面积方法判决）

- A = 42.67 vs 42.00；同为高 A，结构不同（平台+桥 vs 均匀宽带）。
- 盲预测：选择面板 [0.48, 0.60]；与 a1_b64 配对 |Δ| ≤ 4pp（无强方向先验）。
- 判决含义：satpro − a1_b64 ≥ +4pp（holdout）→ 平台+桥设计在等面积下胜出，
  **Sat-Pro 家族获得存在证明**；≤ −4pp → 频谱跳变/桥有代价，均匀宽带已够，
  方法上应停在 a1_b64 类；中间 → 两者等价，用简单者。
