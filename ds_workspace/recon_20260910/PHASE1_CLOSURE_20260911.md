## 二、★ 结论（更正后的版本）

> ### **在每一个达到显著的测量点上，部署表 BM 都优于 MrRoPE。**
> ### **优势的【大小】是模型相关的（112 倍），但【方向】不翻转。**

| 测量 | `BM − MrRoPE` | t | 谁更好 |
|---|---|---|---|
| OLMo RULER 350 行 @16384 | **+34.59pp** | **+13.18** | **BM** |
| OLMo 连续 @4096 / 8192 / 16384 | −0.2546 / −0.3006 / **−0.8260** | +6.24 / +5.59 / **+6.68** | **BM** |
| Qwen1.5B 连续 @131073 | **−0.0074** | **−3.34** | **BM** |
| Qwen1.5B 连续 @65537 / @98305 | +0.0029 / −0.0014 | +0.93 / −0.19 | 均不显著 |
| Qwen3B RULER @32768 / @131072 | +4.44pp / +7.29pp | +1.43 / −0.96 | 均不显著 |
| Qwen7B RULER @131072 | +13.33pp | −1.43 | 不显著 |

**（符号约定：`BM − MrRoPE` 在 NLL 上越低越好 ⟹ 负值 = BM 更好。本文每一条都按此重算过。）**

### 并且这不是"差一点"

- **OLMo 上差距是 34.59pp / 0.826 nats**，t = 13.18 / 6.68
- **剂量曲线**：MrRoPE↔BM 族在 1×/2×/4× 上单调，**最优全在最大压缩端**，
  MrRoPE 端在每个长度上都被显著拒绝（t = +6.24 / +5.59 / +6.68）
- **Qwen 上三处任务对比全部不显著** ⟹ Qwen 侧是"未决"，不是"MrRoPE 赢"

## 三、整个计划里**唯一**大幅有效的改动是一个**标量**

| 改动 | 效应 |
|---|---|
| **gain（YaRN mscale）** | **+38.19pp (t=+15.05)**，350 行 |
| 全部频率分配改动 | **±5pp，且 out-of-sample 归零** |

**而且 gain 不是独立设计面——它是"频率表能不能工作"的开关**：

| 表 | gain 1.0 | gain YaRN |
|---|---|---|
| native | 0.2361 | 0.2351 |
| BM | **0.0371** | **0.4190** |

**同一张 BM，@gain YaRN 比 native 高 +18.4pp；@gain 1.0 比 native 低 −19.9pp（38pp 摆幅）。**
**gain 对 native 本身是零（+0.10pp, t=0.08）。**

**⟹ "gain 值 38pp"的正确解读：它让频率表生效，不是它自己有效。**
**⟹ 而 gain 是 YaRN 的【解析成分】——增益扫描测得最优正是 `0.1·ln4+1 = 1.1386`。**

**⟹ YaRN 的成绩单**：gain（解析）✅ / 频带（解析）✅ / **带内 ramp（经验选择）❌**
**—— 本项目全部失败都发生在那个经验的部分。**

## 四、解空间收缩结果（**没有留下指向"更好的频率表"的方向**）

| 方向 | 判决 | 依据 |
|---|---|---|
| 7 条"建模再求解"推导 | **关闭** | 全部 ≤ 部署表；`step42` out-of-sample −3.37pp |
| 12 个静态泛函作选择器 | **关闭** | 三类受控对；且**要选的东西不存在**（最优端固定） |
| 在 350/180 行上调参 | **关闭** | 选择效应 **4 次**，每次同一形状 |
| "慢端 ν 微调"（LongBridge） | **关闭** | 选择面板 +5.50pp → held-out **−3.31pp** |
| `S` / forcing 形状 / Fisher 代价 | **关闭** | 机器精度 / 符号错 |
| EVQ（冻结表替换） | **关闭** | τ=0.5/1/2 全部 acc = **0.0000** |
| 长度轴 @32768 | **关闭** | OLMo 全部臂 **0/48**（8× 硬崩溃） |
| ~~按模型自适应~~ | **关闭（本轮新）** | 它是"符号翻转"的推论，而翻转不存在 |
| **gain 轴** | **有大幅正效应的方向** | +38.19pp；**但它是 YaRN 的解析成分，不是频率分配问题** |
| **振幅轴（`m > 1`）** | ⚠ **仍然开着——我先前误判为关闭** | 见 §四·补 |
| 找一个与任务同向的廉价代理 | **仍未做** | NLL 在细结构上与任务反向，在粗结构上同向 |

> **⟹ 诚实交代：撤回"按模型自适应"之后，在【`m ≤ 1` 这一族内】没有留下任何指向
> "比部署表更好的频率表"的开放方向。唯一的正效应（gain）属于 YaRN，不属于本项目的议题。**

### 四·补 ⚠ **重要更正：`m > 1`（振幅轴）是族【外】的一条开放方向——我先前的收口过度断言了**

**核对（已穷举，不是抽查）**：把 `experiments/curvature_20260910/tables.py` 里
**全部 8 个表生成器**逐个实例化并取 `max(m)`：

```
m_C42V24  1.000   m_C42     1.000   m_interp  1.000   m_mrpro  1.000
m_smoothstep 1.000  m_turns 1.000   m_yarn    1.000   m_native 0.000
超过 1.0 的表数: 0 / 8        全场最大 m = 1.0000000000000002（浮点）
```

**⟹ 本 campaign 测过的每一张表都满足 `m ≤ 1`，即覆盖上限固定在 4×。**
本文档 §二 的"这一族"指的就是它。

**⟹ 于是 s8 的 8× 全零不是"模型不行"，而是【这一族的结构性后果】**：
`m ≤ 1` ⟹ 覆盖上限 4W ⟹ 8× 处**没有任何表能覆盖**，所以所有臂一起塌。

**这与另一条独立路线（`theory/COVERAGE_CEILING_THEORY_20260911.md`，Codex 线）汇合**：
那里用两条公理（能力封顶 `t_j(W)`；信号下限 δ）把表形式化为**深度轴上的窗覆盖**，
并指出绑定约束是 **`m` 的盒子（上限 4W）**，不是带内形状。
**两条路线从不同方向得到同一事实：`m ≤ 1` 是硬盒子。**
（该理论的处方 `scale8x_wide` = `1.5 × 宽带 BM`，即把整表抬到 `m ≤ 1.5`，
**是 `m > 1` 的第一张表，已预注册 P1–P5，本 campaign 从未测过。**）

> **⟹ 因此更正：指向"比部署表更好的频率表"的开放方向确实存在一条——
> 【振幅轴，`m > 1`】。它不在我测过的族内，所以本文档前四节的判决不适用于它。**

**并且两条路线给出同一个可检验预测**（值得优先测）：
**若 gain 的作用是补偿"槽被压到接近信号下限 δ 后留下的幅度缺口"，
则【最优 gain 应随压缩量单调上升】。**
本 campaign 只测了两个点（native：gain 无效应；BM：+38.19pp），**中间全空**。

## 五、**没有**解决的问题（诚实清单）

1. **Qwen 侧的"谁更好"实际上未决**：任务仪器与 NLL 仪器方向相反，且都不显著。
   有功效复检（30 篇新语料、按书聚簇 SE）**因 GPU 从实例消失而未跑完**。
2. **独立模型只有 2 个族**（OLMo-2、Qwen2.5）。第 3 个族的证据缺失。
3. **只测了 MrRoPE↔BM 这一条族**。别的族（EVQ 的加速方向、跨层/跨头分配、非单调表）
   是否也能提供一个优于部署表的点，**未测**——本项目只证伪了**这一族内**的改进空间。
4. **"救援量"是模型属性**（1.5B 与 7B 同族同 θ 同窗口，救援量 +0.18 vs −0.05），
   **但如何从预训练配置预测它，未答**。
5. **OLMo 的 native 在 1×→2× 之间从 2.98 跳到 7.24**——是崩掉不是渐差，
   所以"救援"这个量在 OLMo 上是阶跃的。

## 六、方法学产出（可迁移到别的项目）

1. **有符号对是低信噪比下唯一有效的设计**（两臂只差一个符号 ⟹ 面板级偏置全部抵消）。
2. **选择效应的形状是固定的**：选择面板正、held-out 零或负。本项目出现 **4 次**。
3. **`D_pattern` / `RATIO`**：区分"真修对了"与"改了一堆但净额碰巧为正"。
   gain 的 RATIO = **1.03**，频率表 **2.65 ～ 37.18**。
4. **NLL 与任务可以在细结构上反向**（走线：窗内 NLL −0.0234 t=−2.88 而 RULER@4096 −10.56pp t=−2.45），
   但在粗结构上同向。
5. **符号约定必须写出来**：本轮最贵的一次错误就是把它读反（见 §七）。
