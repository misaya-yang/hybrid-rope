### 2. YaRN / MrRoPE / 部署 BM 是同一单纯形的三个顶点（机器精度验证）

增量坐标下 `Lε` 是设计变量：
- **部署 BM**：`Lε` **逐点常数**（`+0.00175`，min == max）
- **MrRoPE**：`Lε` = **慢端一个点源**（其余全零）

**⟹ "MrRoPE 的中频改进"在理论上就是：把 forcing 从常数改成慢端的一个点源。**
第四个顶点（快端）从未被试过 —— **实测判决：角是坏的，最优在内部**。
→ `FOUR_CORNERS_20260911.md`

### 3. ⚠ 已更正：均值 NLL 与任务准确率**反向**移动（"带内免费"是被代理量误导）

原结论："带内重分配免费"（逐槽窗内梯度符号交替、均值 +0.0015，在 1 SE 内）。
**该测量没错，但把它当成【任务代价】的代理是错的。**

走线（`m(a)=(1−a)m_BM+a·m_a1b64`，5 档，**读数前规划**）给出：

| a | 窗内连续 NLL @4096 | t | RULER@4096 准确率（整行答对） |
|---|---|---|---|
| 0.00 | 2.955406 | — | — |
| 0.50 | −0.0178 | **−3.16** | |
| 0.75 | −0.0219 | **−3.20** | |
| 1.00 | **−0.0234** | **−2.88** | **−10.56pp (t=−2.45)** |

> **⟹ 窗内均值 NLL 显著【改善】，同时窗内任务准确率显著【变差】。两个都显著、方向相反。**
> **⟹ 正确表述：带内重分配在【均值 NLL】上不仅免费而且有利；它在【任务准确率】上有代价。**
> **"免费"还是"有害"，取决于量哪一个。**

**这统一解释了"5 条推导全部产出比 BM 更差的表"**：它们都在优化 NLL 型代理，
而 NLL 代理与任务准确率可以反向 ⟹ **不是推导算错，是目标函数选错。**

## 六·补 本轮的流程性教训（都已在服务器上遇到并修复）

| # | 问题 | 修法 |
|---|---|---|
| 1 | **嵌套 heredoc 静默失败**（`ssh '... <<"EOF" ... EOF'`）：外层引号吃掉终止符，文件**没被创建**却无报错 | **一律写本地文件 + `scp`**；部署后立即 `ls -la` 核验 |
| 2 | **`$ROOT` 未定义** ⟹ `--root "$ROOT/holdout"` 展开成 `/holdout`，最终测试写到了文件系统根 | chain 脚本里每个变量显式定义；启动时 echo 出来核验 |
| 3 | **重复启动**：等待条件相同的两条链会同时醒来；且 `setsid` 后 ppid=1，来源不易追 | 串行化 + 部署后核对 `pgrep -af` |
| 4 | **`pkill -f` 自杀**（模式匹配到自己的命令行） | 用中括号 `chai[n]` 且按 PID kill |
| 4b | **★ 同一个陷阱换了个形状又中了一次**：`while pgrep -f "[o]lmo_longnll"; do sleep; done` 之后的**命令体里**又写了 `python olmo_longnll.py` —— 中括号只保护了 `pgrep` 这一处，**命令体里的裸字符串照样自匹配**，等待循环永远不退出（空转了 1 分钟才发现） | **等待循环与被等待的命令【分开成两个文件/两次调用】**；或等待条件用 `pgrep -f` 之外的方式（如等输出文件出现）。**中括号只解决"grep 命令行自身"，不解决"同一命令行里的其它裸字符串"** |
| 4c | **补丁的「已打过」守卫假阳性**：`"native" in s and "np.zeros(64)" in s` 在**未打补丁**的文件上也为真（`"native"` 出现在 GEOMETRY_FREE 元组里）⟹ 跳过编辑并挂了一条会被 runner 拒绝的链 | 守卫只查**目标块内**的精确键，并追加一次**端到端 dry-run** 证明 |
| 4d | **外部击杀**：11:29:13 三个 runner 同时死，链脚本静默（没写 FAILED） | **每个 stage 声明完成条件（行数），由监督器重跑**——不假设进程会活到结束 |
| 5 | **runner 缺依赖时静默** | 每次构造表后跑一个**已知答案的自校验** |

> **共同点：都是「命令成功了但什么都没发生」或「发生了两次」这类静默失败。**
> **⟹ 纪律：部署后立即核验产物存在且内容正确，不信 exit code。**
