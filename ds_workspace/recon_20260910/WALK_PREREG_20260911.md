`verdict()` 的定义就是用户的 KKT 条件本身：
```python

else 'TRADEOFF' if deltas['16384'] > 0 else 'NO_LONG_GAIN'
```

**三个成员全部是 TRADEOFF**：长程赢，窗内输。合并数 +2.57pp 只是这两个反向数的加权平均。


## 四、★ 判据（写死）

**主输出**：五个 a 上的配对 (Δ4096(a), Δ16384(a))，各自 SE。**a=0 与 a=1 是内置对照**
（与已存的 `beta_b1p0` / `wide_b1p0` 必须逐行零差；不是零差 ⟹ 仪器变了，实验作废）。

**强零假设**：**线性**。因 a=0 处 Δ ≡ 0（构造上），线性模型给出 `Δ(a) = a·δ`，
用五个点拟合并报 δ 与残差。若线性成立 ⟹ 前沿是**过原点的直线** ⟹
**段上不存在任何"长程赢而不输窗内"的内点**。

| 观察 | 判定 |
|---|---|
| 存在被测 a>0 使 **Δ4096(a) ≥ 0** 且 **Δ16384(a) ≥ +4pp** | **前沿有内点 DEVELOPMENT_WIN 候选**。但按本 campaign 最贵的教训：**这是在同 180 行上定位的，必须先在【新数据】上确认才能称为结果**。本实验**只定位，不下结论** |
| 所有 a>0 的 **Δ4096(a) < 0**，且 \|Δ4096\| 与 Δ16384 均随 a 单调 | **段上是纯交易**。报**换算率**。解空间收缩：本段无 DEVELOPMENT_WIN |
| 其它（非单调、或符号混乱） | **仍未决**：报区间并停止 |

**必须同时报的**：
1. **绝对准确率**（BM 与各 a 在两个 cap 上）——Δ 大而两者都接近地板不算能力
2. **每个 cap 的逐任务分解**
3. **线性拟合的残差**——若残差大，说明响应有拐点，那才是要找的东西
