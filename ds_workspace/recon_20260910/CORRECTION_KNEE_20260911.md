## 三、`mechanism` 给出了一个**比 Σm 更好的量**，而且是机制性的

模型只在 `[0,W]` 上训练过。槽 j 压缩 `m_j` 后，它在距离 Δ 上的相位 = 原生在 `Δ·4^(−m_j)` 处的相位。
所以「Δ 上仍是被校准过的位置读数」⟺ `Δ ≤ W·4^(m_j)`；在测试区间 `[0,4W]` 上的覆盖：

```
coverage_j = min(1, 4^(m_j − 1))          C = (1/64)·Σ_j coverage_j
```

**拟合九点：`C` 的 R² = 0.938 / adj 0.929，优于 Σm 的 0.926 / 0.915**，而且它修好了 Σm 唯一排错的那一对（`a0p5`）。

这是本次行动里**第一个既优于经验拟合、又有独立机制论证的量**。而它的形式（`4^(m−1)` 在 m=1 处饱和）
正好说明：**`m=1` 是「无损迁移到 4× 网格」的那个点**——`ν=ω/4` 恰好是 4 倍长上下文模型的原生频率。

**角点定理**：`G_j(m) = 0.25·4^m − λ·4t_j(1−4^(−m))` 严格凸 ⟹ 每槽最优在**端点**；
`G(1)>G(0) ⟺ t_j < t* = 0.25/λ`。**⟹ 最优形状是转数坐标下的阶跃，不是 ramp。**

**我的 `step_hi` 族正是转数坐标下的阶跃**，已排在 OLMo 轨里；`t*∈[4,8]`（九点读出）
对应 `hi≈21–25`，而族的 `hi=22, 25` **正好落在里面**。已补 `hi=20`。

## 四、`sep-cause` 的零成本收缩

**候选空间是 3 维不是 5 维**（两条精确恒等式）：
- `mean(m) = S/64` **逐位相等（0.000e+00）** ⟹ 不是候选，是换单位
- `S = L_ramp + n_plateau`（残差 ≤7.1e−15）⟹ 固定 S 下**两者是同一个检验**
- `ν_held` 与 `n_held` 误差 **0.00e+00**，且 `ν_held/Σν ∈ [0.93, 0.99]`
  ⟹ **`Σν` 有 ≥93% 是一个整数的确定性函数**

实测配对 SE = **0.0262**。偏相关：`r(acc,S|·)=+0.782`；`r(acc,Σν|·)=+0.101`（原始 −0.868 **塌掉并翻号**）。
**Σν 基本出局（~85%）**；那 12pp **是 4.6σ 的真效应**；4 参数模型残差 0.0573 = **实测噪声的 2.2 倍**
⟹ **S 故事是被失拟打败的，不是被噪声打败的**。
