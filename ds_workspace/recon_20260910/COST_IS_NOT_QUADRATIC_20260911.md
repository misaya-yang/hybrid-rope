## 二、判决：二次 Fisher 模型**符号错误**

理论用的代价模型是 `D_j(m) ≈ ½ F_jj (ln4)² m²`——**随 m 单调递增的凸函数**。
实测**单调递减、且为负**。

**这不是"外推太远"的问题，是定性错误。** 原因一目了然：

`t_W = 4.754` 圈 / 4096 —— 槽 24 在窗内**本来就是混叠的**（一个周期只有 862 token）。
压缩把它降到 `4.754/4 = 1.19` 圈，**进了可读区**。这不是灾难性遗忘，这是收益。

**这一个事实同时解释了本轮之前的两次失败：**
- `derive_tstar`（`V≡const`）解出转数坐标阶跃 `hi*=25` —— 阶跃把最大的 `m` 放在最多的槽上，
  而那正是"代价"符号错得最厉害的地方 → RULER **0.1121**（部署 0.4167）。
- `V = 覆盖边际` 的不动点收敛回**部署 BM** —— 一个把代价当凸函数的模型，自然会回到平滑的在位解。

## 三、窗口结构：问题的正确形状

`t_W,j = 651 · (1/1.2276)^j`（OLMo，W=4096）

| 在 4096 窗内 | 槽 | 压缩的效应 |
|---|---|---|
| `t_W > 16`（混叠） | **0 – 18** | 有益——但需要 `m > 1` 才够，**不可救** |
| `t_W ∈ [0.25,16]`（可读） | **19 – 38** | 需实测（粗网格正在测 20/22/…/36） |
| `t_W < 0.25`（过慢） | **39 – 63** | 有害——压下去会跌出下端 |

在长程 `4W = 16384`：`t_D = 4·t_W·4^(−m)`，可读需 `t_W·4^(−m) ∈ [0.0625, 4]`。

**于是真正的矛盾不是"预算 vs 遗忘"，而是双边窗口覆盖：**

> **把 `19–24` 压进 4× 可读区（需要 `m = 0.86/0.72/0.57/0.42/0.27/0.12`，合计 2.965），
> 同时别把 `39+` 挤出下端，并且在 `25–38` 上做任何事之前先问清楚它到底有益还是有害。**

**注意 `19–24` 的需求合计正好是 2.965，而实测最优臂的 `S_entry` 是 2.907（C42V24）**——
即**赢家已经把可挽救的预算花掉了 98%**。这与本节的窗口结构一致。

## 四、这把什么作废了

| 作废 | 原因 |
|---|---|
| `D_j(m) ≈ ½F_jj(ln4)²m²` | **符号错误**（本节测量） |
| `derive_tstar` 整条路线 | 建立在该二次模型上 |
| 覆盖边际不动点 | 同上；它返回在位表正是该模型"凸代价"的产物 |
| `F_jj` 作为"损伤度量" | 它是 native 处的**局部曲率**，不是代价。`fisher_stability.py` 仍在测它是否至少是可复现的曲率 |
| 把窗内损失当"约束" | **它在快半上是收益。** 约束只对 `39+` 成立 |

**仍然成立的**（与 Fisher 无关，纯几何）：
- `Lε` 框架（BM 常数 forcing / MrRoPE 末端点源，机器精度）
- **四个角**：YaRN 两端 / MrRoPE 慢端 / BM 全带 / **快端（从未试过）**
- `S = 31 + Σ(19−i)ε_i`（10 个 case 机器精度）
- 缺角判决：**角坏、最优在内部**（同带上 b=3 显胜缺角，t=−3.98）
