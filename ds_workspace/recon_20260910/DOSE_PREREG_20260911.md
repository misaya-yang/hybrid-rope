# 预注册：压缩剂量曲线 a*(L)（写在读数之前）

**2026-09-11 ~14:15** · OLMo-2-0425-1B-Instruct · 连续仪器（tail-512 NLL，16 篇配对）

## 问题

今天的结论是**"最优压缩量取决于基座需要多少救援"**——但那是一个**方向**，不是**策略**。
要变成策略，需要**同一个模型上、最优点随长度的函数** `a*(L)`。

## 族（端点都是已测过的表，内部被夹在中间）

```
m(a) = (1−a)·m_MrRoPE + a·m_BM ,  a ∈ {0, 0.25, 0.5, 0.75, 1}
a=0 逐位等于 mrpro ✓   a=1 逐位等于 beta_b1_BM ✓
sum_m: 37.667 → 38.375 → 39.083 → 39.792 → 40.500
```

**选这条段落的理由**：它是**唯一已知会在模型间换号的那条线**（OLMo 上 BM 好 0.826、Qwen 上 MrRoPE 好）。

## 长度：4096（1×）、8192（2×）、16384（4×）

## ★ 判据（写死）

**主输出**：`a*(L) = argmin_a NLL(a, L)`，三个长度各一个。

| 观察 | 判定 |
|---|---|
| **a\*(L) 随 L 增大** | "基座越崩、压缩越多"在**长度轴**上也成立 ⟹ 自适应策略可表述为 `a*(救援量)` |
| **a\*(L) 恒为 1**（全线最优在 BM 端） | **最优点在本模型上不随长度移动**；杠杆故事只适用于**跨模型**，不适用于**跨长度** |
| **a\*(L) 有内点** | 存在比两端都好的表 ⟹ 那是本 campaign 第一个**有功效支持的内部最优**，需另做预注册检验 |

**我预测 a\*(L) 恒为 1**（因为两个端点在三个长度上都显示 BM 更好），
**但边际（margin）随长度增大**（0.255 → 0.301 → 0.826）。

**若确实恒为 1，则结论写作**：On OLMo the optimum is at maximum compression at
every length tested; what changes with length is the SIZE of the advantage, not
its location. ⟹ **跨模型换号、跨长度只换幅度**——这本身是一条清晰的结论。
