# 转数窗口：解释 YaRN/MrRoPE、跨模型族通用、并与 KKT 同构的一个理论

日期 2026-09-10。本文全部结论可当场复算；数值来源标注在每一处。

---

## 1. YaRN 家族的频带规则是"窗内转数"，不是槽位

`find_correction_dim` 通常被读成一条有两个手调常数的经验公式。它不是。

把 ω_j = θ^(−2j/d) 代入"该频率在训练窗内转过的圈数"

    turns_j = W·ω_j / 2π

解出槽位：

    j = d·ln(W / (turns · 2π)) / (2 ln θ)

这**逐字就是 YaRN 的表达式**，只是把它的两个常数认成了什么：

    slow edge:  ω = α·2π/W   ⟺  turns = α = 1
    fast edge:  ω = β·2π/W   ⟺  turns = β = 32

**所以 YaRN/MrRoPE 说的事情是：在训练窗内转数落在 [1, 32] 圈的频率进过渡带；转数更多的保持不动；转数不到一圈的自由缩放。**

当场验算（`experiments/curvature_20260910/tables.py: band_from_turns`）：

| 模型 | θ | W | 快边 W·ω/2π | 慢边 W·ω/2π | 推出的带 | 部署的带 |
|---|---|---|---|---|---|---|
| Qwen2.5-3B | 1e6 | 32768 | **31.8 ≈ β** | **0.93 ≈ α** | [23, 40] | [23, 40] ✓ |
| OLMo-2-0425-1B | 5e5 | 4096 | **30.1 ≈ β** | **0.92 ≈ α** | [14, 32] | [14, 32] ✓ |

**转数是无量纲的，所以同一个 (α, β) 自动落到任何 checkpoint 上**——这正是"通用"该有的形式，
也解释了为什么 MrRoPE 的改进**只在带内部**：两端点被 Σε = 1 锁定，形状只能改桥。

### 复现（机器精度）

| 调用 | 目标 | 结果 |
|---|---|---|
| `m_turns(1,32,θ=1e6,W=32768,d=128,ramp='mrpro')` | MrPro | max\|Δm\| = **2.8e−17** |
| `m_turns(1,32,θ=5e5,W=4096,d=128,ramp='beta1')` | 部署 OLMo BM | max rel = **1.16e−7**（float32 舍入） |

## 2. 三段式是 KKT 解的**形状**，不是设计

用服务器上已采的真实全模型全前缀梯度（`rope_unification_20260910/full_model_response.jsonl`，
6 行，Qwen2.5-3B，含 128K），算 ∂L/∂m_j = ln4 · ∂L/∂x_j：

| 区域 | 平均 |∂L/∂m| | 读法 |
|---|---|---|
| 保持区 槽 0–23（m=0） | **84.6** | 转数多、窗内分辨好，压它代价极大 |
| 过渡带 槽 24–39（自由） | 2.21 | 真正做选择的地方 |
| 压缩区 槽 40–63（m=1） | **0.062** | 转数 <1、窗内根本没分辨，压它**免费** |

所以：

- `m = 1` 出现在压缩边际代价为零处——**这是自由区，不需要任何设计决策**；
- `m = 0` 出现在约束绑住处（原生代价极大处）；
- **真正的自由只在两者交叉处**。

> **三段式不是被设计出来的，它是 `min L_long s.t. D_N ≤ ε` 的解的形状。**
> YaRN/MrRoPE/BM 之间的差别全部落在交叉处内部（桥的形状），这与"端点被锁定"一致。

**这是一个诊断量，不是能力声明。** transcript 记录的重复失败模式 R1（local-geometry →
capability 跳接，历史 10 次、4 小时内再犯 2 次）正是把这类量当结论。本文只用它来定位
**哪里**有杠杆，不用它宣称**多少**能力。

## 3. 为什么它们一般不是最优，以及最优在哪里

YaRN 家族把交叉处**手工固定**在 (α, β) = (1, 32)，**与模型无关**。而 KKT 条件说交叉点
的位置由该模型自己的两个边际曲线给出。

### 直接求最优（不靠扫描）

设快边落在槽 j，把它移入带内一格（即多压一个槽）的净代价是

    Δ(j) = ∂L_long/∂m_j  +  λ · ∂D_N/∂m_j

其中 λ ≥ 0 是原生约束的乘子。**最优快边是 Δ(j) 变号处**；慢边同理（把槽移出带 = 少压一格，取反号）。

**λ 从约束本身定**：`λ = max(0, −nᵀe / nᵀn)`，即 plan §5 的残差诊断。`e` 是长程梯度
（MrRoPE 表处），`n` 是原生梯度（native 表处）。

**这正是 `kkt_residual.py` 在测的两个向量**（已排队，~15 min）。所以最优边界是**算出来的，
不是扫出来的**——这是"直接找到最优"的正确形式，也是它与 KKT 同构的地方：

| 对象 | KKT 的角色 |
|---|---|
| 桥内每对相邻 gap 的价格相等 | 桥形状的最优性（plan §5 的 price_i = Σ_{j≥i} v_j） |
| 交叉点 Δ(j) = 0 | **带边界的最优性**——YaRN 用手调常数近似的那条线 |
| λ | 原生约束的影子价格，同时是 Pareto 斜率 dL*/dε |

### 可证伪的预言

转数阈值应当**随模型移动**，而 YaRN 把它们固定。所以：

1. 在 OLMo 上扫同一个 (α, β) 网格，**最优点若 ≠ (1, 32)**，则 YaRN 的常数被证伪，且新的
   (α*, β*) 是可直接迁移到其它模型的通用改进；
2. 若 = (1, 32)，则 YaRN 的规则被确认为跨模型最优，且它同时是 KKT 解；
3. 由 `kkt_residual` 算出的 Δ(j) 变号点，应当与扫描出的 (α*, β*) **在转数坐标下一致**
   —— 这是一致性检验，两者若不符，说明 λ 的估计或梯度口径有问题。

**三条都是结果。** 正在跑：OLMo 350 行面板（端点差 48.5 个百分点，是 Qwen 的 6.6 倍），
臂 = (1,16) / (1,64) / (0.5,32) / (2,32)，锚点 (1,32) 用归档的 41.67%，**不重跑**。

## 4. 已记录的混杂与限制

1. **Σm 随 (α, β) 变动**（OLMo 上 38.5–42.0，锚点 40.5）。窗内代价是 Σm 的函数（round 1），
   所以沿 (α, β) 的分差不能全归给形状。回执逐臂报 Σm。
2. **λ 的估计对口径敏感**：`kkt_residual.py` 用**窗内尾部 NLL**作原生度量，而 plan 的 D_N 是
   **output-KL**（无一阶项、二次型 = Fisher）。两者不等价，回执里写明这是一处已声明的简化。
3. **OLMo 上 16K 是 4× 外推**，与 Qwen 128K 同为 4×；两端点的对照是同一倍率，这一点是干净的。
4. 本文的梯度诊断只用来说明**杠杆位置**。任何"因为某个几何量变好所以能力变好"的推论都不被
   本文支持，且历史上已有直接反例。
