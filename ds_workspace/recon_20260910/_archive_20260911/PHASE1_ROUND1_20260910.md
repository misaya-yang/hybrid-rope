## 对账中发现的参照错误（已纠正）

驱动给**所有**臂装了 `gain = GAIN_YARN = 1.1386`，所以那条叫 `native` 的臂实际是
"原生频率 + YaRN gain"，而归档的 `Native` 用 `gain = 1.0`。32K 上：

| | NLL |
|---|---|
| 归档 Native（gain 1.0） | 2.03850 |
| 本run「native」（原生频率 + YaRN gain） | 2.08866 |
| MrPro（本run 与归档一致到 4e−4） | 2.08939 |

$$\text{MrPro 的总窗内代价 } +0.0505 = \underbrace{0.0502}_{\text{gain}} + \underbrace{0.0007}_{\text{频率分配}}$$

**所以下面的 table 里，`native` 那一行不是保真度下界**，而是"保持 gain 不变时，把频率
换成原生的收益"。保真度下界是归档的 Native（gain 1.0），本run 未测；已加 `native_gain1`
臂补测。**这与 L6 是同一类错误：仪器口径没与归档逐项对齐。**

## 结论

1. **整个中段族在窗内只动 ~5e−3 nats**，而 native 是最好的。所以"压得越少越贴近 native"
   只是**趋势**，不是全部：`incr_r0p5`（Σm 30.46）比 `yarn_lin`（30.10）和 MrPro（29.33）
   都差，而 `incr_r2`（27.89）几乎与 MrPro 齐平。**形状与总量都在起作用，且都不大。**
2. **窗内轴没有分辨力**。把 Σm 从 26.4 扫到 32.0、单调与非单调形状都算上，全部落在
   5e−3 nats 内，而 MrPro 距保真度下界仅 2.5e−4。**这些表在窗内是等价的。**
3. 因此**中段形状的选择必须由长程轴做出**。若 36 行 RULER 也分不开，结论就是
   **Qwen 上中段形状在这些仪器下不可辨识**——一条真正的负结果，也是最强的一种收缩：
   它意味着任何"更好的中段曲线"的主张在 Qwen 上都缺少可测依据。

这与 transcript 的 **R2**（"Qwen 128K 失败与用哪条中段曲线无关"）从另一侧吻合：
R2 是长程侧分不开，round 1 是窗内侧分不开。
