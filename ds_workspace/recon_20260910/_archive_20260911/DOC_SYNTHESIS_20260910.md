## 3. 仍然可用、而且价值最高的那一项：**排序因果实验**

文档 §十一 实验 1（它自称「回答'MrRoPE 为什么强'的**最高 ROI 实验**」）：

> **固定**：高频/低频端点、总 log-span、中段长度、gain、**{ε_q} 多重集**
> **只变**：增量的**顺序**
> Progressive（= MrRoPE）/ Reversed / **4 个预先固定 seed 的随机排列** = 6 张表
>
> 原话：「**这不是搜 6 条方法，而是一个排序因果实验。**」

**为什么它今晚特别值钱：**

1. **它是不依赖 g_long 的。** 它问的是"顺序是不是因果变量"，不是"梯度指向哪"——
   所以它**不受 kill 条件影响**，是文档里唯一一条既能回答核心问题、
   又不需要任何局部量的实验。
2. **它自己就带判决逻辑**（4 个结果各有含义）：
   - Progressive 稳定最好 → 顺序是 causal variable
   - 只有 exact-match 好、margin 不稳 → 收益主要是**阈值放大**（跨 argmax）
   - **随机排列中存在同样好或更好者 → 算术递增不是规律，只是一个幸运点**
   - cosine-sum 排序与任务排序不同 → 正式否定其任务充分性
3. **我们已有的数据已经偏向其中一个结局。** `<e, BM−MrRoPE> = −0.178` 对 `|e| = 92.4`
   近乎正交（cos = 0.115）——若顺序真是个有梯度的因果变量，一阶量不该这么平。
   子代理的原话：「已偏向'幸运点'结局」。
4. **成本极低**：6 张表，同带、同多重集、Σε=1 自动守恒，**零训练**，
   在 OLMo（效应 48 点宽）上 350 行/臂 ~12 分钟。

**⟹ 这是下一步要跑的实验。** 已实现并排队（见 §5）。

## 4. 后半里唯一可操作的东西（如果第一期走通）

三部分分解（doc-part1 抽取，坐标 `x_j = −log ν_j`）：

```
x_j = x_j⁰ + c + Σ_{i≤j} Δ_i
  c       全局平移           PI:          c = log S, Δ = 0
  A = ΣΔ  跨度预算（span）   YaRN/MrRoPE: c = 0,     A = log S
  内部 spacing transport      ← 文档原话：「我们真正要优化的是这一部分」
```

**这正好是用户问题的答案框架**：PI / YaRN / MrRoPE / EVQ 都在同一个坐标里，
差别是**把预算花在哪一段**。而「内部 transport」那一段，正是我们今晚测出
**窗内平、长程梯度零**的那一段。

**后半的 route–read 框架**（`Router PE ≠ Reader PE`）是另一个问题（稀疏注意力的
位置编码），**需要新训练**（150M–300M 四臂），按用户第 4 条 ROI 规则，
**在第一期走通之前不启动**。

## 5. 已实现：排序因果实验

新增 `m_order(perm)`：固定 MrRoPE 的增量多重集 `{2q/(n(n+1))}`，
只置换顺序。因为 ε > 0 恒成立，`m = cumsum(ε)` 必然单调，六张表全部合法
（ν 严格递减自动满足——native log-gap 0.2159 远大于任何 ε 的压缩量）。

`ord_progressive` 与 `mrpro_n17` **逐位相同**，是免费构造自检。
