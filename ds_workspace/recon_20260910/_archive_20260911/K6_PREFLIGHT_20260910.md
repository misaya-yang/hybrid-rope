## 结论

`NEXT_DERIVATION_KKT_PROBLEM.md:125` 与 `INTEGRATION_20260910.md:92` 把 K6 描述为

> `ν^fast_j = max(ν_j^YaRN, ν_j^MrPro)`、`ν^slow_j = min(...)`（= M_A+Y_B / Y_A+M_B 两种拼接），同端点、同 gain、保排序

并把它列为"最高优先 GPU 判决"（`INTEGRATION_20260910.md:111`）。

**按这个字面公式算出来的四格，不是"两种拼接"，而是对原表各改 2 个槽。**

| 量 | 值 |
|---|---|
| YaRN 与 MrPro 不同的槽位 | 恰好 16 个，`24..39`（与 `R1_ordering_and_tables.md` 一致） |
| `max(νY,νM)` 与 MrPro 相同的槽 | **62 / 64** |
| `min(νY,νM)` 与 YaRN 相同的槽 | **62 / 64** |
| 两者唯一不同的槽 | **38, 39** |
| `mY` 与 `mM` 的交叉位置 | 槽 37 与 38 之间（`sign(mY−mM)` 在 24..37 全为 +1，38..39 为 −1） |

所以四格实际是：

| 格 | 实际内容 |
|---|---|
| F00 | YaRN |
| F11 | MrPro |
| F10 "fast" | **MrPro**，把槽 38、39 换成 YaRN 的 |
| F01 "slow" | **YaRN**，把槽 38、39 换成 MrPro 的 |

判决表是按"中前段保护 vs 中后段压缩"两侧分工读的。而这个构造里，前段（24..37）**两格都取 MrPro**，后段（38,39）才分叉——它测的不是 A/B 两侧的分工，是**最后两个槽**的作用。

## 为什么会这样

`max/min` 是逐槽按频率大小取，而这个大小关系**在带内会翻转**：YaRN 的 `m` 前段比 MrPro 大（压缩更多），后段比 MrPro 小。取 max 就等于"每槽各自选压得少的那个"，结果几乎恒等于 MrPro。这不是拼接。

## 符合原意的构造

原意（`STARTING_POINT_YARN_VS_MRPRO.md:106`、本批文档 §2.2）是"A 的前段 + B 的后段"，那是一个**按分裂点取值的族**：

    ν^(s)_j = ν^Y_j  (j < s)
              ν^M_j  (j >= s)

当场验算（`s` 从 24 到 40）：

| s | 单调 | 取 YaRN 的槽数 | 相对 YaRN 最大变化 | 相对 MrPro 最大变化 |
|---|---|---|---|---|
| 24 | 是 | 24 | 0.124 | 0.000（= MrPro） |
| 28 | 是 | 28 | 0.124 | 0.098 |
| 32 | 是 | 32 | 0.103 | 0.111 |
| 36 | 是 | 36 | 0.028 | 0.111 |
| 40 | 是 | 40 | 0.000（= YaRN） | 0.111 |

所有 `s` 都保序（严格递减）✓，端点相同 ✓，增益可固定 ✓。四格在该族中是两端，而**真正有判别力的中间格在 s≈28 附近**（理由见附录的 η 交叉推导）。

注意 `s` 正是 K1 里"交点位置随 S 移动"要重推导的那个量（附录给出 S=4 时 s=28），`s` 因此有一个由推导给出、而非手选的默认位置。**把四格改成分裂族，等于把 K6 与 K1 接到同一条线上**——K6 不再是四个孤立点，而是沿 K1 预言的分裂位置做的一次判决。

## 因此

1. **按字面跑 K6 会浪费一次 GPU 判决**：四格里有两格只差 2 个槽，任何结果都无法归因到"前段保护"或"后段压缩"。
2. 建议的修正是把四格替换为**分裂族的判决**：至少包含 `s=24`（= MrPro）与 `s=40`（= YaRN）两端，以及中间的分裂点；**分裂点的默认值由 η 交叉给出（S=4 时 s=28）**，若要保留"四格"框架，就让 F10/F01 取该点两侧各一。
3. 这件事本身不改变 K6 的资格：它仍然零新参数、不置换槽位身份（每个槽拿到的仍是 YaRN 或 MrPro 的该槽频率，**没有跨槽搬运**），因此不触碰 V-E4。

## 附：分裂点 s 的理论默认值（η 交叉）

分裂族的 s 不必手选。文档 §2.2 的两个机制各自有一个可算的判据，而 MrRoPE 之所以在后段"更有效地承担尺度扩展"，判据是

    η_q(S) := −∂log ν_q / ∂log S

当场推导：YaRN 的 `ν_q = ω_q(1−t+t/S)`，`t=q/N` ⇒ `η^Y = t/(S(1−t)+t)`；MrRoPE 的 `ν_q = ω_q S^{−m_q}` ⇒ **`η^M = m_q`，与 S 无关**。两者都验证过。

于是：

| S | `η^Y > η^M`（YaRN 减速更多） | `η^M > η^Y`（MrPro 减速更多） |
|---|---|---|
| 4 | q ≤ 4（槽 24–27） | **q ≥ 5（槽 28–40）** |
| 8 | q ≤ 1 | q ≥ 2 |
| ≥ 16 | 无 | 全部 |

交叉点满足 `S*(q) = t(1/m_q − 1)/(1−t)`，在 S=4 时落在 **q=5，即槽 28**。

**这给出两件事：**

1. **文档 §2.2 的两段式说法被量化了。** 前段（槽 24–27）MrPro 的 η **更小**——它在前段的优势不来自 η，而来自 O(1/N²) vs O(1/N) 的扰动阶次（§2.2 第一项）。后段（槽 28 起）η^M > η^Y，第二项机制才成立。两个机制的作用区间由 S 决定，不是固定划分。
2. **K6 分裂族的默认分裂点是 s=28（S=4 时）**，而 s 随 S 移动——这正是 K1 要重推导的量。K6 因此不再是一张四位判决表，而是"沿 K1 预言的交叉位置切一刀"的一次判决。

**注意这与 m 值的交叉（槽 37/38）是两个不同的交叉**，不要混：m 交叉是"谁的压缩更深"，槽 37/38；η 交叉是"谁还在继续减速"，槽 28。文档把两件事都叫"中后段"，但它们的位置不同。

## 两条分裂族（都全程保序，已验算）

    A(s):  m = m^MrPro (j < s),  m^YaRN (j ≥ s)      "MrPro 前段 + YaRN 后段"
    B(s):  m = m^YaRN  (j < s),  m^MrPro (j ≥ s)     "YaRN 前段 + MrPro 后段"

`s = 24..40` 全部严格保序（ν 严格递减），端点与 gain 可固定，且

- `A(24) = YaRN`，`A(40) = MrPro`；
- `B(24) = MrPro`，`B(40) = YaRN`。

以这两族替换原四格，判决表就是 K6 的原意，而且是**曲线而非四点**：

| 观察 | 读法 |
|---|---|
| `A(28) ≈ MrPro` | 前段保护（改动阶次）是主因，后段压缩可让给 YaRN |
| `B(28) ≈ MrPro` | 后段集中压缩是主因，前段可让给 YaRN |
| 两者都 < MrPro | A/B 双侧配合是必要条件；任何单侧几何规则被判死 |
