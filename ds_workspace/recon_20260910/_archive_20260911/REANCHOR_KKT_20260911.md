## 0. 核心目标（原文，作为校验基准）

> RoPE 本质是非均匀离散傅立叶变换。低频负责外推/远距离，中频过渡，高频负责近距/native。
> YaRN：高不动、中过渡、低 /s 获得更多旋转分量。MrRoPE 改中频，是 YaRN 升级。
> **我们是 EVQ，是频率间距的预算：压缩高频侧的 log-frequency 间隔，把间隔让给低频侧，
> 使慢时钟之间更分散。**
>
> **核心问题只有一个：KKT 条件——最小化 in-window 损失，最大化外推范围/能力。
> 这一定是可以解析的数学问题。YaRN 类型（含 MrRoPE）和我们的 EVQ，本质都是在做同一个。
> 目的是寻找这个 KKT 的最优解析解，或近似最优策略。**

## 1. 更正：我一直在优化的东西，和 EVQ 是**两种不同的预算**

实测 log-frequency 间隔（Qwen 配置）：

| 表 | span | 快端 gap / native | 慢端 gap / native | 结构 |
|---|---|---|---|---|
| native | 13.600 | 1.000 | 1.000 | — |
| **YaRN / MrRoPE / BM** | **14.986 = native + ln4** | 1.000 | 1.000 | **平移**慢半段 |
| `evq_deployed`（项目发明） | 14.965 | 1.083 | 1.116 | 两端**都**往外散 |
| **`evq_shift` = 用户的 EVQ** | **13.606 ≈ native** | **0.824（压）** | **1.159（散）** | **重分配** |

**两个可分离的预算：**

```
Λ = span（log-frequency 总跨度）        shape = 槽在 span 内的分布
  YaRN/MrRoPE/BM : Λ = Λ_native + ln S   ←  买新间距
  EVQ            : Λ = Λ_native          ←  重分配已有间距
```

**我之前用的 `S = Σm` 度量的是「整体平移了多少」**，不是「间距怎么分」——
`Σm(evq_shift) = −24`，因为 EVQ 把中段频率**抬高**了（ν/ω 在槽 32 达 2.23）。

**两处具体错误，都已更正：**
1. 我拿 `m_evq_deployed` 当 EVQ 并推出「EVQ 没平台 ⇒ 到不了获胜预算」。
   **那不是 EVQ**（它两端都往外散），而且**EVQ 不需要平台**——它在另一个预算上。
2. **EVQ 从未在长程测过**（全部长程臂：beta×3 + turns×4，全是 YaRN 家族）。
   已排队 `chain_v9`（τ=0.5/1.0/2.0，OLMo 16K，350 行）。

## 2. 更正之后，KKT 的形状清楚了

**约束侧**（二阶）：`D_N = ½ Σ_j w_j (δ ln ν_j)²`，`w_j` = 槽 j 的输出 Fisher 敏感度。
Phase-0 实测方向：**槽 0–23 极贵，槽 40–63 近零**。

| | 对 `δ ln ν` 做了什么 | 窗内代价 |
|---|---|---|
| **span-extension** | 慢半段**整体平移** −ln4（常值） | **≈ 0**（实测 29 臂全在 0.005 nats 内） |
| **EVQ** | 中段抬高（ν/ω 到 2.23）→ 扰动的正是**高敏感**槽 | **+0.087**（τ=1）、**+3.17**（τ=2） |

> **span-extension 之所以窗内免费，是因为它把全部扰动放在低敏感度（慢）槽上。**
> **EVQ 之所以要付费，是因为重分配必然扰动中/快槽。**

**而三个事实正好互锁：**
1. span-extension 的窗内代价 ≈ 0 ⇒ 它**深在可行域内部**（约束松弛）
2. 而它的长程分数跨度巨大（7% → 54%）⇒ **决定它的是另一侧**
3. EVQ **不在内部**——它在**约束面上**交易

**⟹ KKT 的自然形态：**
```
min  L_long(Λ, shape)
s.t. D_N(Λ, shape) ≤ ε
```
- span-extension 走的是「增大 Λ」这条路，**约束松弛**，所以最优在它能达到的边界
- EVQ 走的是「重分配 shape」这条路，**约束 binding**，所以最优由边际交换率决定

**这解释了为什么三段式结构是对的**：平台 `m=1` = 「把慢槽平移满一个 radix」
（最大有用平移，且低敏感度）；`m=0` 平台 = 「不动快槽」（高敏感度）；
ramp 是两者的连接。**它恰好是把预算全部花在低敏感度槽上的结构。**

## 3. 因此真正该问的问题（三个，都可解析）

**Q1（EVQ 的边际交换率）**：EVQ 花 ΔD_N 换来多少 ΔL_long？
对比 span-extension 用同样的 ΔD_N 能换多少。
**这条从未测过，`chain_v9` 是第一测。**

**Q2（span-extension 的上界在哪）**：Λ 能买到多大？`Λ = Λ_native + k·ln S`，
k 能不能 > 1（即压缩 4² = 16 倍）？已排队 `chain_v7`（β=128/256）与 `chain_v6b`（b=3–8）。

**Q3（在固定 Λ 下，shape 的最优解析解是什么）**：这才是「中频过渡」那一段。
实测：`beta_b0p25`(S=38.465) 与 `turns_a1_b16`(S=38.500) **差 12pp** ⇒ **shape 有独立效应**。
已排队 `chain_v8`（`step_hi` 族）分离「预算」与「集中度」。
