# 为什么：把今晚全部理论与全部实测放在一起

**日期**：2026-09-11 凌晨
**触发**：用户要求「多分析一下为什么，结合之前的理论和需求，对那么多理论不能抓瞎」
**结论**：**操作变量是一个全局积分量（预算），不是任何局部量。这一条同时解释了
今晚三次收缩、三个赢家、以及 EVQ 为什么输。**

---

## 0. 先说方法

我把 16 个**只从表本身算出来、不花 GPU** 的候选量拿去对 9 个 OLMo 实测分数，
并且用**配对判决**（两个臂在某个量上相同、分数却差很多 ⇒ 该量被证伪）。
代码 `experiments/zerotrain_20260910/why.py`，可复算。

**先说清楚**：9 个点里有 4 个是同一族，相关性高是弱证据、相关性低是**强**证据。
所以下面只用**负结果**和**配对判决**下结论，不用最高相关下结论。

**最后三行是重点**：间隙规整度与谱洞——**正是部署 BM 的构造目标**

> **BM 之所以好，不是因为它优化了那个目标。** 这独立确认了 KKT_ANALYTIC §1.2
> 的**证明**（Dirichlet 能量不是 Fisher 损伤型）：那个目标从一开始就不是原因。

**16 个候选里没有一个在配对判决上超过 3/5。** 也就是说：**没有任何静态表量
能解释数据。**

## 2. 为什么所有局部量都失败——一个统一解释

今晚的两次收缩说：

- 长程梯度在频带内**恒为零**（`<e, BM−MrRoPE> = −0.178` 对 `|e| = 92.4`）
- 窗内代价对形状轴 ≈ 0

而 16 个候选量告诉我们的进一步事实是：**能追踪分数的量全是全局积分量**
（`Σm`、`Σν`、交叉槽位），而**所有局部/逐槽量都失败**。

> **统一解释：操作变量是一个跨越整个频谱的积分量。**
> `∂L/∂m_j` 在任何单点取值都看不见它——不是梯度算错了，是**它本来就不可见**。

这解释了 LESSONS L1 那 10 条同型失败、Pro 文档的 kill 条件被触发、
以及为什么这一整晚没有一个局部量预测到任何事。**不是运气差，是维度错了。**

## 4. 关键在于：**约束就在那里开始咬**

把窗内代价曲线（Qwen，32K 列，逐长度 offset 已除）与预算对齐：

| mean(m) | 臂 | 窗内代价 |
|---|---|---|
| 0.536 | `leak_a0p005` | −0.0038 |
| **0.572** | `leak_a0p01` | **−0.0060（最便宜）** |
| 0.633 | `beta_b1`（部署 BM） | −0.0013 |
| **0.644** | `leak_a0p02` | **+0.0026 ← 转正** |
| 0.691 | `power_p2` | **+0.0406** |
| 0.734 | `power_p4` | **+0.0668** |

> **窗内代价在 `mean(m) ≲ 0.63` 上为零甚至为负，此后急剧上升。**
> **而三个赢家全部落在 `mean(m) = 0.656–0.662`——正好在拐点之后一点点。**

**这就是 KKT 的形状**，只不过它不在形状上，在**预算**上：

```
min  L_long(预算)      ← 单调递减（越压越远）
s.t. D_N(预算) ≤ ε     ← 拐点在 mean(m) ≈ 0.63
⟹ 最优在约束边界上，即 mean(m) 刚过拐点
```

**λ ≠ 0，约束是 binding 的——只不过 binding 在预算轴上，不在形状轴上。**
（而 `kkt_residual.py` 第一次测出来 `λ̂ = 0`，正是因为它在**形状轴**上求的 λ。
轴选错了，所以影子价格是零。）

## 5. 这直接回答了 EVQ 为什么输——而且是**结构性**的

`evq_deploy` 家族（全局 companding，两端 m=0 与 m→1）：

| τ | Σm | mean(m) |
|---|---|---|
| 1.0 | 29.575 | 0.462 |
| 1.414 | 27.554 | 0.431 |
| 2.0 | 24.370 | 0.381 |
| 4.0 | 15.420 | 0.241 |

**EVQ 的 mean(m) 全部远低于 0.63。** 而 τ→0 的极限是均匀 ramp，mean(m) → 0.5 左右。
**EVQ 的参数化根本到不了获胜预算。**

**为什么？** 因为**它没有平台**。三段式的 `m=1` 平台（OLMo 上是槽 33–63，31 个槽）
贡献了 Σm 的绝大部分；一个处处 `m<1` 的光滑 companding **在结构上就无法沉淀那么多预算**。

> **三段式相对 EVQ 的真正优势，不是"保护高频"，而是"能把预算沉淀成完全压缩的平台槽"。**
> 保持区留在 m=0 **不是**为了保护高频——§1 已经证明那个论证是错的。
> 它是为了**让预算花在别处并且花满**。

**这是一条可行动的结论**：给 EVQ 加一个平台（即 `ε ∝ k(C−k)` 或 `m_mixC`），
它就能达到获胜预算。**`mixC` 族已实现，正在 support2 里跑。**

## 6. 可证伪的预测（已排队）

**预测**：分数随 `mean(m)` 上升，在拐点附近达峰，**然后掉下来**。

已排队 `chain_v6b` 的 b=3/4/6/8（OLMo 几何）：

| 臂 | Σm | mean(m) |
|---|---|---|
| `beta_b3` | 43.637 | 0.682 |
| `beta_b4` | 44.534 | 0.696 |
| `beta_b6` | 45.723 | 0.714 |
| `beta_b8` | 46.474 | 0.726 |

以及 `chain_v7` 的 β=128/256（带 [7,32] / [4,32]，预算更高）。

- **若分数继续涨** ⇒ 预算轴还没到顶，继续推，**并且拐点说在别处**
- **若在 mean(m) ≈ 0.68–0.73 掉头** ⇒ **KKT 读数确认**，最优 = 约束边界，
  并且我们**第一次有了定量的 λ**

**两条都是结果，且都是定量的。**

## 7. 诚实的边界

- 拐点比较用的是 **Qwen 的窗内曲线** 对 **OLMo 的分数**。`mean(m)` 是可比化后的量，
  但两个 checkpoint 的窗内代价曲线**没有同时测过**。**这是本分析最弱的一环。**
- 9 个点、4 个同族、无 seed 重复。
- `Σm` 与 `mean(m)` 相关 0.96 但**不充分**：`beta_b0p25`(Σm 38.465) 与
  `turns_a1_b16`(38.500) 差 12 个百分点。**预算解释大部分、不是全部**，
  剩余的 12pp 说明**花法仍有独立效应**。
- 因此本文的立场：**预算轴是主变量（这是新结论），形状轴是次变量（不是"不存在"）。**
  这与今晚之前"形状是主变量"的整个工作重心相反。
