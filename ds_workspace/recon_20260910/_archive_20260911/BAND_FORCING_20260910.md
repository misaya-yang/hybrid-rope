## 2. BM 是关于增量粗糙度的**唯一极小点**

归档代码 `scripts/analysis/build_boundary_matched_mrpro.py` 自己写明了目标：

```
minimize   Σ_{i=0}^{N} (ε_{i+1} − ε_i)²
subject to ε_0 = ε_{N+1} = 0,  ε ≥ 0,  Σ ε = 1
```

并用**精确 Fraction 高斯消元**独立求解，断言闭式解与独立解一致（否则 raise）。

**这不是启发式，是一个定理。** 该目标的 Euler–Lagrange 方程是二阶的：

```
∂/∂ε_k :  2(2ε_k − ε_{k−1} − ε_{k+1}) = λ     ⟺     L ε = const,  L = 三对角 Dirichlet Laplacian
⟹  ε = c · L⁻¹ 1  ∝  k(n+1−k)                  （离散 Poisson 方程，零 Dirichlet 边界）
```

归一化给出 `ε_k = 6k(n+1−k)/(n(n+1)(n+2))` —— **正是部署 BM**。

**为什么 `ε_0 = ε_{n+1} = 0` 不是假设而是结论**：`ε_k := m_{lo+k} − m_{lo+k−1}`，
所以 `ε_0 = m_lo − m_{lo−1} = 0 − 0`（快侧平台）而 `ε_{n+1} = m_{hi+1} − m_{hi} = 1 − 1`
（慢侧平台）。零边界条件 = **m 在频带两侧都贴住了上下界**。频带本身就是
`m ∈ (0,1)` 的**活跃集**。

---

## 3. 两张部署表是同一个算子的两个 forcing

把零边界条件写进算子后，一切都是 `L ε = f`：

| f | 解 ε | 是哪张表 |
|---|---|---|
| `f ≡ const` | `ε ∝ k(n+1−k)`（抛物线） | **BM** |
| `f = (2/n)·δ_n`（**只作用在最慢一圈的点源**） | `ε ∝ k`（直线） | **MrRoPE** |

**数值核实（n = 18）**：

```
L⁻¹(1) 归一化后 − 抛物线            最大偏差 1.4e−17
L @ ε^MrRoPE  逐项：内部全部精确为 Fraction(0)，只有最后一格 = Fraction(1,9)
```

即 MrRoPE 的直线ramp 是**精确地** `L⁻¹[(2/n)δ_n]`，不是近似。

**粗糙度比值是闭式**：`R_mr = 4/(n(n+1))`，`R_bm = 12/(n(n+1)(n+2))`，
所以

```
R(BM) / R(MrRoPE) = 3/(n+2)          n=18 → 恰好 0.15；n=17 → 0.1579
```

且 `R(BM) = 0.00175 < R(uniform) = 0.00617`，抛物线确实在受约束集上取到下界
（归档代码用精确 Fraction 高斯消元独立确认过同一件事）。

> **MrRoPE ＝「只在频带最慢端加一个点源」的 Green 函数响应；
> BM ＝「均匀 forcing」的响应。** 两者是同一个椭圆算子的两个右端项。

这解释了 L2 里那条看似矛盾的事实：MrPro 在「处处不比它更压缩」的表里粗糙度最小，
但 BM 的粗糙度**更小**——因为 L2 的比较集不含「端点增量归零」这个条件。BM 不在 L2 的
比较集里，两者不冲突。

## 4. 推广到测量：解析预测

真实问题的 forcing 是**长程损失的梯度**，不是常数也不是点源。于是

```
min_m  gᵀm      s.t.   ½·(增量粗糙度) ≤ δ,   0 ≤ m ≤ 1
        g := ∂L_long/∂m        （kkt_residual.py 测的就是它）
```

KKT：内部（μ = 0，即 m 严格在 (0,1) 内）

```
L ε = −g/λ        ⟹        ε = −(1/λ) L⁻¹ g
```

**即：最优增量剖面 = 长程梯度被 Dirichlet Green 函数磨光后的结果。**
频带 = 盒子约束 `0 ≤ m ≤ 1` 的活跃集，自然涌现，不需要手调。

- g 平坦 → 抛物线 → **BM**
- g 集中在慢端 → 直线 → **MrRoPE**
- g 集中在快端 / 其他形状 → 第三种表，**目前没人测过**

**模型相关性只从 g 进来**。这正好解释了「(α, β) 频带规则是模型无关的常数近似，
而最优 *形状* 逐 checkpoint 不同」这一对现象。

## 5. 可证伪的预测（**写在看结果之前**）

已测量的长程梯度（Phase 0，Qwen，MrRoPE 表上）：槽 0–16 端**大且为负**（均值 −21.7，
最大 |·| 27），到槽 40 衰减到 ≈ 0；压缩区 40–63 已 ≈ 0.062。

把它当作 forcing：`f = −g/λ` 在**快侧大、慢侧近零**。Green 函数对快侧点源的响应是
一个**峰值靠近快端的帐篷**——也就是「**前端压得急、后端压得缓**」。

对应到正在跑的 beta 族 `ε_k ∝ k(n+1−k)^b`：

| b | 形状 | 前端/后端 |
|---|---|---|
| 0 | 直线（= MrRoPE） | 后端陡（末增量最大） |
| 1 | 抛物线（= BM） | 两端缓、中间陡 |
| **> 1** | 前端平、后端平、中段更陡 | **前端更急** |

> **预测 P1**：如果 forcing 确实偏快侧，最优 b **> 1**，且在 OLMo 上比 Qwen 更明显
> （OLMo 的效应宽 48 点，Qwen 只有 7 点）。
>
> **预测 P2（判别性）**：把实测 g 代入 `ε = −(1/λ)L⁻¹g` 得到的剖面，
> 应当比 MrRoPE 和 BM **两者都好**。这是「不是搜索，是解出来」的直接检验。

**P1 的检验已经在 GPU 上跑**（OLMo `--betas 0.25,0.5,2.0`，Qwen round 2 `b=0.25,0.5,2.0`）。
**b = 2.0 是 P1 的判决臂**：若 b=2 双向都输给 b=1，则 forcing 不是快侧集中的，
`L⁻¹g` 这条路线**当场作废**——这正是本工作区要的解空间收缩。

## 6. 这条路线**不能**说什么（L1 边界）

`ε = −(1/λ)L⁻¹g` 是**一阶量的一阶条件**。它给出的是「在实测点上，沿哪个方向二阶
可改进」。它**不**蕴含任何任务分数的提升。本仓库有 10 条独立记录显示把这类局部量
当成能力声明会失败（LESSONS L1）。

所以本文的立场是：**它是一个预测生成器，不是一个结论**。它的价值完全取决于
第 5 节那两个预测是否被已经排队的实验证实。若 P1 被证伪，本文降级为
「一个好看的几何恒等式」，不进 KKT 路线。
