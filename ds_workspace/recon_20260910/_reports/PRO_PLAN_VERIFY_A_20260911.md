## 1. §2/§4 精确说了什么

- **§2**：原函数 `G_j(m)=4^m/4 − 4λt_j(1−4^−m)` 的二阶导 `=(ln4)²[4^m/4+4λt_j 4^−m] > 0`、端点差 `3/4−3λt_j`，**这部分代数正确**；但 `derive_tstar` 换了成本 `D_F=½(ln4)²ΣF_jj m_j²`，**改变了问题与曲率，原角点定理不再适用**。换了之后 `G_F''=(ln4)²[4^m/4−λF_jj]` 可以有内部极大（给了单槽反例）。即使不换成本，固定 λ 的角点也不自动是约束最优（给了对偶间隙例子）。Fisher 成本 m=0 处导数为零 ⟹ 该模型预测渗入 ⟹ 不能用 taper/leak 否定水填充。硬保二元时端点判据变成 `c_j=½(ln4)²F_jj` 对 `3/(4λ)`，与 `t_j < 1/(4λ)` **不可互换**。**A 的实际处理**：不要把现有 A 标成解析最优；要单点诊断 ramp 是否必须坍缩，就用赢家 S=42 导出唯一同预算阶跃 **h=22**。
- **§4**：参考点应是真 native `θ0=(native 表, g=1)`，那里 KL 梯度为零、Hessian = 模型输出 Fisher；**NLL 是另一个目标**（梯度在 θ0 不必为零、Hessian 一般 ≠ Fisher）；把 KL 当局部稳定性辅助、native NLL 当性能约束。二阶近似在 m=1 不必精确。**64 个对角不够**（给了 199× 反例），`F_jj≈[KL(p0‖p_{+h})+KL(p0‖p_{−h})]/h²` 要查 h 稳定性、要核实 `F_m=(ln4)²F_x` 不重复计入。**更便宜**：在明确方向测小矩阵（3 维 = 参考+6 对称前向）= 投影 Fisher。**非循环 λ 检验**：投影掉活跃谱等式后 `e+λn=0`，单约束 `λ=max(0,−n'e/n'n)`，≥2 独立方向查残差；n→0 时 λ 不可识别；约束不活跃时 λ=0。

## 3. 判决 (f)：成本是真的便宜，SNR 增益是 √N 而不是"解决"

### 3.1 前提正确，但增益有上界

计划的前提成立：方向探针**连贯地移动很多槽**，所以信号是 `⟨g,u⟩` 而不是单个 `g_j`。**但噪声不会随槽数平均**——一次前向给出的是**一个**配对损失差，其 SE 与移动了几个槽无关：

```
SNR_single = |g_j| / (σ/δ)          SNR_dir = |⟨g,u⟩| / (σ/δ) ≤ √N · SNR_single
```

上界 `√N`（`N` = 带内槽数 18，`√18 = 4.24`），取等当 `u ∝ sign(g)`。

### 3.2 定量 `[量]`（输入全部是已测量的）

| 目标 | σ（16 篇配对 SE） | 单槽 SE(`δ`=0.05) | 实测单槽信号 | **单槽 SNR** | **方向 SNR（×4.24）** |
|---|---|---|---|---|---|
| **窗内 D** | 0.005 | 0.100 | 0.002–0.010 | **0.02–0.10** | **0.08–0.42 → 仍 <1** |
| **长程 R** | 0.0284 | 0.567 | 0.016–0.28 | **0.03–0.49** | **0.12–2.1 → 擦边** |

**判决**：**(f) 解决不了窗内目标**（要清 SNR=2 需要 `g≥0.047`，是实测均值 0.01 的 5 倍，而"实测均值"本身就被 0.1 的 SE 淹着——所以既不能确认也不能排除）；**长程目标勉强可及，但只在谱的上端**。**所以 (f) 不是"解决 SNR<1"，是把它从 0.1 抬到 0.4–2。**

### 3.3 但方向探针**确实能出信号**——我方已有一对实测证据

`ctl_C42 → ctl_C42V24` 就是一个**带内连贯方向**的探针：`‖Δm‖=0.2621`、`max|Δm|=0.0896`、支撑槽 15–31、**同带同 S 同质心同平台**。实测：

```
连续  ΔR = −0.1109 nats,  SE 0.0284,  t = −3.91        [实测]
RULER Δacc = +10.73pp,    t = +5.47                     [实测]
```

即 **方向探针 SNR ≈ 3.9（连续）/ 5.5（面板）**，而同一批数据里单槽探针 SNR < 1。**所以"连贯方向能测出信号"是实测事实，不是希望。**

**但它同时暴露了一件事**：`0.1109 nats / 0.2621‖Δm‖ = 0.423 nats per unit ‖Δm‖`。若逐槽可加，18 槽平均位移 0.062 应只给出 ~0.01 nats；实测给了 0.111，**大一个数量级**。两种读法都成立、且都**未被判定**：
1. 该方向与 `∇R` 特别对齐（`‖∇R‖` 沿此方向 0.42，比任何单槽 |g_j| 都大，最多可大 √N 倍）；
2. 逐槽梯度测量本身是**噪声主导**的，真实 |g_j| 比"实测"的大。

**⟹ 这条恰恰说明"单槽梯度 SNR<1"的判决是软肋（见 §6）。**

### 3.4 (f) 的真实内容与改靶建议
