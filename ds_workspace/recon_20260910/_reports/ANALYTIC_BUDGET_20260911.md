## 0. 五句话结论

1. `[证]` **预算 S 就是增量分布的均值槽位的补**：`S = Σ_j (K−j)·ε_j`，`ε_j = m_j − m_{j−1}`。
   即 `S = K·m_{K−1} − j̄`；当归一化 `Σε=1` 时 **`S = K − j̄`**，`j̄ = Σ j ε_j`。
   **每张表都与「在均值槽位处的一个纯阶跃」预算相等** —— 预算轴是 ε 的一阶矩，形状轴是它的高阶矩。
2. `[证]` 权重向量 `c_j = K−j` 恰在 Dirichlet Laplacian 的核里（`L c ≡ 0`，精确）。
   而 `MrRoPE` 的 `ε ∝ k` 是**反调和**的 ⇒ 它在固定频带内取到 **S 的最小值**（OLMo 带：`S = 32`）；
   前端阶跃取到最大值 `S = 49`。**两张部署表都坐在预算轴的低端**（37.667 / 40.5）。
3. `[证]` Fisher/输出-KL 损伤在 **m 坐标下是对角的**：`D = (ln4)²/2 · Σ_j w_j m_j²`（无交叉项）。
   于是固定预算下的最优剖面是**水填充解** `m_j = clip( μ / (2w_j) )`：
   一个**几何斜坡 + 平台**，不是多项式斜坡。**「全压」m≡1 不是最优**（它是 S=64 的角点，`Q̂ = 925.6`，
   比 S≈48 的最优剖面贵 10³ 倍）。**阻止它的是快槽的窗内相位敏感度（转数²）曲率，不是保持区、不是频带。**
4. `[据实测拟合]` 用 Qwen 32K 的 8 个窗内代价点标定，转动数坐标下的损伤坐标 `Q̂ = Σ (turns_j/turns_lo)^p m_j²`
   拟合 `R² = 0.992–0.996`（`p ∈ [1,2]`）；**平坦权重（p=0）被一个配对判决当场杀掉**。
   该模型把 m≡1 判成 `+0.02–0.09` nats —— **即"全压"在窗内并不贵**，与 `evq_d_t1`（每个槽 m>0，S=29.6）
   实测 `−0.0004` nats 一致。
5. `[据实测拟合]` **排队的 b=3/4/6/8 与 β=128/256 在损伤坐标里比"已实测为平"的最高锚点低 80–1600 倍。**
   所以**窗内约束不会在排队区间咬合**；`WHY §6` 的"在 mean(m) 0.68–0.73 掉头"用的是
   **错误的对齐坐标**（同 mean(m) 下两个模型的 `Q̂` 差 **1606 倍**）。我的推导预测：**继续涨**。

## 1. 重新陈述问题：正确的参数化

### 1.1 预算函数 `[证]`

设槽 `j = 0..K−1`（K=64），`m_j` 为非降的压缩剖面，`m_{K−1} = 1`（慢端压满一个 radix）。
取 `m_{−1} := 0`，定义增量 `ε_j = m_j − m_{j−1}`，`j = 0..K−1`。则

```
m_j = Σ_{i ≤ j} ε_i          (CDF)
S := Σ_j m_j = Σ_i ε_i · #{j ≥ i} = Σ_i (K − i) ε_i
```

> **`S = Σ_j (K − j)·ε_j`**，且当 `Σε = 1` 时 **`S = K − j̄`，`j̄ = Σ_j j·ε_j`**。
> 机器校验：64 条臂（OLMo 与 Qwen 两套几何、含非归一化的 EVQ 臂）上
> `max |S − (K·m_63 − j̄)| = 2.8e−14`。

**这条恒等式把整晚的争论归一了。** 「预算」不是别的，就是**压缩增量的平均槽位**；
`S = 42.379`（`beta_b2`）与「在槽 21.62 处的一个纯阶跃」预算**完全相同**。
于是：

- **预算轴 = ε 的一阶矩**（等价地：`j̄`，或 `mean(m) = S/K`）；
- **形状轴 = ε 在固定一阶矩下的高阶矩**（方差、偏度、支撑）。

WHY 用的 `mean(m)` 是对的坐标名，但它是**一阶矩**；WHY §7 说的「剩余的 12pp 说明花法仍有独立效应」
在解析上就是：**一阶矩不足以决定目标函数，需要更高阶矩**（见 §4）。

### 1.2 为什么是 `K−j`：预算函数在算子的核里 `[证]`

`c_j := K−j`。对内部节点 `j = 1..K−2`：

```
(L_D c)_j = 2c_j − c_{j−1} − c_{j+1} = 2(K−j) − (K−j+1) − (K−j−1) = 0     精确为 0
```

即 **`c` 是 Dirichlet Laplacian 的核向量**（仿射 ⇒ 调和）。这与前一份推导形成对偶：

| 对象 | 是什么 |
|---|---|
| 部署表的剖面 | `ε = L_D^{-1} f`（`f ≡ const` → BM；`f = (2/n)δ_n` → MrRoPE），**Green 函数像** |
| 预算函数 | `S = ⟨c, ε⟩`，`c ∈ ker L_D`，**核向量** |

核向量与像正交，所以**粗糙度目标 `εᵀL_Dε` 对预算轴没有任何偏好** —— 这与
[KKT_ANALYTIC §1.2](KKT_ANALYTIC_20260910.md)（Dirichlet 能量不是 Fisher 损伤型）是同一件事的另一种写法。

### 1.3 固定频带内，预算轴的真实跨度 `[量]`

OLMo 带 `[14,32]`（`n=18`），`ε` 只能落在槽 `15..32`：

| 剖面 | S | mean(m) |
|---|---|---|
| 后端阶跃 `ε = e_n` | **32.0** | 0.5000 |
| **MrRoPE `ε ∝ k`** | **37.6667** | 0.5885 |
| **BM `ε ∝ k(n+1−k)`** | **40.5000** | 0.6328 |
| 均匀 `ε = 1/n` | 40.5000 | 0.6328 |
| 前端阶跃 `ε = e_1` | **49.0** | 0.7656 |

**两张部署表都坐在低端**（37.7 / 40.5），而整晚的三个赢家把 S 推到 42.0–42.4。
「为什么是 42 而不是 49」这个问题，下面 §3 给答案。

### 1.4 预算 binding 时的最优条件 `[证]`

正确的参数化是 `(S, 固定 S 下的形状)`。在固定 S 的等值面上，形状是自由变量；而实测告诉我们
**形状轴的一阶条件是退化的**（长程梯度在带内恒零，`⟨e, BM−MrRoPE⟩ = −0.178` 对 `|e| = 92.4`，
见 [CONTRACTION_KKT1](CONTRACTION_KKT1_20260910.md)）。所以形状轴上**没有一阶价格**，
价格全部落在预算轴上：

```
min  L_long(S, shape)   s.t.  D_N(S, shape) ≤ ε

若两个目标在固定 S 下对形状都不敏感（这正是实测结论），问题塌缩成一维：
        L'(S) = λ · D'(S) ,   λ ≥ 0 ,   λ (D(S) − ε) = 0
```

**关键结构性后果**：`D_N` 在 m 坐标下是**凸二次型**（§2.1），`L_long` 在实测区间内**单调递减**。
两个单调函数之间**不存在内部最优**：`min L s.t. D ≤ ε` 的解一定在约束边界上，
即 `S* = max{ S : D(S) ≤ ε_tol }`。

> **「拐点」不是表族的性质，是 `ε_tol` 的性质。** 分数在 S 上掉头，只能来自
> (i) 撞到 `D_N ≤ ε_tol` 的边界，或 (ii) `L_long` 自己掉头。两者都是可判别的（§3、§5）。

## 2. 预算约束下的最优剖面：「全压」是不是最优？

### 2.1 损伤模型在 m 坐标下是对角的 `[证]`

`ν_j = ω_j·S^{−m_j}`，故 `∂ log ν_j / ∂ m_j = −ln 4`（对角！）。输出-KL 的二阶型
`D = ½ Σ_j w_j (δ log ν_j)²` 于是在 **m 坐标**下是

```
D(m) = (ln 4)²/2 · Σ_j w_j m_j²                ← 无交叉项
```

（这与 [KKT_ANALYTIC §1.1](KKT_ANALYTIC_20260910.md) 在 **ε 坐标**下的稠密型
`K_W = UᵀWU`、`(K_W)_{ij} = Σ_{q ≥ max(i,j)} w_q` 是**同一个对象**；只是 m 坐标把它对角化了，
而预算轴在 m 坐标下才是透明的。）

**这条对角性是整个 §2 的引擎**：它意味着
1. `D` 关于 m **凸**，逐槽可分；
2. 边际损伤 `∂D/∂m_j = (ln4)² w_j m_j` **正比于 m_j** —— 压得越多的槽再压越贵；
3. 固定预算下的最优化是一个**水填充**问题。

### 2.2 最优剖面 = 水填充 = 几何斜坡 + 平台 `[证]`

```
min Σ_j w_j m_j²   s.t.  Σ_j m_j = S ,  0 ≤ m_j ≤ 1
KKT:  2 w_j m_j = μ      (内部)
      m_j = 1            (2 w_j < μ 的槽，即最便宜的那些)
⟹  m_j = clip( μ / (2 w_j) )
```

`w_j` 随 j 递减（快槽贵、慢槽便宜）时，**单调性不是假设而是结论**；解的形态是
**几何斜坡 `m_j ∝ 1/w_j` + 慢端平台 `m_j = 1`**。

前一份推导里 `w ≡ const` 的特例给出「后端阶跃 `e_n`」
（[KKT_ANALYTIC §1.3](KKT_ANALYTIC_20260910.md)）——那正是**平坦权重的水填充解**，
与本节的通式一致，是 `w` 取常数的退化情形。

### 2.3 `w_j` 的第一性形式：窗内转数的平方 `[假设下推导]`

RoPE 的相位 `φ_j(d) = ν_j·d`。把 `log ν_j` 扰动 `δ` 时**每个相位按比例缩放**：
`φ → φ(1−δ)`。窗内 `d ≤ W`，所以扰动的幅度是 `δ·ω_j·W = δ·2π·turns_j(W)`。
二阶（Fisher）损伤于是

```
w_j  ∝  (turns_j(W))²          turns_j(W) = ω_j·W/(2π)
```

**这是无量纲且跨 checkpoint 可比的**（频带规则本身就是按转数定义的：带内 `turns ∈ [1,32]`，
所以同一个 `(α,β)` 自动落到任何模型上）。`[证]` `θ^{−j/64} = θ^{−2j/head_dim}`，
与 `tables.native_inv_freq` 逐位相符。

### 2.4 用实测把这把尺子校准 `[据实测拟合]`

可用的实测只有 Qwen2.5-3B 冻结、32K 列（逐长度 offset 已除）的 8 个点
（`CONTRACTION_SUPPORT §5`）。取损伤坐标

```
Q̂(m) = Σ_j ( turns_j(W) / turns_lo )^p · m_j²          turns_lo = 带快边的窗内转数
cost ≈ c0 + a · Q̂
```

| p | a | c0 | R² | RMSE (nats) | 留出臂 `evq_s_t2` 预测 vs 实测 |
|---|---|---|---|---|---|
| 0.75 | 1.782e−3 | −0.00766 | 0.9843 | 0.00316 | +0.167 vs **+3.171** |
| 1.00 | 8.759e−4 | −0.00559 | 0.9917 | 0.00230 | +0.137 vs +3.171 |
| 1.50 | 1.611e−4 | −0.00426 | 0.9954 | 0.00172 | +0.103 vs +3.171 |
| 2.00 | 2.406e−5 | −0.00373 | 0.9956 | 0.00166 | +0.086 vs +3.171 |

**三条结论，我按证据强度排序：**

1. `[证-by-实测]` **平坦权重（`p=0`，即 `Σ_j m_j²`）被配对判决杀掉**：
   `leak_a0.02` 的 `Σm² = 34.7531`，`power_p2` 的 `Σm² = 34.2584`（**差 1.4%**），
   而窗内代价是 **+0.0026 vs +0.0406 nats**。这正是 `why.py` 的配对判决法，
   结论与它一致：**损伤必须有频率权重，不是槽数的函数。**
2. `[据实测拟合]` `p ∈ [1,2]` 都拟合得极好（R² ≥ 0.99），**数据不能把 p 钉死**；
   第一性给的 `p=2` 与 `p=1` 都在可接受带内。**这是一个 1 参数族、只有整体尺度被标定。**
3. `[反例]` 模型在**盒外**臂 `evq_s_t2` 上错 **19–37 倍**（该臂 `m` 取到 `−1.83`，是全谱提速）。
   **所以这是一个局部模型：只在 `m ∈ [0,1]` 内有意义，不许外推到盒外。** 这条必须写在脸上。

### 2.5 「全压」（m≡1）是不是最优？

**不是。** 三条，从硬到软：

- `[证]` m≡1 是预算轴的**端点**：`ε = e_0`（一个 radix 的压缩全部集中在槽 0，即最快的那一槽），
  `S = K − 0 = 64`。它**满足** `Σε = 1`，所以它**在盒子 `[0,1]^64` 里**；
  它只是**不在三段式家族的图卡里**（那个家族额外钉了 `m_0 = 0`）——
  **保持区是一个设计约束，不是盒子约束**（这与 leak 实测免费一致）。
- `[证]` 在 Fisher 损伤下，`m_j = clip(μ/(2w_j))` 严格优于任何其它同预算剖面；
  `m≡1` 的损伤是 `Q̂ = 925.6`，而 S≈48 的水填充解是 `0.959` —— **贵 965 倍**。
- `[假设下推导]` **阻止它的是快槽的曲率**：`h_j = (ln4)²·w_j ∝ turns_j(W)²`。
  压槽 0（窗内转数 651.9）的边际损伤是压槽 30（转数 1.39）的 **2.2×10⁵** 倍。
  **不是保持区、不是频带宽度、不是粗糙度。**

**但必须说清楚数据并没有把 m≡1 关掉**：唯一一个"每个槽都被压"的实测臂是 `evq_d_t1`
（`m_0 = 0.0060` 单调升到 `m_63 = 0.9908`，S = 29.575），它的窗内代价是 **−0.0004 nats**。
按标定模型，m≡1 只比它贵 ~10 倍，代价 `+0.02–0.09` nats —— **在这个尺度上"全压"是买得起的**。

> **诚实的结论**：**窗内约束在已测范围内不排除 m≡1。** 若 m≡1 真的不行，原因必须在 `L_long`
> 那一侧（有效位置尺度被整体缩短 4 倍），而 `L_long` 在 S > 42.4 上**从未被测过**。
> 这是一个可以**一条臂判决**的问题（见 §5 P4）。

### 2.6 顺带：为什么 EVQ 输了（对 WHY §5 的修正）`[据实测拟合]`

WHY §5 说 EVQ 输在"没有平台 ⇒ 沉淀不了预算"。**在 Fisher 模型下这个论证是对的，而且更精确**：
水填充解就是「平台（`w` 最小处，m=1）+ 几何斜坡」，而光滑 companding **没有平台**，
所以它把预算花在了最贵的槽上。但 WHY 的措辞（"保持区留在 m=0 是为了让预算花在别处"）
只说对了一半：**保持区留在 m=0 本身没有损失**（leak 实测免费），**关键是平台必须存在**。

## 3. 预算天花板：闭式条件与拐点位置

### 3.1 约束的曲率给出墙的位置 `[假设下推导]`

在固定几何下，取「压缩前锋落在窗内转数 `τ` 处」的剖面（阶跃极限）：

```
Q̂(τ) = (τ/τ_lo)^p / (1 − r^p) ,     r = turns_{j+1}/turns_j = θ^{−1/64} = 1/1.2276
```

代入标定 `cost = c0 + a·Q̂`，令 `cost = ε_tol`，解出墙的位置：

| p | ε_tol=0.002 | ε_tol=0.005 | ε_tol=0.010 |
|---|---|---|---|
| 0.75 | τ = 26.2 | 37.6 | 58.6 |
| 1.00 | 59.4 | **82.8** | 121.9 |
| 1.50 | 174.8 | 226.9 | 302.6 |
| 2.00 | 330.7 | **408.2** | 511.9 |

**注意 `c0 < 0` 是拟合出来的非物理常数**，所以"解出墙"这一步对 `c0` 极敏感：
在 `(p, ε_tol)` 的合理盒子里，墙可以落在 `τ ≈ 26` 到 `τ ≈ 408` 的任何地方。
**实测最优 `turns_a1_b64` 的前锋在槽 12，即 `τ = turns_12 = 55.67`
落在整个盒子的低端** —— 与 `p ≈ 1, ε_tol ≈ 0.005 nats` 一致，但**不足以把参数钉死**。

> **能说的是**：约束的曲率**确实预测出一个墙，且墙的位置由 `turns_j(W)²` 决定**，
> 也就是由 **YaRN 的 β 所编码的那个量**决定 —— 这是"β 是手调常数"的一个**推导性支持**。
> **不能说**的是墙的精确位置（`c0` 的不确定性吃掉了它）。

### 3.2 拐点为什么不在 mean(m) 上 —— 与 WHY §4/§6 的分歧 `[据实测拟合]`

WHY §4 把 **Qwen 的窗内代价曲线**按 `mean(m)` 对齐到 **OLMo 的分数**上，读出"拐点在 0.63–0.65"。
**这个对齐在损伤坐标里是错位的，误差三个数量级：**

| mean(m) | OLMo 臂 | `Q̂`（OLMo） | Qwen 同 mean(m) 的臂 | `Q̂`（Qwen） | 比值 |
|---|---|---|---|---|---|
| 0.6622 | `beta_b2` | **0.127** | `leak_a0.02` | **204.1** | **1606×** |
| 0.7262 | `beta_b8` | 0.594 | `leak_a0.04` | 816.1 | 1374× |

**原因**：Qwen 的 `leak/power` 族把压缩**推进到窗内转数高达 5220 的快槽**（`turns_0 = 5220`），
而 OLMo 的 `b/β` 族**只压带内**，带内最大转数就是 `β ≈ 37`。
`mean(m)` 把这两件完全不同的事算成了同一个数。

> **正确的读法**：`Qwen` 的 leak 曲线约束的是「压快槽」这件事的代价；
> OLMo 的 `b/β` 族**根本没有压快槽**。所以那条曲线**管不到** `b=3/4/6/8` 与 `β=128/256`。
> **WHY §6 预测的"在 mean(m) 0.68–0.73 掉头"没有依据**（它的依据是错位的对齐）。

### 3.3 形状能买多少？`[量]`

固定预算下，b 族最好的点 vs 水填充前沿：

| S | `Q̂`(最佳 b 族) | `Q̂`(水填充) | 比值 |
|---|---|---|---|
| 42 | 0.1099 | 0.0828 | 1.33 |
| 44 | 0.2286 | 0.1881 | 1.22 |
| 46 | 0.4881 | 0.4271 | 1.14 |
| 48 | 1.1387 | 0.9699 | 1.17 |

**形状在固定预算下最多能买 1.14–1.33 倍的损伤**（≈ 2e−5 nats）。这是一个**独立于 WHY 的、
解析的**结论：**形状是次变量不是因为观测，是因为在 Fisher 度量下它的可达改进有上界。**
顺带这也解释了 [CONTRACTION_SUPPORT](CONTRACTION_SUPPORT_20260910.md) 的"形状轴窗内不可辨识"。

## 4. 那 12 个百分点：残差项是什么

### 4.1 配对判决：预算不充分 `[量]`

| 对比 | S | mean(m) | `j̄` | `sd(j)` | 窗内质量占比（槽 15–19） | RULER |
|---|---|---|---|---|---|---|
| `beta_b0.25` | 38.4650 | 0.6010 | 25.535 | **4.3917** | **0.2673** | 0.1447 |
| `turns_a1_b16` | 38.5000 | 0.6016 | 25.500 | **3.3242** | **0.0250** | **0.2651** |

`ΔS = 0.035`（0.09%），`Δscore = +0.1204`。**两条臂差在整个频带/支撑的分布上，
一阶矩几乎相同。** `‖Δm‖₂ = 0.2622`，支撑在槽 15–31。

**解析上残差项是什么**：实测已给出一阶项为零（带内 `∂L/∂m ≡ 0`），所以

```
ΔL_long = ⟨g, Δm⟩ + ½ Δmᵀ H Δm = 0 + ½ Δmᵀ H Δm
```

**整个 12pp 必须是二阶项**：长程 Hessian `H` 在带内的二次型。这不是"还有一个没说清的因素"，
而是**一个被定位到具体算子的量** —— 正是 `experiments/curvature_20260910/` 建来测的那个对象。

### 4.2 但数据不允许把它归给任何二阶标量 `[量]`

- 数据里只有**另一对**同预算臂：`turns_a1_b64`(S=42.000, `sd`=4.899) vs `turns_a2_b32`(S=42.000, `sd`=3.550)，
  `Δscore = 0.0284` —— **落在噪声里**（350 行朴素标准误 2.6pp，行按任务聚集更大）。
- 而它的 `sd` 排序与上一对**方向相反**（这一对是"扩散大的赢"）。因为该差在噪声内，
  它**不构成对 `sd` 说的反例，但也不提供支持** —— 即：**数据里恰好只有一对可用的同预算臂。**
- 尺度检验：部署对（BM−MrRoPE，`‖Δm‖ = 0.7505`）值 48.5pp；本对（0.2622）值 12.0pp。
  分数比 4.04，距离比 2.86，距离平方比 8.19 —— **落在一次与二次之间，不判别**。

> **诚实的说法**：**预算是一阶主变量（这被 WHY 证明，也被本节再次确认）；残差是二阶项，
> 已被定位为 `½ΔmᵀHΔm`，但现有数据只有一对可用的同预算臂，不足以把 `H` 的任何标量投影钉死。**
> 要钉死它需要 `curvature` 包的实测 `H`，或至少再补 2–3 对同预算臂。

## 5. 可证伪的预测

### P1（主预测）排队的 b=3/4/6/8 与 β=128/256 继续涨 `[据实测拟合]`

损伤坐标与"已实测为平"的锚点对比（锚点 = `Qwen leak_a0.02`，`Q̂ = 204.1`，实测 `+0.0026` nats）：

| 臂 | S | mean(m) | `Q̂` | 比锚点低 |
|---|---|---|---|---|
| OLMo `beta_b2` | 42.379 | 0.6622 | 0.1271 | 1606× |
| OLMo `beta_b3` | 43.637 | 0.6818 | 0.2012 | 1015× |
| OLMo `beta_b4` | 44.534 | 0.6958 | 0.2804 | 728× |
| OLMo `beta_b6` | 45.723 | 0.7144 | 0.4410 | 463× |
| OLMo `beta_b8` | 46.474 | 0.7262 | 0.5941 | 344× |
| OLMo `turns_a1_b128` | 44.000 | 0.6875 | 0.4317 | 473× |
| OLMo `turns_a1_b256` | 45.500 | 0.7109 | 1.035 | 197× |

**预测：这些臂的分数继续单调上升，不因窗内约束掉头。**
- **证伪条件**：任一 `b ≥ 3` 的读数 ≤ `beta_b2` 的 0.5001（超出噪声）；或 `β=256 < β=64`。
- **反方向的预测**（`WHY §6`）：在 mean(m) 0.68–0.73 掉头。**两者相反，这次排队判决一次分清。**
- 若我错而 WHY 对：说明损伤权重 `w_j` 在 OLMo 上比 `turns²` **陡得多**（需要 `p ≳ 4` 才能把
  b=8 推到锚点以上），那本身就是一条可解释的机制差别（OLMo 窗口 4K vs Qwen 32K）。

### P2（形状 vs 预算的干净判决）`[据实测拟合]`

排队对 `beta_b2`（S=42.379，`Q̂`=0.127）vs OLMo 几何下的 `leak_a0.01`（S=42.740，`Q̂`=0.983）。
- 两者预算差 0.9%，**损伤坐标差 7.7 倍**（leak 更高）。
- **我的预测**：`beta_b2` **赢或平**，且赢的幅度 ≤ 噪声；`H_shape`（前端集中是原因）
  与 `H_budget`（压得更多是原因）**都不成立**；真正的判别量是转数加权的损伤坐标。
- **证伪条件**：`leak_a0.01`(OLMo) 显著赢 ⇒ 损伤坐标（至少 `p=2` 那一支）被证伪，
  必须回到 `L_long` 侧去找压快槽的收益。

### P3（下一条形状族，不是 b 族）`[证]`

推导给的族是**几何水填充**：

```
m_j = min( 1 , γ^{ p (j − j0) } ) ,   γ = θ^{−1/64} = 1.22757 , p ≈ 1…2
```

它**不在 b 族里**（b 族是多项式斜坡，这是指数斜坡）。`[量]` 在 S ≈ 42.0 处
`Q̂_geo = 0.0819` vs `Q̂_{b族最好} ≈ 0.11–0.13`，vs 水填充前沿 0.0828 —— **几何族打到前沿**。
**建议排队**（两个参数：`j0` 控制预算、`p` 控制斜坡陡度；`p=1` 与 `p=2` 各 3 个 `j0` 即可扫完）。
预期增益小（形状最多买 1.3 倍损伤），但它把"形状轴已经用尽"从观测变成**证明**。

### P4（最高信息量的一条臂）`[猜]`

**测 `m ≡ 1`（全谱均匀 4× 下移）**，或它的单参数插值 `m_j ≡ \bar m`。
- 窗内：按标定模型只贵 `+0.02–0.09` nats，**大概率过 gate**。
- 长程：`L_long` 在 S=64 上完全未测。若它**不显著差于** `beta_b2`，
  则**整个三段式结构（保持区 + 频带 + 单一 radix）被证伪**，问题塌缩成"位置尺度"一个问题。
- 若它**显著差**，则 §3.1 的墙是真的，且**第一次有了对 `L_long` 侧墙位置的测量**。
- **这一条臂把"保持区是否有用"从一个设计习惯变成一个判决**，成本 = 1 臂。

## 6. 反例与边界（不许省略）

1. **Qwen 128K 与预算方向相反** `[量]`：预算说 `BM`(S=32.0) > `MrRoPE`(S=29.33)。
   实测 32K（窗内）`BM 91.67 > MrPro 87.22`（+4.45pp）**一致**；
   128K（4×）`BM 70.83 < MrPro 78.13`（−7.29pp）**相反**。
   `[据文档]` Qwen 128K 长端有已记录的检索地板（`codex R2/R3`：换中段表族不影响该失败），
   所以这条端点的分辨力可疑 —— **但它是一个未解释的反例，不是可以忽略的**。
2. **拟合模型在盒外臂上错 19–37 倍**（`evq_s_t2`）。§2.4 已标为局部模型。
3. **`c0 < 0` 未被物理解释**。它更像是一个只在"压过头槽"时出现的**负一次项**
   （leak 族实测比原生还便宜 0.006 nats）。**一阶项的符号是实测的，但它的剖面没测过** ——
   这是约束侧唯一缺的测量，且很便宜（单槽压缩扫描）。
4. **跨模型转移假设**：`a` 与 `c0` 是在 Qwen 上标的，用到 OLMo 上。**OLMo 自己的窗内代价（4K NLL）
   从未测过。** 我做了方向性论证（OLMo 窗口短 8 倍 ⇒ 同槽转数低 ⇒ 只会更不敏感），
   但这是论证，不是测量。
5. **9 个 OLMo 点、无 seed 重复、4 个同族。** 所有 Spearman 都是弱证据。
   本文只把**配对判决**与**恒等式**当证据。
6. **`native` 与 EVQ 族不归一化**（`Σε = 0.9908 / 0.9858 / 0.9471`，`evq_s_*` 甚至为负），
   所以它们的 `S` 与三段族不可直接比 —— 这是 `[量]` 的（`budget_20260911.py` P1 会打印）。
