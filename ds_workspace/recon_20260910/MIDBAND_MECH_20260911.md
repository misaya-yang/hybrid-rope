## 1. 推导：为什么"转数窗口内的槽数"应该是操作变量

### 1.1 只有 `T_j` 进入相位几何 [已证]

RoPE 的 logit 里，槽 `j` 对相对距离 `Δ` 的贡献**精确地**是

    z_j(Δ) = a_j · cos(ν_j Δ + ψ_j),    a_j = |q_j||k_j| ≥ 0

（旋转不变性）。整张表在测试端**唯一**能做的事，就是把这 64 个频率 `ν_j` 摆好。而

    ν_j = ω_j · 4^(−m_j)  ⟹  ν_j Δ = (2π/D) · T_j · (Δ/D),    T_j := D·ν_j/2π

所以 `[0, D]` 上的**整个相位几何**由 `{T_j}` 这个多重集完全决定；两个表只要 `T`-剖面相同，
它们在 16K 上的位置编码就是同一个对象（差别只在槽的标号 = 内容）。**[已证]**：

    log4 T_j = 1 + log4 t_j − m_j,        t_j = W·ω_j/2π（窗内转数，与表无关）
    T_j = 4 t_j 4^(−m_j) = (D/W) · t̃_j,   t̃_j := W·ν_j/2π（**压缩后**的窗内转数）

**操作变量是一个 T-剖面上的泛函。** 这解释了 `WHY §2` 的"局部量看不见、全局积分量才看得见"：
`∂L/∂m_j` 是逐槽量，而 T-剖面是被整条 m-曲线**联合**决定的。**注意：本条只说明坐标，不说明泛函形式。**

### 1.2 三条判据，每条给出窗口的一侧

**(a) 非退化（给下界）[已证]。** 槽 `j` 的 logit 在 `[0,D]` 上的**总相位行程**是 `2π·T_j`。
`T_j ≪ 1` 时 `z_j(Δ)` 在整段上下文上几乎是常数：它带**零**位置信息，只贡献一个偏置。
一个正交对 `(cos, sin)` 能分辨相位的最小行程是 π/2 ⟹ `T_j ≳ 1/4`。

**(b) 校准（给上界的一个必要条件）[已证，MECHANISM §1]。** 模型只在 `Δ' ∈ [0,W]` 上训练过，
槽 `j` 在测试距离 `Δ` 上的相位等于原频率在 `Δ_eff = 4^(−m_j)Δ` 处的相位。所以
"该槽仍是一个被校准过的位置读数" ⟺ `Δ ≤ W·4^(m_j)`，在 `[0,D]` 上覆盖比例 `min(1, 4^(m_j−1))`。
`m_j = 1` 是让整个 `[0,4W]` 都留在训练弧上的唯一取值。

**(c) 混叠预算（给上界的另一个必要条件）[已证]。** `Δ ↦ ν_jΔ` 在 `[0,D]` 上是 `T_j` 对 1 的；
槽 `j` 单独只能把 `Δ` 定位到 `D/T_j` 宽的格子里。要让它对**整段**上下文有用，
`D/T_j` 不能小于"训练窗给出的最小可用尺度"。

> **两侧都成立 ⟹ 窗口必须是双侧的，且必须写在 T 上（不是槽号、不是 m）。**
> `[0.25, 16]` 就是"下界取 (a) 的 π/2、上界取 (c) 的一个 O(1) 倍数"。

### 1.3 窗口 = 围绕**原生剖面**的一条斜带 [已证]

    log4 T_j ∈ [−1, 2]   ⟺   m_j ∈ [log4 t_j − 1,  log4 t_j + 2]

即：**压缩量必须落在原生剖面上下 1~2 个 log₄ 单位以内**。
在 `t̃ = T·W/D` 坐标里这是 `t̃_j ∈ [1/16, 4]`（`4^[−2,+1]`）。

**关键结构（本文所有后续都靠它）[已证，逐臂验算]**：`T_j` 对单调表**严格递减**，
所以"窗口内的槽"是一个**连续槽区间** `[j_fast, j_slow]`。而这 12 张表上

- **慢端 `j_slow = 38` 对每一臂都相同**——因为它落在 `m=1` 平台里，那里 `T_j = t_j` **与表无关**：
  `t_38 = 0.2694 ≥ 0.25 > t_39 = 0.2119`。慢边只贡献一个**常数**。
- 快端 `j_fast ∈ {24, 23, 22}`，完全由 ramp 在哪里穿过 `T = 16` 决定。
- 因此 **`N = 39 − j_fast`**：N 对这张面板只携带**一个整数**的信息。

> **m=0 的保持槽永远进不了窗口**（`T = 4t_j ≥ 26 > 16`，slot 18 的 `T = 65`）。
> 这是"保持区与 N 无关"的证据，也是 KNIFE 的 leak 臂打不中任何东西的原因（§3.3）。

### 1.4 边界可辨识性 —— **窗口的形式是导出的，数值不是** [已证]

把"硬窗口"这个形式钉住，反解两个边界：

| 边界 | 数据给的约束 | 结论 |
|---|---|---|
| **快边** | 需 `T* ≥ max_{N=17} T_22 = 15.985`（BM 的 slot 22），且 `T* < min_{N<17} T_22 = 18.085` | **`T* ∈ [15.985, 18.085)`，宽 2.1**；候选值 `16 = 4² = (D/W)²` 落在区间内，但只落在**下界上方 0.7%** 处 |
| **慢边** | 只有 slot 38 必须在内；任何 `b ∈ (−0.946, −0.798]` 给出**逐臂完全相同**的计数 | **本数据集对慢边零信息** |

**必须直说**：`[0.25, 16]` 里的 `16` **没有被数据确认**，只被"夹"在 `[16.0, 18.1)`。
它之所以值得留作候选，是因为 `16 = (D/W)²` 有量纲上自然的读法，**而且这个形式是量纲无关的**
（转数无量纲 ⟹ 同一套数自动落到任何 checkpoint 上，这正是 TURN_WINDOW §1 的论证）。
但它目前的地位是**候选常数**，不是导出的常数。**这是本文对 lead 提问 1 最诚实的回答。**

**鲁棒性（这是正面结果）**：排序结论对边界**不敏感**——慢边在 `T ∈ [0.06, 0.44]` 内、
快边在 `T ∈ {2, 12.1, 16, 32, 84}` 上，**配对判决都是 0 错**（§7 表）。被识别的不是 `16`，
而是"**存在一个快阈，ramp 穿过它时多一个槽**"。

## 2. 34.58 个百分点：函数形式

### 2.1 先更正一处口径

Lead 写"MrRoPE 与 BM 在 N 上只差 1（15 vs 17）"。实测 **15 vs 17，差 2**。
每步的跳跃量见下，两步大致相等，所以 34.58pp 是**两步**之和。

### 2.2 `N` 是硬计数，且**必须**是硬的 [已证]

把 N 换成连续的穿越点 `j*`（`log4 T` 与 2 的交点，插值到小数）：

| 量 | 加权 χ²/dof（12 点，350 行） | 配对错 |
|---|---|---|
| `N`（整数计数） | **5.68** | **0** |
| `j*`（连续穿越点） | 差（rms 0.353，系数方向正确） | **54 / 60** |

**离散化在做好事**：分数连续坐标几乎完全排错，整数计数一个不错。
⟹ 机制是**阈值型**的（一个槽要么可读要么不可读），不是"离边界多远"。

### 2.3 正确的函数形式是 logistic，不是线性

三个 N 档的几何均值：`0.0709 / 0.1944 / 0.4447`；取 logit：

    N = 15 → −2.574      N = 16 → −1.422      N = 17 → −0.222
    相邻差：          +1.151 nats            +1.200 nats        （差 4%）

> **`acc ≈ σ(−20.45 + 1.19·N)`，即 `odds(正确) ∝ 3.2^N`：每多一个可读槽，几率乘 3.2。**
> 两个独立测出的间隔只差 4%，这是"线性 + sigmoid"而不是"线性"的强证据
> （线性模型在 [0.07, 0.54] 上会被两端压扁；实测两端正好落在 sigmoid 的两肩上）。

**机制读法 [猜测]**：检索是对正确 key 与干扰 key 的**证据竞争**，`logit(acc) = Σ_j LLR_j`，
每个可读槽贡献约 **1.2 nats 的常数证据**。这与"计数 + sigmoid"完全同构，
且解释了为什么**不是** `√N`（那会是随机相消的匹配滤波）。

## 3. N=17 内部的 15.4pp

### 3.1 先做分解：15.4pp 不是一块，是两块 [已证]

| 子群 | 臂 | 精度 | 组内间距 |
|---|---|---|---|
| A | knife_both .3846 / knife_taper .3937 / knife_leak .3969 / BM .4167 | ≤41.2% | 3.2pp |
| B | b2 .5001 / a2b32 .5100 / a1b64 .5384 | ≥50.0% | 3.8pp |

350 行的边际 SE = **2.6pp**（acc≈0.5），两臂之差的 SE ≈ **3.7pp**。
所以 **A/B 之间的 8.3pp 是 2.2σ（边缘显著），两个组内散布各约 1σ（噪声）**。
"15pp 的二阶量"实际只需要解释 **8.3pp**。

### 3.2 二阶量：`S_in` = 落在带内的预算 [已证 + 拟合]

    S_in(m) := Σ_{j : T_j ∈ [0.25,16]} m_j

**为什么应该是它**：`S = Σ_j m_j` 是总预算，但 §1.3 已经证明**保持槽与 `T<0.25` 的深平台
永远进不了带**。落在那里的预算是"花了但买不到可读性"的。`S_in` 就是**真正花在可读带上的那部分**。

| 判据 | A 组 | B 组 | 分开？ |
|---|---|---|---|
| `S_in` | 14.26 / 14.26 / 14.39 / 14.39 | **14.95 / 15.52 / 15.61** | ✅ 切口 (14.39, 14.95) |
| `S` | 37.4 / 38.0 / 40.5 / 41.16 | **42.00 / 42.00 / 42.38** | ✅ 切口 (41.16, 42.00) |
| `C`（机制覆盖量） | .6436 / .6473 / .7055 / .7092 | **.7200 / .7261 / .7294** | ✅ |
| `drift` | 161 / 161 / 673 / 673 | 191 / 209 / 254 | ❌ 交错 |

### 3.3 `S_in` 让 KNIFE 第一次变得可理解 [已证]

    knife_leak:   S 40.500 → 41.162  (+0.662)      S_in 14.39 → 14.39  (+0.000)
    beta_b2:      S 40.500 → 42.379  (+1.879)      S_in 14.39 → 15.61  (+1.22)

**leak 把 +0.66 的预算全部花在保持槽上——那里 `T = 4t_j ≥ 26 > 16`，读不出来。**
所以它"多了预算却低了 2pp"，而 b2 的 +1.88 里有 65% 落在带内。taper 更直接：
它把平台的 `m` 从 1 削到 0.805，**从带内抽走预算**（`S_in` 14.39→14.26），同时破坏 `m_63 = 1`。

> **KNIFE 的判决（"两端都承重"）在 T-坐标里是一条陈述**：
> **离开可读带的花法都是损失；只有把预算推进带内才是收益。**

### 3.4 诚实的边界：`S_in` 解释组间，**不解释组内**

B 组内部 `S_in` 是**反序**的：a1b64 14.95（0.538）> a2b32 15.52（0.510）> b2 15.61（0.500）。
**带内不是"越压越好"。** A 组内部同理（leak 的 `S` 最高却排第三）。这两处都是 ~1σ，
本报告**不声称有第二个标量**：用 3 个变量拟合 χ²/dof 反而变差（2.63 → 2.92）。

## 4. 最小参数集

### 4.1 数据只要一个数 [已证]

贝叶斯加权（`SE = 1/√(350·p(1−p))`，异方差）拟合 `logit(acc)`：

| 统计量 | χ²/dof | 配对错 |
|---|---|---|
| `S = Σm`（旧主变量） | **21.00** | 15 |
| `C`（机制覆盖量） | 差（9 点时最好，12 点被一对反序杀死） | 16 |
| `N`（计数） | 5.68 | **0** |
| `S_in`（带内预算） | 3.35 | 4 |
| **(N, S_in) 两参数** | 2.63 | 4 |
| **`Ψ = N + S_in`（一参数）** | **2.37** | 4 |

**两参数拟合的系数比 = 0.4421 / 0.4113 = 1.075**，且 χ² 与一参数版**逐位相同（23.70 vs 23.72）**。
⟹ 数据分不开 `N` 与 `S_in` 的权重，它们**退化成一个数**：

    Ψ(m) = Σ_{j : T_j ∈ [0.25,16]} (1 + m_j),        logit(acc) = −13.59 + 0.421·Ψ

（等价的、统计上不可区分的写法：`√(N·S_in)` χ²/dof 2.33；`N + Σ min(1,4^{m−1})` 2.37。
三种"带内质量"的定义在这 12 点上等价。）

`Ψ` 在 12 点上的值：26.70 / 28.57 / 28.81 / 29.05 / 29.11 / 31.26 / 31.26 / 31.39 / 31.39 / 31.95 / 32.52 / 32.61。
**跨程 5.91 × 0.421 = 2.49 nats**，与实测 logit 跨度 2.73 一致。

### 4.2 哪些旋钮是冗余的

| 参数 | 判决 |
|---|---|
| **gain** | **不是频率参数**。12 臂全程固定在 `GAIN_YARN`，本数据集对它零信息；而 L6b 已测出它在窗内值 0.050 nats（是频率表的 70 倍）。**必须分开报，不能折进表里。** |
| **taper δ** | **不是设计自由度，是损失**。它把预算从带内抽走（`S_in` ↓）并破坏 `m_63 = 1` ⟹ −2.30pp，p=0.003。 |
| **leak a** | 同上。它把预算加到保持槽（**永远在带外**）⟹ −1.98pp，p≈0.04。与 taper **次可加**（+1.07pp 交互）。 |
| **带 lo/hi 与 ramp 指数 b** | **不独立**：在 T-坐标里两者都只是重写同一条 m-剖面；它们的效应**完全由 (N, S_in) 中介**。β=32→64 的 92.5% 是 slots 15–31 的重塑形（MECHANISM §4），就是这条。 |
| **S（总预算）** | **在 `S_in` 给定后冗余**。`S = S_in + S_out`，而 `S_out` 的变动（±1.6）与分数无关。χ²/dof 21.0 → 2.37 就是这个冗余的量度。 |

> **决定一张表质量的最少数字：2 个（设计口径），1 个（评分口径）。**
> 设计上你需要定"剖面在哪里穿过带的两条边"；评分上它们塌缩成 `Ψ`。
> **"给自己加了那么多参数"确实错了**——其中两个（taper/leak）是纯损失，
> 一个是另一张脸（gain），剩下的带/形状**只有两条边是承重的**。

## 6. 本报告**不能**解释什么
