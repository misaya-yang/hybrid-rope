1. `[证]` **N 有闭式**：可读窗在 (槽, m) 平面上是**一条宽 3 的斜条带**，斜率 −λ/2。
   OLMo 上 64 个槽恰好分成五类，`N = 14（免费）+ #{快侧竞争槽赢下} + #{慢侧竞争槽赢下}`，

2. `[证-恒等式]` **条带斜率 ≡ ν 退化斜率 ≡ lnθ/(2K·ln2)**（OLMo 0.147902879）。

3. `[量]` 12 个已测 OLMo 点里 **11 个**（9 个 + 2 个 KNIFE）**全部**是 `14 + k`，k=1/2/3，

4. `[证]` **加入计数目标后 KKT 从光滑变 bang-bang**：逐槽收益是 0/1 阶跃，最优解是

## 1. N 的精确形式

坐标：`t_j(W) = ω_j·W/2π`（窗内转数），`t_D,j = 4·t_j·4^{−m_j}`（4× 测试距离上的转数），
`N = #{j : t_D,j ∈ [0.25, 16]}`。取 `g_j = log2 t_j(W) = G − λj`（严格仿射），
`h_j = log2 t_D,j = 2 + g_j − 2m_j`，则

```
可读  ⟺  h_j ∈ [−2, 4]  ⟺  g_j − 2 m_j ∈ [−4, 2]  ⟺  m_j ∈ [θ_j , θ_j + 3]
                                    θ_j = (g_j − 2)/2        （条带下沿，m 单位）
```

**条带宽恰好 3**（= 6 个 log2 单位 ÷ 2），且随 j **以 −λ/2 下滑**。

### 1.1 五类槽与精确分解 `[证 + 量]`

因为 θ 单调降，两个边界（θ=1、θ=−2、θ=−3）把 64 槽切成五段：

| 类 | 条件 | 可读性 |
|---|---|---|
| 太快 | θ_j > 1 | **永不可读**（即使 m=1） |
| **快侧竞争** | 0 < θ_j ≤ 1 | 可读 ⟺ `m_j ≥ θ_j` |
| **免费** | −2 ≤ θ_j ≤ 0 | **任何 m ∈ [0,1] 都可读** |
| **慢侧竞争** | −3 ≤ θ_j < −2 | 可读 ⟺ `m_j ≤ θ_j + 3` |
| 太慢 | θ_j < −3 | **永不可读**（即使 m=0） |

### 1.3 为什么要用「穿越率」而不是「计数」`[证]`

设剖面在条带内以每槽 ρ 上升，条带以每槽 δ = λ/2 下滑，则间隙 `m_j − θ_j` 以 (ρ+δ) 变化，
出带前跨过宽度 3：

```
        N = 3 / (ρ + δ) + O(1)          δ = λ/2 = lnθ/(2K ln2)
```

| 剖面 | ρ（由 N 反解 `ρ = 3/(N−1) − δ`） | N |
|---|---:|---:|
| native / interp（平） | 0 | **20.3**（实测 native 21、interp 20 ✓） |
| MrPro | 0.0664 | 15 ✓ |
| BM / 三个赢家 | 0.0396 | 17 ✓ |
| `evq_deploy` τ=1 | 0.0188（解析快端斜率 `tanh τ/(Kτ)` = 0.0119，同向同量级） | 19 ✓ |
| **滑行条带** | **−δ** | **→∞**（被盒子截断，上限 27） |

### 1.4 恒等式 `[证]`

条带斜率 `dθ/dj = −λ/2 = −lnθ/(2K ln2)`；
ν 严格递减的边界 `Δm > −lnθ/(K ln4) = −lnθ/(2K ln2)`。**两者是同一个数。**
⟹ **在条带内精确滑行 ⟺ ν 恰好常数**（机器校验：滑行段的 ν 变化 < 1e−9）。
这条恒等式同时说明了：**N 的最大化 = 在穿越区把 log 间隔压到 0**。

## 3. 任务 2：加入「可读槽数」后，最优密度是什么

原泛函 `J[ρ] = (α/2)∫ρ² + (β/2)∫S_ρ²` 的光滑变分给 `αρ''−βρ=0` ⟹ `ρ* = A cosh(τφ) + B sinh(τφ)`。
加入计数目标后**正则性变了**：

```
max N(m) − μ·D(m),   N(m) = Σ_j 1[ m_j ∈ I_j ],  I_j = [θ_j, θ_j+3] ∩ [0,1]
```

逐槽可分 + 每槽收益恒为 1 ⟹

1. `[证]` **不是 Euler–Lagrange 问题**：计数项的「梯度」在条带边界是 δ 测度，
   光滑罚项 (ρ², S_ρ²) 相对它是**次阶**。解是**自由边界 / bang-bang**：
   ```
   m_j ∈ { 0,  θ_j  (快侧竞争，贴下沿),  θ_j+3  (慢侧竞争，贴上沿),  1 (免费段，任意) }
   ```
   每槽的代价 `c_j = w_j·m_j²`（取条带内最便宜的点）⟹ **均匀收益 + 逐槽代价 = 背包**，
   贪心即最优（`[量]` DP 与贪心逐位一致，见代码 §5/§10）。
2. `[证]` **形状的极限**：条带内的最优「形状」是**贴着边界滑行**，而由 §1.4 的恒等式，
   滑行 = **ν 常数**。于是 `N` 的**无约束极限是「若干段常数频率」的谱**。
3. `[量]` OLMo 上的**精确 N 前沿**（贪心，无族假设）：

   | 累计 Q̂ | N | 边际买的槽 |
   |---:|---:|---|
   | 0.000000 | 14 | 免费段 only |
   | 0.000051 | 21 | 7 个慢侧竞争槽（几乎免费） |
   | 0.000308 → 0.008807 | 22 → 24 | 槽 24、23、22 |
   | 0.027109 / 0.070912 | 25 / 26 | 槽 21 / 20 |
   | 0.166998 | 27 | 槽 19（入口最高，最贵） |

   **快侧 6 个槽的入口代价极不均匀**（0.00026 → 0.096，360×）：
   进入越早，ν 被压得越狠，代价按 `w_j θ_j²` 涨。

## 4. 任务 3：两条路的极限对比

**结论：EVQ（重分配）的 N 上界严格更高，差距是结构性的，不是数值的。**

| | 三段式（YaRN/MrRoPE/BM） | EVQ（log-间隔重分配） |
|---|---|---|
| 参数化的硬约束 | **m 单调**（`0…0│ramp│1…1`） | m 可降（受 ν 严格递减约束，每槽 ≤ 0.148） |
| 快侧 6 槽 | 赢 ≤3（ramp 以 ρ≈0.04 穿过条带） | 赢最多 6（贴条带下沿） |
| **慢侧 7 槽** | **结构性赢不到**：平台 `m=1 > θ_j+3` | **可赢全部 7**（贴条带上沿） |
| N 上限（压缩已交付） | **20**（N=17 已实测） | **27** |
| 达到 N=17 的代价 | Q̂ = 0.0637 | — |
| 达到 N=20 的代价 | Q̂ = 0.383（`step_hi19`） | Q̂ = 0.169（快侧翼） |
| 结构 | 单次穿越 | **双翼 + 平台（两次贴边）** |
| 极限形态 | 阶跃 | **常数 ν 段**（违反 RoPE 前提，见 §6.1） |

**为什么三段式更低**：不是「有平台」，也不是 span 扩展 —— 是 **m 必须单调**。
慢侧竞争槽的可读条件是 `m_j ≤ θ_j+3`，而 θ 以 −δ 下滑；要留在带内，
剖面必须以 ≥ δ 的速率下降，而 ν 严格递减**禁止**比 δ 更快的下降。
**贴着 `θ_j+3` 滑行是唯一合法解，而它要求 m 下降** —— 单调族做不到。
反过来，快侧竞争槽（`m_j ≥ θ_j`）对单调族是**可行的**，只是要花钱：这正是 β 从 32 推到 64 买到的那 3 个槽。

> **一句话**：三段式买的是「位置尺度」（span + ln4），EVQ 能买的是「穿越区的 ν 平坦度」。
> 在 N 这个机制下，**后者是更贵的那个变量**，而它恰好是慢侧 7 个槽唯一的门票。

## 8. 追加：把「span 守恒」放进 forcing 框架（回答 team-lead 的判决性问题）

**框架**：`ε_j = m_j − m_{j−1}`（`m_{−1} = 0`），`f = Lε`，`L` 为零边界一维 Laplacian。
本节的数是当场算的（`[量]`）。

### 8.1 span 在 forcing 框架里是什么

```
span_m := m_63 − m_0 = Σ_{j≥1} ε_j        （丢掉 ε_0，它只定偏移）
ln(ν_0/ν_63) = lnθ·(K−1)/K + ln4·span_m   （nats）
```

`[量]` **四个角全部落在 `mass = Σε = 1`、`span_m = 1` 这一片上**（它们本来就是归一化的），
彼此只差 **f 的形状**。所以：

> **span 是 ε 的零阶矩（forcing 两端尖峰的净额），而 team-lead 的四角是在 mass=1 切片内
> 按 f 的形状区分的。mass 与那四个角是正交的两个轴，不是同一坐标的换法。**

| 表 | mass=Σε | span_m | ε 支撑 | f 的形状 `[量]` |
|---|---:|---:|---|---|
| BM（部署） | **1.0000** | 1.0000 | [15,32] | j=15..32 上 **+0.00175 常值**，两端反号尖峰（j=14 −0.0158、j=33 −0.0158） |
| MrRoPE | **1.0000** | 1.0000 | [15,32] | 内部 0，**j=32 +0.11111 / j=33 −0.10526**（末端单极） |

| **evq_shift τ=1** | **−0.0130** | **0.0045** | [0,63] 全域 | **两端反号：j=1 −0.0178、j=63 +0.0260**（**偶极子**，净额 ≈0） |

### 8.2 三条判决性结论

1. `[证]` **任何表都能写成 `Lε = f`**（全网域零边界下 Poisson 解唯一）。**"band" 不是框架的一部分，
   它是解 ε 的支撑集**——所以 EVQ **能**进这个框架，只是 ε 全域非零。
2. `[量]` **`evq_deploy` 不是 span 守恒的那条路。** 它的 mass = **0.9908**、span_m = **0.9849**
   ——与 YaRN 家族同一个 mass 片（1.0000），只是支撑从紧支撑变成全域。这与
   [REANCHOR](REANCHOR_KKT_20260911.md) §1 的更正一致：**拿 `m_evq_deployed` 当 EVQ 是本项目
   已经犯过一次的建模错误。** span 守恒的是 `evq_shift`（ν=θ^{−φ}）。
3. `[证]` **span 守恒 = forcing 是偶极子，span 扩展 = forcing 是单极子。**
   四角全是单极（末端尖峰无对手，净额 1）；`evq_shift` 快速端一个**负**尖峰 + 末端一个正尖峰，
   几乎对冲（τ=1 净额 −0.013）。**这是同一个空间里的另一个点，不是在别的坐标里重画四角。**

### 8.3 对「一个理论能否覆盖两条路」的回答

**能，但条件是把 band 限制去掉。** band 限制（ε 在带外恒 0、两端 Dirichlet）**本身就是在假设
span = 1** —— 它结构性地禁止了快速端尖峰。所以「EVQ 在我的 band 家族之外」这句话，
正确的读法是：**band 限制与 span 选择是同一个动作**。把框架放到全网域后，设计变量是 f 本身：

```
mass(f) = Σε = span 扩展量        ← 零阶矩，四角在这一维上全部相同
shape(f)                        ← 四角在这一维上互相区分
快速端尖峰（负）↔ 间隔重分配       ← EVQ 走的正是这一维
```

**旁证（已测）**：`K_taper` / `K_both` 是本项目**唯二 ε 有负项**的实测表
（[RESOLUTION_MISSING_TERM](RESOLUTION_MISSING_TERM_20260911.md) §2 已指出 `K_taper` 的
`p = ε/Σε` 含负项），而它们正是 Σm 排序错得最离谱的两个点（预测 0.0–0.11，实测 0.385/0.394）。
**forcing 框架的"第五个顶点"在数据里已经有弱证据。**
