# 第三次收缩：新增的 KNIFE 数据**同时削弱了 `S` 与 `C`**

**日期**：2026-09-11 · 12 个 OLMo 16K RULER 点（原 9 点 + 3 个 KNIFE 格）

## 1. 结果

| 量 | 9 点时 | **12 点时** | 线性拟合残差 rms |
|---|---|---|---|
| `S = Σm` | Spearman +0.900 | **+0.734** | 0.1023 |
| **`C = mean(min(1,4^{m−1}))`**（`mechanism` 的覆盖量，9 点时 R²=0.938 **优于 S**） | +0.938 | **+0.706** | 0.1298 |
| `μ_ε` | — | −0.692 | 0.1292 |

**`C` 在 9 点上比 `S` 好，在 12 点上比 `S` 差。它没有survive新数据。**

## 2. `C` 的死因是一对**反向排序**

```
C(MrPro)             = 0.6727   →  RULER 0.0709
C(knife_d0p0063_a0)  = 0.6436   →  RULER 0.3937
```

**`C` 说 MrPro 更好，数据说反了 32 个百分点。** 一对直接反例即证伪——这是
LESSONS 里反复强调的判据（负结果优先于相关性）。

## 3. 顺带发现：**`S = 64 − μ_ε` 的前提是 `m_63 = 1`，而 KNIFE 的 taper 破坏了它**

```
一般式：  S = 64·(m_63 − m_0) − μ_ε
部署表：  m_63 = 1  ⟹  S = 64 − μ_ε
taper 臂：m_63 = 0.805  ⟹  上式不成立（例：S=37.375, μ=14.13, 64−14.13=49.87 ✗）
```

**⟹ KNIFE 的「行效应」并不是纯粹的 S 旋钮**——taper 同时改了**终点条件**
（不再把最慢的槽压满）。所以那个 −2.30pp **不能单独归给 S**；它的正确读法是
**「拿掉 `m=1` 平台」的代价**（这个读法仍然成立，也仍然显著）。

**plan-design 说 taper 是「纯 S」不准确**——它在 S 之外还动了 `m_63`。

## 4. 收缩之后剩下什么

| 候选 | 状态 |
|---|---|
| `C`（机制的覆盖量） | **证伪**（一对反向排序） |
| `Σm` / `mean(m)` | **弱化**（0.900 → 0.734），仍非充分统计量 |
| `μ_ε`（质心） | 与 Σm 同量级的弱关系 |
| `Σν`、`n_plateau`、`L_ramp` | **早已出局**（`sep-cause` 的恒等式 + 全对判决） |

**⟹ 现在没有任何一个标量能解释这 12 个点。** 这不是「还没找到对的标量」——
而是**12 个点里存在真实的、标量之外的结构**（例如 KNIFE 的两对同 S 不同分的结果）。

**但这不等于「形状很重要」**：`sep-cause` 已证 4 参数模型残差是实测噪声的 **2.2 倍**
⟹ 缺的是**项**，不是**噪声**。缺的那个项**是什么**，目前没有候选。

## 5. 对已排队实验的影响

- **`b=3/4/6/8` 更有价值了**：`mechanism`（角点：全跌）与 `analytic-budget`（水填充：续涨）
  的相反预测，现在是在**没有任何标量可信**的背景下跑的——无论哪边赢，都会给出一条
  能解释 KNIFE 那两对的机制线索。
- **`C42 / C42-V24` 的价值上升**：它们**在 S 与质心固定下**改变分配，
  正是「标量之外的结构」的直接探针，而且**不破坏端点条件**（`m_63 = 1` 保持）。
- **`step_hi0`（m≡1）** 现在是唯一能判定「平台是否必要」的单臂。
