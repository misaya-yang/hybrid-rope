# 天花板/覆盖理论：用两个常数解释整场战役

**2026-09-11** · 伴生代码 `code/coverage_theory_20260911.py`（纯 numpy，复算本页每个数）
· 预注册 `COVERAGE_PREREG_20260911.md`（P1–P5，在未读结果前写入）

回答的问题：**YaRN→MrRoPE 是一个很小的改动，为什么效应巨大？
能不能用一个不含复杂参数的理论解释它，并从理论推出比 MrRoPE 更好的表？**

---

## 0. 一页答案

冻结模型每根槽的能力在训练时就封顶了：槽 j 只认识**转数 ≤ t_j(W)** 的相位模式
（W=4096 训练窗；t_j(W) = 651.9·θ^(−j/64)，从 652 转单调降到 0.13 转）。
压缩表 m_j 不改变槽认识什么，只改变**这份能力被投放到哪个距离段**：

```
槽 j 在深度 u = log4(d/W) 处可用  ⟺  m_j − min(κ_j, L) ≤ u ≤ m_j
κ_j = log4(t_j(W)/δ)     信号余量（δ=0.25 转≈90°，唯一标定常数；L≈2）
```

**m_j 就是天花板的位置**：每根活槽覆盖一段以 u=m_j 为顶、向下延伸 min(κ_j,L)
的深度窗。一张表 = 深度轴上的一组窗。任务分 ≈ 外推区 [0,1] 被多少窗覆盖
（记 n(u)），外加两条结构性约束：频谱无空洞（相邻 ν 间距 ≲2× 原生）、
快槽钉在 m≈0 保窗内局部职责。

**YaRN→MrRoPE 为什么"小改动大效应"**：ε 的形状就是天花板的分布。
ε 从均匀（YaRN，天花板铺满全区，n_int=11.99）改成 ∝k（MrRoPE，凸剖面，
70% 的带内天花板挤在 u<0.5，n_int=9.08，中段覆盖 12→8）——公式只动了一个
因子，整张 tiling 被重排。**部署 BM 的抛物线 ε（n_int=11.99）恢复了铺开
的 tiling，再加宽带（n_int 13.5→18.3）继续加密**。实测分数沿 n_int 单调：
0.07 → 0.14 → 0.23 → 0.42 → 0.50 → 0.54–0.56。

**比 MrRoPE 更好**：这个问题战役已经解决（BM/宽带家族 +34~+48pp）；本理论给出
的是**为什么**，以及下一代：**振幅 = log4(目标长度/W) × 剖面**——表应当随目标
外推倍数整体抬高。8×（32768）上现有全家 = 实测 0.0/48×4臂，理论处方
`scale8x_wide`（=1.5×宽带BM）是唯一有 8× 覆盖（n(1.5)=7）的无空洞表，已预注册。

## 1. 两条公理与两个常数

**公理 A（能力封顶）**：槽 j 在训练中见过的相位差全部满足转数 τ ≤ t_j(W)。
超出即分布外（OOD），模型对它的行为未定义——实测表现为噪声。

**公理 B（信号下限）**：槽在距离 d 上有信息量，需转数 ≥ δ（相位差 <90° 的槽
对任意两个位置给出几乎相同的内积，无分辨力）。

由 A、B，槽 j 压缩 m_j 后在深度 u 可用 ⟺ T_j = t_j(W)·4^(u−m_j) ∈ [δ, t_j(W)]。
移项即开头的窗口式。两个常数 δ=0.25 转、L=2 在敏感性网格
（δ∈[0.125,1]，L∈[1,10]）里 rho 变动 <0.02（脚本 §sensitivity）——**结论不依赖
它们的精确值**。

活槽共 39 根（j≤38；j≥39 的 t_W<δ 在训练中就近乎退化，压不压都一样）。
其中 j≤14 是窗内主力（t_W ∈ [37,652] 转，κ≥3.7），j∈[15,32] 是 18 根自由槽
（κ 从 3.45 递减到 0.61），j∈[33,38] 是 6 根"顶灯"槽（κ ∈ [0.03,0.61]）。

**外推区 [W,4W] 的深度宽度恰好 = 每根槽窗口的对数宽度量级** —— 所以表设计的
本质就是：把 18+6 根自由/顶灯槽的天花板摆进这一段，摆得越满、越用高 κ 槽，
分数越高。

## 3. "为什么这么牛逼"：形状=tiling，小公式≠小改动

ε ∝ k^a(n+1−k)^b 家族里，(a,b) 从 (1,0)（MrRoPE）到 (1,1)（BM）只是给 ε
乘了个对称抛物线因子——**但 m 是 ε 的累积和**，ε 的二阶变化直接变成 m 剖面的
曲率变化，而 m 剖面就是天花板分布：

| 表 | m 剖面形状 | 天花板分布 | n_int | 实测 |
|---|---|---|---:|---:|
| MrRoPE (1,0) | 凸（≈(k/n)²） | 70% 挤在 u<0.5，中段 8 槽 | 9.08 | 0.0709 |
| YaRN (0,0) | 线性 | 均匀铺开 | **11.99** | 未测 → **P5 预测 ≈0.42** |
| BM (1,1) | S 形 | 铺开且中段加密 | 11.99 | 0.4167 |
| wide BM | 同上+3 高κ槽 | 中段再加密 | 13.48 | 0.5384 |

**MrRoPE 论文语境（训练时用表）与我们的零训练语境不同**：零训练换表时，
凸剖面把中段覆盖砍半，就是灾难。YaRN 的均匀 ε 反而有与 BM 相同的 tiling——
所以理论给出一个未测的可证伪预测（P5）：**零训练 16K 上 yarn_uniform ≈ BM
（0.32–0.48），不介于 MrRoPE 与 BM 之间**。若实测 ≈0.2 以下，本归因被削弱。

## 4. 从理论推出的表（比 MrRoPE 好，且按目标长度参数化）

**设计规则只有一条：振幅 = log4(目标长度 / W)，剖面用已验证的宽带 BM。**

```
m*(j) = log4(s) · m_wideBM(j),   s = 目标长度 / 4096
```

- s=4（16384）：**精确等于已测的宽带赢家**——理论解释了它为什么赢。
- s=8（32768）：`scale8x_wide` = 1.5×m_wideBM。sum_m=63.0，ν 严格递减，
  无空洞（最大间隙 1.69× 原生；对照 +0.5 平移版有 4.49× 空洞，被判为劣——
  这正是 step 家族教训的应用），n(1.5)=7、n(0.95)=11，同时保住 4× 区。
  **这是全战役第一张在 8× 有非零覆盖的表**，就绪命令与表文件见
  `code/tables/`、`code/patch_mfile.py`，判据见预注册 P1。

为什么不是继续在 m≤1 盒子里调形状：**8× 全零已经判决了那条路**（§2 第一行）。
盒子的边界不是形状的边界，是覆盖范围的边界。

## 5. 边界与不自量力的部分（照旧不藏）

1. **二阶形状效应无分辨率**：C42/C42V24、平台成员互比、condEVQ±——理论只给
   一阶（谁有覆盖、谁有空洞、覆盖多少），±2pp 以内明确放弃。
2. **窗内侧（u<0）的定量化最弱**：interp 的失败读法用了过度压缩界 L≈2；
   δ、L 的敏感性稳定，但"过度压缩=浪费/干扰"的机制解释停留在模型层面。
3. **n_int 与 S 在家族内共线**（rho 0.926 vs 0.924）：理论的证据力不在相关性，
   而在结构预测（零 vs 非零、空洞、8× 塌零、分层交换）——这些是 S/N/12 个
   静态泛函全部给不了的。
4. **8× 全零的预测部分样本外**：理论标定只用 4× 数据（holdout180 分层在先），
   但我在读 s8 拆分前只知道合并分 0.2447——诚实记为"半预期"。
5. P1–P5 全部未读；理论的可操作部分押在 P1（scale8x_wide 8× 非零）上，
   0/48 即证伪处方。

## 6. 与既有框架的关系

- **四角/Lε forcing**（FOUR_CORNERS）：forcing 是 m 的差分算子，本理论是它的
  语义层——forcing 形状 ⟺ m 曲率 ⟺ 天花板分布。"形状不预测"（NO_STATIC
  §六）说的是 forcing 坐标下的静态形状；天花板分布是**带 per-slot 训练边界
  解释的**形状，在家族内给出单调序（且不与"形状相关 0.899 结果相反"那对
  冲突——那对本理论也不分辨，属二阶）。
- **EVQ_LIMIT 的可读窗 N**：N 是 n(u) 在 u=1 的单深度切片＋全局带界；本理论
  把它推广成整条 n(u) 曲线，修掉它的 native 反例（per-slot 边界），并加上
  空洞与窗内两个约束。他们的"条带斜率 ≡ ν 退化斜率"恒等式就是本理论里
  窗口向下延伸率与 κ 的关系。
- **约束松弛**（CONSTRAINT_IS_SLACK）：带内窗内代价平坦 ⟸ 活槽在窗内
  深度的覆盖弹性大；代价在带外 ⟸ 破坏窗内主力槽或制造空洞。同一个事实，
  本理论给出坐标。
