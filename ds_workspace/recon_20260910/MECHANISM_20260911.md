## 1. 物理：一个槽在测试距离 D 上贡献什么（定量）

RoPE 的 logit 里，槽 j 对相对距离 Δ 的贡献**精确地**是

    z_j(Δ) = a_j·cos(ν_j·Δ + ψ_j)

（a_j = |q_j||k_j| ≥ 0，旋转不变性）。整张表的作用就是把这 64 个频率摆好，其余都是内容。

**校准段（本文的核心量）。** 模型学到的映射是"相位 → 位置"，且它**只在窗内被训练**：位置 Δ' ∈ [0,W]。压缩 m_j 后，测试距离 Δ 上 slot j 的相位等于原频率下 Δ·4^(−m_j) 处的相位。所以

> **slot j 在 Δ 上仍是一个"被校准过的位置读数" ⟺ Δ ≤ W·4^(m_j)。**

在整段 [0, D] 上，校准覆盖比例 = **min(1, 4^(m_j−1))**（[已证]，定义直接算出）。

**漂移。** 相对原生轨迹，slot j 在 Δ=D 处的相位差是

    d_j(D) = 4·t_j·(1 − 4^(−m_j))   圈            [已证]

边际 ∂d_j/∂m|_(m=0) = 4·t_j·ln4 = 2.77·t_j。数值：slot 0 → 3615 圈/单位 m；slot 12 → 309；slot 20 → 59.9；slot 32 → 5.1；slot 63 → 0.009。**跨度 707×[已证]。**

**所以 Q1 的定量回答是**：4× 外推下，"压得更多"= 把该槽的相位轨迹拉回校准段内；需要的压缩量正好由外推倍率给死（要在 Δ=4W 处仍被校准，需 Δ·4^(−m) ≤ W ⟺ m ≥ 1）。**每多压一格，就少一个槽处在"读数超出校准段"的状态。** 而它的代价是漂移，且漂移 ∝ t_j——**代价几乎全部由快端付，收益几乎全部落在慢端**。这一条不对称是整个机制的全部内容。

## 2. α=1 是被推出来的，不是手调常数 [已证]

t_j < 1 的槽，窗内相位只走过 2π·t_j 的一段弧；**圆上剩下的 (1−t_j) 从未被损失函数约束过**（那是初始化+训练留下的任意函数）。测试端它的相位前进 4^(1−m_j)·t_j 圈，一旦 Δ > W·4^(m_j) 就走进那段未约束相位。

> **m_j = 1 是唯一让整段 [0,4W] 都留在训练弧上的取值。** ⟹ 对所有 t_j<1 的槽必须全压，这正是 α = 1。

实测支持：**a0p5_b32 是九个臂里唯一违反它的**（slot 32/33/34 的 m = 0.9334/0.9656/0.9881），把 **7.7% / 4.7% / 1.6%** 的测试段留在未约束相位上（`mech_final.py §2`）。它比自己的预算该得的分低 3.8pp（覆盖轴拟合 0.1982 vs 实测 0.1604）。**一个成功（β=64 把 α 保持在 1）与一个有判别力的失败（α=0.5），同一个机制解释。**（L4）

## 4. Q3 —— β=64 到底改了什么（硬数字，与"上界"叙事相反）

β: 32→64 只把带从 [14,32] 挪到 [11,32]，**新增的三个槽（12/13/14）拿到 m = 0.0119/0.0344/0.0666**：

    ΔΣm = 1.500   =   0.113（slots 12–14） +   1.387（slots 15–31）
    边缘三槽的份额 = 7.5%                      重塑形份额 = 92.5%

**[已证] β=64 的增益 92.5% 不是"允许更多高频槽进带"，而是把 ramp 在 slots 15–31 上整体重排到更靠快端。** 原因：在 slot 空间参数化的 ramp 里，带宽 n 同时决定 ramp 的形状（`m_turns` 的 `lo,hi` 同时定带与形状）。所以

> **β 不是物理量，它是 YaRN 家族里唯一能在不动两端点的前提下把"压缩前缘"推向快端的旋钮——即 t\* 的代理旋钮。**

在机制坐标里：β=32→64 把 t@50 从 5.84 推到 7.94、t@75 从 2.97 推到 3.63、C 从 0.7055 到 0.7200、漂移 161→254 turns。**它为什么"在这里是好的"：因为在这套表里，提高 β 是提高 t\* 的唯一手段。** 推论（P4/P2）见 §7。

## 5. 角点定理与天花板 [假设下推导]

设每槽净效用

    G_j(m) = 0.25·4^m  −  λ·4·t_j·(1 − 4^(−m))        （效用 = C 的被加项；代价 = 漂移）

则 G''_j(m) = (ln4)²·[0.25·4^m + 4λt_j·4^(−m)] > 0，**严格凸 ⟹ 每槽最优必在端点 m ∈ {0,1}**。角点判据：

    G_j(1) − G_j(0) = 0.75 − 3λ·t_j  > 0  ⟺  t_j < 0.25/λ ≡ t*

> **最优表是转数坐标下的阶跃：m_j = 1[t_j < t\*]，不是 ramp。**

**天花板在哪：** C 在 m=1 处饱和（C ≤ 1），而漂移无界增长 ⟹ 存在内点最优 t\*。λ 由窗内约束定：Σ_(t_j<t*) (1/2)F_jj(ln4)² ≤ ε，其中 **F_jj 是可测的**（`curvature_20260910/local_probe.py --fisher diag`，64 次前向）。所以

> **天花板在 t\* 上，不在 Σm 上。Σm ≈ 42 是 ramp 参数化的产物，不是物理位置。**

而 t* 在某区间内是**算出来的**：λ 自洽解出后 t\* = 0.25/λ。当前九个点把 t\* 读在 **4–8**（a1_b64 的 t@75=3.63、t@50=7.94；β=128/256 会把它推到 4.75/5.80）。

### Q2：为什么 m≡1（纯插值）不是最优——四条定量理由

1. **饱和**：m≡1 时 C = 1.0000，已是上限。再多压买不到任何覆盖（`mech_final.py §6-PI`）。
2. **漂移爆炸**：Σ_j d_j(D) = **10549 turns**，是最优臂（a1_b64，254）的 **41×**；其中 slot 0–11 占 **91.5%**，slot 32–63 只占 0.14%（[已证]）。机制说这笔钱买不到东西。
3. **窗内代价**：它动了**每一个**槽，包括 ∂L/∂m 量级最大、F_jj 最大的 slot 0–11（CONTRACTION_KKT1 实测那里 |∂L/∂m| = 10–70，而槽 24+ 是 ≤0.05）。
4. **token 尺度分辨率**：Σ_j(1−cos ν_j) 从 native 的 **1.4138** 掉到 PI 的 **0.0926**，比值 **0.0655 ≈ 4^(−2) = 0.0625**（三种加权下都是 0.066±0.001，[已证]）。**token 尺度的位置对比度掉 15 倍**，而 RULER 的答案是**多 token 串**，需要在 token 尺度上定位。

**一句话**：m≡1 把预算全花在"已经是校准的槽"上（覆盖已饱和），同时把分辨率、窗内代价、漂移三样全部付满。**最优只能在"覆盖还能涨、漂移还付得起"的中间——而在给定 t_j 后这个折中是角点，所以最优形状是阶跃。**

## 7. 可证伪的定量预测（全部要新臂判决；按判别力排序）

**P1 — 最便宜、最判别（一条臂）。**
`step_t4`：m_j = 1[j ≥ 25]，Σm = **39.0**，C = **0.7070**（≈BM 的 0.7055），漂移 **62.7 turns**（BM 的 161 的 **39%**）。
- 机制 ⟹ **≥ BM 的 0.4167，可能接近 0.50**；
- Σm 线性外推 ⟹ 只有 **0.2222**。
**若 step_t4 落在 0.22 附近 ⟹ 本机制死，Σm 是主变量。** 若落在 0.5 附近 ⟹ 形式预测成立且 Σm 是代理。

- 机制 ⟹ **不涨或下降（≤ 0.538）**；Σm 外推 ⟹ 0.70 / 0.85。
两条预测差 0.2–0.3，**这一对单独就能定案**。

**P3 — 已排队。** beta_b3/4/6/8：C = 0.746/0.758/0.775/0.785，漂移 247/278/324/357。
- 机制 ⟹ **全部低于 b=2 的 0.5001，且随 b 单调下降**（b=3 的 t@75 = 6.95 已越过读出的 t\*）。

**P4 — 已排队（chain_v6b），且与 WHY §6 冲突。** OLMo leak 族：

|---|---|---|---|

- WHY §6 的 H_budget（"花在哪都行"）⟹ leak 应赢。
**方向相反的两条预测，跑完即判。**

**P5 — 天花板是算出来的（64 次前向）。** `local_probe --fisher diag` 给 F_jj；由 Σ_(t_j<t\*) F_jj = 2ε/(ln4)² 自洽解 λ，t\* = 0.25/λ。
**机制说：若 F_jj 随 t_j 上升（快端窗内更贵），t\* 小；若下降，t\* 大。** 这个符号现在**没有数据判过**（leak 的"便宜"可以用 m² 很小解释，不是 F 小）。跑完即可把 t\* 从"读出来的 4–8"变成"算出来的"。

**P6 — 形状与前缘解耦。** 同 t\*、不同过渡宽度（阶跃 vs b=2 型 ramp）各一条：**阶跃应赢**。

**L2/L8 兼容性检查**：阶跃的最大增量 = 1 > c = 2/(N+1)，**不在 L2 的排除域内**；阶跃与原表至少在 30+ 个槽上不同，**远过 L8 的 ≥2 槽门**。

## 8. 本机制**不能**解释什么（必须一起读）

1. **t\* ≈ 4–8 的数值不是推出来的。** 机制给的是**形式**（阶跃）与**算法**（Fisher 自洽），不是数值。数值目前是从九个点读出来的，等价于一次拟合。
2. **机制建立在转数坐标上，因此预言 OLMo 与 Qwen 同序——这是已知错的。** KKT_ANALYTIC §4.3 已证伪转数普适性（Qwen 上 b=0 > b=1）。所以本机制**必然不完整**，缺的正是 λ 与漂移容限的 checkpoint 依赖性（F_jj 与 δ 是模型特异的）。这不是补丁，是机制的一个已证伪推论。
3. **唯一的支配序违反**：b2（C=0.7294，漂移 209）在两轴上都不差于 a1_b64（C=0.7200，漂移 254），却低 3.8pp。在噪声内（350 行、无 seed），但不是零。机制对它没有说法。
4. **给不出绝对分数**，只能给排序与反转。
5. **最弱一环**：§3 的覆盖-分数比较用的是 OLMo 分数对 OLMo 表（比 WHY §7 的"Qwen 窗内曲线对 OLMo 分数"干净），但 §5 的窗内约束仍引用 Qwen 32K 的实测代价曲线。**F_jj 必须在 OLMo 上直接测。**
