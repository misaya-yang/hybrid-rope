## 0. 一句话答案

**它们是为同一个约束优化问题服务的两个 Ansatz 类，但作为参数化它们解的是两个不同的问题——
分歧 100% 落在"保持区（高频段）m=0"这一个边界上，而那里正是两族对原生侧代价的不同信念所在。**
统一陈述见 §3 末；数值依据见 §1–2；判决实验见 §5。

### 1.2 每族"变什么、保什么" `[已验证]`

- **三段族**：变 (lo,hi) 两个整数（转数坐标下 (α,β)）+ 桥内增量形状 ε_q（Σε=1，1 个形状自由度）。
  保：**span 恰为 1**（m_lo=0, m_hi=1，总跨距 = native + lnS 恰），两端精确平台。
- **EVQ-deployed**（ν=ω·S^(−φ)）：变 τ（1 个自由度）。保：函数形式（asinh companding）——
  但**端点并不精确**：m0=+0.0049, m63=+0.9893（τ=1.414），span=0.9844，
  比三段族的 1 短 0.0156 m = **0.0216 nats**。tables.py 里"Endpoints are then m_0=0 and
  m_63=1"的 docstring 在离散网格上是**不成立的**（连续极限 u→0/1 才成立）——"受控对比"只受控到 span 的 1.6%。
- **EVQ-shift**（ν=θ^(−φ)，即训练态 EVQ 对 native 网格的读数）：变 τ。保：**span ≈ native span**
  （φ63−φ0 = 0.984855 vs native 63/64 = 0.984375，多 0.0066 nats）——纯再分配、零扩展；
  Σm = −24.2 是自由的。
- **power_shift**：变 p（1 个自由度）。保：端点**精确** 0/1（归一化强制）、span 恰为 1；
  但内部是**全局支撑**（held=plat=1，只有两个端点本身）。第三种结构型：精确端点锚 + 全局内部。

### 1.3 "EVQ 的预算 == 三段族的 Σm（=带宽 n）？"——不 `[已验证]`

- 三段族守恒的是 **span**（Σ_{带} Δ_q = 1，逐增量归一），Σm 是自由决策变量：
  同 span 下 MrPro 29.33 / YaRN 30.10 / BM 32.00（R4 的数值确认）。带宽 n=17 ≠ Σm。
- EVQ-deployed 花的是**同一个 span 预算**（0.9844，见上），其 Σm 在 τ=1.414 时 = 27.55，
  落在三段族范围内；**τ*=1.0540 时 Σm = MrPro 的 29.3333 恰等**，但 span 仍 0.9848、gap 范围
  [0.2321, 0.2418] vs MrPro [0.2159, 0.3699]——**Σm 匹配后分配结构依旧完全不同**。
- EVQ-shift 花的是**native span 的再分配**（零扩展），Σm = −24.2 自由。
- gap 比（EVQ 自己的"spacing budget"量）：MrPro max/min = 1.713（71% 集中在 17 个带槽）；
  EVQ-deploy τ=1.414 = 1.069（6–14% 摊在全部 64 槽）；EVQ-shift τ=1 = 1.529
  （**高频侧被压到 native 之下** 0.1659，低频侧扩到 0.2536）。
- 结论：**共同预算是 span（总对数频率跨距），不是 Σm**；两族在 Σm 上可重叠、在 span 的**花法**上不可重叠。

## 2. 三段式是 companding 的退化极限吗？——是（弱极限），但不是 EVQ 家族的极限

- **是**：任何 companding φ 的斜率密度 p = dφ/du 弱收敛到带槽上的原子测度 Σ_q ε_q δ_{v_q}
  （带外斜率一致趋于 0）时，离散表收敛到三段表。数值演示 `[已验证]`（高斯宽度 σ 扫）：

  | σ | max\|Δm\| vs MrPro | 保持槽 | 平台槽 | Σm |
  |---:|---:|---:|---:|---:|
  | 1.00 | 3.685e−1 | 1 | 1 | 31.792 |
  | 0.10 | 2.247e−1 | 1 | 1 | 29.334 |
  | 0.02 | 5.408e−2 | 16 | 15 | 29.33333 |
  | 0.003 | **5.117e−4** | 23 | 23 | 29.33333 |

  即三段表在"光滑 companding 空间"的**闭包**上（σ→0），不在其内部（任意有限 σ 无精确平台）。
- **不是 EVQ 家族的极限** `[已验证]`：EVQ 的密度 τcosh(τ(1−φ))/sinhτ 对所有有限 τ 全支撑、光滑；
  τ→0 给**全表线性 ramp**（m=u，held=0/plat=0，Σm=32——"带宽=全表"的退化三段）；
  τ→∞ 给 **native**（Σm ≈ 63.65/τ，τ=32 时 1.989，衰减中）。中间任何 τ 都不产生紧支撑带，
  且 EVQ 没有宽度旋钮。两个端点都是退化三段，但都不是紧凑带。
- 结构差别的精确表述：**支撑**（全局光滑 vs 紧支撑+精确平台）与**守恒量**
  （三段 span 恰 =1；EVQ-deployed span=0.9844 短 0.0216 nats；EVQ-shift span=native span、Σm 自由）。

## 3. 决定性不对称："高频区留在 m=0"是定理还是启发式？

**KKT 陈述。** 问题：min L_long(m) s.t. D_N(m) ≤ ε，盒约束 m ∈ [0,1]，端点/span 锚定。
在保持槽 m_j = 0 处，盒约束 −m_j ≤ 0 的乘子条件给出（μ_j ≥ 0）：

    λ · ∂D_N/∂m_j |₀  ≥  − ∂L_long/∂m_j |₀   ⟺   λ·n_j ≥ |g_Lj|     （保持区逐槽可查不等式）

其中 g_Lj 是长程梯度（Phase-0 已测：槽 0–16 均值 **−21.7**、峰值 −27，槽 40–63 ≈0.062），
n_j 是原生侧边际（m=0 处的右导数），λ 是漂移约束的影子价格（Pareto 斜率 dL*/dε，
可用 TURN_WINDOW 的 λ = max(0, −nᵀe/nᵀn) 估计）。

**答案是"有条件的定理，目前是启发式"。**

- 在项目的平滑漂移模型下（D_N = ½δᵀF_Nδ，solve_kkt.py），**n_j = 0 是构造性的**（二次型在
  展开点无一阶项）。数值核对 `[已验证]`：C(e)=e²/3 的 dC/dm|₀ = 0 恰，
  单侧差商 C(h)/h 随 h 线性趋于 0（槽 0：1.74e4→1.74e0，h=1e−3→1e−7）。
  代入不等式得 0 ≥ 21.7 ——**不成立**。平滑模型下的最优解**必然**把 m 渗入每个 g_L < 0 的槽
  （EVQ 式的全局支撑），精确平台 m≡0 不是平滑问题的 KKT 解。
- 精确平台要成为最优，只可能来自：(i) 原生代价在 m=0 有**一阶扭结**（kink，不等式内容）；
  或 (ii) **精确结构点**论证（DERIVATION §6）：m=0/m=1 是旋转算子与训练算子逐位恒等的唯二点
  ——这是**设计面**（R3），不是边际计算的结果。
- 因此："高频区留在 m=0"是 **YaRN 继承下来的设计锚（启发式）**；它成为定理当且仅当上述
  逐槽不等式成立。Phase-0 只测了右端；**左端（m=0 处原生边际 n_j，槽 0–16）是缺的那次测量**。

**附带张力（一句话）**：可分的平滑模型（C=e²/3 + 随目标圈数单调的长程项）对任意 m 都有
f′_j(m) > 0——**它预言 native 全表最优**，连一张部署表都生不成（DERIVATION §5 的内点 FOC
因此是退化的）。而且 Phase-0 的**符号**（压缩高频钟降低长程损失）与"圈数单调"模型相反，
指向混叠/干涉机制——恰好是 R1 禁止进入目标函数的项类。**符号是测出来的，不是建出来的。**
以上仅作诊断（L1），不作能力声明。

**统一陈述（the unified statement）**：在 span 锚定、m 单调、盒 [0,1] 下，
min L_long s.t. D_N ≤ ε 的最优表 = 逐槽一阶条件（内点）+ 两个边界判据：
快边界 m_j=0 ⟺ λ·n_j ≥ |g_Lj|（本稿的检查式）；慢边界 m_j=1 ⟺ 长程边际消失或设计锚。
EVQ 与三段族都是该问题的可行参数化，分歧全部落在快边界：**EVQ 的参数化假设 n_j 在 m=0 处
二阶（渗入免费），三段族假设一阶（扭结）或精确锚**。哪个对，由 §5 的实验裁决。

**打分**：128K 尾部 NLL + 128K/32K RULER 36 行面板，归档同款 harness（L6）。窗内分预判
**两族都预言平坦**（round 1：34 臂 5e−3 nats 内；渗漏的窗内代价是 η 的二级小量）——
窗内是 sanity gate，不是判决轴。判决在 128K：

- **同一问题（平滑原生代价，n_j≈0）**：B/C 的 128K NLL 应**改善**，方向由 Phase-0 符号保证
  （Σ_{17..22} g_Lj·η，量级用双 η 自校准），窗内不动 → 三段族的 m=0 是同一问题的**过约束**，
  EVQ 的全局支撑合法，统一陈述取平滑 KKT 版。
- **不同问题（m=0 处一阶扭结/精确锚）**：B/C 在 128K **无增益**且窗内 NLL 可测上升（原生门失败），
  或两端全平 → 平台是带扭结代价的主动集最优，EVQ 的全局支撑不合法，统一陈述须含精确锚项。
- **两条分支都是结果**（L4）。成本：3 臂 × 2 长度，同现有 frozen-Qwen 面板量级，无训练。
  **预检**：先用单侧原生探针测 n_j（m=0，槽 17–22），不等 GPU 即可预选分支。
