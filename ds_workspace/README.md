## 留下的经验

- 固定频谱几何或平均NLL的改善，不直接推出每类下游任务改善。
- gain与频率表可能交互；纯配置比较需要保持gain一致。
- 开发面板的胜利必须保留对应留出结果，不能移用成另一方法的证据。
- 旧符号／reader错误已有更正；以原始对照身份和修正后的结果为准。

失败结论可以帮助排除解释；其过时推导、旧队列与重复实现没有必要长期占据工作树。
