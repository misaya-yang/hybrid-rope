# Hybrid-RoPE

研究 RoPE 频率分配与长上下文能力，目标是构造有实际收益的位置编码方法。
活动论文位于 `paper-2027/`。

## 现阶段核心任务

从 MrRoPE-Pro 的有效方案出发，在冻结预训练权重的条件下改进位置编码，目标是在同一评测口径下超过基线并达到 **85 分**。具体模型、评测集和评分方式见实验协议。

本节由作者在阶段完成后通过 Codex 手动更新。
