# Hybrid-RoPE

研究 RoPE 频率分配与长上下文能力，目标是构造有实际收益的位置编码方法。
活动论文位于 `paper-2027/`。

## 现阶段核心任务

以 MrRoPE-Pro 为起点，开发零训练的位置编码改进方法，使模型在长上下文任务上的实际表现优于 MrRoPE-Pro。通过相同模型、输入和评分条件下的比较验证增益，先取得有价值的局部突破，再检验其适用范围。

本节由作者在阶段完成后通过 Codex 手动更新。
