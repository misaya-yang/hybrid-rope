## 0. 成功的定义(先定死,防止事后挪门槛)

**这不是一个"实验",是三个目标不同的东西。分开判定,禁止混合报告。**

| 目标 | 判定标准 | 我的成功概率估计 |
|---|---|---|
| **G1** 解释已有负结果 | 定理→预测的改写通过内部复核,七臂负结果被重新归类 | **~95%** |
| **G2** 成熟模型 4K 无损 + 8K/16K 有增益 | 4K bitwise 等于 Native;8K/16K 严格自回归分数 > 匹配 Native 控制 | **~45%** |
| **G3** protected 恢复到 Native 4K 水平 | RULER 4K macro 追平 72.19 | **~8%** |

**G3 我认为基本不会成立,理由是定理:被换掉的 63−m 个通道功能不可静态还原。** 若把 G3 当作目标,几乎注定失败;把它当作"把 42.44 往上推多少"的度量,则是有意义的。

**G2 是唯一真正值得赌的。** 它的 4K 部分是**构造保证**的,不是训练出来的 —— 风险 100% 集中在"残差能否在 100 步内学到 8K/16K 的东西"。

## 1. 阶段 0 — 零 GPU(先做完这一段再考虑付费实例)

### S0.1 定理→预测改写

**产出**:`theory_results/` 一份改写稿,把 `OLMO2_POSTHOC_FREQUENCY_TRANSPLANT_OBSTRUCTION_20260726.md` 提升为约束性结论,并把 `NON_RULER_ADAPTATION_SEARCH` 的七臂重新归类为定理的独立确认。

**判定**:七个臂是否**全部**落在"原地替换 + 事后适配"这一类。若有任一臂不属于该类,改写不成立,必须缩小结论。

⚠️ **这是可证伪的,不是包装。先做这个检验,不通过就不要写。**

### S0.2 C_app 条件极小化(修掉 protected 的硬伤)

**输入**:OLMo-2 b=500K, d_head=128, K=64, τ=2 的 Native 表与 EVQ 表;论文中已标定的 α, β。

**做法**:对 m ∈ {4, 8, 16, 24, 32},以及若干候选保护集,求

\[
\min_{\{\varphi_j\}_{j\notin\mathcal P}} C_{\rm app}\big(\{\varphi_p\}_{p\in\mathcal P}\cup\{\varphi_j\}\big)
\]

**产出三张图**:
1. **可交换性曲线**:条件极小值 − 无约束极小值,随 m 的变化。
2. **每 pair 的保留代价**:单独保护 pair p 使目标上升多少 → 给出"保护便宜/保护昂贵"的通道排序。
3. **精确核碰撞分数**:条件解 vs 索引级拼接表,在 exact kernel 上的碰撞分数对比。

**关键判定**:索引级拼接表(当前 GPT 规格)在最快 16 对被保护时,最小 log 间距 **0.0062** vs 几何 **0.2050**(已算)。条件解必须显著优于它,否则 §3 的修正没有意义。

**这一步本身就是一条可发表的结果,零 GPU。**

## 2. 阶段 1 — 低成本 GPU 诊断(无优化器)

### S1 Stage D 功能带诊断

沿用 `OLMO2_NATIVE_IMPORTANCE_PROTECTED_EVQ_HYPOTHESIS_20260728.md` §4 的已实现代码,**门槛不改**:

- ≤16 对达到 80% 聚合 KL;两个行半各自 ≤16;
- split-half 余弦 ≥0.98;Jaccard ≥0.60;每层捕获 ≥50%。

**新增一项(本计划要求)**:记录选中集在频率轴上的位置分布。

> **这一项直接决定后续路线:**
> - 若重要 pair **集中在快端** → 索引级拼接会制造 4 组近似重复(已算),**必须走 S0.2 的条件解**;同时说明"in-window 靠快通道",与 LeRoPE dominant band 的解释一致。
> - 若重要 pair **分散** → protected 路线的保护预算不够,**直接放弃 G3**,资源全部转向 far-only。

**成本**:无优化器前向,16 行 × 16 位置 × 16 层。**分钟级。**

## 3. 阶段 2 — far-only 慢端残差(G2 的主赌注)

### S2.0 相对 GPT 原规格的三处改动

| 项 | 原规格 | 本计划 | 理由 |
|---|---|---|---|
| 残差频率 | 完整 endpoint EVQ 表,128 维 | **EVQ 慢端子集 λ ≥ 5×10⁵,16~32 维** | λ=5×10⁵ 时 4K 内 cos 仅变化 **0.0013** → 近距离自动惰性,门控边界无硬不连续 |
| 拼接后头维 | 256 | **144~160** | D256 Flash SDPA 可用性是原规格 gate 里最可能失败的一项 |
| 硬位置门 | 保留 | **保留** | 4K bitwise 恒等的保证不能丢 |

**保留原规格的一切其他内容**:单次 SDPA、单次 softmax、V 侧零填充、Native 输出投影不动、路由在 prefill 前锁定、非空 cache 拒绝切换。

### S2.1 GPU READY gate(原规格 §4,逐条保留,不放宽)

新增一条:
> 9. 残差旋转缓冲区的所有波长 ≥ 5×10⁵,且与 Native 表无任何 pair 的 log 间距小于几何间距的 50%。

### S2.2 训练(单次,不扫参)

沿用原规格 §3 全部超参(100 步,micro 1 / accum 4,LR 5e-5,gain init 0.1,位置偏移 4096/4096/12288/12288,物理长度 ≤4096)。

⚠️ **已知风险,写在前面**:训练用的是**物理短序列 + 伪位置偏移**,残差从未见过真实长序列。
**先例是正面的** —— `SELECTIVE_QK_PHASE_ADAPTATION` 用同样的相位路由把 8K exact 从 0 拉到 17.5%。**但那是在完整 Native 通道上做的,残差支路是全新初始化,不保证同样有效。这是 G2 失败的头号风险。**

### S2.3 评测(与已有基线严格对齐)

| 端点 | 行数 | 对照 |
|---|---|---|
| 4K bitwise smoke | — | 必须与安装前 Native logits 逐位相同 |
| 4K 2Wiki exact / F1 | 200 | Native 22.0% / 25.99% |
| 8K 2Wiki exact / F1 | 200 | Native 0% / 0.07%,**EVQ Q/K-only 17.5% / 21.48%** |
| 16K 2Wiki exact / F1 | 200 | Native 0% / 0%,**EVQ Q/K-only 4.0% / 8.57%** |
| 4K/8K/16K RULER 13 家族 | 20/家族 | Native 72.19 / 2.02 / 0.38 |

**必须同时对两个基线报告:未改动 Native,以及已有的 EVQ Q/K-only 臂。** 只赢 Native 不够 —— 已有的 EVQ Q/K-only 臂 8K 已经 17.5%,新方法若低于它则没有价值。

### S2.4 判定规则(事前锁定)

| 结果 | 结论 | 下一步 |
|---|---|---|
| 4K bitwise 通过 **且** 8K exact > 17.5% | **G2 成立** | 补 16K,补 RULER,考虑 8B 复现 |
| 4K bitwise 通过,8K ∈ (0, 17.5%] | **部分** | 只报告 8K,不宣称优于已有臂;检查是否慢端子集过窄 → 退回全谱残差**一次** |
| 4K bitwise 通过,8K ≈ 0 | **失败** | 残差在 100 步内学不到东西。停,不扫 rank/gain/step |
| 4K bitwise 失败 | **实现错误** | 修实现,不改方法 |

**允许的唯一一次回退:慢端子集 → 全谱残差。除此之外不扫参。**

## 4. 阶段 3 — protected 修正版(仅在 S0.2 + S1 都通过时)

用 S0.2 的**条件解频率表**替换原规格的索引级拼接表,其余照 `OLMO2_NATIVE_IMPORTANCE_PROTECTED_EVQ_HYPOTHESIS` §6 执行(144 步,rank 512,全层注意力恢复目标)。

**事前声明预期**:目标是把 RULER 4K macro 从 **42.44** 往上推。**不预期追平 72.19。** 定理不允许。

**匹配的 full-EVQ 对照(protected set 为空)必须在归因前跑完** —— 否则无法区分"保护"与"新的注意力恢复目标"的贡献。原规格已写明这一点,保留。

## 6. 我的判断

**有希望,但希望集中在 G2,而且 G2 的 4K 部分是白送的。**

- **G1(~95%)** 几乎必成,零成本,而且它把七个负结果从"我们没做成"变成"定理的七次确认"。**单看性价比这一条最高。**
- **G2(~45%)** 值得赌。4K 无损是构造保证;全部风险在"100 步、伪位置偏移、全新初始化的残差支路能否学到 8K"。先例(Q/K-only 相位路由 0→17.5%)是正面的但不同构。
- **G3(~8%)** 不建议作为目标。定理挡着。**当作"42.44 能推到多少"的测量,而不是"能否追平 72.19"的赌局。**

**建议顺序:S0.1 → S0.2 → S0.3 →(评测计时)→ S1 → S2。S3 视 S0.2/S1 结果再定。**
