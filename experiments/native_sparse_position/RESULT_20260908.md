## 3. What the constructions and controls mean

PostMetric4 uses deterministic farthest-first centers in actual post-RoPE key
space and nearest-center assignments; it stores four actual group means plus
log-counts. PreMetric4 changes only the grouping metric to actual pre-RoPE keys,
then stores the same type of post-RoPE group means. MatchedContiguous4 preserves
the PostMetric4 group counts while assigning contiguous offsets. R=4, B=64 and
budgets are frozen; no coefficients, layer splits or representatives are tuned.

The native-pair envelope preserves common RoPE rotations in exact arithmetic and
bounds maximum logits. It does not preserve which token jointly realizes extrema
across different pairs. On the same failed RoPEMean queries, its source-page
bound inflation averages 25.13 versus 25.30 for Quest; selected competitor inflation
averages 26.38 versus 26.80. Native-pair source selection is 69/1200 correlated
layer/query/head/source cells versus 55/1200 for Quest. These counts did **not**
translate into complete-answer recovery and are not independent task wins.

For exact per-pair maxima T and exact whole-token maximum M, U−M=(U−T)+(T−M).
The present real-query diagnostics measured U−M only; they do not identify the
relative size of pair-envelope error and cross-pair mismatch. A checked algebraic
counterexample has identical complete native-pair marginals but different joint
maximum logits. It limits that representation class, not all position-aware
summaries, and is not a new mathematical theorem by itself.

Common-position-shift invariance is not unique to the new envelope: applying
Quest in a common-origin canonical frame also provides it. Correct symmetry and
valid score bounds do not imply better sparse generation.

## 4. Novelty and evidence limits

Key clustering and centroid retrieval already appear in
[ClusterKV](https://arxiv.org/html/2412.03213v2). De-RoPE clustering and asymmetric
query assignment appear in [SAAP](https://arxiv.org/html/2502.08246v1).
[Multipole Attention](https://arxiv.org/html/2506.13059v2) covers time-blocked
clustering and count-weighted centroid contributions; [MuSe](https://arxiv.org/html/2509.10406v4)
covers semantic summaries within spatial blocks and exact retrieval. The present
fixed-page causal controls supply additional experimental evidence, but this
known clustering-family implementation is not an independently novel algorithm.

The tested cheap implementation does not have a confirmed position-specific
advantage or a demonstrated deployment speedup. RPEE does not restore the fixed
answer; the successful mixture overlaps existing work. These limitations prevent
a solid-accept/new-method claim. The existing budget-focused paper remains a
provisional, superseded research draft; it has not been relabeled as a completed
native sparse-position paper.
