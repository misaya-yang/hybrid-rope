## 3 · 实现时抓到并修掉的四个 bug（都由自检发现）

1. **`_prime_power` 没要求底数是素数** —— 36 被识别成 `6²`，于是 `64=2⁶` 与 `36=6²`
   的 gcd=4，"两两互素"这条 M06 赖以成立的性质**静默失效**。
2. **`np.lcm.reduce` 在 int64 上溢出** —— 16 个互素周期的 lcm 返回**负数**。
   改用 Python 大整数，并报位数与"是否超出可部署上下文"。
3. **`d04` 的广播错误** —— `nu_to_m(nu[T])` 把 16 个值除以 64 维的 ω。
   任何真实 C 都会让它崩。
4. **适配器的增益不变量检验写反** —— 拿"已旋转"的输出去比"未旋转"的输入。
   正确做法是同一算子跑 `g=1` 再比 `g×`。

另外：**§6.4 的规则在 `panel.partition` 里是断言而非注释**——同源跨阶段、跨 guard 与长长度、
跨任务，三种都会 `REFUSING` 并指名道姓。

1. **§0.4 修正 1 推翻了 E-B 的"最高理论价值"读法**：reach-only 的 1.13–1.20 峰值
