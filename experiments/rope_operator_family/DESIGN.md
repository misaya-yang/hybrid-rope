## 研究目标与完整证据链

**研究有限 KV 存储下，如何同时保留内容计算和相对位置算子，并在成熟模型上移动质量—缓存预算曲线。**

按所选方案完成四个相连的部分：

1. **机制**：控制内容重建误差，改变旋转近似，预测随距离增长的 attention distortion、margin 和 token loss。
2. **方法**：优化整个内容加权 RoPE operator family，学习不同的 A/B 内容投影与低维旋转；Galerkin 是其中一个对照。
3. **主实验**：在 TransMLA 中替换 FreqFold，在相同总 KV bytes/token 下比较完整模型能力。
4. **资源与推广**：联合分配内容 latent 和旋转维度，检验适配、任务广度、跨模型以及真实缓存与推理成本。

下面的参数是可开跑的设计起点，优化步数、样本量和模型规模随实际曲线与资源调整。实验范围保持上述完整目标；没有预设“必须先赢多少”或“必须训练多少 token”才可继续的门槛。

## 1. 机制实验：内容一样好，旋转是否一样可靠

### 1.1 模型与资产

按附件优先用已有 432M MLA 三种子权重做不训练模型的机制实验。本次在新机器的数据盘中没有找到这组完整权重；已找到 151M Geo/Cosh 的 seed 137/256 权重，以及成熟的 Qwen2.5-1.5B-Instruct。执行时先从项目原 checkpoint 位置恢复 432M；若该资产确实不可用，用已有权重开展同一机制实验，不重新预训练来补资产。Qwen 同时承担成熟模型验证。

模型资产的差异进入解释：151M/432M 适合复现原研究的内容—位置关系，成熟 Qwen 负责验证已有实际能力能否保留。它们不是可互换的能力基线。

### 1.2 两种干预分开做

**干预 A：精确固定内容映射，只改旋转。** 固定同一 A/B，分别采用 FreqFold representative frequency、projected generator 和自由拟合的 ν。因为 Δ=0 时旋转均为单位阵，三者的静态内容计算完全相同。这里改变的是旋转近似，V 固定时 leakage E 本身不变；这个实验不会被误称为“改变了 E”。

**干预 B：内容误差匹配，改变子空间 leakage。** 在相同 rank 下构造不同 V，包括同频选择、邻频混合、PCA 及跨频混合。在 calibration 上测实际 Δ=0 score/reconstruction loss，寻找内容损失相近但 leakage 不同的配对；必要时沿 Stiefel 空间优化，在相同内容损失水平附近分别降低/提高 leakage。配对在 calibration 完成，留出文档评测，不用测试误差挑对照。内容误差并非完全相等时，报告实际差异并将其作为解释变量。

两者组合可回答：相同内容计算下，旋转近似是否重要；以及内容偏好的子空间与旋转兼容性是否发生可观测冲突。

### 1.3 输入与预测

从真实文本捕获 pre-RoPE Q/K、V、位置和 teacher 分数。先固定内容，只改变因果相对距离 Δ；测试从近邻到模型有效长距离的整数位置，避免只取整齐的大步长造成频率 aliasing。另做真实连续长文前向，检验相位回放能否解释真实长上下文现象。

预测量分四类：

| 预测量 | 所代表的解释 |
|---|---|
| 静态内容重建/score loss | 只有内容损失就足以解释退化 |
| 原始频率差、frequency proximity | FreqFold 的近邻启发式 |
| `|δΔ|`、Galerkin leakage 的距离依赖 | 相近频率在远距离也可能失配 |
| calibration 内容统计加权的算子族残差 | 失配取决于距离与模型实际使用的内容方向 |

预测器使用 calibration 的内容统计和已知变换，在接触留出 attention/任务结果前给出误差曲线和候选排序。验证对象是留出文档的实际失真以及后续完整模型行为，避免把同一批 score loss 与自身相关当成预测成功。

观测 score MSE、teacher 重要 key 与竞争 key 的 margin、完整 softmax 的 KL/输出误差、单层替换后的下一 token loss，再验证全层压缩。按距离、层和头分解，误差区间按独立文档计算。可先选首、中、末等六层查看机制，完整模型阶段覆盖全部层。

**这项实验有用的结果**不是又验证一次 2×2 旋转恒等式，而是找到真实模型中“静态内容同样保留、频率也很近、却因距离失配而失败”的实例，并预测哪些压缩能够修复它。若在留出数据上没有额外预测力，记录是哪个预测量失效，以及实际内容匹配是否成立；这决定理论解释该如何修改。

## 2. 方法实验：拟合整个算子族

### 2.1 方法对象

主线保持为

\[
\mathcal L(A,B,H)=\mathbb E_{q,k,\Delta}
\left|q^*\left(R_\Delta-Ae^{i\Delta H}B^*\right)k\right|^2.
\]

A/B 可以不同。Hermitian H 可对角化，特征向量吸收进 A/B 后，以频率 ν 的 2×2 实旋转块实现。`A=B=V, H=V*DV` 是可分析的特例与初始化，不是方法的最终限制。

实际优化使用模型的**实数 scaled attention score**。q/k 可以相关，直接对真实配对累计 loss；两侧 covariance 的 Frobenius 形式在相应统计假设下才等价，可作近似加速并测其偏差。这样保留附件的内容加权目标，同时不把统计近似当成无条件恒等式。

### 2.2 TransMLA 中的完整计算

共同学生布局为

\[
\hat s_{hij}=\frac{q_{C,hi}^{\top}c_j+
q_{R,hi}^{\top}R_\nu(p_j-p_i)k_{R,j}}{\sqrt{128}},
\qquad \hat v_{hj}=U_{V,h}c_j.
\]

`c` 是内容/值共享 latent；`k_R` 是共享 rotary key；q 的映射按 Q head 区分。可以从原始 `q_h`、合并 KV heads 的 `k_all` 构造 `q_R=A_h^T q_h, k_R=B^T k_all`，再将 A/B 融入原 affine 权重。静态内容分支与值分支一起计入压缩，保持 TransMLA 的完整任务。

首个求解从 FreqFold 初始化开始，拟合 A/B/ν，便于观察位置表示改进；再联合更新内容 latent/静态分支，形成真正的内容—旋转联合压缩。前者提供可解释消融，后者用于完整方法。值重建与完整 attention 输出在联合阶段显式纳入目标，避免 rotary loss 下降却损坏 value。

### 2.3 实现与求解方案

- **拟合数据**：自然文本的真实 Q/K 行与因果位置；校准和留出按文档分开。
- **距离覆盖**：既测观测 Δ，也测同一内容的远距离回放。整行位置按比例伸展后计算 teacher/student，保留因果次序和完整 key 集合；真正长文本前向单独验证。
- **求解器**：从 FreqFold 的 A/B/ν 开始，用小矩阵 Adam 或交替最小化求解。先固定 ν 解投影，再更新 ν，可与全部联合更新比较。频率使用相位尺度参数化，依据 loss/梯度曲线选择稳定步长；不预先锁定 Galerkin 频率。
- **联合内容阶段**：交替更新内容/值低秩映射和 rotary 映射，记录各损失与完整输出。相同的联合参数空间也提供给直接蒸馏基线。
- **实现验证**：比较无压缩 adapter 与原模型，再比较同一压缩模型的展开和吸收式计算。检查实际影响结果的 bias、pair 布局、GQA 共享、位置缓存与 scale。Qwen 的原有效温度为 `1/sqrt(128)`，TransMLA 已有的权重补偿保持等效即可。

按拟合曲线报告计算量与收敛，参数更新和数据曝光成对匹配。用普通优化器拟合 A/B/ν 本身不自动构成新算法；最终贡献由机制预测、求解/结构改进和完整预算曲线共同体现。

### 2.4 方法消融

| 对比 | 所回答的问题 |
|---|---|
| FreqFold、同频选择、PCA/Galerkin | 原生选择、内容低秩、投影生成元分别缺什么 |
| 固定 ν 只拟合 A/B，固定 A/B 只拟合 ν，联合拟合 | 内容映射和旋转各贡献多少 |
| `A=B` 与不同 A/B | 两侧内容分布不对称是否值得建模 |
| 静态 Δ=0、真实 Δ、远距离回放 | 距离覆盖是否是必要因素 |
| 冻结共同内容分支、联合内容/旋转优化 | 完整联合压缩是否超出单独修复 RoPE |
| covariance 近似与 paired real-score loss | 统计近似能否在节省拟合成本的同时保持效果 |
| 直接 attention KL/完整输出蒸馏 | 收益是否只是普通联合拟合，也检验目标函数选择 |

这张表覆盖主线的实际组成，不要求每一项都单独跑全套大型 benchmark。机制用对应观测，完整方法与关键消融用模型能力比较。若两个实现的 forward、数据、目标和求解完全一样，记为同一组即可。

## 3. 主实验：在 TransMLA 中替换 FreqFold

### 3.1 模型与实际布局

主模型复用新机器已有的 **Qwen2.5-1.5B-Instruct**。模型成熟、权重齐全，能直接观察压缩对既有能力的影响。原生窗口 32768，28 层、12 Q heads、2 KV heads、head dimension 128、全维 RoPE、base 1e6、BF16。

原生每层每 token 的 K+V 为 `2×128×2=512` 实数。转换后保存共享内容 latent `c` 和旋转后的共享 `k_R`，总 payload 为 `B=r_C+2K`；K 表示复数 pair 数。

| 比较点 | B 实数 | 内容 r_C | rotary 实数 / pairs | BF16 bytes / 层 / token |
|---|---:|---:|---:|---:|
| 原生 GQA | 512 | — | — | 1024 |
| 主预算、更多 rotary | 256 | 128 | 128 / 64 | 512 |
| 主预算、平衡配置 | 256 | 192 | 64 / 32 | 512 |
| 主预算、更多内容 | 256 | 224 | 32 / 16 | 512 |
| 较宽总预算 | 384 | 320 | 64 / 32 | 768 |
| 较窄总预算 | 192 | 128 | 64 / 32 | 384 |

主预算在 16K、batch 1 下的理论 KV payload 是 **448 → 224 MiB**（全 28 层）。这给出了实际资源量级。显存和延迟另测，其中还包含分页、对齐、工作区等。

源码核对的转换参数为：`qk_mqa_dim=2K`，`collapse=128/(2K)`；以上三个 B=256 split 分别对应 collapse 1、2、4。平衡配置为 `qk_mqa_dim=64, kv_lora_rank=192, collapse=2`。FreqFold 的候选倍数需能被该 collapse 整除。

### 3.2 比较组

主表包含原模型、官方 FreqFold、层级选择的 FreqFold、完整 operator-family 方法，以及同架构直接 attention 蒸馏。层级 FreqFold 参考 YouZhi 的逐层选择；否则容易把统一折叠的不足误认为新方法优势。

进一步接入与模型兼容的 EliteKV 和 RAP，比较 frequency importance / joint KV compression 与实际 pair pruning 的竞争方案。分别报告无需语言模型适配的转换结果，以及共同短适配后的结果。不同方案的校准、搜索和恢复成本一起列出，结果不会只剩一个质量数字。

同一 split 下，两方法拥有同样的内容/rotary 空间和训练机会。对直接蒸馏，提供同样的位置覆盖和可学习频率；这能回答算子族设计是否带来独立价值，而不只是增加了参数或更丰富的校准数据。

### 3.3 全模型观测

- 自然长文 NLL/PPL，覆盖短、中、长输入；用同一文档末尾目标 token 比较不同可见前缀。
- 完整 autoregressive 生成：RULER、自然长文 QA、顺序/更新任务。
- 压缩后相对原模型丢失/恢复的能力，外加完整全样本指标。
- 不同总预算下的质量曲线；各个预算点记录真实缓存字节。

先完成机制实验和一个完整的主预算模型结果，再展开曲线与广度。这里的先后是把模型/数据产物复用起来，整个设计仍覆盖所有主实验。

## 4. 内容容量与旋转容量的联合分配

这是附件强调的第二个 hero：在固定 KV 存储下，旋转表示更紧凑后，省下的空间是否可以转为有用的内容容量？

执行方法 × split 的完整比较：

| 方法 | 内容128 + rotary128 | 内容192 + rotary64 | 内容224 + rotary32 |
|---|---|---|---|
| FreqFold / 最强匹配基线 | 测 | 测 | 测 |
| Operator-family | 测 | 测 | 测 |

同 split 的纵向差异衡量方法；同方法的横向差异衡量容量分配；差中差检验新方法是否让小 rotary 配置变得可用。随后在 B=192/256/384 上比较各方法的可达到曲线。实际 backend 如果对某些 shape 做 padding，则用物理字节标出点位或调整等预算配置。

这里既允许内容分支与旋转一起优化，也单独保留初始化/冻结内容消融。最终希望看到的不是某个 rank 指标增加，而是在更小预算获得同等能力，或在相同预算获得更好能力。

Qwen3.5-2B 不作为“半 rotary 就大幅省缓存”的默认 hero：它的 full-attention head=256、rotary=64 实数，物理删去一半 rotary 只减少该层 K+V payload 的约 6.25%；转成 NoPE 则不省存储。主实验的共享 latent 布局更直接对应附件提出的资源问题。

## 5. 适配实验：方法优势能否延续，恢复是否更快

对同一学生架构，比较 FreqFold/直接蒸馏和新方法的转换起点，开放相同 attention projection、内容/值映射和频率参数，使用同一自然语料、token 顺序和优化设置。观察质量随适配 tokens、FLOPs 和实际时间的曲线。

先测真实训练吞吐并运行一组配对学习曲线，再根据曲线选择覆盖恢复过程的训练量。已有模型/任务结果可以复用。需要回答稳定性时补独立优化种子；结果分别表示 checkpoint 的样本变化和训练运行间变化。

这项实验回答三种不同价值：转换即用的质量、达到同一质量所需的恢复成本、适配后的最终质量。若最后追平但恢复更快，方法仍可能有实际价值；若三者均无改善，就据此判断当前求解/表示的收益不足。

## 6. 能力与泛化实验

### 数据和起始规模

用一份 manifest 管理文本、文档/书 ID、tokenizer、顺序、任务答案和生成参数。校准/开发/评测按来源文档分开；相同文档的多个问题作为一组。公开语料是否曾进入基础模型预训练往往未知，如实记录来源即可。

| 用途 | 设计起点 | 解决什么问题 |
|---|---|---|
| 内容校准 | 约128篇自然文本的2K连续窗，已有 FineWeb 原始文本与 PG19 train 长书混合 | 获得真实内容统计和短上下文 Q/K |
| 自然长距离校准对照 | 独立长文的16K连续前向 | 远距离回放能否替代一部分真实长上下文校准 |
| 拟合开发 | 与训练来源隔离的文档/书 | 看求解曲线、选设置和 FreqFold 层配置 |
| 机制留出 | 约64篇短窗及32篇/本真实长文 | 评估未见内容和未用于拟合的距离 |
| 自然 NLL | 既有512篇长文中可用的独立子集；另补 PG19 长书 | 比较4K/8K/16K/接近32K的实际语言建模 |
| RULER | 官方13类，4K/16K/接近32K；每类先约100个独立实例 | 完整长上下文任务画像 |
| 自然 QA | LongBench Qasper、MultiFieldQA-en，各约200例或全部可用样本 | 从合成检索走向自然文档理解 |
| 顺序与更新 | 随机键值的重复写入、latest-write、先后关系、相同内容交换顺序 | 检验相对位置计算和干扰竞争，而不只找一个独特 needle |

这些数字用来安排资源和样本，不是实验停止条件。初始样本不足以分辨效果时，依据配对方差估算进一步需要的样本。完整能力表保留各类表现；局部强结果和失败案例一起解释。

自然 NLL 固定每篇/本的末尾约256个目标 token，按文档平均。16K/32K 使用真正连续的长文；既有8K文本不能靠复制变成真实长程语言建模。所有数据用对应模型 tokenizer；RULER 沿用官方 prompt、回答预算和 scorer。输入加生成预算保持在模型有效窗口内。

### 泛化维度

- **距离迁移**：短校准 → 长评测，与长校准对照；只要原模型本身会，才有可保留的能力。
- **内容迁移**：校准语料与自然 QA/顺序任务分开，检验内容加权是否过拟合校准域。
- **干扰迁移**：needle 数量、重复 key、冲突更新、query 数量、远近位置；检验平均 score loss 是否遗漏 softmax 尾部。
- **模型迁移**：机制复现覆盖原研究模型；成熟模型结论再用不同架构或更大成熟模型复现。先查权重缓存和可用设备，再选择具体第二模型，无需默认重新预训练。

## 7. 实际缓存与推理性能

TransMLA 的两个实现路径要区分：

- `transmla/transformers/mla.py` 会展开 K/V 再 cache update，适合质量参考，配置中的 latent rank 不等于该路径实际缓存字节。
- `transmla/vllm_registry/deepseek.py` 按 `kv_lora_rank + qk_rope_head_dim` 传递紧凑内容与 rotary key，具体 kernel 的 shape、padding 和频率表支持需实际运行验证。

共同 reference 可以只持久存储 `c,k_R`，计算 `q_C c^T + q_R k_R^T`，softmax 后先聚合 c 再做值上投影。这给出与展开模型等价的紧凑计算对象；优化 backend 在同一个对象上测系统性能。

系统表包括：

| 指标 | 如何比较 |
|---|---|
| 缓存居留 | 同长度/batch/dtype，unique backing storage 字节，包括持久副本、padding、分页和元数据 |
| prefill/ decode 峰值 | 分开测量，记录是否产生展开的中间张量 |
| latency/吞吐 | 相同输入与生成长度、共同 backend；预热后交替重复计时，报告分布 |
| 校准与转换成本 | 文本前向、投影求解、频率优化和搜索时间 |
| 恢复成本 | 达到指定质量所需的适配 tokens、FLOPs、壁钟时间 |
| 权重与工作区 | 额外变换/adapter、临时激活和峰值工作内存 |

用自然 EOS 评测质量，用固定输出工作量比较速度，避免早停回答更短制造吞吐差异。若 reference 质量成立但优化 kernel 尚缺，分别报告已有的质量/字节证据和待完成的速度实现。

## 8. 如何判断各实验是否有用

| 结果 | 科学含义与下一步 |
|---|---|
| 内容匹配后，算子残差能预测真实远距离失败 | 支持核心机制，检查预测能否指导方法选择与修复 |
| 原始 leakage bound 很松，但内容加权有限距离残差有效 | 改善解释对象；不必把一个松上界当成全部理论 |
| score 改善，softmax/生成不改善 | 检查高分竞争、value 和跨层累积；结果说明该目标的实际局限 |
| 固定 split 提升，容量重分配又进一步提升 | 方法与资源分配共同支持 hero |
| 仅横向 split 提升，纵向方法无提升 | 收益主要属于容量分配；具体方法优势尚未建立 |
| 普通蒸馏在相同数据/计算下追平 | 区分初始化、校准效率和最终能力，准确定位贡献 |
| 原模型在任务上也很差 | 该任务对能力保留缺少信息，补原模型有能力的情形并保留原结果 |
| 更强基线或跨模型后优势消失 | 找到适用范围，分析频谱、内容分布、rank 或训练造成的差异 |

所有关键比较报告配对效果和不确定性，任务 macro 与各任务结果同时给出。按文档/书或基础实例重采样，训练种子变化单列。不会在看到结果前规定一个通用“顶会成功分数”。

真正值得留下的图表是：**事前误差预测与实际失败/修复、同字节完整能力曲线、内容—旋转分配曲线、适配效率、系统成本。** 两频率示意图用来解释机制，矩阵恒等式用于核对实现；它们不是论文的主要实验证据。

## 9. 更新的 CC/MC-KV 文档：有用之处与对应实验

这份文档提出了一个具体的 **token 轴 KV compaction** 方法；用户选定的主线则是 **每个 token 内的内容/旋转通道压缩**。它补充了研究对象和实验判断，不替换本设计的算子族主线。

值得直接吸收的部分：

- 平均 logit 的线性恒等式，不能推出 softmax mass 或 value output 得到保留。
- key covariance 与 key–value crosscovariance 能描述局部响应，但真实检索可能依赖指数尾部。
- 带 bias 的 synthetic KV 要测完整上下文 softmax 与真实生成；GQA 共享、逻辑位置和实际存储都影响实现。
- 先完整 prefill 再压缩，减少的是后续缓存驻留，不能把此前 prefill 峰值也算成收益。

MC-KV 用共同 source-coordinate 分解生成 `2r` 个带正质量的 sigma slots，full-rank 情况下保留相应均值/covariance/crosscovariance，截断时保留它们在选定 key 子空间的投影。独立算术复核再现了文中的 rare needle：127 个 `(k,v)=(0,0)` 和一个 `(10,1)`，query=1，原始输出 **0.9942673**，两槽输出 **0.0700261**。它说明局部矩保证没有覆盖这个真实 softmax 行为；对实际数据是否有价值仍需实验。

如果将这个候选作为另一条研究线，其完整实验对象如下：

| 实验 | 对比与测量 | 用处 |
|---|---|---|
| 真实缓存 replay | 相同原始块与槽数，mean+bias、weighted merge、MC-KV；完整上下文的 mass/输出和尾部误差 | 看矩构造的近似在真实 query 分布中是否有用 |
| 完整生成 | 同一冻结模型、相同保留窗口/压缩率，测检索、顺序和自然 QA | 排除局部输出改善却不保留能力 |
| 最近强方法 | Attention Matching；可兼容的 MomentKV/其他直接竞争方法 | 区分零 query/训练的编译成本与实际质量，不只比较 mean |
| 编译与服务成本 | 同实际字节，测编译、bias 存储、prefill/decode、peak/steady memory | 判断构造的效率是否补偿质量差异 |
| 组合 | 在独立效果清楚后，与通道压缩做2×2组合 | 分离两轴收益、检验是否互补 |

MomentKV 已利用 key–value 矩补偿 evicted response，Attention Matching 已研究紧凑缓存的质量与输出匹配。因此本更新提供了可检验的新实现候选，尚不构成新颖性或性能已经成立的证据。给定路径下没有找到文中提到的原始 CPU 程序，本项目只声称独立复核了明确写出的反例。

### 实验产物如何串起来

```text
原始权重与文本
  → 真实 Q/K/V 捕获
  → 内容匹配与距离干预、留出机制预测
  → A/B/ν 与联合内容压缩求解
  → TransMLA 完整学生模型
  → 相同字节能力与容量分配曲线
  → 适配、任务/模型推广、系统性能
```

前面的捕获与初始化供后续方法/消融复用，原模型有效评测也复用。每个结果保留实际配置、模型/数据版本与 hash、运行环境、原始回答或每文档指标，以及耗时/显存。报告清楚是设计、实现、运行中、失败还是完成。

估算成本采用当前模型的实测单位成本：文档前向数 × 每种长度秒数；层数 × 拟合步耗时；prompt prefill + 实际 decode；适配 tokens / 持续吞吐。不沿用旧151M吞吐来估计1.5B，也不恢复已被用户撤回的18次从头训练队列。

捕获逐层/分块进行，完整 attention 行按需计算，避免保存 N² 矩阵。复用一份 base 权重，只保存变换/adapter 和必要的中间证据；当前磁盘条件下不复制多份3GB模型。
