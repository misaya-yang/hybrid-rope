# 方法定位：每项实验的用途、价值与失败结论

2026-09-09。依据当前已实现的 `operator.py`、`study.py`、`model.py`、`run.py` 和验证记录整理。当前只有小模型代码验证，尚无真实 1.5B 研究结果；本文描述如何解释结果，不预填成功或失败。

**本轮要决定：这个内容加权算子族压缩方法，是否值得继续。** 先完成本方法的一份配置；表现好，再选一个简单对照；表现不好，记录具体失效原因，转向下一候选。下面是对同一次方法运行的判读，不是一张必须逐项展开的多臂实验表。

“排除路线”指排除一个具体判断或实施方案，例如“固定内容投影、只调频率就能修复静态误差”，或“这次局部拟合足以直接替换整网”。停止投入当前候选，不需要先证明整个数学函数族不可能成功；文档也不把一次求解失败写成那种不可能性证明。

## 1. 现有入口分别产生什么价值

| 入口 | 实际作用 | 能带来的价值 | 失败主要说明什么 |
|---|---|---|---|
| `prepare` | 重编码自然文本，按来源分开校准/留出 | 得到可解释的同一份输入 | 数据长度、来源或 tokenizer 不适配；没有方法结论 |
| `capture` | 保存真实 pre-RoPE Q/K/V 和 token 顺序 | 后续拟合、回放和诊断共用真实内容，减少重复前向 | 捕获/模型接口或资源问题；没有压缩方法结论 |
| `fit` | 拟合一份 A/B、旋转与内容/value 表示 | 判断当前求解能否找到有用的紧凑计算 | 当前目标、求解或表示在这次设置下未奏效 |
| `diagnose` | 测静态/距离误差、几何量、margin 和完整 attention 输出 | 解释方法为什么有效或失效，判断是否迁移到留出内容 | 可定位纯频率、固定投影、代理目标或校准迁移的局限 |
| `evaluate` | 将全部层替换为当前学生，测真实文本 NLL | 检验局部近似组合成完整模型后是否仍可用 | 可能排除“逐层局部拟合后即可直接使用”的当前实现路线 |
| `generate` | 对一个指定 prompt 做真实逐 token 生成 | 观察实际依赖、回答与缓存解码是否被保留 | 排除当前候选在这个具体情形下的有效性；归因取决于原模型是否会做 |
| `profile` | 测当前配置的缓存 storage、prefill/decode 和峰值 | 确认压缩确实落到实现，并了解成本 | 区分紧凑缓存实现、后端效率与数学表示的问题 |
| `report` | 汇总已有证据 | 把观察、判断、失败记录留在一起 | 汇总错误；不会新增或否定方法证据 |

`prepare`、`capture`、`report` 是支撑步骤。13项小模型检查用于确认代码路径；它们通过，不是这个方法的研究成果。

## 2. 实验一：当前目标能否学到有用表示

**代码：** `study.py::fit_layer`；入口 `fit`。

这是当前方法本体：从 FreqFold/PCA 初始化，学习不同 A/B、频率和共同内容/value latent。它回答“有没有通过这种求解找到更合适的压缩计算”，不是先比较一排方法。

### 看什么

分别看 `relative_score_mse`、`relative_value_mse`、`relative_output_mse` 和实际学习曲线。默认训练目标是

\[
L=\mathrm{NMSE}_{score}+\mathrm{NMSE}_{value},
\]

完整输出项的训练权重默认0。因而总 loss 下降可能主要来自 value 重建；不能直接说算子族分数拟合改善。原始 MSE 一起看，避免归一化分母很小时误读 NMSE。

训练日志的首末步可能来自不同文档和位置尺度，而且记录的是各步更新前的 loss。它们适合看优化是否在工作；判断表示是否改善，应查看同一份记录上的诊断，不能把两条不同输入的日志相减当效果。

### 成功的价值

若实际分数误差得到修复、value 没有被破坏，并能迁移到未参与拟合的内容，就支持“可以从现有表示出发，通过内容加权的算子拟合找到有用的压缩”。这个信号值得进入完整模型行为判断。

### 失败排除什么

- **梯度无效、数值爆炸、损失未正常计算：** 说明这次实现/求解未完成，不能据此判定表示没有价值。
- **求解正常，但在当前内容、预算和目标下始终找不到有用表示：** 可以停止当前初始化与求解配方，转下一个候选；没有必要为了证明“理论上绝不可能”继续耗费资源。
- **总 loss 下降，score 反而变差：** 排除“总目标变小就证明位置计算更好”的解释；可能存在分数与 value 的权衡。
- **校准很好，留出很差：** 排除“这份校准上的改进已经具有内容泛化”的判断。此时重复扩大同一校准集上的拟合，不会自动解决泛化问题。

单次优化失败无法区分“函数族表达不够”和“当前求解没找到”。记录可以明确停止当前方案，同时保留这一科学边界。

## 3. 实验二：错误来自内容，还是相对位置计算

**代码：** `study.py::responses / diagnose / generator_diagnostics`；入口 `diagnose`。

同一份 A/B/内容表示下，检查 Δ=0 的静态误差、不同距离上的误差，以及生成元残差。这项实验的价值是定位失效机制，让下一步改变有依据。

### 静态误差与距离误差

Δ=0 时旋转为单位阵。如果静态误差已经很大，说明内容映射本身已经丢失计算；如果静态保留较好而远距离误差明显增大，才有针对旋转表示的直接线索。

自然距离分桶还会改变进入桶内的内容对，因此桶间差异本身不构成纯距离的因果证明。需要进一步归因时，可以在同一捕获记录上只改变 `position_scale` 复读一次；不需要重新训练多份模型。相位回放仍使用短文本中捕获的内容状态，真正长文本行为交给完整模型实验。

### 成功的价值

发现“相同内容计算在不同距离下出现可预测失配”，并看到当前方法在相关距离保留了完整响应，能使研究从频率表几何转向真实模型的相对位置计算。它也能告诉我们下一次应该改变频率、投影还是校准内容。

### 失败排除什么

| 观察 | 可排除的具体判断/路线 |
|---|---|
| 静态误差大，而 A/B 和内容分支固定 | **纯调频不能修复这部分 Δ=0 误差。** 因为任何频率在 Δ=0 都给单位旋转；这不需要额外训练来证明 |
| 静态较好，远距明显失配 | 当前压缩表示尚未保留这些距离的计算；不能用“原生频率很近”作为充分解释 |
| 短内容的远距回放很好，真实长文本失败 | 排除“相位回放成功已经证明真实长上下文可用”的推断；真实内容状态、跨层误差仍可能不同 |
| 原始 leakage 小，但内容加权失真或完整输出仍差 | 排除“只靠小 leakage 选表示就足够”的准则 |
| leakage 大，但完整响应和模型行为好 | 说明这个几何量/上界对当前内容不够紧，不能据此淘汰有效候选 |

### 当前代码能支持到哪里

`generator_diagnostics` 同时报告 `G B − B G_ν` 的残差和 B 列空间的 leakage。它们不同于真实的内容加权 score loss：B 的尺度、A 的使用方式和内容方向都会影响二者关系。几何量用于解释，不单独充当成功判据。

输出字段 `calibration_prediction` 实际是**在校准内容上重新计算当前算子的误差**；`held_out_observation` 是留出内容上的同类测量。这可以检查误差估计的迁移，却尚未自动实现“一个独立预测器事前优于 frequency proximity 等其他准则”的比较。当前单方法定位阶段不据此宣称那种预测优势。

## 4. 实验三：分数保留是否转化为真实 attention 输出

**代码：** `study.py::diagnose`；与实验二复用同一次诊断，不增加一轮模型训练。

这是 score 目标与真实计算之间的关键连接。观察 `attention_kl`、`relative_output_mse`、value 重建和 `teacher_top2_margin_mae`，看低均方误差是否遗漏了对回答重要的竞争。

### 成功的价值

如果留出内容上的完整 attention 输出也保留良好，就说明改进不只存在于一个易优化的标量目标上；方法确实保留了实际值聚合。这比 effective rank、几何 leakage 或平均 logit 更接近模型功能。

### 失败排除什么

- **score MSE 小，完整输出仍差：** 排除“当前平均分数目标已经足够保留响应”的路线。可能是少数关键 key 的竞争、softmax 非线性或 value 路径造成的失败。
- **score 和 attention 概率都接近，但输出仍差：** 直接提示 value 表示有问题。若内容/value 分支固定，则仅修改 A/B/频率不能改变它的 value 重建误差；attention 重分配可能局部补偿，但不是修复该重建本身。
- **训练分数/输出都好，留出输出差：** 主要证据指向内容或距离分布迁移，而非拟合是否能降低训练目标。

完整输出误差可分解为

\[
\hat o-o=(\hat p-p)V+\hat p(\hat V-V).
\]

当前 CLI 分别报告概率、value 和总输出误差，没有自动输出这个分解的两项及交叉项。因此相关指标提供定位线索，不能直接把误差百分比归因给某一分支；有必要时在现有张量上做一次针对性的分解即可。

### 两种不能误判的“坏指标”

**所有有效 key 的分数同时加一个常数，softmax 不变。** 因而 score MSE 或 `log_mass_mae` 较大、输出却保持很好，并不构成方法失败。这里测的是完整 attention 行；MC-KV 中块与块之间的 mass 竞争不是同一个对象。

**attention KL 大也不必然导致输出差。** 若被重新分配权重的 values 相似，功能可以保持。相反，当前 margin 指标只跟踪 teacher 的前两名；它没有覆盖学生把原第三名或更低名次提升到第一名的所有情况。最终仍看完整输出与实际行为。
